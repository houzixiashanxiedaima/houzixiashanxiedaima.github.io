2026-11-07 IDE / SDK 更新：Android OS、VSCode、Melos 等 4 项工具有新版本 | Android XR 平台支持从沉浸式家庭体验到便携即时体验，覆盖全场景空间应用开发 | 新增远程代理主机连接浏览功能，支持在 Agents 窗口中预览远程开发服务器

#ide-updates #ide #automation #Android OS #VSCode #Melos #Claude Code

Android OS From in-app agents to the Android intelligence system: What’s new in intelligent apps at the Android Developer Summit → Build for an expanding lineup of Android XR devices with production-ready tools from Android Developer Summit Qwen/Qwen3.8-27B

新内容

  • Android XR 平台支持从沉浸式家庭体验到便携即时体验，覆盖全场景空间应用开发
  • 在 Android Developer Summit 上发布 XREAL AURA，标志着 Android XR 设备阵容扩展的重要里程碑

VSCode 1.145.0 → 1.145.2 Qwen/Qwen3.8-27B

新内容

  • 新增远程代理主机连接浏览功能，支持在 Agents 窗口中预览远程开发服务器
  • 新增远程画布功能，支持在远程会话中使用画布
  • 支持在同一会话中混合使用多个 Agent 框架（嵌套会话）
  • 本地自动化支持 Cron 表达式调度及自定义 Agent
  • 实验性支持将画布固定到侧边栏以便快速访问
  • Copilot harness 成为新会话默认选项，基于 Copilot SDK 构建
  • 改进工作集功能，支持保留或撤销待处理的 Agent 编辑
  • 当组织强制要求沙箱但本机无法运行时，提供清晰的警告和解决指引
  • 实验性支持选择 Agent 详细程度，以平衡长对话的可读性与细节追踪
  • 优化聊天性能，更平滑地重新打开和浏览长对话，终端输出按需渲染
  • 实验性支持内联聊天附件，可从计算机任意位置添加文件作为上下文
  • 支持 MCP 应用提供的工具，允许语言模型调用这些工具
  • 企业托管的 MCP 允许列表优先于仅限注册表的访问权限
  • 在排除的文件夹中显示特定文件的功能
  • Mermaid 图表中的子图标题智能避让，避免被边缘覆盖
  • GitHub Pull Requests 扩展取得进展，支持处理、创建和管理拉取请求和问题
  • Timeline API 定稿，扩展可向时间线视图添加历史记录
  • 新增 Blobby 跳跃游戏（实验性），可通过 /vscode-pet 命令启动

Breaking Changes

  • Local harness 中移除了 Install Extension (#installExtension) Agent 工具…
  • Local harness 中移除了 Run VS Code Command (#runCommand) Agent 工具，依赖该工具的内置工作流已调整
  • Local harness 中移除了 Create New Workspace (#newWorkspace) Agent 工具和 /new 斜杠命令…

问题修复

  • 修复组织禁用 Claude 或 Codex Agent 后，用户新建聊天变为只读且无法输入的问题，现在会回退到默认 harness 并保留未发送的提示词
  • 修复组织设置 MCP 访问为仅限注册表时，策略刷新失败导致限制被移除的问题，现在会保持最后已知的注册表策略
  • 修复组织强制要求的插件在 Customizations 视图中显示 “卸载” 按钮但操作始终失败的问题

Melos 8.10.0 → 8.10.1 Qwen/Qwen3.8-27B

问题修复

  • 修复版本管理问题，确保在继续预发布时保留并递增构建号

Claude Code 2.1.318 → 2.1.319 Qwen/Qwen3.8-27B

新内容

  • 新增终端 MCP 任务支持：MCP 服务器将工具调用作为任务运行时，Claude Code 立即将其移至后台并在完成后通知结果
  • 新增 CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND 环境变量…
  • 新增 permissions.denyInsteadOfPrompting 设置：权限提示被拒绝时直接拒绝并继续当前轮次，适用于终端会话、子代理和队友
  • 新增 /claude-api latency-optimize 命令，用于定位 Claude API 代码中的延迟瓶颈并尝试更快的配置
  • 新增 CLAUDE_CODE_DISABLE_FEATURE_FLAGS 环境变量，停止获取功能标志但不关闭遥测，所有标志使用内置默认值
  • /usage 为无消费限额的开发者新增今日、本周和本月消费统计（需网关运行此版本或更高版本）
  • Claude apps gateway 新增 admin.pooled_conflict_rule 和 admin.pooled_priority_order…
  • Claude apps gateway 新增可选 login_notice 设置，在浏览器验证页和登录界面显示操作员自定义消息
  • Claude apps gateway 新增 CLAUDE_GATEWAY_LOG_FORMAT=json，操作日志以 JSON 格式输出严重级别…
  • /tasks 新增 “Earlier in this session” 行，列出已完成的子代理，可在其离开列表或重启后重新打开并发送消息
  • /loop 确认中新增说明：云会话中定时器随容器停止，并提供可存活的循环选项
  • 启动时新增警告：当 claude.ai 登录结束但 Claude Code 继续使用 ant auth login 登录时…
  • 启动时新增一行显示使用 ant auth login 登录时被计费的 Claude Console 组织名称
  • Claude apps gateway 新增启动警告：当另一策略的 availableModels 允许某自定义模型 ID 而当前策略按名称列出该模型时发出警告
  • Claude apps gateway 新增启动警告：针对依赖 coworkTabEnabled: false 或 chatSessionRetentionD…

Breaking Changes

  • auto mode 在遥测或功能标志关闭时（包括 LLM 网关后）的行为变更：服务器无法检查的调用将被询问或拒绝，不再回退到内置分类器…
  • LLM 网关后的 auto mode 行为变更：CLAUDE_CODE_AUTO_MODE_SERVER=1 即使在设置 CLAUDE_CODE_DISABL…

问题修复

  • 修复旧版握手 MCP 服务器因 Claude Code 声明了仅新版服务器使用的扩展而导致连接失败或返回空结果的问题
  • 修复 claude.ai 连接器上长时间运行的 MCP 工具调用在 —resume 后有时不报告结果的问题
  • 修复工作目录中存在名为 HEAD 的文件或文件夹时，claude.ai 和移动应用上会话 diff 无法加载的问题
  • 修复 git 仓库顶层存在名为 HEAD 的文件或文件夹时 /diff 显示 “Diff unavailable” 的问题
  • 修复 64 轮以上编辑文件的会话中 /diff 面板打开为空的问题
  • 修复前导空格、制表符或换行后输入的斜杠命令被当作纯文本发送给 Claude 而非执行的问题
  • 修复请求持续以 401 刷新登录并在每次重试时导致其他会话出现 401 错误的问题
  • 修复 /context 在后续每轮都将完整视觉网格发送给 Claude 的问题，现在 Claude 只读取表格
  • 修复 auto mode 下动作因无安全检查可用而被拒绝时 claude -p 退出码为 0 的问题，现在文本和 JSON 输出均退出 1
  • 修复 Linux 上网络文件系统（NFS、SMB、Lustre 等）项目启动时列出所有项目文件的问题
  • 修复客户端连续发送模型变更和 auto mode 请求时 auto mode 被错误拒绝的问题
  • 修复 LLM 网关丢弃服务端审查时 /status 仍显示 “Auto mode server: Enabled” 的问题
  • 修复服务器拒绝组织反馈后 Claude 起草的反馈、调查和 /feedback 仍持续出现的问题
  • 修复第三方网关上 Claude 起草无法发送的反馈的问题
  • 修复权限规则或 autoMode 设置非常大时 auto mode 拒绝动作却不说明原因的问题，现在会解释并在终端询问
  • 修复 Bash deny 和 ask 规则遗漏带引号单词的命令的问题
  • 修复子代理交还报告在非 verbose 模式下展开时显示内部标记和来源注释的问题
  • 修复 claude -p —resume 带提示词时 MCP 服务器缺失导致丢失延迟工具调用的问题，现在退出 1 并保留调用
  • 修复信息性消息发送到 SDK 客户端时文本被丢弃的问题
  • 修复磁盘满时 Agent SDK 主机收到通用退出码错误而非实际运行错误信息的问题
  • 修复 CLAUDE_CODE_RESUME_INTERRUPTED_TURN 在计划模式中断的轮次于其他权限模式恢复时会话恢复时重新运行的问题
  • 修复在 Claude Code 写入配置文件后几秒内对设置文件的编辑被忽略的问题
  • 修复遗留名称配置文件隐藏用户设置且无警告的问题，现在 stderr 会提示主目录下有两个配置文件及哪个在使用
  • 修复磁盘满时在只读文件夹或绑定挂载文件保存时～/.claude.json、设置和编辑文件变为空或被截断的问题
  • 修复 Write 无法读取要覆盖的文件时将轮次结束为拒绝的问题
  • 修复几乎立即完成的后台 Bash 命令在报告完成时丢失输出的问题
  • 修复 Bash 工具变更文件 diff 缺少命令结束前刚写入的文件的问题
  • 修复拼错模型名（如 opus-5-5）时提示更新 Claude Code 而非建议正确模型的问题
  • 修复权限提示打开期间 notebook 变化时 NotebookEdit 修改错误单元格的问题
  • 修复 /login 成功屏幕按 Enter 后约 0.5 秒卡顿的问题，对话框现在立即消失，登录后刷新在后台运行
  • 修复屏幕阅读器模式下输入 “Other” 答案时 Ctrl+G 无法打开外部编辑器的问题

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
