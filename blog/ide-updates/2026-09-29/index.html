IDE / SDK 更新 - 2026-09-29

IDE 更新 • 2026年9月29日 • 5 分钟阅读

2026-09-29 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 新增 Claude Sonnet 5.5 (claude-sonnet-5-5) 作为 Anthropic API 默认 Sonnet 模型，支持 1M 上下文

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.283 → 2.1.284 Qwen/Qwen3.8-27B

新内容

  • 新增 Claude Sonnet 5.5 (claude-sonnet-5-5) 作为 Anthropic API 默认 Sonnet 模型，支持 1M 上下文
  • 自动模式读取工作目录外文件时新增 “是，但下次再询问” 选项，允许单次读取并保留后续提示
  • Claude 应用网关在 /usage 和状态栏中显示美元金额的消费限额（如 “$271.40 / $500.00”）
  • 新增 effortSlider:decreaseEffort、increaseEffort 和 toggleUltracode 键绑定操作…
  • 为 claude.ai 订阅者新增 /rate-limit-options 命令，便于查找使用限制相关设置
  • 交互式终端新增 /mcp reconnect all 命令，一次性重试所有连接失败或需认证的 MCP 服务器
  • Claude 应用网关启动时若 managed policy 的 availableModels 为空或缺少默认模型则发出警告
  • Claude 应用网关遥测转发目标新增 auth: {google: {} }，支持直接导出至 Google Cloud OTLP 端点
  • Claude 应用网关与身份提供商之间新增证书客户端认证 (private_key_jwt) 支持

问题修复

  • 修复损坏响应流显示原始错误（如 JSON Parse error）而非重试或报告中断的问题
  • 修复思考块结束后立即出现过载或服务端错误导致回合以错误结束而非重试的问题
  • 修复压缩后仍提示 “Prompt is too long” 的问题，现在会再次压缩并保留更少近期对话
  • 修复模型不可用且无回退模型时仅显示裸消息而非完整通知及 Learn more 链接的问题
  • 修复 Agent SDK 会话因用户消息中包含格式错误的图像源而崩溃的问题
  • 修复恢复会话中 MCP 工具调用因服务器仍在连接而报 “No such tool available” 的问题
  • 修复 plan-usage 端点限流或拒绝登录后重复调用的问题，/usage 等视图现在会退避
  • 修复 claude mcp add 在受管设置限制 MCP 服务器时误报成功的问题
  • 修复 /plugin configure 界面布尔选项非真 / 假选择、数字选项不拒绝无效输入等问题
  • 修复 ANTHROPIC_FOUNDRY_RESOURCE 未经验证即插入 Foundry 端点主机的问题
  • 修复 Claude Desktop 经网关使用时不提供 1M 上下文选项的问题
  • 修复 shell 模式下 ↓ 键选中隐藏后台任务胶囊导致无法编辑提示词的问题
  • 修复 Windows 上启用多个插件时 Bash 工具因不存在 bin/ 目录被加入 PATH 而失败的问题
  • 修复旧版 git 下 sparsePaths 插件市场克隆为空并替换本地副本的问题
  • 修复全屏渲染在 transcript 模式下擦除终端上方输出的问题
  • 修复滚动位置在回复流式传输完成时跳转的问题
  • 修复窄终端下对话框标签栏截断标题和标签文字的问题
  • 修复 /model 选择器滚动到底部后显示 “+1 model” 计数错误的问题
  • 修复 /keybindings 为无操作的页脚动作写入 Backspace 和 Delete 绑定的问题
  • 修复重绑定的 agent 面板关闭键在查看行输入 “x” 而非自身的问题
  • 修复 vim 模式下。键无法重复极快输入或未括号粘贴文本的问题
  • 修复 vim 模式下 dd 或 yy 后光标停留在图像占位符开头括号的问题
  • 修复终端重新获得焦点瞬间按键提前回答远程控制启用提示的问题
  • 修复在工作目录启动时切换渲染器或更新后工作区信任对话框第二次出现的问题
  • 修复从项目外部符号链接到 .claude/rules 的规则跳过外部导入审批提示的问题
  • 修复来自市场、claude.ai 和 npm 的插件在受管 allowManagedPermissionRulesOnly 下预批准自身工具的问题
  • 修复首次 claude plugin install 失败时插件仍被启用和记录的问题
  • 修复调试日志丢弃同时写入 stdout 的失败 hook stderr 的问题
  • 修复 Elicitation 和 ElicitationResult hooks 返回 {
  • decision
  • block
  • } 被忽略的问题
  • 修复未启用 SendMessage 工具的会话仍被告知使用该工具向其他会话发消息的问题
  • 修复通过远程控制从 Claude 应用发送的照片在队列消息拉回终端编辑时丢失的问题
  • 修复自动使用限制等待期间输入消息使等待脱离 “Continue automatically at usage limit” 设置控制的问题
  • 修复已处于最高 Max 计划的用户收到建议 /upgrade 的使用限制警告问题
  • 修复 Explore 子代理在会话运行 Claude Code 不识别的模型 ID 时切换到 Opus 的问题
  • 修复自定步长模式下 /loop 状态更新常因仅在推理中写出而未显示的问题
  • 修复从 macOS 或 Linux 上 Claude desktop app 创建的 git worktree 启动 /ultrareview 时无法上传工作…
  • 修复 Linux 上工作目录写权限被拒且包含读权限被拒目录时沙箱 Bash 命令无法启动的问题
  • 修复 artifact 数据库写入结果错误告知 Claude 所有查看者都能看到私有数据写入的问题
  • 修复 Claude 应用网关对列出许多组的身份提供商登录请求返回 431 错误的问题

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
