### [VSCode 1.144.1 → 1.145.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_145.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增远程代理主机连接浏览（预览），支持在 Agents 窗口中通过远程主机加载页面并预览开发服务器
- 新增远程画布（预览），支持在远程会话中使用画布功能
- 新增在同一会话中混合使用多个 Agent 框架（预览），支持嵌套会话以保持相关对话集中
- 本地自动化支持 Cron 定时任务和自定义 Agent，可自动调度运行任务
- 新增将画布固定到侧边栏（实验性功能），方便快速访问常用画布
- Copilot 框架成为新会话默认选项，基于 Copilot SDK 构建以统一行为和能力
- 工作集改进（实验性功能），支持保留或撤销待处理的 Agent 编辑
- 当组织要求沙箱但机器无法运行时，提供改进的警告横幅说明终端命令被阻止的原因及解决方法
- 新增选择 Agent 详细程度（实验性功能），可在简洁模式和详细推理模式间切换
- 聊天性能优化，更流畅地重新打开和浏览长对话，终端输出按需渲染而非一次性加载
- 新增内联聊天附件（实验性功能），保持文件引用与所属指令相邻
- 支持从计算机任意位置附加文件到聊天，无需拖拽或让 Agent 查找
- 支持 MCP 应用提供的工具，MCP 服务器注册的交互界面现在可以注册语言模型可调用的工具
- 企业托管 MCP 允许列表优先于仅注册表访问，组织可批准未发布到注册表的服务器
- 在排除文件夹中显示特定文件，提升文件可见性
- Mermaid 图表智能子图标题，边不再覆盖子图标题，标题会自动移至侧面
- GitHub Pull Requests 扩展持续进展，支持处理、创建和管理拉取请求和问题
- Timeline API 定稿，Marketplace 扩展可为文件和文件夹添加时间线视图历史
- 新增 Blobby 跳跃游戏（实验性功能），输入 /vscode-pet 即可游玩

**Breaking Changes**
- Local 框架中移除了 Install Extension (#installExtension) Agent 工具…
- Local 框架中移除了 Run VS Code Command (#runCommand) Agent 工具，依赖此工具的内置工作流现已无需该工具即可运行
- Local 框架中移除了 Create New Workspace (#newWorkspace, 原 #new) Agent 工具和 /new 斜杠命令…

**问题修复**
- 修复组织禁用 Claude 或 Codex Agent 后用户获得只读聊天且无法输入的问题，新聊天现在回退到默认框架并保留未发送的提示词
- 修复组织设置 MCP 为仅注册表访问时，策略刷新失败会临时移除限制的问题，VS Code 现在保留最后已知的注册表策略
- 修复组织要求的插件在 Customizations 视图中显示卸载按钮但操作总是失败的问题


### [Claude Code 2.1.317 → 2.1.318](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增会话中启用 Mod 时的回答记录功能
- Claude Apps Gateway 上游支持 assume_role，用于跨 AWS 账户角色及按开发者进行 AWS 成本归属
- Mod 的 $.model.fork 新增 effort 选项，允许快速副任务以低强度运行并报告实际发送的 effort

- claude -p 文本输出在存储的 claude.ai 登录到期前 10 天开始显示单行 stderr 警告
- 改进共享网络主目录上 ~/.claude.json、设置文件和存储登录的保存可靠性，减少被删除、清空或被旧副本替换的情况
- 改进网络文件系统上的会话：配置文件被错误报告为缺失时会重新检查，减少启动时丢失 MCP 服务器和受信任文件夹的问题

- 改进远程会话在暂停或休眠后的重连速度
- 改进自动更新可靠性：验证发布版本时的短暂网络故障会立即重试而非等待下次检查
- 无头运行（claude -p、SDK 应用）在配置未变更时不再每次重写 ~/.claude.json
- Gateway：当联邦凭证文件中的 Google access token 即将过期时新增日志警告
