IDE / SDK 更新 - 2026-11-05

IDE 更新 • 2026年11月5日 • 10 分钟阅读

2026-11-05 IDE / SDK 更新：Android OS、VSCode、Claude Code 等 3 项工具有新版本 | Android 生态系统支持多设备现实，涵盖手机、折叠屏、平板、可穿戴设备、车载显示屏、XR 和 Googlebook

#ide-updates #ide #automation #Android OS #VSCode #Claude Code

Android OS Developing for Today: 50+ New Developer Sessions on Building Apps Today → Build for every screen with the latest Jetpack Compose updates from Android Developer Summit Qwen/Qwen3.8-27B

新内容

  • Android 生态系统支持多设备现实，涵盖手机、折叠屏、平板、可穿戴设备、车载显示屏、XR 和 Googlebook
  • 自适应开发成为基础，以触达各处的用户

VSCode 1.144.1 → 1.145.0 Qwen/Qwen3.8-27B

新内容

  • 新增远程代理主机连接浏览（预览），支持在 Agents 窗口中通过远程主机加载页面并预览开发服务器
  • 新增远程画布（预览），支持在远程会话中使用画布功能
  • 新增在同一会话中混合使用多个 Agent 框架（预览），支持嵌套会话以保持相关对话集中
  • 本地自动化支持 Cron 定时任务和自定义 Agent，可自动调度运行任务
  • 新增将画布固定到侧边栏（实验性功能），方便快速访问常用画布
  • Copilot 框架成为新会话默认选项，基于 Copilot SDK 构建以统一行为和能力
  • 工作集改进（实验性功能），支持保留或撤销待处理的 Agent 编辑
  • 当组织要求沙箱但机器无法运行时，提供改进的警告横幅说明终端命令被阻止的原因及解决方法
  • 新增选择 Agent 详细程度（实验性功能），可在简洁模式和详细推理模式间切换
  • 聊天性能优化，更流畅地重新打开和浏览长对话，终端输出按需渲染而非一次性加载
  • 新增内联聊天附件（实验性功能），保持文件引用与所属指令相邻
  • 支持从计算机任意位置附加文件到聊天，无需拖拽或让 Agent 查找
  • 支持 MCP 应用提供的工具，MCP 服务器注册的交互界面现在可以注册语言模型可调用的工具
  • 企业托管 MCP 允许列表优先于仅注册表访问，组织可批准未发布到注册表的服务器
  • 在排除文件夹中显示特定文件，提升文件可见性
  • Mermaid 图表智能子图标题，边不再覆盖子图标题，标题会自动移至侧面
  • GitHub Pull Requests 扩展持续进展，支持处理、创建和管理拉取请求和问题
  • Timeline API 定稿，Marketplace 扩展可为文件和文件夹添加时间线视图历史
  • 新增 Blobby 跳跃游戏（实验性功能），输入 /vscode-pet 即可游玩

Breaking Changes

  • Local 框架中移除了 Install Extension (#installExtension) Agent 工具…
  • Local 框架中移除了 Run VS Code Command (#runCommand) Agent 工具，依赖此工具的内置工作流现已无需该工具即可运行
  • Local 框架中移除了 Create New Workspace (#newWorkspace, 原 #new) Agent 工具和 /new 斜杠命令…

问题修复

  • 修复组织禁用 Claude 或 Codex Agent 后用户获得只读聊天且无法输入的问题，新聊天现在回退到默认框架并保留未发送的提示词
  • 修复组织设置 MCP 为仅注册表访问时，策略刷新失败会临时移除限制的问题，VS Code 现在保留最后已知的注册表策略
  • 修复组织要求的插件在 Customizations 视图中显示卸载按钮但操作总是失败的问题

Claude Code 2.1.317 → 2.1.318 Qwen/Qwen3.8-27B

新内容

  • 新增会话中启用 Mod 时的回答记录功能
  • Claude Apps Gateway 上游支持 assume_role，用于跨 AWS 账户角色及按开发者进行 AWS 成本归属
  • Mod 的 $.model.fork 新增 effort 选项，允许快速副任务以低强度运行并报告实际发送的 effort
  • claude auth status 和 claude -p JSON 结果中新增登录过期时间字段（loginExpiresAt /credential_e…
  • claude -p 文本输出在存储的 claude.ai 登录到期前 10 天开始显示单行 stderr 警告
  • 改进共享网络主目录上～/.claude.json、设置文件和存储登录的保存可靠性，减少被删除、清空或被旧副本替换的情况
  • 改进网络文件系统上的会话：配置文件被错误报告为缺失时会重新检查，减少启动时丢失 MCP 服务器和受信任文件夹的问题
  • 改进 MCP 工具错误处理：工具加载前调用现在返回其输入 schema
  • 改进 Bash 工具在 macOS 内置 /bin/bash 下执行 git commit 和 PR 创建的可靠性
  • 用量限制菜单中的 “向管理员申请更多用量” 现可一步完成请求
  • 改进远程会话在暂停或休眠后的重连速度
  • 改进自动更新可靠性：验证发布版本时的短暂网络故障会立即重试而非等待下次检查
  • 无头运行（claude -p、SDK 应用）在配置未变更时不再每次重写～/.claude.json
  • Gateway：当联邦凭证文件中的 Google access token 即将过期时新增日志警告

Breaking Changes

  • Claude Code 在 IDE 终端中启动时不再安装或更新 IDE 扩展；需从外部终端使用 /ide 或通过编辑器扩展视图操作
  • 设置 “Switch models when a message is flagged” 为 “Ask each time” 时，子代理现在停止而非切换模型
  • 所有提供商上后台子代理在 3 分钟后将 shell 命令移至后台，以防止 prompt cache 过期
  • Bedrock、Vertex、Foundry 或遥测关闭时子代理进度摘要：冷 prompt cache 下可等待最多 5 分钟获取子代理待处理响应
  • Mod 在 prompt.submit 时附加的内容保持在用户回合中，不再作为系统消息发出
  • deniedMcpServers URL 条目现在也阻止上游 URL 匹配的 Anthropic 提供服务器及云会话和自托管 runner 上的连接器…
  • /permissions 规则详情、内置规则和删除确认视图改用标准对话框；在这些视图中按两次 Ctrl+C 现在返回或取消而非退出
  • /claude-api managed-agents-onboard 现在为新代理的内置工具和快速入门模板的 MCP 工具默认赋予自动权限策略（“Judge …
  • 移除 2.1.288 中在恢复 2.1.286 或更早开始的对话时保留模型先前思考的修复；该思考现在可能被丢弃

问题修复

  • 修复 —continue 在格式错误的工具调用重试耗尽后有时丢失先前对话的问题（2.1.314 引入的回归）
  • 修复 macOS 上大量 Bash 命令运行时内存增长导致会话停滞的问题
  • 修复权限提示被刚发送消息后或慢速提示出现前输入的按键误答的问题
  • 修复共享网络主目录上配置文件无法更新时 /logout、claude auth logout…
  • 修复同一主目录上另一终端或主机重新登录同账户和组织时作业退出并报 Not logged in 的问题
  • 修复 claude mcp add/remove 未持有锁即写入配置的问题；现在会等待锁或退出码 1
  • 修复 claude plugin 命令在慢速 token 刷新保存前退出可能导致下次运行登出的问题
  • 修复 claude plugin validate 通过自定义名称 marketplace 文件但 claude plugin marketplace add…
  • 修复 stdio MCP 服务器在版本探测时退出后被反复探测的问题；自身原因在 3 秒内退出的服务器固定使用旧握手协议 7 天
  • 修复 allowedProviders 列表因同机其他登录存储而拒绝会话启动的问题
  • 修复空闲压缩用非摘要回复替换对话的问题
  • 修复后台子代理运行时 “Now using usage credits” 通知每约 30 秒重复出现的问题
  • 修复失败的或仅 Claude 可调用的自定义斜杠命令在 claude -p 和 SDK 会话中不输出的问题
  • 修复 API 错误中断回复且 mod 钩住 turn.step 时 claude -p 和 Agent SDK 会话误报成功的问题
  • 修复模型变更后立即发送的消息在无头会话中 Stop 后仍继续运行的问题；Stop 现在会取消或停止该消息
  • 修复已删除会话转录本在空闲非交互会话退出时被最后一条提示重建的问题
  • 修复更新或版本清理移除仍在运行进程的 binary 后 claude remote-control 主机…
  • 修复版本清理将其他用户拥有的运行中 Claude Code 进程（如 sudo claude 遗留）视为已死并可能删除其 binary 的问题
  • 修复 /remote-control 在连接失败后仍将会话显示为可用的问题
  • 修复 /design revoke 在请求 404 失败时误报成功的问题
  • 修复自托管 runner 或云会话重启后批准的 shell 命令在会话启动目录而非请求目录运行的问题；若该目录不可进入则不执行
  • 修复云会话重启后已批准连接器工具不可用时未告知 Claude 的问题
  • 修复服务拒绝上传数分钟时云会话在回合中途被停止的问题
  • 修复 Setup hook 写入 CLAUDE_ENV_FILE 的变量在某些云会话中未到达 Bash 工具的问题
  • 修复 iPhone 应用在响应被工具调用截断或拒绝的图像 / 文档被移除后将云会话回合显示为已完成的问题
  • 修复重启会话重发因 API 错误失败的消息且排在较新消息之前的问题
  • 修复重启紧跟在 Claude 读取大图像或重试工具调用之后时丢弃被打断回合的问题
  • 修复 NODE_EXTRA_CA_CERTS 文件为空、非 PEM 或以损坏证书开头时所有连接失败的问题；现在使用可读证书并在 stderr 发出警告
  • 修复工作流在用量限制后恢复时重跑已完成代理的问题
  • 修复云会话中 /mcp 统计模型无法使用的工具数量；服务器行现在显示可用工具数
