## 2026-09-09 IDE / SDK 更新

**统计信息**

- 生成时间: 2026-09-09 05:55:58 (北京时间)


### [VSCode 1.136.1 → 1.136.2](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_136.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Agent Merge（预览版），可自动处理 PR 审查反馈、失败检查和合并冲突直至可合并
- 多根工作区支持（实验性）：可在多根工作区的所有文件夹中跨 Copilot 和 Claude agent 会话工作
- 重新设计的新会话输入框，将提示词、模型选择和工作区选择等控件整合在单一布局中
- 改进工作区解析：Agent 可通过项目名称解析工作区，并保留多根工作区的 URI 和工作目录
- Agents 窗口中可导航相关聊天和会话，以层级结构展示父子关系并支持直接管理
- 会话文件的面包屑导航现在使用稳定的提供者和会话标签，不再显示内部标识符
- Agents 窗口中的聊天背景（实验性）功能
- Agent 会话通知：当 agent 需要输入或完成工作时可发送通知，默认仅在窗口未聚焦时显示
- Agent host：允许从多个 VS Code 窗口连接到同一 agent 会话，基于 Agent Host Protocol (AHP) 运行
- 企业策略控制听写数据：管理员可强制本地转录并禁用语言模型清理，防止听写数据发送至云端
- Agents 窗口标题栏新增屏幕阅读器优化模式徽章，便于识别当前辅助功能状态
- 编辑器窗口布局密度（实验性）：新增紧凑布局密度选项以显示更多内容
- 拼写检查建议：在可编辑字段中右键点击拼写错误单词可选择建议的更正
- 减少命令执行延迟：扩展执行的终端命令在 shell 集成就绪时不再产生不必要的延迟

**安全修复**
- 修复安全漏洞（1.136.2 更新地址了安全问题）

**问题修复**
- 改进换行处理：注入文本不再将换行行推出编辑器视口；换行考虑颜色装饰器、内联提示间距等的视觉宽度
