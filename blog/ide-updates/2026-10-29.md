### [VSCode 1.143.1 → 1.144.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_144.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增会话连续性，支持在计算机离线时保持会话和自动化运行
- 新增远程环境管理对话框，集中管理 GitHub 环境、Dev Tunnels、WSL 和 SSH 主机
- 新增云端自动化（预览），支持基于 Issue 或 PR 事件触发 Copilot 任务
- 发布 Agent Host Protocol v1.0，开放协议以构建自定义代理 UI 和平台
- 新增 Copilot Fusion，智能路由和编排多个模型以平衡性能与成本
- 新增模型对比功能，支持并排比较不同模型的响应结果
- 新增 Copilot 图像生成功能（预览）
- 新增计算机使用功能（预览），允许代理操作桌面应用程序
- 增强 Canvases 功能，支持在 Agent Customizations 编辑器中管理和从上下文菜单打开画布
- 辅助权限正式可用，减少频繁低风险工具调用的审批负担
- 新增会话创建器控件（实验性），优化新会话的环境选择和配置体验
- Copilot harness 成为默认选项，支持工作集审查文件编辑和使用 Copilot Memory
- 新增 worktree 存储管理（实验性）
- 支持在 Agents 窗口中直接启用和管理扩展
- 新增 Copilot 连接器（预览），通过 MCP 服务器连接 Slack、Notion 等服务
- 新增市场定制发现（预览），浏览和添加技能、工具和完整工作流
- 增强 GitHub Copilot 自定义代理编辑体验，提供补全、悬停提示和验证
