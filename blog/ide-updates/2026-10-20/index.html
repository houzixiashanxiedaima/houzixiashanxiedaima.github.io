IDE / SDK 更新 - 2026-10-20

IDE 更新 • 2026年10月20日 • 6 分钟阅读

2026-10-20 IDE / SDK 更新：Android OS、Claude Code 等 2 项工具有新版本 | 通过 R8 和 Profile guided optimization 技术，将 ANR（应用无响应）减少 32%，并提升启动时间 35% | 新增插件跳过模组钩子时的转录行，显示事件与插件名称

#ide-updates #ide #automation #Android OS #Claude Code

Android OS Bringing our latest frontier model to Android Developers → Grab Reduces ANRs by 32% and improves startup time by 35% with R8 and Profile guided optimization Qwen/Qwen3.8-27B

新内容

  • 通过 R8 和 Profile guided optimization 技术，将 ANR（应用无响应）减少 32%，并提升启动时间 35%

Claude Code 2.1.302 → 2.1.304 Qwen/Qwen3.8-27B

新内容

  • 新增插件跳过模组钩子时的转录行，显示事件与插件名称
  • 新增 decider: “person” 选项，限制权限审批仅由对话框或宿主回调处理
  • 新增 e.isReadOnly 属性，标识工具调用是否为只读
  • 新增 /auto-mode-setup 引导式设置，支持 Bedrock、Vertex 等环境
  • 新增 /claude-api managed-agents-secure 命令，对比安全指南而不修改配置
  • 在转录视图的压缩摘要中显示之前调用的工具名称
  • Pro/Max 计划恢复非活跃对话时新增用量警告提示
  • 改进 /usage 显示速率限制结束时间而非模糊提示
  • 改进多视图工件链接生成，解释地址栏切换行为
  • 优化云会话首回合启动速度，不再等待本地 MCP 服务器（除非 alwaysLoad）
  • 优化自动模式会话文件大小，不再存储安全分类器上下文
  • 优化长对话或恢复会话的请求内存使用
  • 提升多个子代理并发运行时的响应速度与吞吐量
  • 自托管 Runner：改进 git 仓库未找到时的错误提示，明确仓库名与联系人
  • Windows：优化 Git for Windows 启动方式，直接调用 git.exe 提升性能

Breaking Changes

  • 变更模组 settings.read 钩子接收每个设置层并重写合并设置，允许组织设置成为上限
  • 变更 /artifacts 删除确认显示编号选项：1 或 Enter 保留，2 删除
  • 变更会话中启用模组的提示为纯文本，无链接或会话 ID
  • 变更自定义 ANTHROPIC_BASE_URL 后工具搜索默认开启，400/422 错误自动重试
  • 变更压缩后再次向 Claude 发送技能列表；/reload-skills 仅发送新或变更的技能
  • 变更技能钩子限制：每个来源每会话最多 1,024 个钩子和 16,384 个匹配器字符
  • 变更仅允许插件钩子的策略下，主对话中技能若钩子被排除则不再获得 allowed-tools
  • 更新 /claude-api 技能在 AWS Claude Platform 上使用 ant CLI 而非回退到 SDK 或 curl
  • 移除 claude plugin validate 中预测模组钩子运行位置的注释
  • 移除 Opus 5.5 上 /fast 对话框标题中的 “(research preview)” 标签

问题修复

  • 修复组织策略在批准 API 密钥或切换自定义密钥后不刷新的问题
  • 修复 Linux 上沙箱命令因 glob 包含非字符类括号而启动失败的问题
  • 修复 rm -r 挂载驱动器或顶层文件夹时缺少安全提示的问题
  • 修复磁盘满时 CLAUDE_CODE_TRANSCRIPT_LOCAL_GC 从转录中删除消息的问题
  • 修复插件通过生成子代理绕过 —max-turns 或 Stop 限制的问题
  • 修复模组重载失败时移除已加载版本工具及命令的问题
  • 修复相同标签按钮重绘时点击丢失的问题
  • 修复内置插件创作技能中模组共享在受管设置下停止于秘密扫描的问题
  • 修复 Cowork 云会话中 WebFetch URL 审批导致子代理等待 5 分钟的问题
  • 修复 Write 结果和拒绝编辑显示工作目录外文件路径为 ../../… 的问题
  • 修复 claude.ai Directory 插件技能在 Cowork 云会话中无法作为命令运行的问题
  • 修复 Remote Control 在不同账户登录终端时永久保留桌面对话历史的问题
  • 修复付费计划设置 DISABLE_TELEMETRY 时 Remote Control 无法从 Claude Desktop 启动的问题
  • 修复 SDK 和桌面会话中模型切换、消息和中断被上下文检查阻塞的问题
  • 修复 LLM 网关后 context_management 字段导致的错误，现自动重试不带该字段
  • 修复首次运行或登出后 OpenTelemetry 设置被忽略的问题
  • 修复 macOS/Linux 上无沙箱 Bash 命令看不到 shell 启动文件中导出环境变量的问题
  • 修复服务器错误后消费者条款通知被跳过一天以上的问题
  • 修复网络或服务器错误后 /privacy-settings 提供不适用选项的问题
  • 修复停止回合时因压缩过长对话导致的上下文限制错误
  • 修复子代理在完成后立即被消息或恢复时忘记最近工作的情况
  • 修复 claude —help 文本与实际行为不符的问题
  • 修复 claude —worktree 在 HEAD 分离或另一分支时退出前未询问即删除 worktree 的问题
  • 修复恢复和云会话在插件重载时重复发送完整技能列表的问题
  • 修复中断未能结束等待空闲管道或设备命名的 Read 操作的问题
  • 修复 CLAUDE_CODE_EFFORT_LEVEL 为 auto 或未设置时显示猜测的努力级别的问题
  • 修复 PreToolUse 钩子的拒绝原因被超时错误替换的问题
  • 修复 Bash 和 PowerShell 在无法复制大命令输出文件时删除该文件的问题
  • 修复终端宽度小于 100 列时多选问题预览中的笔记被截断的问题
  • 修复自定步调 /loop 唤醒在 1 小时最大间隔触发时缓存失效的问题
  • 修复代理团队中主会话批准关闭请求导致整个 CLI 退出的问题
  • 修复技能的一次性钩子在运行后移除其他技能相同钩子的问题
  • 修复转录模式中 {和} 导致提示符位置不一致或超出屏幕的问题
  • 修复 CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k 静默设置为 100K 窗口的问题
  • 修复 agents 视图中 Ctrl+C 清除文本选择但未复制的问题
