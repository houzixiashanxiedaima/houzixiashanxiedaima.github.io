2026-09-19 IDE / SDK 更新：Android Studio、Flutter SDK、Melos 等 5 项工具有新版本 | 修复 AGP 9.3.0 中新的优化 DSL 未正确设置 ApplicationVariant 对象中的 isMinifyEnabled 的问题

#ide-updates #ide #automation #Android Studio #Flutter SDK #Melos #Claude Code #AGP

Android Studio Quail 4 → Quail 4 Patch 1 Qwen/Qwen3.8-27B

问题修复

  • 修复 AGP 9.3.0 中新的优化 DSL 未正确设置 ApplicationVariant 对象中的 isMinifyEnabled 的问题
  • 修复 D8 9.2.14 在 mergeProjectDexDebug 任务上比 8.13.6 慢约 38% 的性能问题
  • 修复 D8 调试模式下 ArrayIn 相关的错误

Flutter SDK 3.47.3 → 3.47.5 Qwen/Qwen3.8-27B

问题修复

  • 修复在 iOS 27 物理设备上调试时应用偶尔崩溃的问题
  • 修复 Widget Previewer 中重新展开预览组时因滚动恢复类型错误导致的崩溃问题
  • 修复 Dart Development Service 启动失败时 flutter_tools 因未处理的 FormatException 而崩溃的问题

Melos 8.7.0 → 8.8.0 Qwen/Qwen3.8-27B

新内容

  • 允许配置中使用 “x-” 扩展字段，以便 YAML 锚点通过验证
  • 支持在配置中设置所有命令行选项
  • 为纯 Dart 包生成 IntelliJ 的 Dart 运行和测试配置
  • 为 bootstrap、test 和 analyze 命令新增 —no-pub 标志

Claude Code 2.1.274 → 2.1.277 Qwen/Qwen3.8-27B

新内容

  • 新增 AGENTS.md 支持：无 CLAUDE.md 时读取 AGENTS.md，可在 /config 中修改（暂不支持 Bedrock…
  • 新增 CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 环境变量，用于仅通过正向代理出站的网关场景
  • Claude apps gateway 上游新增可选 headers 映射，可向代理发送静态请求头
  • 后台任务完成且面板打开时，显示更新等待提示行
  • 改进 SDK 和 headless 会话启动速度：首轮不再等待目录级 CLAUDE.md 查找
  • 改进 prompt 处理：移除不可见 Unicode 格式字符并在发送前展示清理后的内容
  • 改进 /ultrareview 空状态提示，提供审查最新提交的命令并完整审查新仓库首个提交
  • 改进 Artifact 工具权限提示：更简洁的措辞、按标题或文件名命名页面与工件、链接列于文本之后
  • 改进危险 rm 权限提示：明确标记的命令并建议 ${VAR:?} 保护，便于 headless 恢复
  • 改进 Claude apps gateway 回环错误信息，明确提及 CLAUDE_GATEWAY_ALLOW_LOOPBACK
  • 改进 /plugin Installed 视图：独立列出的 MCP 服务器现在显示其所属插件
  • 改进 claude plugin install 对已安装插件的行为：提示市场是否有新版本并给出 update 命令
  • 改进启动通知溢出行文案为 “N more notices hidden”
  • 改进 artifact 链接处理：有 Artifact 工具时优先使用它而非 WebFetch

问题修复

  • 修复 claude -p 和 Agent SDK 会话在内部错误后挂起无结果的问题，现报告错误并以退出码 1 结束
  • 修复对话因早期助手轮次含空文本块而每次请求失败的问题（包括 —resume 后）
  • 修复同一机器上旧版 Claude Code 构建导致意外登出的问题
  • 修复 ANTHROPIC_API_KEY 用户因～/.claude.json 中 customApiKeyResponses 值畸形导致交互式启动挂起或报错
  • 修复代理返回无效版本时每 30 分钟更新检查报错及 claude update 挂起；畸形 minimumVersion 现被忽略
  • 修复 winget/apk 管理安装中版本查询失败时 claude update 误报 “已是最新”
  • 修复重新安装正在使用的插件版本时可能破坏已安装副本的问题
  • 修复系统资源耗尽时 Grep/Glob 未报告错误而是返回无匹配的问题
  • 修复 Write 工具目标路径为现有目录时静默结束回合的问题，现报告清晰错误
  • 修复 Edit 工具将转义反斜杠加 uXXXX 误判为 \uXXXX 转义的问题
  • 修复 Edit 工具大型非 ASCII 编辑不匹配时报错信息不准确的问题
  • 修复文件路径含 \u0000 转义序列时回合提前结束的问题
  • 修复后台会话因插件 LSP 服务器退出或关闭 stdin 而退出的问题
  • 修复～/.claude.json 中 claudeAiMcpEverConnected 值畸形时打开 /mcp 或 /plugin manage 崩溃
  • 修复～/.claude.json 中 theme 值畸形时启动崩溃
  • 修复 prompt 含终端颜色代码时崩溃的问题
  • 修复恢复保存历史中助手消息为纯字符串的会话时崩溃
  • 修复慢速或高负载机器上首次 spinner 出现时会话以不可恢复接口错误退出
  • 修复罕见情况下内部渲染错误导致屏幕停止更新
  • 修复 Windows 上 Claude 回复后工具调用未执行即报内存不足的问题
  • 修复 /clear 后续接会话因 SessionStart hook 输出丢失首条消息部分内容导致 prompt 缓存失效
  • 修复其他 agent 消息在回合中途出现在错误位置的问题
  • 修复全屏 /resume 选择器拖选文本后 “已复制” 提示不显示
  • 修复启用沙箱时 Bash 命令中 $TMPDIR 展开为空
  • 修复 Cowork 云会话中 WebFetch/WebSearch 拒绝请求时未告知原因
  • 修复 Claude apps gateway 遥测中继忽略 NO_PROXY 中主机名 / 域名的问题
  • 修复 strictKnownMarketplaces/blockedMarketplaces 单条畸形条目禁用整个企业市场策略
  • 修复自动更新失败后在～/.cache/claude/staging 留下大文件
  • 修复 /plugin Installed 标签页未剥离终端控制字符
  • 修复技能或遗留命令命名为内置 Object 属性时 /plugin 和 /skills 崩溃
  • 修复多选安装全部失败时 /plugin 无提示关闭
  • 修复已卸载插件在 /plugin Installed 中重现为加载失败且 Remove 无法清除
  • 修复官方市场插件未记录 commit 及固定 commit 插件更新后保留旧 commit
  • 修复插件重载预览保留所有解包副本及下载失败时覆盖缓存归档
  • 修复～/.claude.json 含畸形占位记录时 Remote Control 会话簿记失败
  • 修复已吊销 claude.ai 登录的错误提示误导，现优先引导 /login
  • 修复快速输入或按键重复时 claude agents dispatch 输入乱码
  • 修复恢复含 stop hook 摘要但 hook 列表畸形的会话转录时崩溃
  • 修复 keybindings.json 重绑定 Enter 后选中 agent 面板行按 Enter 无响应
  • 修复 Windows 长路径下 PDF 页面读取失败
  • 修复 headless resume 会话成本和使用量从零开始，现退出时保存总计
  • 修复主仓库项目技能在 .claude/skills 未跟踪时 —worktree 会话不加载
  • 修复 sandbox.excludedCommands glob 豁免整个复合 Bash 命令的问题，现要求每部分都匹配
  • 修复恢复的子 agent 重新渲染 MCP 工具定义破坏 prompt 缓存
  • 修复速率限制的 artifact 发布错误地告诉 Claude 停止重试
  • 修复恢复或重启后早前附件重新渲染导致扩展思考丢失和 prompt 缓存失效
  • 修复 Console 登录创建 API 键被拒时仅显示通用 400 错误，现显示服务器消息
  • 修复 Claude 工作时输入的消息有时被模型忽略

AGP 9.4.0 → 9.4.1 Qwen/Qwen3.8-27B

新内容

  • Android Gradle 插件 9.4 版本发布，包含多项新功能与改进
  • 支持最高 API level 37

Breaking Changes

  • 从 AGP 10 开始，新的 Variant API 将成为所有项目的强制要求
