IDE / SDK 更新 - 2026-11-04

IDE 更新 • 2026年11月4日 • 7 分钟阅读

2026-11-04 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | /schedule 命令新增警告，提示未请求的云调度任务连接器及移除方法

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.316 → 2.1.317 Qwen/Qwen3.8-27B

新内容

  • /schedule 命令新增警告，提示未请求的云调度任务连接器及移除方法
  • 新增检查，在 Web 或 Shell 工具调用发送账户邮箱前进行确认
  • Agent SDK 钩子回调新增 onFailure: “block” 选项，失败时阻止操作执行
  • Claude Desktop Code 标签页新增远程管理设置加载状态通知
  • 自动模式子代理工具调用无响应时新增通知，避免主视图空白
  • OTel 指标、事件和跨度新增 anthropic.plan 等四个属性
  • Claude apps gateway 管理 API 新增成本报告端点 GET /v1/organizations/analytics/cost
  • 新增每日记录开发者 IdP 组功能，用于成本报告分组
  • 新增环境变量 CLAUDE_CODE_DISABLE_NESTED_SESSION_ID 以控制会话 ID 行为
  • 改进 Microsoft Foundry Azure 凭证错误提示，明确指向凭证问题
  • 改进 /design-sync 命令，提前检测设计系统迁移并停止构建
  • 改进 Claude apps gateway 启动错误提示，区分网络与登录问题
  • 改进退出时的会话恢复提示，显示启动时使用的标志
  • 改进自托管 runner 从服务器错误中恢复的连接处理机制
  • SendMessage 改为将运行中的后台代理命令移至后台而非停止
  • 不同模型的子代理和队友现在使用其模型保存的 effort level
  • 退出时跳过插件监控器的 “后台工作正在运行” 提示
  • 内置插件创建技能在 mod 构建成功后提供分享帮助

Breaking Changes

  • 移除 Read 工具的 “文件自上次 Read 以来未更改” 存根：再次读取未更改的文件将返回其内容

问题修复

  • 修复 Claude desktop 会话中项目和本地 MCP 服务器在第一轮后断开连接的问题
  • 修复自动模式在 LLM gateway 返回 403 或 422 时每轮失败的问题
  • 修复 claude auth status 在慢速 token 刷新保存前退出导致下次登出的问题
  • 修复应用预启动会话忽略项目 effortLevel 设置的问题
  • 修复 claude —from-pr 在多会话项目中报告 “未找到对话” 的问题
  • 修复 claude.ai 和移动应用中第二个并发权限提示不显示文件路径或命令的问题
  • 修复 Remote Control 和 SDK 主机对 mod 工具调用提供 “不再询问” 选项的问题
  • 修复云和 SDK 会话中标题生成期间新消息到达导致标题丢失的问题
  • 修复自定步调 /loop 唤醒有时未调度的问题
  • 修复云会话中自动模式在 Artifact 工具上传时停止等待批准的问题
  • 修复无法写入磁盘时从 claude.ai 同步的技能每十分钟丢失或重新下载的问题
  • 修复 /schedule 创建或更新后结果中缺少云调度任务的下次运行时间和链接的问题
  • 修复屏幕阅读器模式下每次变化都朗读运行中子代理经过时间和 token 计数的问题
  • 修复区域或网络封锁（HTTP 403）被显示为登录失败的问题
  • 修复云会话中同步插件包含相同服务器时 Claude 错误报告 claude.ai 连接器需要授权的问题
  • 修复磁盘满或配额导致 transcript 或～/.claude.json 写入失败时 claude -p 退出码为 0 的问题
  • 修复启动后第一秒内对设置文件的编辑直到再次更改才生效的问题
  • 修复某些运行跳过清理时旧 transcript 未被清理的问题
  • 修复已删除的 agent team inbox 被队友迟到消息重新创建的问题
  • 修复重新创建的 agent teammate 被早期关闭审批从团队中移除的问题
  • 修复关闭调度任务后存储的调度任务无法列出或删除的问题
  • 修复 Claude 在未指定名称时被要求删除 /team-onboarding 指南时删除最近更新的指南的问题
  • 修复服务器拒绝删除时 Claude 错误报告 /team-onboarding 指南已删除的问题
  • 修复 Claude apps gateway 隐藏 Amazon Bedrock “输入过长” 错误导致会话每轮失败的问题
  • 修复自托管 runner 会话在计划等待批准时重启丢失近期轮次或整个对话的问题
  • 修复非常大的 CLAUDE.md 更改后自动压缩出现 “提示过长” 的问题
  • 修复具有许多注册命令插件的无头会话高内存使用和慢启动的问题
  • 修复 stdio MCP 服务器接收到空的 AWS_BEARER_TOKEN_BEDROCK 变量的问题
  • 修复根证书续期后某些 TLS 检查代理后 API 请求失败的问题
  • 修复非常长的对话在压缩需缩短自身请求时丢失早期摘要的问题
  • 修复 PDF 元数据可能导致 Read 和 @-mentions 少计页数的问题
  • 修复 DISABLE_PROMPT_CACHING_OPUS 和 SONNET 对默认模型变体无效的问题
  • 修复拥有 200 个以上个人 artifact 时 /artifacts 和 Artifact 工具共享列表不显示共享 artifact 的问题
  • 修复 Claude 在搜索达到时间限制时将部分 Grep 和 Glob 结果视为完整的问题
  • 修复通过代理的 OpenTelemetry 导出在另一个导出仍在进行时永不发送的问题
  • 修复向阻止 OpenTelemetry 导出的代理发起大量连接尝试的问题
  • 修复 OpenTelemetry 导出在从不响应的代理后无限挂起的问题
  • 修复恢复会话时再次告知 Claude 已知文件更改的问题
  • 修复恢复会话中早期调用因工具关闭而失败后 Claude 有时不使用内置工具的问题
  • 修复 /remote-control 回答 “未知命令” 而非说明 Remote Control 已被禁用的问题
  • 修复 tmux 或 iTerm2 窗格中 agent team teammates 在主会话手动模式下启动自动模式的问题
  • 修复后台会话在升级或退役时有时丢失刚做的权限模式更改的问题
  • 修复在提示符处按 Ctrl+C 清除输入文本时停止所有运行中后台代理的问题
  • 修复 /feedback 在报告发送期间显示 “按 Enter 确认” 的问题
  • 修复已停止 shell 命令的子进程有时收到两次 SIGTERM 导致跳过清理的问题
  • 修复云或自托管 runner 会话中运行的 claude -p 共享该会话 ID 的问题
  • 修复云或自托管 runner 会话中运行的 claude -p 生成自己的标题并发送到该会话的问题
