### [VSCode 1.146.0 → 1.147.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_147.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增“稍后发送”功能，支持将聊天请求保存为草稿或定时执行
- 新增远程环境共享至 GitHub Environments 功能，支持跨设备同步 Agent 会话
- 新增自动化（Automations）功能，支持基于触发器和条件自动运行任务
- 新增模型路由器（Model Router），允许根据任务类型自动匹配首选模型
- 新增浏览器使用（Browser Use）预览功能，允许 Agent 直接操作默认浏览器
- 新增 Skills over MCP 支持，MCP 服务器可自动向模型提供技能
- 新增在集成浏览器中预览远程 HTML 文件及打开非 localhost 链接的功能
- 改进收件箱模式，按需要关注的程度对 Agent 窗口会话进行分组
- 改进模型对比功能，使对比结果更易于查找和理解，并保留在对应聊天中
- Agent 响应支持 HTML 预览和原生视觉展示，如图表和原型图
- 支持在聊天中捕获、裁剪和标记图像，以及内联显示附件胶囊
- 自定义设置中的扩展部分现在显示与编辑器扩展视图相同的详细信息
- 辅助权限增加更多上下文，LLM 审查器会考虑请求来源和用户回答
- Dev Container 重建时可保留聊天会话（实验性功能）
- 其他应用截图可作为附件发送给 Agent（实验性功能）

### [Claude Code 2.1.326 → 2.1.327](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

- 新增 /install-github-app 修改仓库前的确认提示
