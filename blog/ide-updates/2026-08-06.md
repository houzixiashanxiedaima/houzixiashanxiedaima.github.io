### [VSCode 1.131.0 → 1.132.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_132.md) <sup>gpt-oss-120b</sup>

**新内容**
- 集成浏览器支持对网页元素进行精准评论，实现元素级反馈
- 多语言语音输入，支持多语言口述并自动检测语言
- 新增 /btw 侧聊天，可在不打断当前对话的情况下提问
- 实验性混合 Markdown 编辑器支持 Markdown 差异查看，保持可编辑
- Agent Host 允许在多个 VS Code 窗口共享同一代理会话
- 新增 Agents 窗口，用于启动和监控多个代理会话
- 聊天输入上方新增状态徽章，实时显示会话的更改、预览、子代理和浏览器活动
- 编辑器类型下拉菜单，可在普通编辑器和差异编辑器之间切换
- 终端输出随窗口宽度重新换行，提升阅读体验
- 语音输入首次使用引导，提供麦克风校验、波形显示和设备选择
- 终端语音指令支持 shell 语法清理，自动转换口述命令
- 自定义编辑器优先级功能，扩展可为文本编辑器和差异编辑器设置不同优先级

**Breaking Changes**
- 移除 ChatAgentHostEnabled 策略，管理员无法通过策略集中禁用 Agent Host
