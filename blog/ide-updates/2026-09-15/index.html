IDE / SDK 更新 - 2026-09-15

IDE 更新 • 2026年9月15日 • 3 分钟阅读

2026-09-15 IDE / SDK 更新：Xcode 等 1 项工具有新版本 | 新增 Swift 6.4 及 iOS、iPadOS、tvOS、watchOS、macOS、visionOS 27 SDK

#ide-updates #ide #automation #Xcode

Xcode 26.6 → 27.0 Qwen/Qwen3.8-27B

新内容

  • 新增 Swift 6.4 及 iOS、iPadOS、tvOS、watchOS、macOS、visionOS 27 SDK
  • 支持在 iOS 17+、tvOS 17+、watchOS 10+ 和 visionOS 上进行设备端调试
  • Apple Clang 编译器支持使用 API Notes 标注类内声明的 C++ 运算符
  • Background Assets 清单支持路径通配符、文件排除、硬编码源根目录及自定义目标子路径
  • 新增本地化资产包功能，系统根据用户首选语言自动分发对应资产包
  • 新增 Steam Asset Converter 工具，可将 Steam “depots” 转换为资产包
  • Xcode 调试时可通过 Run scheme 选项设置 Background Asset Packs 文件夹向应用提供资产包
  • C++ 标准库实现多项新提案（如 std::chrono 哈希支持、zip、std::optional 改进等）
  • C++ 标准库多项性能优化：关联 / 无序容器最高提升 11 倍，分段迭代器算法最高提升 1600 倍，std::search_n 随机访问迭代器最高提升 70…
  • C++ 标准库多项杂项改进：内部类型重构以加快编译速度、std::align 改为内联函数、std::atomic::wait 支持更多原生等待类型
  • Coding Intelligence 编程助手现支持 Google Gemini

Breaking Changes

  • Xcode 27 要求运行 macOS Tahoe 26.6 或更高版本的 Mac
  • C++ 标准库最低支持的 macOS 部署目标提升至 11.0
  • multi {map,set}::find 算法不再保证返回容器中第一个相等元素的迭代器
  • std::{map,set} lower_bound 和 upper_bound 对非严格弱序比较器的结果行为发生变更
  • ABI 标志 _LIBCPP_ABI_NO_REVERSE_ITERATOR_SECOND_MEMBER 从 LIBCPP_ABI_NO_ITERATOR…
  • 多个内部类型重构为使用 _LIBCPP_COMPRESSED_ELEMENT，可能影响依赖其继承结构的代码
  • ranges::iota_view 现在感知 __int128，某些情况下 difference_type 从 long long 变为 __int128
  • std::allocator 现在是平凡默认可构造的，可通过定义 _LIBCPP_DEPRECATED_ABI_NON_TRIVIAL_ALLOCATOR 恢…
  • bitset::operator [] 现在返回 bool 以符合标准，可通过定义 _LIBCPP_DEPRECATED_ABI_BITSET_CONST_SU…

问题修复

  • 修复方案操作工具栏按钮在处理 “不构建” 变体时的行为异常问题
  • 修复在 macOS Tahoe 26.5.1 及更早版本上安装 Xcode 27 beta 导致虚拟机安装失败的问题
  • 修复未安装 Xcode 27 的 Mac 上的开发设备在未升级 Xcode 27 的 Mac 上保持兼容且无需重启的问题
  • 修复 ba-package 打包工具在指定按需下载策略时可能生成无效资产包存档的问题
  • 修复 Siri 在尝试触发带有 App 枚举值的 AppShortcut 短语时可能产生意外响应的问题
  • 修复通过 Device Hub 访问 CarPlay Simulator 时无法启动 CarPlay 连接的问题

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
