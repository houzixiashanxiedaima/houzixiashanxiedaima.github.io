IDE / SDK 更新 - 2026-10-27

IDE 更新 • 2026年10月27日 • 7 分钟阅读

2026-10-27 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 自托管运行器新增 --hold-idle-file 和 --max-hold-min 参数，用于在主机报告遗留进程时保持空闲会话

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.310 → 2.1.311 Qwen/Qwen3.8-27B

新内容

  • 自托管运行器新增 —hold-idle-file 和 —max-hold-min 参数，用于在主机报告遗留进程时保持空闲会话
  • 新增解释性输出风格提示，当要求 Claude 进行解释时显示
  • 优化 Pro 和 Max 账户启动时间，跳过一小时内重复的网络请求
  • 改进 /teleport 和 claude —teleport，加载压缩后的云会话时发出警告
  • 改进后台会话进程退出时的提示信息，不再承诺自动重启并说明恢复方法
  • 改进多视图 Artifact 工具，通过链接 #name 路由各视图
  • 改进超时 Shell 命令处理，显示已有输出并提示命令仍在后台运行
  • 改进压缩机制，模型回复无摘要时通常再次请求摘要后再替换对话
  • 改进 Artifact 工具对页面与文档的选择逻辑，解释性和可视化工作生成页面
  • 优化仅包含选项及值的启动参数解析速度
  • 改进 “Connection dropped” API 错误提示，指引检查代理、网关或 VPN
  • 改进屏幕阅读器模式下的权限规则删除反馈及问题列表格式
  • 改进粘贴登录代码被拒时的提示信息，建议重新登录
  • 改进 Slack 连接器发送行为，发消息前检查频道主题中的发布规则
  • 交互终端中 ultrathink 在 Opus 5.5 等模型上以 xhigh 努力级别运行当前回合

Breaking Changes

  • ultrathink 彩虹效果仅在关键词可提高努力级别时出现，引用或文件路径部分不再显示
  • Agent 视图中 Ctrl+D 行为更改：空输入时按两次退出，与提示行为一致

问题修复

  • 修复 CLAUDE.md 含超长列表项导致启动及文件读写后长时间冻结的问题
  • 修复 MCP 服务器未响应资源读取或技能下载时中断 Claude 需等待超时的问题
  • 修复标准上下文会话超过 200K token 时停止并提示需要 1M 上下文积分的问题
  • 修复修改数千行文件时 Write 和 Edit 工具停滞且报告 0 行变更的问题
  • 修复子代理无法使用连接完成晚于其启动的 MCP 服务器工具的问题
  • 修复自动压缩后 Claude 看到过期的 MEMORY.md 和 CLAUDE.md 内容的问题
  • 修复 claude -p 和 SDK 会话转录消息顺序错误或保留已撤回消息的问题
  • 修复 SubagentStop 钩子在子代理运行时每分钟触发两次而非结束时触发一次的问题
  • 修复 @ 文件选择器忽略 .ignore/.rgignore 中重新包含 git 忽略文件的否定规则
  • 修复子代理隔离 worktree 在其启动的后台子代理仍工作时被移除的问题
  • 修复自动模式下等待自身 shell 的后台代理每次唤醒都启动新主对话回合的问题
  • 修复 Bash 工具描述错误声称工作目录在调用间始终持久化的问题
  • 修复环境块命名了 Shell 命令未运行的 shell（如 Bash 用 zsh 时显示 fish）的问题
  • 修复仓库根目录下执行 claude mcp add/remove 及 /mcp 时显示当前文件夹而非项目条目的问题
  • 修复 claude mcp list/get 在连接失败行中重复显示错误代码的问题
  • 修复网络代理阻止启动请求时远程控制会话卡在 “Connecting” 约两分钟的问题
  • 修复发送给云端或远程控制会话的消息在 Claude 移动应用中显示为用户自己的消息
  • 修复磁盘满或附件超过 20 个时 Claude 未被告知远程 / 云端会话附件保存失败原因

  • 修复崩溃的后台会话在附加、固定或有计划任务时未重启的问题

  • 修复 Write 工具文件预览在行宽超过终端时跳过行并错误计算隐藏行数

  • 修复 agent teams 会话使用 —resume 等参数返回时显示空任务列表的问题
  • 修复粘贴提及图像文件的文本时附带图像并从提示中丢弃路径的问题

  • 修复引号或括号内单个反斜杠从 Claude 回复中消失的问题
  • 修复设置 DISABLE_COMPACT 时 agent teammates 压缩其历史的问题
