IDE / SDK 更新 - 2026-10-24

IDE 更新 • 2026年10月24日 • 8 分钟阅读

2026-10-24 IDE / SDK 更新：VSCode、Zulu JDK 17、Zulu JDK 21 等 4 项工具有新版本 | Copilot harness 成为新会话默认选项，支持在编辑器与 Agents 窗口间切换

#ide-updates #ide #automation #VSCode #Zulu JDK 17 #Zulu JDK 21 #Claude Code

VSCode 1.143.0 → 1.143.1 Qwen/Qwen3.8-27B

新内容

  • Copilot harness 成为新会话默认选项，支持在编辑器与 Agents 窗口间切换
  • 新增模型对比功能（预览），可在 Agents 窗口中运行同一任务并比较不同模型的解决方案
  • 引入初始文件级工作集支持（实验性），便于管理和审查代理编辑的变更
  • Agents 窗口的 Changes 视图现支持从更多更改集中丢弃待处理更改
  • 空侧边栏中的标签快捷方式：空白区域现在列出可添加的标签及其键盘快捷键
  • 新增会话活动栏（实验性）用于管理会话
  • Files 标签页空白时可直接查找和创建文件（实验性）
  • 大幅优化打开大型聊天时的性能，历史恢复改为分片加载，避免窗口冻结
  • 支持从非活跃 worktree 回收存储空间（实验性）
  • 支持在本地设备运行 Copilot 模型（实验性），如 MAI Code 1.1 Flash
  • 语音模式支持自带 OpenAI 模型（预览），可使用自己的 API 密钥
  • 沙箱证书信任管理：允许工具在不暴露真实令牌的情况下认证到批准的服务
  • 当组织策略允许时，可为单个会话关闭沙箱化
  • 可从聊天菜单直接打开画布（预览）
  • 可查看分离后台 shell 的输出，如开发服务器或文件监视器
  • 诊断高亮限制从每文件 500 个提升至 5,000 个，提升问题可见性
  • 多文件 diff 编辑器文件列表（实验性）
  • 为托管 OpenTelemetry 导出提供动态 HTTP 头生成能力
  • 托管模型默认值：新 Copilot harness 聊天使用组织托管默认值

Breaking Changes

  • Copilot harness 成为新会话默认选项，原有默认行为已变更

Zulu JDK 17 17.0.20.1 → 17.0.21 Qwen/Qwen3.8-27B

安全修复

  • 修复 eMudhra 中间 CA 证书被泄露的安全问题
  • 修复多个通用漏洞披露（CVE）相关的安全漏洞

Zulu JDK 21 21.0.12.1 → 21.0.13 Qwen/Qwen3.8-27B

安全修复

  • 修复 eMudhra 中间 CA 证书被泄露的安全问题
  • 修复特定组件 API 可被利用的漏洞，影响加载不受信任代码并依赖 Java 沙箱进行安全保护的部署环境

Claude Code 2.1.308 → 2.1.309 Qwen/Qwen3.8-27B

新内容

  • 优化 Windows 上 Git 命令执行速度，并统一错误提示为英文
  • 改进磁盘已满时的错误提示，明确指示需清理的目录
  • 更新 dataviz 技能支持 APCA 对比度标准及 apca () 验证函数
  • 更新 /claude-api 技能支持服务账户密钥管理 OpenTelemetry 目标
  • 自托管 Runner 会话迁移时保留中断的工具调用状态标记
  • VSCode 扩展新增证书验证失败时的日志警告与修复指引

安全修复

  • 修复沙箱 Bash 命令在 macOS/Linux 上于沙箱外执行启动文件的问题
  • 修复 macOS 沙箱 denyWrite 通配符通过符号链接绕过路径限制的问题
  • 修复沙箱命令及自动接受编辑可修改 —mcp-config 指定配置文件的问题
  • 修复 Bash 权限检查信任重定向可能失败的命令所设置变量的问题
  • 修复 Edit (path) 拒绝规则未阻止某些含子 shell 命令中 Bash 重定向的问题
  • 修复 Worktree 隔离会话接受本应拒绝的带语言前缀或算术命令的问题
  • 修复配置文件写入保护在通过符号链接访问配置目录时失效的问题
  • 修复 Linux 沙箱后台命令结束后写拒绝策略被解除的问题
  • 修复 Windows PowerShell 权限检查自动批准针对当前目录的 Set-Location 命令的问题

Breaking Changes

  • sed -i 现在获取标准 Bash 提示并按原样运行，不再模拟文件编辑预览，且不被 /rewind 恢复
  • claude ultrareview 要求工作区信任：终端询问否则拒绝；脚本需传 —trust-workspace 或设环境变量
  • Desktop 和 VS Code 中 bypass permissions 模式下危险 rm/rmdir 提示改为立即拒绝并提供重写提示
  • 设置排除沙箱的命令在沙箱启用但无法运行时，写入 write-list 路径前需询问，无沙箱回退被拒绝
  • Worktree 创建和复用不再按需获取 git 对象；部分克隆配置 Bash 沙箱时需先获取对象
  • /claude-api 技能构建 Managed Agents 子代理团队默认使用 multiagent_20261001 动态工作流而非 coordinat…

  • 修复禁用 MCP 服务器在 print/SDK 会话中被后续权限提示重新连接的问题
  • 修复读取超大嵌套 CLAUDE.md 导致会话反复压缩的问题
  • 修复 Ctrl+Enter 在响应开始前仅排队消息、钩子运行时重启钩子的问题
  • 修复键位绑定斜杠命令在！模式下于 shell 中执行的问题
  • 修复 Ctrl+O 不显示其他代理等待投递消息的问题
  • 修复长工具输出预览截断 Emoji 导致 jq 无法解析转录的问题

  • 修复非 Git 仓库目录下 remote-control 状态行显示 HEAD 为分支的问题
  • 修复分屏代理队友未继承领导者命令行工具拒绝规则的问题
  • 修复 /rename 重命名会话在 VS Code 重载后显示生成名称的问题
  • 修复 /rewind 列表对通过 /code-review —fix 等变更的文件显示无代码更改的问题
  • 修复 /privacy-settings 显示过期的帮助改进 AI 模型值的问题

  • 修复 /claude-api 技能关于 ant beta:worker poll 传递 trace 上下文的错误描述
  • 修复 /claude-api 技能 C# 追踪设置缺少云平台客户端 spans 的问题
