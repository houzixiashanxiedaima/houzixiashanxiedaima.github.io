### [Claude Code 2.1.310 → 2.1.311](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 自托管运行器新增 --hold-idle-file 和 --max-hold-min 参数，用于在主机报告遗留进程时保持空闲会话
- 新增解释性输出风格提示，当要求 Claude 进行解释时显示
- 优化 Pro 和 Max 账户启动时间，跳过一小时内重复的网络请求
- 改进 /teleport 和 claude --teleport，加载压缩后的云会话时发出警告
- 改进后台会话进程退出时的提示信息，不再承诺自动重启并说明恢复方法
- 改进多视图 Artifact 工具，通过链接 #name 路由各视图
- 改进超时 Shell 命令处理，显示已有输出并提示命令仍在后台运行
- 改进压缩机制，模型回复无摘要时通常再次请求摘要后再替换对话
- 改进 Artifact 工具对页面与文档的选择逻辑，解释性和可视化工作生成页面
- 优化仅包含选项及值的启动参数解析速度
- 改进“Connection dropped” API 错误提示，指引检查代理、网关或 VPN
- 改进屏幕阅读器模式下的权限规则删除反馈及问题列表格式
- 改进粘贴登录代码被拒时的提示信息，建议重新登录
- 改进 Slack 连接器发送行为，发消息前检查频道主题中的发布规则
- 交互终端中 ultrathink 在 Opus 5.5 等模型上以 xhigh 努力级别运行当前回合

**Breaking Changes**
- ultrathink 彩虹效果仅在关键词可提高努力级别时出现，引用或文件路径部分不再显示
- Agent 视图中 Ctrl+D 行为更改：空输入时按两次退出，与提示行为一致
