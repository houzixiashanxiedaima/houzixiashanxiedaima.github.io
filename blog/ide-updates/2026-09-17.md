### [VSCode 1.137.0 → 1.138.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_138.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 支持在本地 Dev Container 中运行 Agent 会话，使用项目配置的工具和依赖
- 扩展 Codex 支持：跨应用继续会话、选择 Copilot 或 ChatGPT 订阅、使用 VS Code 工具
- 自动化（Automations）默认启用，并支持导出和导入以跨环境共享
- Agent SDK 按需下载提示优化，SDK 缺失时始终显示下载通知
- 支持从 Agent 会话直接创建 Pull Request，可编辑标题、描述及合并选项
- 新增会话清理功能（预览版），自动标记已合并会话为完成并可定期删除
- 新增应用徽章（预览版），在任务栏/启动器上显示需要关注的 Agent 会话状态
- 统一工作区和仓库选择器（实验版），在一个列表中搜索本地文件夹、GitHub 仓库及远程目标
- 支持按颜色主题自定义聊天背景（实验版），可为深色和浅色主题分别设置图案或图片
- 改进语音模式（实验版），支持查找、切换并行 Agent 会话并报告其状态
