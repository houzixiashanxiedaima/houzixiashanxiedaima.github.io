### [VSCode 1.145.3 → 1.146.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_146.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增会话收件箱模式（实验性），集中查看代理状态、运行中任务及待合并内容
- 新增会话列表内联操作（实验性），可在代理窗口直接修复检查失败或处理评审评论
- 新增聊天窗口预览功能，支持将多个聊天拆分为独立窗口以避免切换混乱
- 新增在代理窗口内安装和管理扩展（实验性），无需切换至编辑器窗口即可操作
- 改进模型比较功能，支持跨模型运行提示词、评估结果并综合优势
- 改进画布功能，新增权限提示并优化画布发现与连续性体验
- 新增配置计算机共享（实验性），在远程环境编辑器中集中管理远程连接
- Agent Host 新增对虚拟仓库的支持，可在未克隆的 GitHub 仓库中使用 Copilot 功能
- 新增从 Copilot CLI 继续会话至 VS Code（实验性），通过 /code 命令无缝迁移会话
- 新增可配置的后台发送快捷键，无需打开新会话即可启动
- 新增 MCP 技能支持（预览），允许 MCP 服务器自动向模型提供技能
- 改进权限提示粒度，默认针对特定域名、命令和目录添加许可，避免过度授权
- 新增沙箱环境变量掩码设置，保护敏感信息不被代理工具访问
- 聊天输入框显示沙箱状态，直观反映终端沙箱是否启用
- 欢迎页新增可见键盘焦点轮廓，提升屏幕阅读器用户体验
- 升级 Mermaid 至 12 版本，支持用例图等新型图表及更新布局行为
- 集成浏览器中本地 HTML 文件地址可复制，便于粘贴至外部浏览器或终端
- Copilot 会话支持企业代理配置，包括 PAC 自动配置和 Kerberos 认证
- 组织可通过策略限制被阻止开发者跳转至自定义帮助页面
- 企业控制新增画布扩展限制，强制要求画布扩展来自合格插件

**Breaking Changes**
- Local harness 已弃用，将于 2027 年 2 月移除，需迁移至 Copilot harness

**问题修复**
- 修复代理编辑指标统计错误，不再将未变更文本计为新增或删除代码
