IDE / SDK 更新 - 2026-10-05

IDE 更新 • 2026年10月5日 • 4 分钟阅读

2026-10-05 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 改进插件代码窗格中大型文件的打开速度，按最终宽度一次性布局高亮视图

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.288 → 2.1.289 deepseek-ai/DeepSeek-V4-Flash

新内容

  • 改进插件代码窗格中大型文件的打开速度，按最终宽度一次性布局高亮视图
  • 新增 agent.spawn 供队友使用，插件钩子事件统一 agent id，$.agent.list () 增加空闲与等待状态
  • 改进 mod 的带区或窗格绘制失败时作者看到的提示，指明 mod 名称并说明未绘制任何内容

问题修复

  • 修复复合 shell 命令嵌套部分中 deny 或 ask 规则在受管机器上不覆盖用户安装 mod 批准的问题
  • 修复短代码块含大量未闭合标签或深层嵌套 ${ 替换时终端冻结的问题
  • 修复通过符号链接在 IDE 中 @提及、更改或选择的文件不应用 Read deny 规则的问题
  • [VSCode] 回退 2.1.288 中可能使登出更频繁的 claude auth status 变更
  • 修复插件列表、插件评估和插件更新显示本地文件夹市场安装的插件过期副本，以及符号链接 —plugin-dir 的热重载问题
  • 修复升级后首个会话中已安装 mod 未加载的问题
  • 修复全屏打开后台任务对话框时提示上方插件行显示过期行的问题
  • 修复链接使用 localhost 地址、路径含 @、大写主机或 file: 路径时插件窗格不绘制的问题
  • 修复用户安装插件可改写组织管理 MCP 服务器登录工具描述的问题
  • 修复插件绘制终端不认识的边框样式 Box 时启动阶段冻结或强制退出的问题
  • 修复插件屏幕处理器异步抛出时监督与后台会话结束的问题
  • 修复无高度插件区域持续增长时会话以界面错误结束的问题
  • 修复沙箱自动允许命令时 Bash deny 和 ask 规则漏掉带环境变量前缀展开值（如 TZ=“$HOME” rm -rf build）的命令
  • 修复沙箱自动允许下命令前有裸变量赋值时跳过 Bash deny 或 ask 规则的问题
  • 修复文件夹同时含市场清单时 claude plugin validate 跳过插件的问题
  • 修复 mod 的 ui.render 钩子写入值导致行绘制抛出时会话以不可恢复界面错误结束的问题，引擎现自行绘制该行
  • 修复含制表符、游离转义与 C1 控制符或短文本含制表符与 CRLF 换行时文本绘制到下方行的问题
  • 修复 mod 窗格或带区右对齐内容绘制到关闭标记或 [-] 下方的问题，现距终端边缘保留一列
  • 修复绘制时失败的 mod 的 Client 拖垮其周围绘制内容的问题，现单独失败并触发 ui.fault
  • 修复 claude plugin validate 对 Anthropic 市场自身插件失败且 —json 列出干净 plugin.json 的问题
  • 修复 mod 带区绘制失败时短暂让下方卡片让位的问题
  • 修复失败插件组件在无错误消息时显示 Error 或空白原因的问题
  • 修复发布工件页面在短代码块含大量未闭合标签时冻结或崩溃读者浏览器标签页的问题
  • 修复终端绘制 mod 的 Client 区域抛出后该区域整个会话保持失败状态的问题

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
