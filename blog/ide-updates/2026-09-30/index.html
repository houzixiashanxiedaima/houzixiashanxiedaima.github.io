IDE / SDK 更新 - 2026-09-30

IDE 更新 • 2026年9月30日 • 6 分钟阅读

2026-09-30 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 新增 CLAUDE_CODE_DISABLE_WEB_FETCH 环境变量以禁用 WebFetch 工具

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.284 → 2.1.285 Qwen/Qwen3.5-27B

新内容

  • 新增 CLAUDE_CODE_DISABLE_WEB_FETCH 环境变量以禁用 WebFetch 工具
  • 新增 claude —desktop 命令在当前目录或会话中打开桌面应用
  • 新增 claude plugin configure 命令查看插件选项或通过 stdin 保存新值
  • claude plugin install —config 支持使用 . = 设置内置 MCP 服务器配置
  • 新增 allowedProviders 管理设置以限制机器可用的 API 提供商
  • 新增 CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES 环境变量限制非流式超时重试次数

安全修复

  • 修复日志和转录记录中 URL 密码部分泄露的问题（含 @ 符号及 %40 编码情况）
  • 修复 Artifact 允许规则可能绕过工作目录限制导致文件外泄的问题
  • 修复 /ultrareview 上传包含冒号的凭证文件时未正确过滤的问题
  • 修复 PowerShell 工具在解析器启动失败时跳过拒绝和询问规则的安全漏洞

问题修复

  • 修复子代理调用在 CLAUDE_CODE_FORK_SUBAGENT=1 下无法获取结果的问题
  • 修复 SSH 安装和更新插件时忽略 GIT_SSH 或 git config 设置的问题
  • 修复操作系统拒绝读取管理设置文件时导致程序无法启动的问题
  • 修复云会话压缩后拒绝更新已读取工件的问题
  • 修复插件启用 / 禁用时因大小写差异修改错误配置项的问题
  • 修复远程控控制消息附件下载失败后丢失且无重试机制的问题
  • 修复会话中切换模型后输出令牌限制和自动压缩窗口未重置的问题
  • 修复 SSH 密钥短语和新主机提示占用终端导致阻塞的问题
  • 修复会话中途关闭 MCP 服务器后其工具仍可用问题
  • 修复后台子代理权限请求被自动拒绝而非发送至提示工具的问题
  • 修复 MCP 列表和详情命令输出中包含换行符和转义序列的问题
  • 修复沙箱自动允许对包含等号的脚本重复请求批准的问题
  • 修复分叉子代理未继承父会话计划模式或不询问模式的问题
  • 修复远程控制台帮助文档关于 Chrome 默认设置的误导性描述
  • 修复自动模式下后台子代理报告后出现冗余回复的问题
  • 修复云会话创建和环境读取仅获取最新 20 个环境的问题
  • 修复远程控制台消息标记为已读时机过早及退出时丢失队列消息的问题
  • 修复插件安装到 ID 相似但大小写不同的缓存文件夹的问题
  • 修复钩子和 SDK 权限回调在退出计划模式时看到缺失计划的问题
  • 修复云会话首次回复延迟数十毫秒的回归问题
  • 修复使用 ANTHROPIC_AUTH_TOKEN 认证时未加载组织策略的问题
  • 修复工作流脚本中未处理的 Promise 拒绝导致后台会话终止的问题
  • 修复同步钩子因后台进程输出未关闭而挂起的问题
  • 修复 WebFetch 将域名安全限速误报为网络或企业策略阻止的问题
  • 修复全屏转录在大量文件操作时短暂冻结的问题
  • 修复 Amazon Bedrock 流式传输错误显示原始 JSON 而非错误信息的问题
  • 修复 /autofix-pr 和 /schedule 在未检查状态时报 GitHub App 未安装的问题
  • 修复删除工件行导致文件解绑并创建新工件的问题
  • 修复对话回退后发布覆盖 Claude 仅在回退回合读取的新内容的问题
  • 修复 /cost 和 SDK 在使用不同备用模型时报告错误模型使用情况的问题
  • 修复发布页面时允许覆盖源文件而未重新读取的问题
  • 修复自动模式跳过资产上传和他人工件读取的分类器问题
  • 修复 /ultrareview 因项目文件夹暂时不可读而报错 core.worktree 已设置的问题
  • 修复 macOS 和 Linux 上 /ultrareview 无法从设置 core.longpaths 的工作树上传的问题
  • 修复 Artifact 工具在临时服务器错误重试后误报冲突的问题
  • 修复罕见情况下两个会话同时恢复登录刷新锁导致的认证失败
  • 修复取消的 Shell 命令或钩子在设置阶段仍继续运行的问题
  • 修复 Vim 模式下外部编辑器编辑后 x 或 r 破坏粘贴占位符的问题
  • 修复 API 输出内容过滤器阻止响应后仍持续重试的问题
  • 修复插件静默跳过需配置的内置 MCP 服务器的问题
  • 修复会话压缩或恢复时因转录记录字段缺失或畸形导致崩溃的问题
  • 修复 WSL 下 /ultrareview 拒绝上传文件名含冒号、点或空格的检出
  • 修复 CLAUDE_CODE_RESUME_INTERRUPTED_TURN 重新运行已达最大回合数的回合
  • 修复浏览器显示成功后登录无限等待的问题
  • 修复 Windows 下 /ultrareview 在某些情况下上传根目录为家目录的链接工作树
  • 修复云会话在上传任何文件前报告上传文件夹缺失的问题
  • 修复后台会话等待权限提示时来自 agents 的回复误批准待处理命令的问题
  • 修复命令选项在前时 attach、logs 等命令以命令名作为提示启动新会话的问题
  • 修复 claude mcp list 遗漏 WebSocket (ws) MCP 服务器的问题
