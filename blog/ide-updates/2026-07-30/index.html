VSCode 1.130.0 → 1.131.0 gpt-oss-120b

新内容

  • 新增子代理可视化：显示模型、运行时长、活跃工具调用
  • 新增实验性内置语音输入，可在聊天、编辑器和终端使用，无需安装 Speech 扩展
  • 新增实验性混合 Markdown 编辑器，支持在 Agents 窗口查看、编辑并添加可由代理处理的注释
  • 引入 Agent Host 架构，子代理在独立进程中运行，可在多个窗口共享会话
  • 新增 VS Code 实验性宠物，可通过 /vscode-pet 命令交互
  • 为终端可访问性提供更细粒度控制，可保留光标位置
  • 新增终端尺寸覆盖层设置，可关闭调整大小时的列行覆盖
  • Python 环境管理默认使用 Python Environments，提升项目启动速度并优化环境刷新
  • 扩展内置语音输入的平台支持：Windows、macOS Apple silicon、Linux（glibc≥2.34）及远程工作区

问题修复

  • 修复多处内存泄漏（abstractTaskService、abstractRuntimeExtensionsEditor…
  • 修复因现代 UI 样式导致的性能回归
  • 修复语音回归问题

JetBrains Toolbox 3.6.2.85969 → 3.6.3.86383 gpt-oss-120b

新内容

  • SSH 登录凭证更可靠，重连时不再重复请求用户名 / 密码
  • Remote Development SSH 连接默认迁移至 jetbrainsd，可在高级设置中关闭
  • 改进遥测与诊断功能

问题修复

  • 若干错误修复
