IDE / SDK 更新 - 2026-11-01

IDE 更新 • 2026年11月1日 • 6 分钟阅读

2026-11-01 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 新增 CLAUDE_CODE_DISABLE_ULTRATHINK 环境变量，用于关闭 ultrathink 关键词功能

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.314 → 2.1.316 Qwen/Qwen3.8-27B

新内容

  • 新增 CLAUDE_CODE_DISABLE_ULTRATHINK 环境变量，用于关闭 ultrathink 关键词功能
  • Claude apps gateway 新增池化组预算，支持团队成员共享月度预算，可通过 spend limits admin API 配置
  • 新增 CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP 环境变量，保留相互认证的循环系统交叉证书
  • 新增 CLAUDE_CODE_SUBAGENT_EFFORT 环境变量，独立设置子代理的 effort 级别，不再继承会话设置
  • Claude apps gateway 新增 managed.policy_mode: layered，支持多层策略叠加合并而非仅应用首个匹配策略
  • Bedrock 上游新增 guardrail.input_tagging，自动为提示词添加 Amazon Bedrock 护栏所需的输入标签
  • VSCode 插件支持从聊天面板直接登录 Claude apps gateway，无需终端操作
  • VSCode 中 ultrathink 现以 xhigh effort 运行并在聊天框中以彩虹色显示
  • 云会话新增表单卡片，支持填写或拒绝 MCP 服务器发起的表单请求
  • 云会话新增 “Catching up…” 状态行，显示消息同步进度
  • 企业成员现可自主在云环境中添加和删除网络密钥
  • 代码审查分析页新增按严重程度分类的发现卡片，含每日堆叠图表及计数统计
  • 优化 /code-review 在 Claude Desktop 和 Web 端的展示，云端会话现显示发现卡片而非纯文本列表
  • 优化大型仓库的 /diff 性能，减少全仓库 git 命令执行次数并错峰刷新
  • 改进无 GitHub remote 时的提示信息，明确指引创建仓库且不再建议无效的 gh 命令
  • 改进 SSL 证书错误提示，列出可能原因（如缺少中间证书）及对应修复方法

Breaking Changes

  • Opus 4.8 的 fast mode 已于 2026 年 10 月 30 日弃用，将于 2026 年 11 月 30 日移除…

问题修复

  • 修复 macOS 和 Linux 上 Claude Code 自行退出时 shell 命令残留运行的问题
  • 修复 Bash 工具中换行 bash 别名及以连字符开头的函数名被损坏或丢失的问题
  • 修复导出 SHELLOPTS 后 Bash 脚本执行首条命令即停止的问题
  • 修复 PowerShell hooks 在以类型转换、param、using 或属性开头时未正确阻塞 exit code 2 的问题
  • 修复压缩响应截断或损坏时部分网络请求挂起的问题
  • 修复 Vertex AI 和 Amazon Bedrock 上模型不可用时中途报错而非切换旧版模型的问题
  • 修复 Claude apps gateway 未校验请求中所有模型是否在可用 / 禁用列表中的问题
  • 修复受管设置要求使用 gateway 时 claude auth login 拒绝运行的问题
  • 修复 —restricted 会话在 Read allow 规则覆盖时上传工作目录外文件的问题
  • 修复包含不可见字符的提示需按两次 Enter 才能发送的问题
  • 修复继承父级子代理模型的子代理在后台任务唤醒时错误切换为主模型的问题
  • 修复无 “$defaults” 的 autoMode.allow 列表从主机应用设置等来源恢复内置例外的问题
  • 修复云会话和定时任务在 auto mode 因服务器未返回安全裁决而停止时未标记为失败的问题
  • 修复 claude -p 在后台代理运行时未说明 auto mode 停止原因的问题
  • 修复主机应用启动的会话中 CLAUDE_CODE_AUTO_MODE_SERVER=1 被忽略的问题
  • 修复凭据命名环境变量设为开关值时插件 MCP headersHelper 脚本收到损坏的路径和 URL
  • 修复 SDK register_repo_root 未加载工作目录外 CLAUDE.md 的问题
  • 修复 Artifact 工具在 self 级别显示？及拒绝重新发布时未引用规则的问题
  • 修复 /model 对当前版本不识别的模型未发出警告的问题
  • 修复 “按住空格说话” 提示在一次会话中耗尽三次显示机会及未绑定按键时显示空键的问题
  • 修复 Windows 上搜索进程超时被杀但未退出时 Grep 和 Glob 永不返回的问题
  • 修复罕见情况下恢复对话时计划未还原的问题
  • 修复窄终端下首次运行设置丢失安全说明和终端设置解释中的文字
  • 修复企业调查卡片在短暂停顿后接受输入的 1 或 0 而不需要 Enter 的问题
  • 自托管 runner：修复 Claude 工作时发送的消息在 Stop 后被回答的问题
  • 自托管 runner：修复会话迁移到新机器时 MCP 服务器开关有时丢失的问题
  • Windows Git Bash：修复 rc 文件设置 errexit 和 pipefail 且仅定义 winpty 别名时 Bash 工具丢失别名和函数的问题
  • VSCode：修复模型设置带 [1m] 标签时缺失 Effort 滑块、Ultracode 开关和模型名称的问题
  • VSCode：修复设置文件有错误时保存的 /btw 侧边问题历史被过早删除的问题
  • VSCode：修复计划以 “是，并手动批准编辑” 批准后重载或重启时对话回到 Auto mode 的问题
  • 云会话：修复 Claude 更改目录后文件搜索显示 ../.. 路径的问题，现显示项目根路径
  • Claude Tag：修复 Slack 频道中 canvas 共享到其他频道或 DM 后 Claude 拒绝编辑的问题
  • Claude Tag：修复两个组织均安装 Claude 时 Slack Connect 线程中未标记回复无人应答的问题
  • Claude Tag：修复云定时任务在 Slack 中的实时状态清单停留在半完成状态的问题
  • auto mode 变更：无 “$defaults” 的 autoMode.allow 列表不再移除定时任务提示的内置规则
  • Team 和 Enterprise 登录的服务端管理设置现无需审批提示即可应用，无法验证的存储副本将被拒绝
  • Slack 频道的 Respond automatically 开关改为 Configure 页面和管理设置中的 “How Claude participate…
