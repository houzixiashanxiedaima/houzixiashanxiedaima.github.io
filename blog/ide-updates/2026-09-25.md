### [Claude Code 2.1.281 → 2.1.282](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>deepseek-ai/DeepSeek-V4-Flash</sup>

**新内容**
- 新增 maxProseWidth 设置，限制宽终端中 Claude 散文宽度，表格和代码块保持全宽
- 新增启动通知及 /status、claude doctor 条目，列出被忽略或关闭的遥测变量
- 新增 allowClaudeInChromeWithManagedMcp 托管设置，允许与排他 managed-mcp.json 共存
- 新增 store.readiness_grace_seconds，使 /readyz 在短暂 Postgres 中断期间保持就绪
- 为 /feedback 草稿列表在全屏模式添加滚动条
- 改进大会话恢复时间，包括未压缩会话
- 改进 Windows 会话恢复失败时的错误提示
- 改进 Claude Desktop 未知模型错误建议切换模型
- 改进权限提示中异常 Unicode 渲染
- 改进 /artifacts 列表：标题对齐、详情整体显示、支持键盘和鼠标操作
- 更新 claude-api skill 计费说明与速率限制链接
- 更新 claude-api skill 推荐 ant apply 管理资源
- 自动模式默认使用服务端分类器（可退出，环境变量）
- 改变 sandbox.excludedCommands 生效条件，忽略项目/本地设置

**问题修复**
- 修复对话历史包含无法解密的搜索结果时所有请求返回 400 错误
- 修复继续或恢复会话时以更改形式重发早期消息导致推理丢失
- 修复扩展思考在斜杠命令或恢复场景中被丢弃，并重试无效思考块错误
- 修复压缩在摘要请求被拒时回退到备用模型重试
- 修复安全相关模型切换后 thinking 关闭时 effort 过高导致轮次失败
- 修复 Fable 使用额度提示相关问题（SDK 会话、/model 完整 id）
- 修复登录刷新竞争导致的长时间请求失败及策略获取不重试
- 修复文件系统安全：符号链接访问 macOS 系统路径、Bash 权限规则被跳过
- 修复托管设置锁定键输入错误被忽略及部分无效值导致整块设置失效
- 修复插件通过 allowed-tools 预授权自身工具及卸载时误删选项/密钥
- 修复 Bedrock 阻止消息缺少请求 ID，并修复 Vertex AI 新模型不支持网络搜索
- 修复多项终端渲染与交互问题：闪烁、乱码、过时字符、粘贴换行、滚动条窄列等
- 修复 vim 模式多项问题：缩进、计数、光标位置、重复操作等
- 修复 CLI 命令问题：remote-control --debug 报错、install-github-app 取消后仍执行、反馈保存取消后仍保存
- 修复 artifact 标签过长失败、PDF 错误信息乱码、屏幕阅读器空白行丢失
