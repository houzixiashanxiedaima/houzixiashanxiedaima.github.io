IDE / SDK 更新 - 2026-10-01

IDE 更新 • 2026年10月1日 • 7 分钟阅读

2026-10-01 IDE / SDK 更新：Android OS、VSCode、Claude Code 等 3 项工具有新版本 | 新增云端自主代理工作流，支持复杂多步骤任务在后台执行 | 新增 Copilot harness，提供跨 Copilot 产品一致的代理行为

#ide-updates #ide #automation #Android OS #VSCode #Claude Code

Android OS How R8 made Kotlin Coroutines on Android 2x faster → Build intelligent Android apps: In-app agentic workflows Qwen/Qwen3.8-27B

新内容

  • 新增云端自主代理工作流，支持复杂多步骤任务在后台执行
  • 引入 ADK 框架实现多智能体编排与协调
  • 支持 AG-UI 协议实现后端到设备的实时状态流式更新
  • 支持 A2UI 协议在 Jetpack Compose 中动态渲染交互式卡片
  • 新增 Booking Assistant 示例应用，演示航班、酒店等多场景预订

VSCode 1.139.1 → 1.140.0 Qwen/Qwen3.8-27B

新内容

  • 新增 Copilot harness，提供跨 Copilot 产品一致的代理行为
  • 新增多文件夹会话（实验性），支持在单个代理会话中跨多个文件夹工作
  • 新增 HydraFusion 模型编排（研究预览），自适应选择模型和工作流
  • 新增会话内归档聊天功能，可单独归档已完成的对等聊天
  • 新增自动 Dev Container 清理与更快启动选项
  • 新增远程代理主机任务委派（实验性）及内置工具支持
  • 新增个性化新会话欢迎语（实验性）
  • 改进会话编辑器控件（实验性）
  • 改进代理编排可靠性（实验性），减少协调密集型工作流中断
  • 支持通过 URL 在 Agents 窗口打开新会话
  • 新增持久化代理响应进度（实验性）
  • 终端输出重排优化，适配输出预览宽度
  • 支持在编辑器窗口中使用多个聊天
  • 支持将 MCP 服务器添加到便携式配置文件
  • 新增 Confetti 无障碍信号，为视觉障碍用户提供庆祝反馈
  • 新增跨 worktree 复用忽略文件夹（实验性），避免重复安装依赖
  • 新增控制选中文本匹配大小写敏感性的选项
  • macOS 高 DPI 显示器上终端文本更清晰（实验性）
  • 管理员可设置 AI 功能最低版本要求并解释原因
  • 管理员可为 Auto 模型设置默认层级
  • OpenTelemetry 中捕获用户身份，便于组织归属数据

Claude Code 2.1.285 → 2.1.286 Qwen/Qwen3.5-27B

新内容

  • 权限提示新增计数显示（如 “2 of 5”）
  • 全屏模式下列表的 “更多行” 支持鼠标点击跳转及悬停状态
  • 改进提交指导：若项目包含 verify 技能，提交前自动运行验证
  • 子代理视图中的立即发送（Ctrl+Enter）将命令移至后台以便快速响应
  • 优化背景代理回复格式，不再重复用户消息摘要
  • 统一各类权限提示（文件、网络、脚本等）的视觉样式
  • 全屏模式列表滚动条增加上下箭头按钮并优化布局稳定性
  • 外部编辑器（Ctrl+G）打开时直接定位到光标所在行
  • 斜杠命令建议响应更快，支持按单词前缀匹配描述
  • 输出风格选择器默认显示当前风格并移除数字键选择功能
  • 模型降级通知明确说明上下文窗口缩减情况
  • 协议页面更新以匹配当前发送行为并提示勿拒绝未知输入
  • 空闲时发送的提示词立即以正常颜色显示而非灰色
  • 插件安装限制为仅从注册表包安装依赖，拒绝 Git 仓库或文件夹源
  • 列表屏幕细节列对齐优化，溢出行文本改为 “↑ N more”/“↓ N more”
  • /hooks 命令改为按事件分组的单列表视图，减少操作步骤
  • 主题选择器改为适应终端宽度的滚动列表，移除数字键选择

安全修复

  • 修复错误消息中泄露凭证值（Bearer/Basic 密钥）的问题
  • 修复百分编码 Bearer Token 在错误消息中未完全掩码的问题
  • 修复含不可见字符（如零宽空格）的密钥名导致日志泄露秘密
  • 修复 URL 密码中含特殊字符或跨路径时部分泄露至日志和转录
  • 修复 /feedback 保存的 zip 中转录文件因脱敏产生无效 JSON 行

Breaking Changes

  • —bare 模式变更：仅连接命令行指定的 MCP 服务器，不发送系统提醒且不启动后台任务
  • —bare 模式下超时的 Shell 命令现在直接停止而非移至后台
  • 立即发送键（Ctrl+Enter）变更：将技能自身的 Shell 命令移至后台而非结束它
  • WebFetch 限流错误提示变更：告知 Claude 不要在循环中重试
  • 插件安装策略变更：拒绝从 Git 仓库或文件夹安装，仅限注册表包

问题修复

  • 修复多个进程同时打开登录浏览器的问题（GCP/AWS 凭证过期时）
  • 修复会话崩溃后 —resume/—continue 丢失所有对话轮次的问题
  • 修复工具返回非文本对象导致 API 400 错误的问题
  • 修复云会话因容器停止而永远无法唤醒的问题
  • 修复计费错误：1 小时缓存写入按 5 分钟低价计费及流式调用输入 token 统计错误
  • 修复 macOS 多窗口登录后仍显示未登录状态的问题
  • 修复模型被拒后重试失败的问题，现会重试同层级的上一个模型
  • 修复远程控制在组织策略关闭后仍保持连接的问题
  • 修复回退模型重试速度过慢的问题，现按标准速度执行
  • 修复无头会话重新认证后重复显示 MCP 认证提醒的问题
  • 修复 auth status 错误报告 Console 登录为 claude.ai 而非 api_key
  • 修复 /status 错误显示 Anthropic Profile 与 API Key 同时生效
  • 修复远程控制附件传输失败未通知及下载超时问题
  • 修复退出时到达的消息被标记已送达但未处理的问题
  • 修复 MCP 连接器在握手变更后长时间不列出工具的问题
  • 修复重复的 MCP 登录请求覆盖待处理链接导致失效
  • 修复 /usage 未统计服务器连接期间工具调用的问题
  • 修复插件因临时错误在会话中消失的问题
  • 修复子代理消息在转录中重复显示的问题
  • 修复子代理回传消息显示任务 ID 而非代理名称的问题
  • 修复前景子代理缺失任务跟踪工具的问题
  • 修复工作树隔离子代理重复加载 CLAUDE.md 的问题
  • 修复 Workflow 子代理因连接停滞被重启的问题
  • 修复对背景代理使用 /compact/clear/rewind 误操作主会话的问题
  • 修复后台作业等待批准时显示已完成的问题
  • 修复模型回退时重复发送提交归属提醒的问题
  • 修复全屏模式下点击折叠行空白处高亮但不展开的问题
  • 修复长名称动作行挤压其他行细节的问题
  • 修复超长文件名无法上传至云会话的问题
  • 修复插件市场拒绝加载时的错误提示不明确问题
  • 修复 /plugin Discover 标签页检查新插件时的引用格式不一致

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
