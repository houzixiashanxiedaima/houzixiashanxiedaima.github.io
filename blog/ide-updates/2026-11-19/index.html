VSCode 1.146.0 → 1.147.0 Qwen/Qwen3.8-27B

新内容

  • 新增 “稍后发送” 功能，支持将聊天请求保存为草稿或定时执行
  • 新增远程环境共享至 GitHub Environments 功能，支持跨设备同步 Agent 会话
  • 新增自动化（Automations）功能，支持基于触发器和条件自动运行任务
  • 新增模型路由器（Model Router），允许根据任务类型自动匹配首选模型
  • 新增浏览器使用（Browser Use）预览功能，允许 Agent 直接操作默认浏览器
  • 新增 Skills over MCP 支持，MCP 服务器可自动向模型提供技能
  • 新增在集成浏览器中预览远程 HTML 文件及打开非 localhost 链接的功能
  • 改进收件箱模式，按需要关注的程度对 Agent 窗口会话进行分组
  • 改进模型对比功能，使对比结果更易于查找和理解，并保留在对应聊天中
  • Agent 响应支持 HTML 预览和原生视觉展示，如图表和原型图
  • 支持在聊天中捕获、裁剪和标记图像，以及内联显示附件胶囊
  • 自定义设置中的扩展部分现在显示与编辑器扩展视图相同的详细信息
  • 辅助权限增加更多上下文，LLM 审查器会考虑请求来源和用户回答
  • Dev Container 重建时可保留聊天会话（实验性功能）
  • 其他应用截图可作为附件发送给 Agent（实验性功能）

Zulu JDK 17 17.0.21.0.3 → 17.0.21.1 Qwen/Qwen3.8-27B

新内容

  • 新增 JMX RMI 连接的专用反序列化过滤器
  • 支持跨域 Kerberos 票据的过渡路径验证
  • Windows MSI 安装程序支持可配置的 PATH 位置
  • 更新 IANA 时区数据版本

安全修复

  • 修复关键安全漏洞（CSPU 月度安全补丁）

Zulu JDK 21 21.0.13.0.3 → 21.0.13.1 Qwen/Qwen3.8-27B

新内容

  • 新增 JMX RMI 连接的专用反序列化过滤器
  • 支持跨 Realm Kerberos 票据的转接路径验证
  • Windows MSI 安装程序支持可配置的 PATH 位置

安全修复

  • 包含针对关键安全漏洞的月度 CSPU（Critical Security Patch Update）修复

Claude Code 2.1.326 → 2.1.327 Qwen/Qwen3.8-27B

新内容

  • 新增 /install-github-app 修改仓库前的确认提示
  • 新增 claude mcp add-json - 命令，支持从标准输入读取服务器 JSON 配置
  • 恢复会话时若早期消息无法加载，将显示提示行
  • /status 新增列表，展示损坏的代理、技能、命令及输出样式文件、键位错误等状态
  • /config 中当其他设置覆盖某项时，新增覆盖提示说明
  • 网关提示头新增 x-claude-code-managed-settings-checksum 字段
  • 支持通过 attributionProject 设置命名会话计费组
  • 新增 /tui classic 作为非全屏渲染器的名称，/tui default 仍可用

Breaking Changes

  • 账户变更后，部分预启动的后台会话将被丢弃
  • 终端中因用量限制暂停的工作流在登录后保持暂停，直到先前登录返回或输入提示词
  • 不再向未获取会话 token 的命令传递 CLAUDE_CODE_OAUTH_SCOPES，需要该变量的命令需手动设置

问题修复

  • 修复 worktree 模式下停止服务器时误删运行中会话 git-ignored 文件（如 .env）的问题
  • 修复自托管 runner 启动时删除 GIT_CONFIG_GLOBAL 指定目录的问题，现保留该目录并忽略变量
  • 修复项目作用域下 claude mcp add/remove 误删 .mcp.json 中其他顶层键的问题
  • 修复 /export 覆盖现有文件前不询问的问题，现会弹出对话框确认
  • 修复重启后按 Stop 已允许的命令仍在运行的问题
  • 修复 Enter 键关闭 /teleport 加载错误屏幕的问题
  • 修复在 /plugin 中点击后按 Enter 导致意外安装或禁用插件的问题
  • 修复用量限制菜单后多按一次 Enter 导致未输完的！命令执行的问题
  • 修复包含括号的 —disallowedTools 规则部分失效的问题
  • 修复自动模式忽略部分通配符 PowerShell 允许规则的问题
  • 修复自动模式下并行脚本触发权限提示和拒绝的问题
  • 修复嵌套 claude 使用自身 token 时被 forceLoginOrgUUID 拒绝的问题

  • 修复输出 token 限制截断后的压缩丢失工具调用及其结果的问题
  • 修复 /config 等命令的设置更改保存失败且无警告的问题，现会在提示下方显示
  • 修复 /rewind 在部分文件无法恢复时无提示直接关闭的问题

  • 修复拒绝写入超大文件后提示词冻结的问题，现显示简短预览

  • 修复不同模型的 in-process agent teammates 在主代理上下文限制处压缩并使用错误模型的问题
  • 修复完成的子代理以兄弟子代理的模型和 effort 恢复的问题
