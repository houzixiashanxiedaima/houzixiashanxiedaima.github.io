### [Claude Code 2.1.278 → 2.1.280](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Claude Opus 5.5 (claude-opus-5-5) 作为默认 Opus 模型，支持 1M 上下文

- 新增 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH 环境变量以调整 MCP 工具描述长度上限
