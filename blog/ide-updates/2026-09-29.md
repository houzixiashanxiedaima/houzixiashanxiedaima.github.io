### [Claude Code 2.1.283 → 2.1.284](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Claude Sonnet 5.5 (claude-sonnet-5-5) 作为 Anthropic API 默认 Sonnet 模型，支持 1M 上下文
- 自动模式读取工作目录外文件时新增“是，但下次再询问”选项，允许单次读取并保留后续提示
- Claude 应用网关在 /usage 和状态栏中显示美元金额的消费限额（如“$271.40 / $500.00”）
- 新增 effortSlider:decreaseEffort、increaseEffort 和 toggleUltracode 键绑定操作…
- 为 claude.ai 订阅者新增 /rate-limit-options 命令，便于查找使用限制相关设置
- 交互式终端新增 /mcp reconnect all 命令，一次性重试所有连接失败或需认证的 MCP 服务器
- Claude 应用网关启动时若 managed policy 的 availableModels 为空或缺少默认模型则发出警告
- Claude 应用网关遥测转发目标新增 auth: { google: {} }，支持直接导出至 Google Cloud OTLP 端点
- Claude 应用网关与身份提供商之间新增证书客户端认证 (private_key_jwt) 支持
