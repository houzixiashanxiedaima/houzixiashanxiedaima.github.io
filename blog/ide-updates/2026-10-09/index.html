IDE / SDK 更新 - 2026-10-09

IDE 更新 • 2026年10月9日 • 6 分钟阅读

2026-10-09 IDE / SDK 更新：Android Studio Canary、Claude Code 等 2 项工具有新版本 | 修复 ACP agent 在 npm registry 镜像未同步 ACP registry 固定版本时启动失败的问题（ETARGET）

#ide-updates #ide #automation #Android Studio Canary #Claude Code

Android Studio Canary Rabbit 2 Canary 3 → Rabbit 2 Canary 4 Qwen/Qwen3.8-27B

问题修复

  • 修复 ACP agent 在 npm registry 镜像未同步 ACP registry 固定版本时启动失败的问题（ETARGET）
  • 修复 Gradle 9.8.0 报告 Configuration 相关的问题

Claude Code 2.1.293 → 2.1.295 Qwen/Qwen3.8-27B

新内容

  • 新增命令和 HTTP 钩子的 onFailure: “block” 选项，失败时阻止操作
  • 支持程序状态协议 (OSC 7501)，终端可显示 Claude Code 工作状态
  • /copy 选择器支持引用文本，复制草稿消息时去除 > 标记
  • claude plugin install/enable/disable/marketplace add 在配置文件无法加载时发出警告
  • claude -p 运行时若保持打开，stderr 会显示当前等待内容
  • Claude apps gateway 上游支持 timeouts.upstream_ttfb_ms 超时设置
  • 停止回合时若 ← 正在等待工具完成，显示 “Backgrounding cancelled” 消息
  • Claude apps gateway 上游支持可选 models 列表，仅发送指定模型
  • 无托管设置的机器上支持 forceLoginMethod: “gateway” 和 forceLoginGatewayUrl
  • claude plugin validate 在插件 README 缺少安装行时提供建议
  • Claude apps gateway 推理审计事件新增 upstream_request_id 字段
  • mods 新增 $.ui.notify，通过通知设置触发原生通知
  • mod 的 Button 支持 children，允许包含字符串和 Text 元素
  • 新增 CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS 限制无人值守重试等待时间
  • Claude apps gateway 成功推理响应新增 request-id 头

问题修复

  • 修复网关拒绝 context-1m beta 时所有请求失败的问题，现自动重发
  • 修复 claude -p 文本输出在后台工作启动新回合时丢失早期响应的问题
  • 修复远程 MCP 服务器在长时间中断后保持断开或紧密循环重连的问题
  • 修复 MCP 服务器错误回复包含网络错误名称时连接被断开的问题
  • 修复 MCP 服务器重复分页游标导致同一页被请求多达 20 次的问题
  • 修复 MCP 工具返回的 CSS/JS/XML 文件被保存为 .bin 导致 Read 工具拒绝的问题
  • 修复 Bash 工具调用因模型传递 command_description 而非 description 而失败的问题
  • 修复 Claude in Chrome 未对端口 80 的站点拒绝规则应用的问题
  • 修复 /plugin Errors 标签页在 Enter 时未询问即移除市场并卸载插件的问题
  • 修复 claude plugin marketplace add 对无效市场报告成功的问题
  • 修复 CLAUDE_AUTO_BACKGROUND_TASKS 在编辑或 shell 命令等待时将子代理移至后台的问题
  • 修复 PushNotification 在特定情况下错误报告推送未发送的问题
  • 修复远程会话一次发送超过 256 个文件时被拒绝的问题
  • 修复登录刷新后启动时罕见地无法加载托管设置的问题
  • 修复 /tui 在无法重新启动 Claude Code 时无消息退出或显示原始系统错误的问题
  • 修复链接地址因颜色或隐藏样式而被隐藏的问题
  • 修复 Fable 模型在 Claude apps gateway 会话中不出现在 /model 选择器的问题
  • 修复 Claude apps gateway 管理员支出视图显示旧分组和上限的问题
  • 修复 CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 隐藏支出限制的问题
  • 修复独立 worktree 中的子代理显示父会话 git 分支、状态和提交的问题
  • 修复提示输入取消后台化时 Claude 停止工作的行为，现继续前台运行
  • 修复 —tools 和 —restricted 未应用于启动后注册的内置工具的问题
  • 修复中断在等待 MCP 服务器资源列表时直到超时而未结束回合的问题
  • 修复 mod 钩子接收被截断的深层嵌套工具输入且无错误的问题
  • 修复 Esc 无法停止已移至后台的自我节奏 /loop 的问题
  • 修复后台会话中的命令和钩子继承 FORCE_COLOR=3 导致输出包含颜色转义码的问题
  • 修复 claude agents 在会话打开时停止新后台服务导致关机延迟的问题
  • 修复名为 worker 的自定义代理在自动模式拒绝通知中显示为 “Agent” 的问题
  • 修复 Bash 权限检查对 glob 模式的 for 循环不准确的问题
  • 修复从 Workflow 子代理调用的分叉技能将结果发送到主对话而非调用代理的问题
  • 修复进程内代理队友首次 SendMessage 调用失败直到通过工具搜索加载工具的问题
  • 修复恢复时告知 Claude 未完成的后台工作流可能被 TaskStop 停止的错误信息
  • 修复从任务面板或连接客户端停止长时间运行的 MCP 工具调用时未告知 Claude 的问题
  • 修复后台会话的 /loop 在进程关闭时下次唤醒到期而无通知停止的问题
  • 修复回复或队友消息中的原始终端超链接字节被渲染为隐藏地址的可点击链接的问题
  • 修复具有大型 git 子模块的插件市场仓库添加或刷新失败的问题
  • 修复 /advisor 对话框对不再可用的已保存顾问模型显示勾选标记的问题
  • 修复移至后台的 MCP 工具调用通知显示缩短的任务 ID 的问题
  • 修复 vim 模式～将光标移过行末导致 x 无效及 3~ 跨行的问题
  • 修复从 macOS 粘贴带重音字符文本时光标位置偏移的问题
  • 修复响应达到数万行时终端冻结且 ctrl+c 被忽略的问题
  • 修复插件 hooks worker 重启期间 mod 重新加载时的调用绕过另一个 mod 守卫钩子的问题
  • 修复 hooks 模块代码嵌套数千层深的插件加载或验证时出现栈溢出错误的问题
  • 修复 claude plugin test 传递会移除真实会话保留块的 session.append 钩子的问题
  • 修复会话被杀死并第二次恢复后未告知 Claude 可用 SendMessage 恢复后台子代理的问题
  • 修复 Bash 命令如 cat 运行但未打印后文件被视为已读取的问题
  • 修复命名为 constructor 或 prototype 的插件选项始终读取默认值且不重新加载的问题
  • 修复 mod 热重载遗漏在 /reload-plugins 或会话启动期间保存的问题
