IDE / SDK 更新 - 2026-09-10

IDE 更新 • 2026年9月10日 • 3 分钟阅读

2026-09-10 IDE / SDK 更新：VSCode、Flutter SDK、Melos 等 3 项工具有新版本 | 新增 Automations（预览版）：支持按小时、每日或每周调度重复的 Agent 任务，也可按需运行 | 修复所有平台调用 Actions.handler 时始终返回 null 的问题

#ide-updates #ide #automation #VSCode #Flutter SDK #Melos

VSCode 1.136.2 → 1.137.0 Qwen/Qwen3.8-27B

新内容

  • 新增 Automations（预览版）：支持按小时、每日或每周调度重复的 Agent 任务，也可按需运行
  • 新增 Voice Mode（实验版）：支持通过语音与 Agent 交互，并可在其工作时进行打断或重定向
  • 支持在工作区中继续快速聊天：可将项目附加到现有快速聊天而不丢失对话历史或当前请求
  • 新增 Agent-queued messages：允许在 Agent 处理请求时排队发送消息，避免中断当前会话
  • 新增 Agent host：支持从多个 VS Code 窗口连接到同一 Agent 会话，基于 AHP 协议运行
  • 新增智能 diff 编辑器布局：支持在常规 diff、多文件 diff 和 Agents 窗口中统一选择内联、并排或自动布局
  • 多文件 diff 中显示二进制文件变更：如图片等二进制文件不再被省略，而是显示占位符并可打开标准 diff 视图
  • GitHub Pull Requests 扩展更新：加快 PR webview 打开速度，所有 github.com 链接默认由该扩展打开
  • 支持在任意聊天中附加 GitHub issue 或 pull request 作为上下文，无需手动复制内容
  • 新增 Markdown 编辑器中的 GitHub 链接支持（实验版）

Flutter SDK 3.47.2 → 3.47.3 Qwen/Qwen3.8-27B

问题修复

  • 修复所有平台调用 Actions.handler 时始终返回 null 的问题
  • 修复 Android 设备使用 B 系列 PowerVR GPU 的 Impeller 渲染器时出现的视觉异常和性能下降问题
  • 改进 macOS 或 iOS 构建时 Xcode 安装不完整或缺失的错误提示，避免未处理的 ProcessException 崩溃
  • 修复使用 Android SDK Command-line Tools 23.0+ 时 flutter doctor 错误报告 “Android license…

Melos 8.6.0 → 8.7.0 Qwen/Qwen3.8-27B

新内容

  • 新增 changed 命令，用于列出自指定提交或标签以来发生变化的包

问题修复

  • 支持 cli_util 0.6 和 pub_updater 0.6 依赖版本

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
