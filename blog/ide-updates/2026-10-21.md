### [Claude Code 2.1.304 → 2.1.305](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 sandbox.allowNestedUserNamespaces，允许 Linux 沙箱命令创建用户命名空间以绕过文件保护
- 新增 CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS，使无人值守重试模式能感知已解除的使用限制
- 改进 /usage：每条警告现在是一行修复建议并指明来源，按 f 可应用修复；VS Code 和 /doctor 中同步显示
- 改进 MCP 同意对话框，降低 Enter 键被误识别为接受的风险
- 改进 mod 的 Image 在 iTerm2 3.5+ 全屏渲染下正常显示图片而非仅替代文本
- Remote Control：改进 spawn-mode 消息，按 w 提示新模式已保存，后续启动时说明来源
- [VSCode] 新增“正在运行启动钩子”旋转状态及屏幕阅读器播报
- [Cloud sessions] 改进删除自托管环境的对话框与错误信息，明确阻塞原因和影响范围
- [Claude Tag] 将 Claude 未加入的公开 Slack 频道添加到管理端 Add place 搜索中
- [Claude Tag] 改进大型组织中的管理页面，插件、技能和捆绑包编辑在频道列表加载期间仍可操作
