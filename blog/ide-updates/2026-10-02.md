### [Claude Code 2.1.286 → 2.1.287](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.5-27B</sup>

**新内容**
- 新增 Claude Mods 功能，插件可修改更深层行为
- 内置 You should know 插件，由侧边代理监控并提示遗漏事项
- agents 视图新增 n: 过滤器，支持按会话名和任务匹配及展开折叠项
- OpenTelemetry user_prompt 事件新增 prompt_text 字段以兼容嵌套键后端
- MCP 服务器支持 URL 提示（如登录），旧版连接需配置 bareElicitationCapability
- Windows 启动时增加警告：禁用 Bash 工具将同时关闭 PowerShell 导致无 Shell 可用
- 自托管 Runner 内置 gh api（仅 REST），用于 macOS/Linux 未安装 GitHub CLI 的场景
- 优化 /config：循环设置支持左右键切换，窄终端堆叠显示，PgUp/PgDn 翻页
- 优化插件市场错误提示，明确说明被忽略原因及解决方法
- 优化插件列表显示依赖缺失状态，更新插件时自动重试未完成安装

**安全修复**
- 修复危险 rm 命令（如针对根目录或家目录）在重定向输出时绕过始终询问保护机制的问题
- 修复名为 __proto__ 的 MCP 工具导致组织级工具权限上限被静默丢弃的安全问题
