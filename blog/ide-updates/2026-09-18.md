### [Claude Code 2.1.273 → 2.1.274](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>deepseek-ai/DeepSeek-V4-Flash</sup>

**新内容**
- 内存严重时新增醒目警告，并提供释放内存或安全重启步骤
- 新增 CLAUDE_CODE_MCP_STARTUP_WAIT_MS 限制首轮等待 MCP 连接时长（0 为不等待）
- 新增 managed_settings_resolved OTel 事件，可记录管理设置摘要与脱敏配置
- 遥测 span 新增 effort 属性，网关遥测新增 enduser.sub 字段与并发超限警告
- 网关新增 Postgres 连接超时配置，并改进数据库不可达时的启动错误提示
- 全屏模式支持点击展开折叠的队友和代理消息
- 改进流式 JSON 会话启动，首轮不再等待短连 MCP 服务器
- 改进 Monitor 工具通知，合并脚本输出与退出，节省模型轮次
- 改进 Artifact 工具未登录提示与旧版发布阻止
- 移除代理工作树前增加子模块安全检查
- 改进 OTEL 原始请求日志，新增索引文件与关联属性
- 改进网关启动重试与限额检查，减少数据库往返，限流错误更明确
- 将 Bedrock、Vertex、Foundry 等默认切换为 v2 MCP 客户端与新版协议协商
- /code-review 改用精炼内联审查提示，减少子代理生成

**Breaking Changes**
- 默认对 Bedrock、Vertex、Foundry 等启用 v2 MCP 客户端与新版协议协商，可通过环境变量退出

**问题修复**
- 修复会话无限重试 tool_use_id 400 错误，转录损坏自愈或给出 /rewind 提示
- 修复 MCP 服务器连接与超时问题（http+SSE 4xx、Streamable HTTP 超时、列表不刷新）
- 修复 MCP 403 权限误报为登录过期，现指明权限并指向 /mcp 重新认证
- 修复钩子驱动会话上下文溢出后不压缩、活动 /goal 在恢复后丢失
- 修复 claude agents 自动更新后丢失启动参数（--model、--effort 等）
- 修复语言服务器诊断导致的性能下降，以及 headless 会话多次模型调用
- 修复 Bedrock/Vertex/Foundry 上子代理模型 opus 导致的会话模型切换问题
- 修复自托管 runner 令牌刷新失败后的持续 401 错误，现持续重试并获取新令牌
- 修复本地文件链接在 VS Code 等终端无效，以及 Linux Wayland 下多余空窗口
- 修复转录重新编号导致有序列表数字错乱，以及子代理消息重启后消失
- 修复 AskUserQuestion 预览注释与选项错位、提交时丢失高亮选项
