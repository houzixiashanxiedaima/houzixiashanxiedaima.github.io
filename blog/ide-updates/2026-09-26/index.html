IDE / SDK 更新 - 2026-09-26

IDE 更新 • 2026年9月26日 • 7 分钟阅读

2026-09-26 IDE / SDK 更新：VSCode、Claude Code 等 2 项工具有新版本 | 支持在 SSH、Tunnel 和 WSL 远程主机上的 Dev Container 中运行 Agent 会话

#ide-updates #ide #automation #VSCode #Claude Code

VSCode 1.139.0 → 1.139.1 Qwen/Qwen3.8-27B

新内容

  • 支持在 SSH、Tunnel 和 WSL 远程主机上的 Dev Container 中运行 Agent 会话
  • Agent 宿主基于 AHP 协议在专用进程中运行，支持多窗口连接同一会话
  • 优化大型 Agent 会话列表加载速度，首次列出提速约 12 倍，刷新提速约 4 倍
  • 新增紧凑视图模式，可在会话列表中显示更多会话并支持悬停查看详情
  • 支持在会话列表中直接重命名会话或嵌套聊天
  • 新增词换行指示器，通过箭头标识换行列位置
  • 改进括号自动闭合行为，避免输入时插入重复的右括号
  • AuthenticationSession API 提案新增 expiresAfter 属性以暴露访问令牌剩余有效期

Breaking Changes

  • Linux DEB/RPM 包桌面启动器文件名改为反向 DNS 格式，旧版固定启动器需手动重新添加

问题修复

  • 修复组织策略禁用 Agent 模式时的绕过漏洞（#336968）
  • 修复企业托管 OpenTelemetry 配置中的竞态条件问题（#336701）

Claude Code 2.1.282 → 2.1.283 Qwen/Qwen3.8-27B

新内容

  • 新增网关提示头 x-claude-code-prompt-id，支持 LLM 网关按用户提示分组请求（需启用环境变量）
  • 新增 availableModelsMatch 管理设置，支持精确匹配模型版本以阻止未列出的新发布
  • 新增 deniedModels 管理设置，允许在可用列表之外屏蔽特定模型
  • 新增 /doctor prompt-audit 命令，用于审计 CLAUDE.md、技能及代理中的旧版提示模式
  • 全屏模式下截断消息支持点击展开
  • stream-json 系统初始化错误中新增插件目录加载失败的路径信息
  • Claude apps 网关配置新增可选 load_test_mode，支持构建并签名但不发送上游请求的负载测试
  • Claude apps 网关新增 Mantle 上游提供商，支持 Amazon Bedrock 的 Mantle 端点
  • MCP 工具、WebFetch 和 WebSearch 输出在启用 OTEL_LOG_TOOL_CONTENT=1 时加入 OpenTelemetry spa…
  • 优化 /mcp 工具列表：显示更多工具、支持翻页与鼠标滚动、标记组织屏蔽的工具
  • 优化 MCP 工具结果：返回的图片现保存至文件，供 Bash、Read 等工具读取
  • 优化 /tasks 界面：显示状态图标、名称及关键事实，支持分页、鼠标滚轮与点击
  • 优化多个选择器列表（如 /help、/hooks 等）的分页、鼠标滚轮与点击交互
  • 优化压缩动画：计时器从压缩开始启动，并实时统计摘要 token 数
  • 优化首次响应延迟：模式编译步骤移至流式传输期间执行，复用预连接 API 连接
  • 优化启动性能：claude -p 和 Remote 不再加载交互式 UI，部分规则与工具改为按需加载

安全修复

  • 修复 Windows PowerShell 工具允许 cmd /c rd, rmdir, del 或 erase 删除驱动器根目录、主文件夹等敏感路径的问题

问题修复

  • 修复 SDK 会话在提前结束、工作进程重启或非流式回退时丢失延迟工具调用、审批提示或使用量数据的问题
  • 修复长时运行工具转入后台后 MCP 进度通知被丢弃的问题，现在显示最新进度
  • 修复会话结束时 stdio MCP 服务器仍在启动过程中未被正确终止的问题
  • 修复无状态远程 MCP 服务器短暂返回 HTTP 404 导致整个会话期间不可用的问题
  • 修复无有效 URL 的 MCP 服务器登录失败时显示不透明 SDK 错误的问题
  • 修复遥测禁用时每周 Fable 限制未在 /usage 和 VS Code 用量表中显示的问题
  • 修复 /model 接受带有日期或 -v1:0 后缀的 Sonnet 4.6/5 [1m] ID 的问题
  • 修复 /model 选择器在 ANTHROPIC_DEFAULT_HAIKU_MODEL 固定其他模型时显示硬编码 Haiku 版本和价格的问题
  • 修复模型回退期间启动的动态工作流所有代理均使用回退模型而非重试配置模型的问题
  • 修复 DISABLE_PROMPT_CACHING_HAIKU 在 Haiku 为主模型时无效的问题
  • 修复 claude plugin validate 接受无法安装的插件或市场名称的问题
  • 修复 claude plugin validate 通过 outputStyles、themes 等路径缺失或指向外部目录的插件的问题
  • 修复 claude plugin details 对声明了 MCP 服务器的插件显示为 0 个的问题
  • 修复 claude plugin marketplace remove 未列出随市场卸载的已安装插件的问题
  • 修复 claude plugin uninstall 误删仅大小写不同的另一个已安装插件及其选项和密钥的问题
  • 修复未声明版本的插件在缓存文件缺失时静默恢复至源最新提交而非已安装版本的问题
  • 修复用户安装的插件和市场在移动主目录或配置目录后加载失败报 cache-miss 的问题
  • 修复 installed_plugins.json 包含无效插件 ID 记录时显示为空的问题
  • 修复 installed_plugins.json 包含当前版本无法读取的记录时被重写并丢失数据的问题
  • 修复屏幕阅读器模式下权限对话框将引用的命令和路径读作对话框自身文本的问题
  • 修复 /context 未计算 MCP 服务器指令的问题，现在单独显示并计入总数
  • 修复 Warp 终端中 Markdown 链接渲染为纯文本而非可点击超链接的问题
  • 修复 claude mcp add/add-json/remove 在配置文件无法写入时仍报告成功的问题
  • 修复云会话中回复开头几个字有时延迟出现而非流式输出的问题
  • 修复内置键位指南错误地说明组合键超时时间为 1 秒（实为 3 秒）及 cmd 是 meta 别名的问题
  • 修复 keybindings.json 静默接受拼写错误的修饰键（如 ctl+k）而不警告的问题
  • 修复重新绑定或解绑 footer:openSelected 后底部提示仍显示 Enter to view 的问题
  • 修复快速连续按键（预输入、重复、ssh/tmux 突发）有时针对过期状态处理的问题
  • 修复 worktree 检出在通过 GIT_CONFIG_COUNT 传递 CA 证书时 Git LFS 下载证书验证失败的问题
  • 修复沙箱化 git 询问凭据助手存储沙箱代理登录信息导致打印 failed to store 的问题
  • 修复嵌套值无效时托管沙箱设置被完全忽略的问题，现在无效值失败关闭且其余块生效
  • 修复在 git 仓库子目录启动时 Claude 对自身自动记忆笔记的编辑被阻止为敏感文件写入的问题
  • 修复付费计划在禁用遥测时远程控制不可用的问题
  • 修复窄终端下 /remote-control 菜单 QR 码提示中途截断单词的问题
  • 修复 vim 模式。命令丢失 Shift+Enter 换行、光标停留在重音字母内及重复旧更改的问题
  • 修复 vim 模式光标定位问题：正常模式下回忆超长提示词光标越界，V 后 p 未落在首个非空白字符
  • 修复 vim 模式 J 合并行间距与 Vim 不一致及 3J 或可视模式 J 在最后一行光标移动异常的问题
