### [Xcode 27.1 → 27.2](https://developer.apple.com/documentation/xcode-release-notes/xcode-27-release-notes) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- Xcode 27 包含 Swift 6.4 及 iOS、iPadOS、tvOS、watchOS、macOS 和 visionOS 27 SDK
- 支持在 iOS 17+、tvOS 17+、watchOS 10+ 及 visionOS 上进行设备端调试
- Apple Clang 编译器新增对类内 C++ 运算符的 API Notes 注释支持
- Background Assets 清单现支持路径通配符、文件排除、硬编码源根目录及自定义目标子路径
- 新增本地化资源包功能，系统可根据用户首选语言自动分发相应的本地化资源包
- 新增 Steam Asset Converter 工具，可将 Steam “depots” 转换为资产包
- 调试时可通过 Run scheme 选项卡中的 Background Asset Packs 文件夹向应用提供资产包
- C++ 标准库实现了多项新提案，包括 std::chrono 哈希支持、zip、std::optional 等
- C++ 标准库性能显著提升：关联容器最高提速 11 倍，分段迭代器算法最高提速 1600 倍
- C++ 标准库多项内部重构优化编译速度并减少调试信息，std::align 现为内联函数
- Coding Intelligence 编程助手现支持 Google Gemini
- CarPlay Simulator 修复了通过 Device Hub 访问时无法启动 CarPlay 连接的问题

**Breaking Changes**
- Xcode 27 要求运行 macOS Tahoe 26.6 或更高版本的 Mac
- C++ 标准库最低支持的 macOS 部署目标提升至 11.0
- multi{map,set}::find 算法不再保证返回容器中第一个相等元素的迭代器
- std::{map,set} lower_bound 和 upper_bound 对非严格弱序比较器的结果行为发生变更
- ABI 标志 _LIBCPP_ABI_NO_REVERSE_ITERATOR_SECOND_MEMBER 从 _LIBCPP_ABI_NO_ITERATOR_…
- ranges::iota_view 现支持 __int128，某些情况下 difference_type 从 long long 变为 __int128
- std::allocator 现为平凡默认可构造类型，可通过定义宏恢复旧行为
- bitset::operator[] 现返回 bool 以符合标准，可通过定义宏恢复旧行为

**问题修复**
- 修复 Scheme 操作工具栏按钮在处理 Control 键变体时的行为，使其恢复为正常构建后执行操作
- 修复在 macOS Tahoe 26.5.1 及更早版本上安装 Xcode 27 beta 导致虚拟机安装失败的问题
- 修复在未安装 Xcode 27 的 Mac 上用于开发的设备兼容性，无需重启即可在未升级的 Mac 上继续开发
- 修复 ba-package 打包工具在指定按需下载策略时可能生成无效资产包存档的问题
- 修复 Siri 在尝试使用 App enum 值触发 AppShortcut 短语时可能生成意外响应的问题

### [Claude Code 2.1.312 → 2.1.314](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>本地降级</sup>

**原始更新记录**
- Added permissions.blockWritesOutsideWorkingDirectories: Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode
- Added an optional groups list to Claude apps gateway upstreams: only developers in the listed IdP groups are sent to that upstream, on failover too
- Added guardrail_trace to Claude apps gateway Bedrock upstreams, to log which Amazon Bedrock guardrail filter fired on a request, without the matched text
- Added idle compaction to VS Code and Claude Desktop's Code tab: a 200K+ token conversation left idle is summarized, and the summary is used on your next message if the prompt cache has expired
- Fixed sessions failing turn after turn with "Invalid effort level" when an organization's admin caps a model's effort: Claude Code now lowers the effort, retries, and says which level it uses
