IDE / SDK 更新 - 2026-09-23

IDE 更新 • 2026年9月23日 • 5 分钟阅读

2026-09-23 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 新增 Claude Opus 5.5 (claude-opus-5-5) 作为默认 Opus 模型，支持 1M 上下文

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.278 → 2.1.280 Qwen/Qwen3.8-27B

新内容

  • 新增 Claude Opus 5.5 (claude-opus-5-5) 作为默认 Opus 模型，支持 1M 上下文
  • 增强全屏模式鼠标支持：滚轮可滚动 /skills 列表，/plugin 中技能状态选项可点击
  • 新增 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH 环境变量以调整 MCP 工具描述长度上限
  • 在 hook_execution_complete OpenTelemetry 事件中增加钩子输出大小及超限文件数量统计

问题修复

  • 修复通过符号链接路径写入时权限校验错误的问题
  • 修复自动模式下安全检查拒绝或无响应时的无限重试问题
  • 修复 Write 调用因参数名不匹配导致的验证失败
  • 修复多数对话框中按两次 Ctrl+C/Ctrl+D 会退出程序而非关闭对话框的问题
  • 修复终端窗口聚焦点击误触发指针下方元素的问题
  • 修复 y/n 键意外确认或关闭对话框的问题（Enter/Esc 现为默认）
  • 修复对话框文本框按键绑定导致字符丢失的问题
  • 修复 Windows 终端移除不可见字符后提示行乱码的问题
  • 修复不可见字符清理误删波斯语 / 阿拉伯语零宽非连接符的问题
  • 修复语音听写未正确停止、取消或误触发的多项问题
  • 修复从宿主应用切换模型导致提示缓存失效的问题
  • 修复恢复分叉子代理时重建工具列表破坏提示缓存的问题
  • 修复子代理交接消息在非详细模式下显示内部来源前缀的问题
  • 修复插件更新后 installed_plugins.json 保留旧提交哈希的问题
  • 修复～/.claude/skills/ 中的技能被 manifest.json 误移至回收站的问题
  • 修复会话反馈调查在浅色和 ANSI 主题下无悬停高亮的问题
  • 修复 /workflows 打开前短暂显示单行列表的问题
  • 修复全屏模式下隐藏选项的列表无法用滚轮滚动的问题
  • 修复已禁用技能与加载失败插件在 /plugin 和 /skills 中图标混淆的问题
  • 修复多选选项描述缩进位置错误的问题
  • 修复全屏模式下 /plugin、/skills 和 /mcp 搜索框右侧边框丢失的问题
  • 统一 /mcp 服务器列表与详情视图的状态图标为
  • 修复 /config 设置列表及选择列表中 Home/End 键无效的问题
  • 修复 /skills 菜单中 PgUp/PgDn 越过首尾项循环的问题
  • 修复 /config 列表中 Tab 键意外更改设置值的问题
  • 修复每轮对话因 ‘role system’ 顺序错误导致 API 报错的问题
  • 修复代理网关不支持特定输入标签导致顾问对话失败的问题
  • 修复保存历史中包含畸形 MCP 通知导致会话和 /compact 失败的问题
  • 修复恢复包含畸形系统消息或缺少文件列表的记忆通知的会话时崩溃的问题
  • 修复损坏的缓存消息列表导致长时会话因界面错误退出的问题
  • 修复配置文件被替换为命名管道时 Claude Code 挂起的问题
  • 修复～/.claude.json 中残留 null/false 值导致 /config 崩溃或偏好读取错误的问题
  • 修复恢复含未完成后台任务的会话时自动启动模型回合的问题
  • 修复无头 / SDK 会话中发送给正在结束的子代理的消息丢失的问题
  • 修复压缩对话导致已完成子代理报告丢失的问题
  • 修复启用 LSP 插件时后台子代理无法使用 LSP 工具的问题
  • 修复后台 shell 任务将良性非零退出码误报为失败的问题
  • 修复环境变量含 NUL 字符时后台会话无法运行 git/hooks 等辅助程序的问题
  • 修复存在后台子代理时需按三到四次 Ctrl+C 才能退出的问题
  • 修复 IDE 选区在编辑、回退或启动钩子运行时丢失的问题
  • 修复！shell 模式提示暂存后恢复异常及 / 命令列出文件路径的问题
  • 修复临时目录满或不可写时 claude agents 显示空白屏幕而非错误信息的问题
  • 修复重新添加同名 MCP 服务器后仍显示需认证而非重连的问题
  • 修复自托管 runner 生命周期钩子在 —configure-git 下签名失败的问题
  • 修复 Windows 后台清理误删用于重定位的目录符号链接或 junction 的问题
  • 修复自托管 runner 在 —retire-at 释放点结束时丢失完成信号的问题
  • 回退 2.1.260 引入的全屏模式下 ctrl+l/cmd+k 清除转录视图的行为，现改为重绘屏幕
