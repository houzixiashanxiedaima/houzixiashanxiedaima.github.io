### [Claude Code 2.1.309 → 2.1.310](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Monitor 工具及插件监控，支持 Bedrock、Vertex 和 Foundry，并在禁用遥测或非必要流量时生效；同时在此类场景下阻止长时间前台休眠
- 改进自动模式在首次读取工作目录外文件前的提示，明确说明阻止此类读取会导致 shell 命令请求权限
- 优化非交互式会话（-p、Agent SDK）在转录文件极大时的压缩内存占用
- 改进 tmux 中启用 allow-passthrough 和 focus-events 时，kitty…
- Linux：改进 /sandbox 及沙箱启动警告，明确指出 Ubuntu AppArmor 对用户命名空间的限制及解除方法…
- 更改 MCP 工具调用在非交互式会话中超时且服务器 elicitation 未响应时的错误信息，告知 Claude 无响应且不重复调用
- [VSCode] 修复按 Enter 键点击计划审查卡片的“发送反馈并继续规划”按钮时误批准计划而非返回评论的问题
- [VSCode] 修复从会话历史 Web 标签页打开的云端会话执行“切换分支并继续”后面板显示“出错了”的问题
- [云端会话] 将 Claude Code 云端会话和远程控制权限添加到企业自定义角色，允许所有者按角色控制访问
- [云端会话] 新增“选择文件”按钮，可从文件加载云端环境的设置脚本
- [云端会话] 改进会话启动检查清单，在滚动框中显示云端环境的设置脚本输出
- [Claude Tag] 修复 Claude Tag 管理频道和工作区页面在后台刷新捆绑列表失败时被加载错误替换的问题
- [Claude Tag] 修复 Claude Tag 管理设置中的支出限制页面在频道名称仍在加载时报告没有频道匹配过滤条件的问题
- [代码审查] 改进代码审查管理部分，首次加载失败时重试并显示一个“再试一次”横幅

**问题修复**
- 修复某些网关和兼容服务器拒绝 effort-2025-11-24 beta 值或对话中途系统消息导致请求失败的问题；现在会自动重试而不包含这些内容
- 修复当 cleanupPeriodDays 设置为极大值时，后台清理删除近期文件（如粘贴的图片）的问题
- 修复“Prompt is too long”错误后的压缩保留过多密集文本（如 base64 或 SVG）导致下次请求再次失败的问题
- 修复文件读取权限提示未显示符号链接指向位置的问题
- 修复外部编辑器在长时间编辑后关闭时，问题的自动继续超时立即触发的问题
- Windows：修复 Git Bash 缺失且钩子命令仅为带引号字符串（如带引号的路径）时…
- [云端会话] 修复云端环境编辑对话框中保存和归档失败时对话框内不显示错误的问题
- [云端会话] 修复例程 API 令牌操作失败时仅显示 toast 的问题；错误现在会出现在例程编辑对话框中
- [云端会话] 更改管理员设置中开启云端会话或远程控制时需确认并列出拥有该权限的自定义角色
- [云端会话] 更改云端环境对话框，从行中打开网络访问、设置脚本和环境变量，而非一次性列出所有编辑器
- [Claude Tag] 修复 Claude Tag 在粗体、斜体或删除线中发送时将 !restart 和 !help 等 ! 命令视为普通消息的问题
- [代码审查] 修复代码审查管理部分在仓库列表刷新失败后隐藏其仓库和开关的问题
