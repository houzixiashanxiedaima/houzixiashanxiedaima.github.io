### [VSCode 1.145.2 → 1.145.3](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_145.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 远程代理主机连接浏览（预览）：在 Agents 窗口中通过远程主机加载页面并预览开发服务器
- 远程画布（预览）：支持在远程会话中使用画布功能
- 混合 Agent 框架（预览）：允许在单个主聊天会话中嵌套多个相关对话
- 本地自动化 Cron 调度与自定义 Agent：支持使用五字段 cron 表达式精确调度任务
- 固定画布至侧边栏（实验性）：可将常用画布固定在左侧边栏以便快速访问
- Copilot 框架成为新会话默认选项，基于 Copilot SDK 构建以统一行为与能力
- 工作集改进（实验性）：优化对 Copilot 框架会话中待处理编辑的审查体验
- 沙箱不可用时的改进指引：当组织强制要求沙箱但机器无法运行时，提供清晰的警告与解决建议
- Agent 详细程度选择（实验性）：可在简洁模式与详细推理/工具调用模式间切换
- 聊天性能优化：更平滑地重新打开和浏览长对话，复用推理标题并即时渲染终端输出
- 内联聊天附件（实验性）：支持将文件引用等上下文直接附加在对应指令旁
- 从任意位置附加文件：可通过标准文件对话框添加工作区外的文件（如截图、设计稿）
- MCP 应用工具支持：MCP 服务器提供的交互式界面可注册供语言模型调用的工具
- 企业托管 MCP 白名单优先级提升：托管 allowedMcpServers 列表优先于仅注册表访问限制
- 排除文件夹中显示特定文件：支持在 files.exclude 和 search.exclude 中精细控制文件可见性
- Mermaid 图表智能子图标题：边线不再遮挡子图标题，标题会自动移至侧面
- GitHub Pull Requests 扩展进展：新增多项功能以支持拉取请求和问题的创建与管理
- Timeline API 定稿：Marketplace 扩展可向时间线视图添加自定义历史记录
- Blobby 跳跃游戏（实验性）：在聊天中输入 /vscode-pet 即可与 VS Code 宠物互动

**安全修复**
- 修复 1.145.3 版本中的安全漏洞

**Breaking Changes**
- Local 框架移除 Install Extension (#installExtension) 工具，Agent 不再自动安装扩展
- Local 框架移除 Run VS Code Command (#runCommand) 工具，依赖该工具的内置工作流已适配
- Local 框架移除 Create New Workspace (#newWorkspace/#new) 工具及 /new 斜杠命令…

**问题修复**
- 修复组织禁用 Claude/Codex Agent 后用户获得只读聊天且无法新建会话的问题，现回退至默认框架并保留未发送提示词
- 修复 GitHub Copilot 策略刷新失败时 MCP 注册表限制被临时移除的问题，现保留最后已知策略直至成功刷新
- 修复组织强制要求的插件在 Customizations 视图中显示卸载按钮但操作始终失败的问题
