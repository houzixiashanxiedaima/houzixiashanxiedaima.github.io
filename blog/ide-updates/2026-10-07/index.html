IDE / SDK 更新 - 2026-10-07

IDE 更新 • 2026年10月7日 • 6 分钟阅读

2026-10-07 IDE / SDK 更新：Claude Code 等 1 项工具有新版本 | 新增 --marketplace 参数支持在插件安装时自动添加市场

#ide-updates #ide #automation #Claude Code

Claude Code 2.1.289 → 2.1.292 Qwen/Qwen3.8-27B

新内容

  • 新增 —marketplace 参数支持在插件安装时自动添加市场
  • Agent 工具新增 effort 参数，允许指定子代理运行强度
  • 新增 CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS 环境变量以调整过载重试延迟
  • 新增 prompt.autocomplete 事件供 Mod 扩展提示框自动补全列表
  • 为 $.model.complete 增加提示缓存功能，支持按块缓存请求
  • agent.spawn Mod 钩子新增工作流代理信息，支持拒绝特定代理
  • 优化 claude -p 和 SDK 会话启动速度，不再等待 MCP 服务器响应
  • 提升长列表回复的渲染、缩放及转录重开速度
  • 改进 Ctrl+C 草稿恢复机制，清空后仍可通过 Up 键找回
  • 优化钩子输出处理，转义标签以防止注入
  • 优化工具输入容错性，Grep 支持 file_path，部分工具忽略多余参数

安全修复

  • 修复 PreToolUse 钩子和自动模式绕过网络路径文件读取权限提示的问题
  • 修复沙箱命令可读取～/.claude/seed-admin 下 /ultrareview 上传文件副本的问题
  • 修复 macOS 和 Windows 上通过链接替换读取未授权外部文件的安全漏洞
  • 修复篡改磁盘上的服务器管理设置缓存可关闭内置策略插件的问题
  • 修复 Windows 下使用短名或替代拼写执行 rm -rf 未被识别为删除主目录的问题
  • 修复托管沙箱读拒绝路径变更时未撤销项目权限或停止凭据注入的问题

问题修复

  • 修复 permissionMode: auto 的子代理定义在自动模式不可用时错误进入该模式的问题
  • 修复 NO_PROXY 在设置 HTTPS_PROXY 时被 Claude Code API 请求忽略的问题
  • 修复名称超过 128 字符的 MCP 工具导致所有请求失败的问题
  • 修复首次运行时组织托管设置加载前执行插件命令的问题
  • 修复一次性运行过早终止后台命令及丢失计划唤醒的问题
  • 修复从会话选择器恢复时计划模式未正确还原的问题
  • 修复 /resume 等操作后创建的保存任务永不触发的问题
  • 修复后台会话进程重启后 /loop 静默停止的问题
  • 修复 Grep 和 Glob 在无法读取文件时报告无匹配而非重试或报错的问题
  • 修复 Read 工具处理 PDF 页码列表时仅返回第一项且不报错的问题
  • 修复 @- 提及的大于 256KB 文本文件被静默忽略的问题
  • 修复用量限制警报在多个后台代理中重复出现的问题
  • 修复桌面应用或 IDE 托管会话中远程查看者看到空白子代理面板的问题
  • 修复跨会话通知将相似名称会话合并显示及过期通知归因错误的问题
  • 修复桌面应用中 Send now 结束正在等待的子代理回合的问题
  • 修复发送报告期间使用快捷键导致 /bug 等命令重置或误报取消的问题
  • 修复 /remote-env 立即回车时覆盖默认环境变量的问题
  • 修复多次粘贴重叠时部分文本被当作输入文本发送给 Claude 的问题
  • 修复 Vim 模式下光标位置异常及按键跳转逻辑错误的问题
  • 修复 /add-dir 路径框允许换行及快速按键误触的问题
  • 修复选中提示页脚行时快速输入、输入法文本及分解重音丢失的问题
  • 修复 iTerm2 全屏模式下窗口调整大小产生大量陈旧滚动记录的问题
  • 修复符号链接目录下设置 Read 拒绝规则时出现虚假检查备注的问题
  • 修复 /cd 或权限变更后指令文件状态行过时或缺失的问题
  • 修复压缩摘要重复 /name 导致 Claude 调用保留技能的问题
  • 修复工具行隐藏 Mod 拒绝原因的问题，现在会显示具体理由
  • 修复云会话在 worker 停止时显示未结束回合的问题
  • 修复大型转录云会话在批准后再次请求权限的问题
  • 修复消息重试或编辑时云会话丢失计划任务和队列通知的问题
  • 修复容器重启后云会话忘记客户端选择的思考设置的问题
  • 修复 Cowork 云会话在无法确认组织设置时错误提示代理阻止的问题
  • 修复频繁调用 $.state 的插件钩子模块加载缓慢的问题
  • 修复 claude plugin validate 错误列出引擎从其他位置读取的值的问题
  • 修复插件提供的 $ 方法重启钩子源导致守卫钩子无限循环的问题
  • 修复插件钩子 worker 重启期间接口调用缺失其他插件钩子的问题
  • 修复 Mod 钩子在调用 next (e) 后拒绝时被错误报告为失败的问题
  • 修复主题保存发生在插件 config.set 钩子询问之前的问题
  • 修复插件 tool.check 钩子允许运行需用户确认的工具而不显示对话框的问题
  • 修复 hooks worker 替换时 Mod 启动提示或子代理被二次排队的问题
  • 修复回合中断时调用 next (e) 后失败的钩子未被拒绝的问题
  • 修复插件提示丢弃或设置拒绝因原因过长而被忽略的问题
  • 修复组织插件重载或崩溃时错误卸载用户 Mod 的问题
  • 修复插件钩子 worker 重启期间工具调用缺失权限钩子的问题
  • 修复插件 tool.call 钩子在参数修复前看到工具调用的问题
  • 修复另一 Mod 钩子调用下守卫钩子的 .catch 被静默跳过的问题
