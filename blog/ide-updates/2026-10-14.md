### [VSCode 1.141.0 → 1.141.1](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_141.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Copilot harness，提供与 GitHub Copilot 产品一致的代理功能
- 支持跨平台沙箱化，限制代理对文件和网络资源的访问
- 新增工作树清理功能，可手动或自动回收非活动代理会话的磁盘空间
- 支持在 Agents 窗口中网格排列会话，便于对比结果和监控任务
- 新增后台 Shell 跟踪功能，可查看正在运行的命令及其输出流
- 支持多个 GitHub Enterprise 实例登录，方便在不同企业实例间切换
- 新增 Codex 聊天交接功能，可在 VS Code 中继续 ChatGPT 或 Codex CLI 中的对话
- 新增远程文件下载功能，可直接从编辑器保存远程文件到本地
- 新增紧凑布局密度选项，提升 Agents 窗口的内容显示效率
- 新增自定义新会话欢迎消息、上下文选择器位置改进等实验性功能

**安全修复**
- 使用统一托管设置强制启用沙箱化，防止绕过（预览版）

**Breaking Changes**
- 旧版 VS Code 策略迁移至 Agent Host 托管设置，部分旧版沙箱设置和设备策略已弃用
