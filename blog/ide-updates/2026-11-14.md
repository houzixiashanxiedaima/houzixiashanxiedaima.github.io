### [Claude Code 2.1.322 → 2.1.325](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增代码模式（Code Mode），实验性选项，允许 Claude 编写 JavaScript 调用工具
- 插件系统支持在 plugin.json 中声明 engines["claude-code"]，限制插件安装与加载的版本范围
- claude plugin validate 新增 TypeScript hooks 模块类型检查及 $ 名词变更报告
- 支持 CLAUDE_CODE_AUTO_MODE_MODEL 环境变量用于第三方提供商的 Claude Desktop 会话
- 模型用量额度不足时新增操作菜单（停止、切换至使用额度、升级）
- 长耗时 hooks 运行时每 30 秒发送进度心跳，防止宿主误判为挂起
- Artifact 工具资产上传新增 .docx 格式支持
- diff 面板新增 /diff 关闭提示，? 快捷键指南新增面板聚焦与关闭按键说明
- 启动时检测 Bash allow 规则变量值中的通配符并给出警告
- 插件语言服务器启动失败时显示具体名称与排查建议
- 检测到 Perforce 配置且未开启对应模式时显示一次性启动提示
- 新增 CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES 环境变量以禁用子代理进度摘要
- 新增 CLAUDE_CODE_RESUME_HINT_COMMAND 环境变量自定义退出时的恢复命令提示
- claude plugin install --json 结果新增 unsetOptionCount 字段
- mod 面板绘制 props 新增 isPromptCovered 属性
- VS Code 等集成终端中读取或编辑 Jupyter notebook 后显示重运行单元格的旋转提示
- 组织策略阻止请求时在错误下方新增继续操作的指引（/rewind 或 /clear）
- 沙箱化 git checkout/stash/autostash pull 无法更新受保护文件时为 Claude 添加说明

**安全修复**
