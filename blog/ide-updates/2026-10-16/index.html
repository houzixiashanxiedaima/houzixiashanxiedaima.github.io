2026-10-16 IDE / SDK 更新：Android Studio Canary、Xcode 等 3 项工具有新版本 | Android Studio Rabbit 2 Canary 5 已在预览渠道发布

#ide-updates #ide #automation #Android Studio Canary #Xcode #Claude Code

Android Studio Canary Rabbit 2 Canary 4 → Rabbit 2 Canary 5 Qwen/Qwen3.5-27B

新内容

  • Android Studio Rabbit 2 Canary 5 已在预览渠道发布

问题修复

  • 修复 Android CLI 中 android describe 命令无法使用的问题

Xcode 27.0 → 27.1 Qwen/Qwen3.8-27B

新内容

  • Xcode 27 包含 Swift 6.4 以及 iOS、iPadOS、tvOS、watchOS、macOS 和 visionOS 27 的 SDK
  • 支持在 iOS 17+、tvOS 17+、watchOS 10+ 及 visionOS 上进行设备端调试
  • Apple Clang 编译器新增对类内 C++ 运算符使用 API Notes 进行注释的支持
  • Background Assets 清单现支持路径通配符、文件排除、硬编码源根目录及自定义目标子路径
  • 新增本地化资源包，系统可根据用户首选语言自动分发相应的资源包以减少存储占用
  • 新增 Steam Asset Converter 工具，可将 Steam “depots” 转换为资源包
  • 调试时可通过 Run scheme 选项卡中的 Background Asset Packs 文件夹向应用提供资源包
  • C++ 标准库实现了多项新提案（如 std::optional、zip、std::views::indices 等）
  • C++ 标准库性能显著提升：关联 / 无序容器最高提速 11 倍，分段迭代器算法最高提速 10-1600 倍
  • C++ 标准库多项内部优化：vector::reserve 提速 2 倍，num_get 提速 2.8 倍，ofstream::write 避免大块拷贝
  • Coding Intelligence 编程助手现支持 Google Gemini

Breaking Changes

  • Xcode 27 要求运行 macOS Tahoe 26.6 或更高版本的 Mac
  • C++ 标准库最低支持的 macOS 部署目标提升至 11.0
  • multi {map,set}::find 算法修改，不再保证返回容器中第一个相等元素的迭代器
  • std::{map,set} lower_bound 和 upper_bound 对于非严格弱序比较器的结果行为发生变更
  • ABI 标志 _LIBCPP_ABI_NO_REVERSE_ITERATOR_SECOND_MEMBER 从 LIBCPP_ABI_NO_ITERATOR…
  • ranges::iota_view 现在感知 __int128，导致某些情况下 difference_type 从 long long 变为 __int128
  • std::allocator 现在是平凡默认可构造的，可通过定义宏回退旧行为（该宏将在未来移除）
  • bitset::operator [] 现在返回 bool 以符合标准，可通过定义宏回退旧行为（该宏将在未来移除）

问题修复

  • 修复 Scheme 操作工具栏按钮在处理 “不构建” 变体时的行为，使其恢复为正常的先构建后执行操作
  • 修复在 macOS Tahoe 26.5.1 及更早版本上安装 Xcode 27 beta 导致虚拟机安装失败的问题
  • 修复在未安装 Xcode 27 的 Mac 上用于开发的设备在升级后无需重启即可保持兼容的问题
  • 修复 ba-package 打包工具在指定按需下载策略时可能生成无效资源包存档的问题
  • 修复 Siri 在尝试触发带有 App 枚举值的 AppShortcut 短语时可能产生意外响应的问题
  • 修复通过 Device Hub 访问 CarPlay Simulator 时无法启动 CarPlay 连接的问题

Claude Code 2.1.300 → 2.1.301 Qwen/Qwen3.8-27B

新内容

  • 新增 CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS，防止无人值守重试模式在用量限制重置过远时无限等待
  • 为 claude-api skill 增加 OpenTelemetry 追踪指南，包括使用 ant CLI 配置追踪目标
  • Vim 模式新增 % 运动：跳转至匹配括号，支持单独使用或与 d/c/y 组合
  • Mod 的 Input 新增 rows 属性，支持多行文本输入，Enter 提交，Shift+Enter 或反斜杠加 Enter 换行
  • OpenTelemetry tool_decision 事件新增 classifier_verdict 和 permission_mode…
  • OpenTelemetry tool_decision 事件新增 classifier_category…
  • 改进小上下文窗口模型切换：对话过长时先由旧模型总结再切换
  • 改进长运行子代理渲染性能：进度轨迹增量更新而非每次全量重处理
  • 改进 Artifacts：页面绘制粘性标题上方色带，移动端滚动文本不再显示在该区域
  • 改进 Mods：VS Code 及桌面 / 移动应用中问题对话框上方的树形结构支持 Markdown 和最多 48 行；终端保持 12 行纯文本
  • [VSCode] Claude 响应中新增 LaTeX 数学公式渲染，支持 $、多行 [ … ] 块及内联 $…$ 和 (…) 公式
  • [VSCode] Pro 和 Max 计划的使用量限制横幅新增 “获取更多用量” 链接（VS Code 和 JetBrains 面板）

问题修复

  • 修复退出时未询问即移除 WorktreeCreate hook 创建的 worktree（可能包含未推送提交）的问题
  • 修复 fable/best 模型别名在组织不可用最新 Fable 模型时报错，现自动重试上一版本
  • 修复磁盘满导致登录刷新失败时误导性错误提示，现明确提示磁盘空间不足并建议删除文件
  • 修复 Grep/Glob 在搜索程序意外失败前无结果时误报无匹配，现返回明确的搜索失败错误
  • 修复工作流代理读取 harness note 后跳过步骤但仍报告成功的问题
  • 修复 PreToolUse hook 覆盖 Edit/Write 时 artifact 更新被拒，现改为编辑文件后重新发布
  • 修复技能 / 命令参数名过多或过长导致调用卡顿数秒，现仅填充前 64 个且每个不超过 64 字符
  • 修复技能 / 命令 /hooks 参数填充大量占位符时内存占用过高
  • 修复 VTE 0.53 以下终端（如 RHEL 8 MATE Terminal）中多余字符覆盖文件夹信任提示和 shell 提示符
  • 修复部分 iTerm2 版本启动时提示符出现多余 GOK 文本
  • 修复切换到含 application-inference-profile 的模型时非 Bedrock 提供商误触发 awsAuthRefresh 并延迟 ho…
  • 修复短命令中途退出导致 token 刷新超时和意外登出
  • 修复权限检查期间消息中断导致工具调用被误报为用户拒绝
  • 修复切换到小上下文窗口模型时未经确认即消耗用量额度生成摘要
  • 修复 LLM 网关响应模型名与请求不符时对话被反复压缩且使用非选定模型
  • 修复慢速 / 繁忙机器上 Vim 模式按 Esc 后仍停留在 INSERT 状态
  • 修复 Vim 模式中 Esc 丢弃已输入的 AskUserQuestion 答案，现自由文本字段支持 NORMAL 模式
  • 修复 Read 工具将 .xlsm/.parquet/.epub/.heic 等二进制文件作为文本读取
  • 修复仅含表头的 Markdown 表格在终端过宽时不渲染（含计划审批卡片）
  • 修复 /claude-api skill 错误声称 CMEK 外部密钥端点在 AWS Claude Platform 不可用
  • 修复使用 /rewind 后技能不再列出给模型
  • 修复恢复会话中压缩行提供 ctrl+o 访问未加载历史，现说明早期消息保存位置并在全屏显示
  • 修复中断响应后立即再次出现 “新任务？/clear 节省 tokens” 提示
  • 修复插件 /skill hook 的 ask 决策权限提示未显示来源插件或技能
  • 修复 reftable 仓库中 git 检查超时 / 失败时 /diff 未检测到冲突 cherry-pick/revert
  • 修复同一会话 Bash cd 后工作流脚本读取 / 编辑 / 重跑时请求权限或被拒
  • 修复深色 ANSI 主题和 16 色终端中暗色文本渲染异常（填充框内、选中 / 搜索高亮下、列表描述）
  • 修复 Mod 的 $.model.fork 在新进程首次响应完成前调用返回 nothing-to-fork
  • 全屏模式：修复 /compact 和自动压缩重建可见转录时短暂冻结 UI
  • 自托管 runner：修复 Slack 启动的会话在 MCP 服务器受限时无法找到 / 附加仓库，建议使用 deniedMcpServers
  • 自托管 runner：修复无关设置 / 会话失败引用 git missing-ref 措辞时会话被报告为源分支已删除且不重试
  • 自托管 runner：修复日志对即将结束的会话承诺重试失败 / 拒绝的会话释放，现重复失败显示计数
  • Windows：修复停止的后台 PowerShell 命令输出文件缺少 [killed] 结尾行
  • Mod hook 的 .catch 处理器仅在 hook 抛出或超时时执行，hook 自身调用引发的 events 跳过该 hook 而不询问其 .catch
  • Mod 的 $.env.set 在变量设置 / 取消后以 {} 解析，写入未执行时以 { deny} 说明原因
  • [VSCode] 修复崩溃 / 冻结的对话在每次重载时被重新打开
  • [VSCode] 修复长思考期间聊天面板变慢，不再每次更新都重新解析整个思考文本
  • [VSCode] 修复某些语言服务器诊断显示 [object Object] 而非规则代码（如 MD013）
  • [VSCode] 修复未提供听写功能时（非 claude.ai 登录、远程窗口）仍加载原生听写音频模块检查麦克风权限
