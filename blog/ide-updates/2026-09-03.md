### [VSCode 1.135.0 → 1.136.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_136.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Agent Merge（预览版），自动处理评审反馈、失败检查和合并冲突直至 PR 可合并
- 多根工作区支持（实验性）：允许 Copilot 和 Claude agent 会话跨所有文件夹工作
- Agents 窗口聊天背景（实验性）：支持内置图案或自定义图片个性化界面
- 聊天会话层级管理：将相关聊天组织在会话层级中，快速查看需要关注的会话
- 重新设计的新会话输入框：整合提示词、模型选择、工作区选择等控件于单一布局
- 改进的工作区解析：Agent 可通过项目名称解析工作区，支持远程 URI 及同名工作区匹配报告
- Agents 窗口中导航相关聊天与会话：以树状结构展示父子关系，支持展开/折叠、重命名、移动等操作
- 会话文件面包屑优化：使用稳定的提供者和会话标签替代内部标识符，提升可读性
- Agent 会话通知：当 agent 需要输入或完成工作时发送通知，默认仅在窗口未聚焦时显示
- Agent host：通过专用进程运行 agent harnesses，支持从多个 VS Code 窗口连接同一 agent 会话
- 企业级听写数据控制：管理员可通过策略强制本地转录并禁用语言模型清理，防止数据上传云端
- Agents 窗口标题栏新增屏幕阅读器优化模式徽章，便于识别和切换无障碍模式
- 编辑器窗口布局密度（实验性）：新增紧凑布局选项，可在更小空间内显示更多内容
- 拼写检查建议：在可编辑字段中右键拼写错误单词可选择建议修正，持久化会话中支持添加到词典

**问题修复**
- 修复注入文本导致换行内容超出编辑器视口的问题
- 修复换行未考虑颜色装饰器、内联提示间距、进度指示器和断点占位符视觉宽度的问题
- 修复 shell 集成就绪时扩展执行终端命令产生不必要延迟的问题，消除 JavaScript 调试器启动时的五秒延迟
