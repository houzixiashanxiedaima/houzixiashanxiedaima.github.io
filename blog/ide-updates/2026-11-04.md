### [Claude Code 2.1.316 → 2.1.317](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- /schedule 命令新增警告，提示未请求的云调度任务连接器及移除方法
- 新增检查，在 Web 或 Shell 工具调用发送账户邮箱前进行确认
- Agent SDK 钩子回调新增 onFailure: "block" 选项，失败时阻止操作执行
- Claude Desktop Code 标签页新增远程管理设置加载状态通知
- 自动模式子代理工具调用无响应时新增通知，避免主视图空白
- OTel 指标、事件和跨度新增 anthropic.plan 等四个属性
- Claude apps gateway 管理 API 新增成本报告端点 GET /v1/organizations/analytics/cost
- 新增每日记录开发者 IdP 组功能，用于成本报告分组
- 新增环境变量 CLAUDE_CODE_DISABLE_NESTED_SESSION_ID 以控制会话 ID 行为
- 改进 Microsoft Foundry Azure 凭证错误提示，明确指向凭证问题
- 改进 /design-sync 命令，提前检测设计系统迁移并停止构建
- 改进 Claude apps gateway 启动错误提示，区分网络与登录问题
- 改进退出时的会话恢复提示，显示启动时使用的标志
- 改进自托管 runner 从服务器错误中恢复的连接处理机制
- SendMessage 改为将运行中的后台代理命令移至后台而非停止
- 不同模型的子代理和队友现在使用其模型保存的 effort level
- 退出时跳过插件监控器的“后台工作正在运行”提示
- 内置插件创建技能在 mod 构建成功后提供分享帮助

**Breaking Changes**
- 移除 Read 工具的“文件自上次 Read 以来未更改”存根：再次读取未更改的文件将返回其内容
