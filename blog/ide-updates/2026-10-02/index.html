IDE / SDK 更新 - 2026-10-02

IDE 更新 • 2026年10月2日 • 7 分钟阅读

2026-10-02 IDE / SDK 更新：Android Studio、Android Studio Canary、Flutter SDK 等 4 项工具有新版本 | Android Studio Rabbit 1 稳定版现已发布

#ide-updates #ide #automation #Android Studio #Android Studio Canary #Flutter SDK #Claude Code

Android Studio Quail 4 Patch 1 → Rabbit 1 Qwen/Qwen3.8-27B

新内容

  • Android Studio Rabbit 1 稳定版现已发布

Android Studio Canary Rabbit 2 Canary 2 → Rabbit 2 Canary 3 Qwen/Qwen3.8-27B

问题修复

  • 修复使用 JDK 25 时 generateReleaseRFile 任务中的警告
  • 修复 AGP 8.11+ / 9.0 在移除 ANDROID_PREFS_ROOT 后仍阻止构建的问题
  • 修复 Compose Preview Screenshot Testing 中 XML 元素类型解析错误

Flutter SDK 3.47.5 → 3.47.6 Qwen/Qwen3.8-27B

问题修复

  • 修复 Windows 生产环境应用挂起的问题

Claude Code 2.1.286 → 2.1.287 Qwen/Qwen3.5-27B

新内容

  • 新增 Claude Mods 功能，插件可修改更深层行为
  • 内置 You should know 插件，由侧边代理监控并提示遗漏事项
  • agents 视图新增 n: 过滤器，支持按会话名和任务匹配及展开折叠项
  • OpenTelemetry user_prompt 事件新增 prompt_text 字段以兼容嵌套键后端
  • MCP 服务器支持 URL 提示（如登录），旧版连接需配置 bareElicitationCapability
  • Windows 启动时增加警告：禁用 Bash 工具将同时关闭 PowerShell 导致无 Shell 可用
  • 自托管 Runner 内置 gh api（仅 REST），用于 macOS/Linux 未安装 GitHub CLI 的场景
  • 优化 /config：循环设置支持左右键切换，窄终端堆叠显示，PgUp/PgDn 翻页
  • 优化插件市场错误提示，明确说明被忽略原因及解决方法
  • 优化插件列表显示依赖缺失状态，更新插件时自动重试未完成安装

安全修复

  • 修复危险 rm 命令（如针对根目录或家目录）在重定向输出时绕过始终询问保护机制的问题
  • 修复名为 proto 的 MCP 工具导致组织级工具权限上限被静默丢弃的安全问题

Breaking Changes

  • MCP 服务器若不再连接，需在配置中添加 bareElicitationCapability: true

问题修复

  • 修复远程会话中 fast mode 因代理无用户账户而保持关闭的问题
  • 修复 Remote Control 重连请求无响应时消息延迟数分钟的问题，现 30 秒后重试
  • 修复 asyncRewake hook 脚本缺失时反复唤醒 Claude 发送通知的问题
  • 修复模型响应流停滞时工具心跳无法到达 SDK 主机的问题
  • 修复 Bedrock/Vertex 启动检查忽略 enforced availableModels 导致 /model 显示异常
  • 修复 Chrome 浏览器选择器在无法连接时显示 JSON 解析错误
  • 修复 Fable 模型保存版本 ID 导致默认模型不跟随最新版本的问題
  • 修复 Opus/Sonnet 5.5 切换重写早期 MCP 工具公告导致丢失扩展思考内容
  • 修复 Amazon Bedrock Guardrails 中途拦截时因包含 thinking 内容返回 API 错误
  • 修复 claude -p 及 SDK 会话在模型切换后重复执行回退逻辑
  • 修复会话恢复或压缩后 CLAUDE.md 被重复附加的问题
