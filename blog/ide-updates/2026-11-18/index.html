  • /status 命令新增一行，显示提供商或环境变量（如 DISABLE_TELEMETRY）关闭功能的时间
  • /plugin 和 claude plugin list 命令在忽略格式错误的 plugin.json 字段（如 author 或 homepage）时显示备注
  • 新增 Ctrl+O 快捷键以显示隐藏的启动通知
  • 空提示符中新增提示，说明请求失败后的操作建议
  • 子代理视图中新增 Esc 停止页脚提示的说明，防止误触停止操作
  • 新增 OTEL_RESOURCE_INCLUDE_HOST 环境变量，用于在 OpenTelemetry 资源属性中包含 host.name 和 host.i…

问题修复

  • 修复仅源文件受 Edit 拒绝规则覆盖时，复制文件被拒绝的问题
  • 修复 Bash 命令删除或覆盖文件时在转录中被错误汇总为搜索或读取的问题
  • 修复部分无 rm 命令但 Claude Code 无法可靠读取时，Bash 权限提示中出现误导性 “危险 rm 操作” 警告的问题
  • 修复后台会话在崩溃后、从其他文件夹重新打开或后台服务缺失时丢失 LLM 网关的问题
  • 修复后台服务因进程号被其他用户进程重用而终止自身进程（如 SSH 登录）的问题
  • 修复 /permissions 或主对话工具提示中添加的规则以及 /add-dir 文件夹在设置文件无法写入时看似已保存的问题
  • 修复失败的 MCP headersHelper 或未在不受信任文件夹中运行的情况导致其他会话缺少该服务器的问题
  • 修复具有特定键名的托管设置导致 Claude Code 无法启动或影响其他托管文件的问题
  • 修复嵌套数千层深度的设置值导致 Claude Code 崩溃或仅部分应用的问题，超过 64 层的值将被丢弃并警告
  • 修复会话中途保存的设置文件出错时被静默跳过的问题，现在会显示文件名警告
  • 修复托管设置中设置的子代理模型未在 Claude Desktop 代码选项卡中应用的问题
  • 修复 Linux 上通过符号链接访问 /net 中的主目录或配置目录且沙箱设置拒绝读取时，沙箱化命令无法启动的问题
  • 修复 Linux 上在沙箱化命令期间停止 Claude Code 时，项目中有时残留空占位文件（包括 .git/config.lock）的问题
  • 修复在已受信任父文件夹下显示的文件夹信任提示中，按 Up 然后 Enter 回答 Yes 的问题
  • 修复设置结束时多按一次 Enter 接受将自动模式设为默认的提议的问题
  • 修复在启动自动模式提议上输入的消息丢失及其 Enter 键接受提议的问题
  • 修复在权限提示上输入的备注在 Tab 隐藏后被发送给 Claude 的问题
  • 修复托管设置中的 PreToolUse 钩子在拒绝直接工具调用时未留下 OpenTelemetry tool_decision 事件或 permission_…
  • 修复在 /sandbox 或 /permissions 中的删除问题上输入字母移动选择的问题
  • 修复崩溃后恢复的会话在上一轮以空回复结束时丢失最近回合的问题
  • 修复内存不足时恢复的会话丢失早期对话历史的问题
  • 修复 Linux 上未加载功能标志时，Remote Control 和云会话中重发的文件覆盖 Claude 修改副本的问题
  • 修复打开、停止或删除其对话所恢复的旧会话时，后台会话被杀死且请求丢失的问题
  • 修复 stdout 重定向时 claude purge 隐藏提示词，导致未见的 Enter 可能删除项目数据的问题
  • 修复花费限制菜单在打开时按下 Backspace 和 Enter 未询问即移除月度限制的问题
  • 修复慢速备份副本仍在运行时两次运行 /branch 后 /rewind 仅恢复部分文件的问题
  • 修复 shell 命令更改了无法恢复的文件时 /rewind 显示 “无代码更改” 的问题，现在显示 “代码更改未知”
  • 修复 /rewind 中 Esc 取消摘要、全屏列表显示多个过去提示以及长提示不再隐藏关于丢失后续文件更改的警告的问题
  • 修复 /skills 中两次按 Ctrl+C 或 Ctrl+D 退出 Claude Code 并丢弃更改的问题，现在会保存并关闭面板
  • 修复使用限制菜单在您输入时擦除草稿并打开的问题
  • 修复 ↑ 回忆用 Esc Esc 清除的草稿时粘贴的文本和图片被丢弃的问题
  • 修复在未按 Enter 的情况下继续时，编辑过的对 Claude 问题的输入答案发送旧文本的问题
  • 修复从列表中返回已回答的问题时光标位于第一个选项，Enter 替换您的答案的问题
  • 修复 /feedback 和 /bug 在确认屏幕上输入空格时发送报告，以及在 Ctrl+O 或 Ctrl+Z 后丢失已输入报告的问题
  • 修复在 --add-dir、--allowedTools 或其他列表选项后输入的提示词无消息地丢失的问题
  • 修复 plan 模式已开启时 /plan 忽略描述的问题
  • 修复同一批次中 API 拒绝读取另一个 PDF 后，有效 PDF 从对话中丢失的问题
  • 修复绘制屏幕时单次内存分配失败导致会话结束的问题
  • 修复 Bedrock、Vertex 和 Foundry 上以及遥测关闭时的压缩有时回复您的消息而非总结，或遗漏 Claude 最后回复的问题
  • 修复 Vertex AI 上图像密集的会话因请求大小超过 30 MB 限制卡在 400 错误而非压缩重试的问题
  • 修复 max_tokens 超过模型限制时的错误，现在会以 Anthropic API 报告的最大值重试请求
  • 修复 Bash 工具中的 grep 静默跳过某些文本文件的问题
  • 修复崩溃的 Node 或 Python 钩子仅显示堆栈跟踪第一行的问题，现在显示错误，Ctrl+O 显示最多 10,000 字符的输出
  • 修复 Stop 钩子运行且后台工作仍在进行时输入的 /goal clear 或新 /goal 未生效的问题
  • 修复计费到使用额度的回复后发送自动会话摘要的问题，/recap 仍可用
  • 修复由于过时的保存值（如来自旧版 Claude Code）导致自动模式停留在计入使用的本地分类器上的问题
