### [VSCode 1.142.0 → 1.143.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_143.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- Copilot harness 成为新会话默认选项，支持在编辑器与 Agents 窗口间切换
- 新增模型对比功能（预览），可在 Agents 窗口中运行相同任务并比较不同模型的解决方案
- 引入初始文件级工作集支持（实验性），便于管理和审查代理编辑变更
- Agents 窗口中的 Changes 视图现支持从更多 changeset 中丢弃更改
- 空侧边栏现在显示可添加的标签页列表及其快捷键，方便快速访问
- 新增会话活动栏（实验性），用于管理会话状态
- Files 标签页为空时支持查找和创建文件（实验性）
- 大幅优化打开大型聊天时的性能，历史恢复改为分片加载，避免窗口冻结
- 新增从非活跃 worktree 回收存储的功能（实验性）
- 支持在本地设备运行 Copilot 模型（实验性），如 MAI Code 1.1 Flash
- 语音模式支持自带 OpenAI API 密钥和模型（预览）
- 新增沙箱证书信任管理，允许工具在不暴露真实令牌的情况下认证服务
- 当组织策略允许时，可为单个会话关闭沙箱限制
- 可从聊天菜单直接打开画布（预览），无需通过 Copilot 请求
- 支持查看分离后台 shell 的输出，如开发服务器或文件监视器
- 诊断高亮上限从每文件 500 个提升至 5,000 个，提升问题可见性
- 多文件 diff 编辑器新增文件列表功能（实验性）
- 管理员可通过 managed setting 动态生成和刷新 OpenTelemetry HTTP 头
- 企业策略下，新 Copilot harness 聊天将使用组织管理的默认模型设置

**Breaking Changes**
- Copilot harness 成为新会话默认选项，用户需适应新的交互方式
