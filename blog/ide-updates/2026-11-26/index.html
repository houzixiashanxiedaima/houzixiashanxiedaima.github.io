VSCode 1.147.0 → 1.148.0 Qwen/Qwen3.8-27B

新内容

  • Agent 会话支持在后台保持主机唤醒，防止空闲休眠（预览）
  • 新增远程 Agent 工作树清理功能，回收磁盘空间
  • 聊天性能优化：响应启动速度平均提升 30%
  • Inbox 导航与组织功能（实验性），按关注点分组会话
  • 重新设计远程环境编辑器，展示状态、活动及操作系统信息
  • 新增远程连接故障排查功能，提供诊断报告与修复建议
  • 支持为 Agent 会话创建 Dev Container（实验性）
  • 支持为远程环境配置沙箱配置文件（实验性）
  • MCP Apps 支持全屏模式，可移至编辑器区域或侧边栏
  • 集成浏览器支持设置默认 User-Agent
  • 集成浏览器支持 HTTP Basic 认证登录
  • 新增标签页体验（实验性），支持快速创建多种类型文件
  • 空编辑器提示操作重设计（实验性）
  • 基于 Rust 的 WebAssembly diff 算法（实验性）
  • 浮动评论控件（实验性），避免代码被推挤
  • 支持在聊天中为 Agent Shell 命令输入密码
  • 发布 Agent Host Protocol 1.1.0，支持 TCP 端口转发等
  • VS Code CLI 体积减小约 40%，提升连接速度与资源效率

Breaking Changes

  • Local harness 已弃用，将于 2027 年 2 月移除

  • 修复临时目录不可访问或已满时 flutter run/attach 发生 RPCError 崩溃

  • 新增 OpenTelemetry assistant_response 事件，记录通过 SendUserMessage 发送的文本
  • 新增 VS Code 和桌面端警告，提示部分会话未保存及如何使用 /compact 保存
  • 新增启动头部显示 Cyber Verification Program 访问层级
  • 2.1.331：终端会话支持 Amazon Bedrock、Google Cloud Agent Platform 等平台的 Code Mode
  • 2.1.331：Claude apps gateway 新增 oidc.groups_jsonpath 配置项
  • 2.1.331：claude doctor 新增 API 连接状态报告部分
  • 2.1.331：新增 CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION 环境变量以禁用响应压缩
  • 2.1.330：支持登录 Anthropic Enterprise Admin Console 管理的组织并应用其设置
  • 2.1.330：新增内置 easel 模块，可在 macOS/Linux 上绘制图表
  • 2.1.330：自托管 runner 新增 --start-dir 参数指定工作目录
  • 2.1.330：plugin install --json 结果新增 commandPrinted 和 commandFailed 字段

问题修复

  • 修复 claude auth login 在无法保存时错误报告成功的问题，现退出码为 1 并提示检查项
  • 修复 Read、@-mentions 和 compaction 在无写入命名管道上挂起的问题，现 20 秒后失败
  • 修复多次自动压缩失败后因上下文限制导致回合结束于 “Prompt is too long” 的问题
  • 修复权限规则或钩子条件含多个通配符且命令较长时导致的冻结问题
  • 修复钩子无限输出导致的冻结和内存失控问题
  • 修复本地 MCP 服务器标准输出泛滥导致的终端冻结和 Ctrl+C 失效问题
  • 修复 SSE MCP 服务器事件流中断后工具调用挂起或拒绝的问题
  • 2.1.331：修复 MCP 工具调用在畸形回复下挂起长达 30 分钟的问题
  • 2.1.331：修复 /install-github-app 在特定情况下跳过仓库步骤及 Esc 键无效的问题
  • 2.1.331：修复 /diff 在窄窗口隐藏按键提示及不选择文件的问题
  • 2.1.330：修复压缩超长对话后 Claude Code 冻结数分钟的问题
  • 2.1.330：修复 WebFetch 在某些页面上冻结会话或返回空结果的问题
  • 2.1.330：修复 ExitWorktree 误删其他正在使用的 worktree 的问题
  • 2.1.330：修复多个进程同时保存用户设置导致变更丢失的问题
  • 2.1.330：Linux 下修复 Bash 命令在大型忽略文件夹仓库中等待数秒且不显示 diff 的问题
