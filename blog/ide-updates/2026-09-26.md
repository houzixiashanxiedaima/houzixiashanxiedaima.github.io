### [VSCode 1.139.0 → 1.139.1](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_139.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 支持在 SSH、Tunnel 和 WSL 远程主机上的 Dev Container 中运行 Agent 会话
- Agent 宿主基于 AHP 协议在专用进程中运行，支持多窗口连接同一会话
- 优化大型 Agent 会话列表加载速度，首次列出提速约 12 倍，刷新提速约 4 倍
- 新增紧凑视图模式，可在会话列表中显示更多会话并支持悬停查看详情
- 支持在会话列表中直接重命名会话或嵌套聊天
- 新增词换行指示器，通过箭头标识换行列位置
- 改进括号自动闭合行为，避免输入时插入重复的右括号
- AuthenticationSession API 提案新增 expiresAfter 属性以暴露访问令牌剩余有效期

**Breaking Changes**
- Linux DEB/RPM 包桌面启动器文件名改为反向 DNS 格式，旧版固定启动器需手动重新添加

**问题修复**
- 修复组织策略禁用 Agent 模式时的绕过漏洞（#336968）
- 修复企业托管 OpenTelemetry 配置中的竞态条件问题（#336701）


### [Claude Code 2.1.282 → 2.1.283](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增网关提示头 x-claude-code-prompt-id，支持 LLM 网关按用户提示分组请求（需启用环境变量）
- 新增 availableModelsMatch 管理设置，支持精确匹配模型版本以阻止未列出的新发布
- 新增 deniedModels 管理设置，允许在可用列表之外屏蔽特定模型
- 新增 /doctor prompt-audit 命令，用于审计 CLAUDE.md、技能及代理中的旧版提示模式
- 全屏模式下截断消息支持点击展开
- stream-json 系统初始化错误中新增插件目录加载失败的路径信息
- Claude apps 网关配置新增可选 load_test_mode，支持构建并签名但不发送上游请求的负载测试
- Claude apps 网关新增 Mantle 上游提供商，支持 Amazon Bedrock 的 Mantle 端点
- MCP 工具、WebFetch 和 WebSearch 输出在启用 OTEL_LOG_TOOL_CONTENT=1 时加入 OpenTelemetry spa…
- 优化 /mcp 工具列表：显示更多工具、支持翻页与鼠标滚动、标记组织屏蔽的工具
- 优化 MCP 工具结果：返回的图片现保存至文件，供 Bash、Read 等工具读取
- 优化 /tasks 界面：显示状态图标、名称及关键事实，支持分页、鼠标滚轮与点击
- 优化多个选择器列表（如 /help、/hooks 等）的分页、鼠标滚轮与点击交互
- 优化压缩动画：计时器从压缩开始启动，并实时统计摘要 token 数
- 优化首次响应延迟：模式编译步骤移至流式传输期间执行，复用预连接 API 连接
- 优化启动性能：claude -p 和 Remote 不再加载交互式 UI，部分规则与工具改为按需加载

**安全修复**
- 修复 Windows PowerShell 工具允许 cmd /c rd, rmdir, del 或 erase 删除驱动器根目录、主文件夹等敏感路径的问题
