### [Claude Code 2.1.302 → 2.1.304](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增插件跳过模组钩子时的转录行，显示事件与插件名称
- 新增 decider: "person" 选项，限制权限审批仅由对话框或宿主回调处理
- 新增 e.isReadOnly 属性，标识工具调用是否为只读
- 新增 /auto-mode-setup 引导式设置，支持 Bedrock、Vertex 等环境
- 新增 /claude-api managed-agents-secure 命令，对比安全指南而不修改配置
- 在转录视图的压缩摘要中显示之前调用的工具名称
- Pro/Max 计划恢复非活跃对话时新增用量警告提示
- 改进 /usage 显示速率限制结束时间而非模糊提示
- 改进多视图工件链接生成，解释地址栏切换行为
- 优化云会话首回合启动速度，不再等待本地 MCP 服务器（除非 alwaysLoad）
- 优化自动模式会话文件大小，不再存储安全分类器上下文
- 优化长对话或恢复会话的请求内存使用
- 提升多个子代理并发运行时的响应速度与吞吐量
- 自托管 Runner：改进 git 仓库未找到时的错误提示，明确仓库名与联系人
- Windows：优化 Git for Windows 启动方式，直接调用 git.exe 提升性能

**Breaking Changes**
- 变更模组 settings.read 钩子接收每个设置层并重写合并设置，允许组织设置成为上限
- 变更 /artifacts 删除确认显示编号选项：1 或 Enter 保留，2 删除
- 变更会话中启用模组的提示为纯文本，无链接或会话 ID
- 变更自定义 ANTHROPIC_BASE_URL 后工具搜索默认开启，400/422 错误自动重试
- 变更压缩后再次向 Claude 发送技能列表；/reload-skills 仅发送新或变更的技能
- 变更技能钩子限制：每个来源每会话最多 1,024 个钩子和 16,384 个匹配器字符
- 变更仅允许插件钩子的策略下，主对话中技能若钩子被排除则不再获得 allowed-tools
- 更新 /claude-api 技能在 AWS Claude Platform 上使用 ant CLI 而非回退到 SDK 或 curl
- 移除 claude plugin validate 中预测模组钩子运行位置的注释
- 移除 Opus 5.5 上 /fast 对话框标题中的 "(research preview)" 标签
