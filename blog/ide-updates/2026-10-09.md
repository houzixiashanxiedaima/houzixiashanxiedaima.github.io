### [Claude Code 2.1.293 → 2.1.295](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增命令和 HTTP 钩子的 onFailure: "block" 选项，失败时阻止操作
- 支持程序状态协议 (OSC 7501)，终端可显示 Claude Code 工作状态
- /copy 选择器支持引用文本，复制草稿消息时去除 > 标记
- claude plugin install/enable/disable/marketplace add 在配置文件无法加载时发出警告
- claude -p 运行时若保持打开，stderr 会显示当前等待内容
- Claude apps gateway 上游支持 timeouts.upstream_ttfb_ms 超时设置
- 停止回合时若 ← 正在等待工具完成，显示“Backgrounding cancelled”消息
- Claude apps gateway 上游支持可选 models 列表，仅发送指定模型
- 无托管设置的机器上支持 forceLoginMethod: "gateway" 和 forceLoginGatewayUrl
- claude plugin validate 在插件 README 缺少安装行时提供建议
- Claude apps gateway 推理审计事件新增 upstream_request_id 字段
- mods 新增 $.ui.notify，通过通知设置触发原生通知
- mod 的 Button 支持 children，允许包含字符串和 Text 元素
- 新增 CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS 限制无人值守重试等待时间
- Claude apps gateway 成功推理响应新增 request-id 头
