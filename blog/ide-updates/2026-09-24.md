### [VSCode 1.138.0 → 1.139.0](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_139.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- Agent 会话支持在 SSH、Tunnel 和 WSL 远程主机的 Dev Container 中运行
- 优化大型 Agent 会话列表加载速度，首次列出提速约 12 倍，刷新提速约 4 倍
- 新增会话列表紧凑视图，支持原地重命名会话及嵌套聊天
- 新增词换行指示器，并在输入时避免插入重复的闭合括号
- Agent Host 基于 AHP 协议在独立进程中运行，支持多窗口连接同一会话
- AuthenticationSession API 提案新增 expiresAfter 属性以暴露访问令牌剩余有效期

**问题修复**
- 修复组织策略禁用 Agent 模式时的欢迎页显示及绕过控制问题
- 修复企业托管 OpenTelemetry (OTel) 配置中的竞态条件导致设置丢失的问题


### [Claude Code 2.1.280 → 2.1.281](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Claude 应用网关支持，兼容新版桌面密钥及策略块（如 blockReadsOutsideWorkingDirectories）
- 新增 Bedrock 上游 assume_role 功能，支持通过 STS 跨账户调用 IAM 角色
- 新增 Bedrock 上游 guardrail 配置，可对请求应用 Amazon Bedrock 护栏
- 新增 telemetry.resource_attributes 配置，为遥测数据添加固定标签
- 新增 settings.json 中的 attribution: false 选项以隐藏提交和 PR 署名信息
- 新增 MCP URL 模式引导，支持服务器请求打开基于浏览器的流程
- 增强 claude plugin validate 命令，检查 .mcp.json 条目、未声明引用及不安全 URL
- /insights 新增自动模式建议，估算近期会话中可处理的权限提示数量
- 全屏模式下 /skills、/mcp 和 /plugin 列表新增滚动条，支持鼠标悬停显示及拖拽操作

**安全修复**
- 修复 macOS 下权限对话框在批准前读取 /.vol 等路径可能访问网络挂载的安全问题
- 修复递归 rm 命令在自动或跳过权限模式下未经提示执行的问题，现在会要求确认
- 修复包含 NUL 字节的权限规则被扩展为通配符匹配的问题，此类规则现不匹配任何内容

**问题修复**

- 修复恢复会话时重新发送早期轮次导致 API 丢弃对话历史的问题
- 修复恢复超大会话时仅恢复最后几条消息的问题
- 修复重启后恢复会话时历史记录不一致导致提示缓存失效的问题
