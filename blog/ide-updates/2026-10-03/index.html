IDE / SDK 更新 - 2026-10-03

IDE 更新 • 2026年10月3日 • 5 分钟阅读

2026-10-03 IDE / SDK 更新：Android OS、Claude Code 等 2 项工具有新版本 | Android CLI 新增 Android Device Streaming 功能，支持通过命令行访问真实设备

#ide-updates #ide #automation #Android OS #Claude Code

Android OS Build intelligent Android apps: In-app agentic workflows → Device Streaming and Android skills - available in Android CLI Qwen/Qwen3.8-27B

新内容

  • Android CLI 新增 Android Device Streaming 功能，支持通过命令行访问真实设备
  • 发布更多 Android skills，包括 Wear OS Compose Material 3 skill（wear/wear-compose-m3）
  • 新增 Play 政策合规审计功能，检查应用清单、运行时权限、目标 SDK 级别和隐私披露
  • 新增 Jetpack Credential Manager 重新认证实现，支持设备设置和云恢复场景
  • 新增 Android Intent 安全检测，防止隐式 intent 劫持并验证 PendingIntent 声明
  • 新增 Android profilers 集成，支持使用自然语言查询 PerfettoSQL 诊断 UI 帧率下降和 CPU / 内存问题
  • 新增 CameraX 迁移技能，将旧版 Camera1/Camera2 代码替换为生命周期感知的 CameraX
  • 新增 Leanback 到 Compose for TV 迁移技能，现代化 Android TV 体验
  • 新增 Media3 Cast 集成，连接 Jetpack Media3 媒体会话与 Google Cast 接收器设备
  • 新增 Play Engage SDK 集成，发布用户推荐和集群表面
  • 新增测试策略配置，包括单元测试套件、Compose UI 测试规则和截图测试基础设施
  • 新增 R8 配置审计功能，优化应用性能
  • Android skills 支持跨环境使用，兼容 Android Studio、Antigravity 及第三方 agent（如 Claude、Codex）

Claude Code 2.1.287 → 2.1.288 Qwen/Qwen3.8-27B

新内容

  • 新增 $.ui.selection () API，用于在 Mods 中获取全屏模式下最后选中的文本及所在行
  • 为无 GitHub CLI 的云会话内置 gh api，并修复控制字符发送至终端的问题
  • 新增 Ctrl+C 清除提示后的恢复功能：按上方向键可找回草稿（含粘贴文本和图片）
  • 当 MCP 服务器在工具调用中请求更多 OAuth 权限时，新增重新认证提示
  • 新增 Ctrl+F 按名称查找会话，Alt+↑/↓ 在代理视图中跳转分组；支持在 keybindings.json 中重绑定
  • 新增屏幕阅读器模式，在批准计划时播报新的权限模式（包括使用 Shift+Tab 时）
  • 新增 —max-findings 参数用于 /code-review，以报告多于或少于默认数量的发现项

问题修复

  • 修复响应中途 API 超时导致回合失败的问题：非交互会话和子代理现可从部分响应继续，仅思考的响应会重试
  • 修复长对话因最后回复报告零 token 用量而未自动压缩，导致 “Prompt is too long” 错误
  • 修复 —resume 有时丢失压缩刚恢复的文件和其他上下文的问题
  • 修复恢复会话时有时未保存回合最后响应，导致下次 —resume 显示未回答的提示
  • 修复恢复会话时偶尔加载被截断的转录文件（同一会话在加载期间重写文件）
  • 修复从 2.1.286 或更早版本开始的对话恢复时丢失模型早期思考内容的问题
  • 修复 Mantle 或拒绝结构化输出的网关下，会话标题、记忆召回和提示钩子失败的问题…
  • 修复自动模式拒绝时将 Claude 指向 Bash 权限规则（即使被阻止的工具不是 Bash）的问题
  • 修复 Bedrock 和 Mantle 上自动模式在请求旧模型后整个会话切换到本地分类器的问题
  • 修复云会话在新选模型重启后，服务器拒绝该模型仍用其回复的问题
  • 修复 Cowork 云会话在 WebFetch 权限提示对未批准 URL 五分钟内未回答后仍标记为等待输入的问题
  • 修复手机加入在其他设备上启动的 Cowork 云会话时不显示提示建议的问题
  • 修复 Mod 按钮在 Claude Code 重启前绘制的视图上按下时有时执行不同按钮操作的问题
  • 修复插件面板在单个 Code 元素包含无法解析的 diff 时显示为空的问题；现作为普通代码绘制
  • 修复插件 LSP 服务器在 initializationOptions 和 settings 中收到字面量占位符而非替换值或清单默认值的问题
  • 修复插件 tool.call 钩子导致 worktree 中运行的子代理 Bash 失败和文件搜索读取错误文件夹的问题
  • 修复 git-subdir 插件安装在旧版 git（如 Ubuntu 22.04 的 2.34）上失败或缓存不完整插件的问题
  • 修复使用 —plugin-dir 加载的插件在 /plugin 中不显示 “Configure options” 的问题
  • 修复后台会话在插件重载或禁用时，若其定时器或读取仍在运行则结束的问题
  • 修复沙箱 heredoc 使用未加引号的分隔符时的相关问题

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
