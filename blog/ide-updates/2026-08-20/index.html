IDE / SDK 更新 - 2026-08-20

IDE 更新 • 2026年8月20日 • 2 分钟阅读

2026-08-20 IDE / SDK 更新：VSCode、Zulu JDK 17、Zulu JDK 21 等 3 项工具有新版本 | 新增并排聊天功能，支持分组对比相关对话 | 发布首个月度关键安全补丁更新 (CSPU) 机制，提升补丁速度 | 新增月度关键安全补丁更新 (CSPU) 发布机制

2026-08-20 IDE / SDK 更新

统计信息

  • 由 Qwen/Qwen3.5-35B-A3B (3) 总结
  • 今日更新: 3 项工具
  • 生成时间: 2026-08-20 05:07:36 (北京时间)

VSCode 1.133.0 → 1.134.0 Qwen/Qwen3.5-35B-A3B

新内容

  • 新增并排聊天功能，支持分组对比相关对话
  • 新增提示词时间轴，快速导航和查看文件变更
  • 在聊天中搜索文本，支持全文检索
  • 默认使用集成浏览器预览本地 HTML 文件
  • 新增 Agent Host，支持多窗口连接同一代理会话
  • 优化侧边栏布局，支持单面板模式及标签显示控制
  • 支持拖放子代理聊天到组中进行并排查看
  • 支持 Alt+ 选择打开侧边聊天
  • 支持从标签页关闭其他编辑器

Zulu JDK 17 17.0.20 → 17.0.20.1 Qwen/Qwen3.5-35B-A3B

新内容

  • 发布首个月度关键安全补丁更新 (CSPU) 机制，提升补丁速度
  • SBOM 文件命名规则变更：从按版本生成改为按平台构建生成

安全修复

  • 包含针对关键问题和安全漏洞的修复（具体 CVE 未列出）
  • 修复可通过 API 或 Web 服务利用的安全漏洞
  • 修复 Java 沙箱在运行不受信任代码时的安全风险

Breaking Changes

  • SBOM 文件命名模式变更：由 SBOM-zulu {版本}-{季节}-{索引} 改为 {bundle-name}_sbom
  • SBOM 交付粒度变更：每个平台构建将拥有独立的 SBOM 文件

Zulu JDK 21 21.0.12 → 21.0.12.1 Qwen/Qwen3.5-35B-A3B

新内容

  • 新增月度关键安全补丁更新 (CSPU) 发布机制
  • SBOM 文件命名规则变更：从按版本改为按平台构建生成

安全修复

  • 包含本月度关键安全漏洞修复与严重问题修补
  • 修复可通过 API 或 Web 服务利用的 Java 安全漏洞

Breaking Changes

  • SBOM 文件命名格式变更，需适配新的 {bundle-name}_sbom 模式

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
