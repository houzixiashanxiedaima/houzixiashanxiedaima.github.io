IDE / SDK 更新 - 2026-10-10

IDE 更新 • 2026年10月10日 • 3 分钟阅读

2026-10-10 IDE / SDK 更新：Flutter SDK、Claude Code 等 2 项工具有新版本 | 修复 iOS 上 OverlayPortal 显示时，无障碍帧因设备像素比缩小并锚定在左上角…

#ide-updates #ide #automation #Flutter SDK #Claude Code

Flutter SDK 3.47.6 → 3.47.7 Qwen/Qwen3.8-27B

问题修复

  • 修复 iOS 上 OverlayPortal 显示时，无障碍帧因设备像素比缩小并锚定在左上角…
  • 修复 iOS 上使用 VoiceOver 配合 ReorderableListView 时，语义焦点错误地移动到屏幕左上角的问题

Claude Code 2.1.295 → 2.1.296 deepseek-ai/DeepSeek-V4-Flash

新内容

  • 新增 managed.policies [] 的 code 键，应用于 Claude Desktop 的 Code 标签页并开启网关模式
  • 新增 subagent 的 autoCompactWindow 选项，可提前自动压缩对话窗口
  • 新增环境变量 CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL 与 CLAUDE_CODE_OVERLOADED_RETRY_MAX_D…
  • /plugin 新增同名插件钩子被跳过的提示说明
  • Read 工具新增 allow_large 选项，可读取超出常规限制的文本文件
  • 改进全屏模式：鼠标指针下的链接显示下划线
  • 优化 transcript 切换（ctrl+o）在代码密集对话中的响应速度
  • 改进网关会话无法启动时的原因显示
  • 改进被拒绝云会话的错误信息，说明策略加载失败原因
  • 改进 —debug 输出：提示未知 frontmatter 字段、记录钩子耗时与结果
  • 改进 auto mode：未运行的调用显示为 “未运行” 而非红色错误
  • 优化 transcript 本地 GC，避免无意义重写大文件
  • 更新 Sonnet 5.5 缓存读取定价为 $0.10 / 百万 tokens
  • 更新 dataviz 技能的视觉配色与紧凑轴标签
  • MCP 工具描述与服务器指令的默认限制从 2048 提升至 4096 字符

问题修复

  • 修复托管设置 PreToolUse 钩子拒绝调用未结束回合、PostToolUse 钩子未应用 updatedMCPToolOutput
  • 修复无头会话启动已关闭的 .mcp.json 或插件 MCP 服务器
  • 修复 Claude apps 网关相关：锁定笔记本、忽略已保存登录（回归）等
  • 修复 —teleport 在无法读取历史时打开空会话
  • 修复 Haiku 5.5 等模型在网关下的 token 计数错误
  • 修复恢复的子代理误报用户拒绝工具调用
  • 修复钩子输出被篡改及共享转录、调试日志中秘密脱敏缺失
  • 修复终端复制后多出转义序列、通知被对话框遮挡等问题
  • 修复 Esc 或中断导致无头会话结束、提示消失或放行未检查提示
  • 修复多个插件相关问题（SessionStart 跳过、$ 方法目录、注册、HTTP 请求、市场命令、secret 删除等）
  • 修复自托管运行器错误信息与 git 操作冲突
  • 修复工作流脚本深层嵌套截断及 Workflow 工具拒绝 CRLF 文件
  • 修复 Bash 权限检查误放过 BASH_ARGV0、Edit 替换非 UTF-8 字符等问题
  • 修复云会话相关问题（跳过检查、/code-review 输出为原始 JSON 数组等）
  • Windows 修复：长命令权限、MCP 强杀、插件安装、rm -rf 等；VSCode 修复 spinnerVerbs 设置

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
