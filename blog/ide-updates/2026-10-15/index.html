IDE / SDK 更新 - 2026-10-15

IDE 更新 • 2026年10月15日 • 7 分钟阅读

2026-10-15 IDE / SDK 更新：VSCode、Claude Code 等 2 项工具有新版本 | 新增画布（预览）功能，支持在聊天旁使用可视化交互界面与智能体协作 | 新增 prompt 装饰中的 virtualText，显示在提示框但不进入草稿或提交内容

#ide-updates #ide #automation #VSCode #Claude Code

VSCode 1.141.1 → 1.142.0 Qwen/Qwen3.8-27B

新内容

  • 新增画布（预览）功能，支持在聊天旁使用可视化交互界面与智能体协作
  • 支持在 Agents 窗口中通过自然语言将当前聊天移动到其他文件夹或新的 Git worktree，保留对话历史
  • Agents 窗口引入会话级布局（实验性），允许不同会话独立设置编辑器可见性和面板显示
  • Agents 窗口底部面板支持自定义对齐方式，可选择居中对齐以优化侧边栏空间
  • 聊天标题直接显示当前使用的 harness 名称（如 Copilot 或 Codex），便于快速识别
  • Copilot harness 会话中支持停止后台运行的 shell 命令，无需等待其完成
  • BYOK 自定义端点支持无状态 Responses API，可通过配置发送完整对话历史
  • 重新设计模型选择器，采用标签页界面分离 Copilot 和 BYOK 模型，便于切换
  • Markdown 编辑器编辑模式下每行源码独立显示，更贴近源文件结构
  • Markdown 编辑器支持直接粘贴图片，无需手动保存和插入文件
  • Markdown 编辑器支持重命名文件链接，更改会反映到整个文档
  • Markdown 编辑器集成大纲视图和面包屑导航，便于查看标题结构和跳转章节
  • Markdown 编辑器代码块悬停时显示复制按钮，方便复制多行代码片段
  • 新增合并来自不同提供者的文档高亮功能，可通过设置启用
  • Python 环境扩展修复了环境发现、解释器选择和终端激活问题，uv 管理的安装现显示在全局下
  • 企业策略管理支持自动将受策略管理的聊天移至 Copilot Agent Host 以强制执行权限和沙箱策略
  • 管理员可独立管理 Copilot 权限模式，例如允许辅助模式但阻止全允许模式
  • Windows 数值策略支持 DWORD 和 QWORD 值类型
  • GitHub Pull Requests 扩展启用堆叠拉取请求支持

Breaking Changes

  • 不再支持 Windows 上 Local harness 的沙箱功能，需使用 Agent Host 会话进行沙箱化命令执行

Claude Code 2.1.296 → 2.1.300 Qwen/Qwen3.5-27B

新内容

  • 新增 prompt 装饰中的 virtualText，显示在提示框但不进入草稿或提交内容
  • OpenTelemetry api_request 事件新增 cache_creation_5m_tokens 和 cache_creation_1h_tok…
  • 新增 $.ui.view ({agentId}) API，可在主视图查看代理对话记录
  • Text 组件新增 dir 属性支持从右向左文本，适配 Windows 和 VS Code 终端
  • AWS Claude Platform 新增 /advisor 功能，支持通过 advisorModel 或环境变量控制
  • Trace spans 新增 OpenTelemetry GenAI 语义约定属性（如 gen_ai.provider.name）
  • agent.spawn 钩子现支持重写工作流代理的提示词和模型
  • 新增 prompt.change 钩子，响应非打字操作（如历史召回、撤销、插件填充）
  • Cowork 云会话中 WebFetch 改进：页面近期失败时不再重复获取
  • 内置插件开发技能改进：扫描 mod 文件前先检查密钥，外部文件夹需确认
  • Claude 3 模型对 @提及 PDF 的说明优化，减少未阅读即回答的情况
  • Artifact 工具更新优化：小改动单次调用重发布，大编辑单响应内完成
  • 大型请求默认启用 gzip 压缩（即使禁用遥测），可通过环境变量关闭
  • 后台会话恢复改为通过 Workflow 工具审批而非直接运行交接文件

Breaking Changes

  • CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST 会话忽略 CA 包、工具代理及 git TLS 配置变量
  • 退出时强制终止仍在运行的后台命令（全屏模式下此前可能残留）
  • Claude Desktop Code 标签页在特定网关场景下应用托管设置
  • claude gateway 在桌面端遇到不支持的策略键时启动即停止并报错
  • claude-api 技能默认保留 Managed Agents 会话，除非明确要求归档或删除

问题修复

  • 修复云会话错误报告组织策略阻止主机的问题
  • 修复 /autocompact 在选择较小窗口时误报高 token 消耗
  • 修复 SessionEnd 钩子在后台命令运行时有时不执行
  • 修复 claude —help 描述中包含已移除工具名称
  • 修复数据不完整时 agents 不刷新拉取请求状态
  • 修复云会话容器替换后背景代理被误判为丢失不可恢复
  • 修复子代理完成任务后从 /tasks 消失导致无法回溯对话
  • 修复查看子代理时父代理从面包屑中消失
  • 修复输入突发时 agents 视图误将单词识别为按键指令
  • 修复自动工具搜索在 MCP 服务器重连中途关闭
  • 修复强制登录拒绝后仍保留被拒组织的 token
  • 修复 reftable 仓库中 diff 视图未检测到冲突的 cherry-pick 或 revert
  • 修复 Artifact 工具在输入到达时显示不可打印路径而非等待状态
  • 修复会话恢复后首条转录记录因崩溃截断而丢失
  • 修复包含 Unicode 分隔符时 /branch 丢弃消息及 purge 跳过子文件夹
  • 修复 WorktreeCreate/Remove 钩子在 —worktree 启动时未运行
  • 修复 reftable 仓库中 git commit -q 后 OpenTelemetry 缺少 git_commit_id
  • 修复 prompt.submit 重写或丢弃的提示词仍被记录为已输入
  • 修复 mod 热重载提示错误出现在转录记录中
  • 修复代理钩子忽略模型设置导致别名解析或回退异常
  • 修复 —worktree 会话因标签名与 commit ID 相似而从错误提交启动
  • 修复 reftable 仓库中分支显示为 .invalid 及 worktree 无法重新打开
  • 修复会话暂存区中文件仅使用相对路径而非完整路径
  • 修复远程控制中心在短暂登录错误后放弃连接续期
  • 修复裸仓库 worktree 中 origin 默认分支不可获取时的启动失败
  • 修复集成终端中编辑器命令行工具被重复启动
  • 修复 chat:newline 键绑定输入换行时 prompt.edit 钩子未触发
  • 修复 API 拒绝 MCP 工具输入模式后每轮对话返回 400 错误
  • 修复 headless 或 Agent SDK 会话恢复时丢失压缩保留的消息
  • 修复压缩后 MCP 服务器连接完成前工具说明未告知 Claude
  • 修复多会话服务器上 Remote Control 会话被误标记为停止
  • 修复重试或未完成的回复后压缩摘要丢失或历史回滚
  • 修复 Claude 轮询后台命令输出文件或休眠等待
  • 修复 TLS 检查代理下特性标志和分阶段发布保持陈旧
  • 修复 daemon stop —any 在后台服务卡住时未强制终止
  • 修复遥测关闭时 daemon stop 无输出且会话仍显示运行
  • 修复 Cowork 云会话中本地文件写入成功但实际未传输
  • 修复会话恢复时搜索已在早期加载的延迟工具
  • 修复深色 ANSI 主题和 16 色终端下次要文本样式异常
  • 修复组织策略不可读时云会话每轮挂起 5 分钟
  • 修复长回复期间重启导致已回答消息被重复运行
  • Self-hosted runner 修复无人读取输出时冻结问题，日志保留最新 256 KiB
