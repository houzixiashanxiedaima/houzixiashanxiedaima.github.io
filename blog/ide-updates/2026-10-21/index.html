IDE / SDK 更新 - 2026-10-21

IDE 更新 • 2026年10月21日 • 5 分钟阅读

2026-10-21 IDE / SDK 更新：Android OS、Claude Code 等 2 项工具有新版本 | 新增 Remote Compose alpha 库，支持构建交互式 Android 游戏小组件

#ide-updates #ide #automation #Android OS #Claude Code

Android OS Grab Reduces ANRs by 32% and improves startup time by 35% with R8 and Profile guided optimization → Remote Compose Gaming Widgets Qwen/Qwen3.8-27B

新内容

  • 新增 Remote Compose alpha 库，支持构建交互式 Android 游戏小组件

Claude Code 2.1.304 → 2.1.305 Qwen/Qwen3.8-27B

新内容

  • 新增 sandbox.allowNestedUserNamespaces，允许 Linux 沙箱命令创建用户命名空间以绕过文件保护
  • 新增 CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS，使无人值守重试模式能感知已解除的使用限制
  • 改进 /usage：每条警告现在是一行修复建议并指明来源，按 f 可应用修复；VS Code 和 /doctor 中同步显示
  • 改进 MCP 同意对话框，降低 Enter 键被误识别为接受的风险
  • 改进 mod 的 Image 在 iTerm2 3.5+ 全屏渲染下正常显示图片而非仅替代文本
  • Remote Control：改进 spawn-mode 消息，按 w 提示新模式已保存，后续启动时说明来源
  • [VSCode] 新增 “正在运行启动钩子” 旋转状态及屏幕阅读器播报
  • [Cloud sessions] 改进删除自托管环境的对话框与错误信息，明确阻塞原因和影响范围
  • [Claude Tag] 将 Claude 未加入的公开 Slack 频道添加到管理端 Add place 搜索中
  • [Claude Tag] 改进大型组织中的管理页面，插件、技能和捆绑包编辑在频道列表加载期间仍可操作

Breaking Changes

  • allowedMcpServers 不再过滤 managed-mcp.json 中仅在 env 使用 ${VAR} 的 stdio 服务器…
  • Claude Desktop 按路径挂载的插件在组织设置 allowManagedPermissionRulesOnly 时不再保留其 allowed-too…
  • /artifacts 删除确认改为 1/Enter 保留、2 删除、Esc 取消，y/n 不再有效
  • mod 的停靠面板宽度限制在终端宽度的 45% 以内，包括从更宽终端继承的宽度

问题修复

  • 修复 Vertex、Bedrock 等提供商因工具搜索被拒绝导致所有请求失败的问题（2.1.304 回归）
  • 修复模型名称大小写或 [1m] 标签差异导致 /effort 和 /autocompact 设置不生效的问题
  • 修复裸仓库中新 worktree 有时从本地 HEAD 而非默认分支开始，以及未变更的子代理 worktree 未被清理的问题
  • 修复磁盘满时 Bash 命令报原始 ENOSPC 路径而非明确提示磁盘已满的问题
  • 修复云会话或 SDK setMcpServers 传入的 MCP 服务器被同名配置覆盖的问题
  • 修复子代理切换到回退模型后 Claude 仍使用错误模型名称的问题
  • 修复云会话和 teammates 未在压缩摘要中告知遗漏最旧消息的问题
  • 修复计划 Cowork 云会话因 WebFetch URL 审批无人处理而每个子代理等待五分钟的问题
  • 修复 Workflow resume 重新运行已完成 pipeline () 和 parallel () 代理而非从日志恢复的问题
  • 修复 Remote Control 切换对话后 /resume 留下空 “(session)” 条目的问题
  • 修复窄终端中 /usage 行被截断的问题
  • 修复启动警告以原始文本打印在 logo 上方，现改为输出到调试日志，无限制的权限规则显示为横幅下方警告行
  • 修复屏幕阅读器模式下搜索框读作 “telephone recorder” 及高亮提示文本内多余空格的问题
  • Self-hosted runner：修复共享 stdout 且设置 TERM 时启动脚本报 Resource temporarily unavailable…
  • Self-hosted runner：修复 git credential helper 通过 GIT_CONFIG 读取设置导致仓库访问失败的问题（2.1.2…
  • Self-hosted runner：修复后台 runner 保持输出打开时 orchestrator 误报 spawn-runner 钩子超时的问题
  • [VSCode] 修复 spinnerVerbs 设置为短词时旋转器截断 “Compacting…” 的问题
  • [VSCode] 修改会话未及时启动且无钩子运行时的提示信息，优先展示输出日志和原因列表
  • [Cloud sessions] 修复 Cloud environments 管理页错误拒绝保存已有环境并报 “installs packages” 错误的问题
  • [Claude Tag] 修复访问捆绑包中移至其他 GitHub 账户的仓库无法再次添加的问题
  • [Claude Tag] 修复 Slack DM 线程中另一例程重启对话后原例程停止发布的问题
  • [Claude Tag] 修复 Slack 线程中对话结束后例程报告成功但未实际发布的问题，现跳过并通知创建者
  • [Code Review] 修复审查期间多次推送导致未审查最新提交的问题
  • [Code Review] 修改重新审查不再在早期阻塞性发现未解决时以 LGTM 开头

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
