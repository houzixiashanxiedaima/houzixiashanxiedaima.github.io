### [VSCode 1.144.0 → 1.144.1](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_144.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增会话连续性，支持在计算机离线时保持会话和自动化运行
- 新增远程环境管理对话框，集中管理 GitHub 环境、Dev Tunnels、WSL 和 SSH 主机
- 新增云端自动化（预览），支持基于 Issue 或 PR 事件触发 Copilot 任务
- 发布 Agent Host Protocol v1.0，开放可扩展协议以构建自定义代理 UI
- 新增 Copilot Fusion，智能路由和编排多个模型以平衡性能与成本
- 新增模型对比功能，支持并排比较不同模型的输出结果
- 新增图像生成功能（预览）
- 新增计算机使用功能（预览），允许代理操作桌面应用
- 改进 Canvases（预览），使其更易查找、管理和打开
- 辅助权限正式可用，减少频繁工具调用的审批负担
- 新增会话创建器控件（实验性），优化新会话设置体验
- Copilot harness 成为默认选项，基于 Copilot SDK 构建
- 新增工作集审查功能（实验性），用于审查和撤销代理文件编辑
- Copilot harness 支持 Copilot Memory，自动回忆仓库事实和用户偏好
- 新增 worktree 存储管理（实验性）
- 支持在 Agents 窗口中直接启用和管理扩展
- 新增通过 GitHub Environments 共享本地代理的选项
- 新增 Copilot connectors（预览），无需本地配置即可连接 Slack、Notion 等服务
- 新增市场自定义发现（预览），提供技能、工具和完整工作流
