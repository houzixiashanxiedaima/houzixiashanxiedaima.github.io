新内容

  • 在巴西、印度尼西亚、新加坡和泰国参与商店上线用户保护功能

Claude Code 2.1.327 → 2.1.328 Qwen/Qwen3.8-27B

新内容

  • Claude Opus 4.6 和 Sonnet 4.6 在 Bedrock、Agent Platform 等新增自动模式
  • MCP 工具钩子支持 onFailure: block，调用失败时阻断操作
  • 跳过权限提示的会话消息被云端丢弃时发出警告
  • /status 和 claude doctor 提示 OpenTelemetry 导出器无端点
  • 新增 CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME 环境变量
  • 嵌入应用可启用策略插件 allowManagedModsOnly 选项
  • Claude apps gateway 启动时校验 maxEffortLevel 有效性
  • 自托管运行器新增 --repository-folder 参数指定仓库文件夹
  • 自托管运行器启动时警告 settings.json 默认权限模式被忽略
  • orchestrator 新增 --hook-label 参数传递会话标签给 spawn-runner 钩子
  • claude --environment 新增 --metadata key=value 为会话添加标签
  • orchestrator /metrics 新增会话队列等待时间指标（按原因区分）
  • orchestrator 新增 sessions_given_up_total 指标统计放弃启动次数

问题修复

  • 修复 zsh 中 Bash 命令以 = 开头的词导致 not found 错误
  • 修复自动压缩复用旧系统提示而非重建的问题
  • 修复超长或畸形 Markdown 输入导致渲染冻结
  • 修复权限提示后快速输入丢失 Esc 键的问题
  • 修复慢连接下粘贴内容被截断并误输入到提示符
  • 修复保存定时任务时其他已存任务被清空的问题
  • 修复定时任务文件中拼写错误的任务下次保存时被删除
  • 修复恢复云会话时可能丢失压缩摘要或近期消息
  • 修复 spinner 和子代理 token 计数重复计算重试回复
  • 修复用量额度耗尽时错误显示为速率限制
  • 修复网关拒绝 beta 时 auto 模式每轮失败
  • 修复 CLAUDE_STREAM_IDLE_TIMEOUT_MS 未延长网关连接限制
  • 修复第三方提供商上大型工具结果导致 Prompt is too long

  • 修复 Code Mode 向只读子代理提供 write () 和 edit ()
  • 修复 Code Mode 中 Esc 后跟命令导致 Claude 自行开始回合
  • 修复 Code Mode 未告知仅在被要求时运行工作流
  • 修复 Remote Control 重复断开消息且建议重连不可重连的会话

  • 修复刚启动或标题含 @ 的云会话在跨会话消息中不可达

  • 修复 Send now 告知 Claude 已停止的搜索无结果
