IDE / SDK 更新 - 2026-10-08

IDE 更新 • 2026年10月8日 • 5 分钟阅读

2026-10-08 IDE / SDK 更新：VSCode、Claude Code 等 2 项工具有新版本 | 新增 Copilot harness，提供与 GitHub Copilot 产品一致的代理功能 | 新增 Claude Haiku 5.5 模型，作为默认 Haiku 模型，支持 1M 上下文

#ide-updates #ide #automation #VSCode #Claude Code

VSCode 1.140.0 → 1.141.0 Qwen/Qwen3.8-27B

新内容

  • 新增 Copilot harness，提供与 GitHub Copilot 产品一致的代理功能
  • 支持跨平台沙箱化，限制代理在 Windows、macOS 和 Linux 上的文件和网络访问
  • 新增工作树清理功能，可手动或自动回收非活跃代理会话占用的磁盘空间
  • 新增后台 Shell 跟踪功能，可查看正在运行的命令及其输出流
  • 增强代理消息控制，支持在不同会话间调整委托任务并发送纠正指令
  • Agents 窗口支持网格布局，便于并行监控多个长时运行任务
  • 新增紧凑布局密度选项，提升 Agents 窗口内容显示效率
  • 支持多实例 GitHub Enterprise 登录，可同时管理多个 GHE 账户
  • 支持从编辑器直接下载远程文件至本地
  • 支持 Codex 聊天在 ChatGPT 应用、Codex CLI 与 VS Code 间无缝切换
  • 改进上下文选择器定位，使其紧邻触发按钮并保持视觉关联
  • 新增发现型 MCP 服务器展示，在自定义编辑器中查看插件提供的服务器
  • 新增毛玻璃效果覆盖层和菜单（实验性）
  • 新增块粘贴扩散功能，可将复制的块分布到后续目标行
  • 新增 /vscode-pet 命令，引入名为 Blobby 的宠物互动功能

Breaking Changes

  • 旧版 VS Code 策略逐步迁移至 Agent Host 统一托管设置，部分旧版沙箱设置已弃用

Claude Code 2.1.292 → 2.1.293 deepseek-ai/DeepSeek-V4-Flash

新内容

  • 新增 Claude Haiku 5.5 模型，作为默认 Haiku 模型，支持 1M 上下文
  • 新增 agentType 到 subagentStatusLine 负载，可区分自定义子代理类型
  • 为 mods 新增 $.tool.register 的 isDeferred 选项，控制工具 schema 展示时机
  • 改进 Team 和 Enterprise 组织启动性能，策略与设置提前获取并重试停滞请求
  • 改进 Claude in Chrome：浏览器慢时更少拒绝页面操作，并优化无法访问时的提示
  • 改进 Bash 编辑差异说明，列出命令运行期间可能被其他进程写入的文件
  • 改进 artifacts：将库固定到两周或更早的精确版本
  • 调整 claude.ai 技能同步频率，无会话时约每 40 分钟检查一次
  • 调整代理列表与 MCP 服务器排序，非 ASCII 名称排在 ASCII 之后
  • 调整 OpenTelemetry 日志，每次最多记录 100 个代理和 100 个 MCP 资源事件
  • 自托管 runner 轮询间隔改为 4-6 秒随机，避免多个副本同时轮询
  • Claude Tag 管理设置中列出未连接的企业网格并提供连接按钮
  • Claude in Slack 加入公告频道（仅管理员可发帖）且不发送介绍
  • Claude Tag 频道规则限制从 20 提高到 50（每工作区和组织级）
  • Code Review 添加仓库对话框列出失败原因，如缺少 GitHub 写权限

问题修复

  • 修复 Claude 有时将压缩前最后操作误判为已完成，导致撤回或重做已完成的工作
  • 修复 HTTP MCP 连接内存泄漏，连接关闭前不再保留每个请求
  • 修复 ← 后台移动相关：消息丢失、排队消息无法移动时提示、10 秒后取消移动及 Esc 不停止等
  • 修复 /model effort 循环越界及 /tui 在 Chrome 会话中的断开问题
  • 修复子代理相关：工具被移除仍被指示使用、内置工具被误报禁用、自定义代理名称显示异常
  • 修复 claude.ai 同步技能的编辑描述延迟，直到新对话或 /clear 才生效
  • 修复登录过期或即将过期时，claude 日志及 daemon 等命令有时退出登录
  • 修复远程控制：长会话回复不流式、凭据恢复后重复上传历史、误报 Remote Control 无效
  • 修复 /ultrareview 上传在 Linux 上的拒绝问题及 split-index 的 git 建议
  • 修复插件测试与 eval：$.session.append 失败、Mac 上 Docker Desktop 拒绝 Bash 运行
  • 修复网关启动失败（桌面策略设置内置浏览器键）及后台会话忽略 bypass 权限
  • 修复界面显示与输入处理：footer 计数丢失、Artifact 路径显示、agents 视图占位、路径规则加载、粘贴文本误判
  • 修复 purge 静默失败、/feedback 无法取消、keybindings 空格检查、vim 模式光标及 Windows 进程终止，并回退两项先前的更改
  • 修复 Claude Tag 多个问题：共享频道误报未配置、任务中断、线程例程运行、连接器显示等

说明

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
