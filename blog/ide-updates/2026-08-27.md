**新内容**
- 新增外部 Agent 会话支持，可在 VS Code 中继续其他应用中的 Copilot 或 Claude 会话
- 新增实验性功能 Rubber Duck，通过互补模型获取对 Agent 工作的第二意见
- Agent 窗口 UX 改进：默认启用单窗格侧边布局，简化会话控件与信息展示
- 新增详细聊天用量视图，按模型显示输入、缓存输入和输出 token 明细
- 新增 Agent Host，支持从多个 VS Code 窗口连接同一 Agent 会话
- 新增实验性聊天粘性滚动功能，长响应浏览时保持当前提示可见

**问题修复**
- 本地 Agent harness 沙箱化回退至 0% 默认开启率，仍可通过 UI 手动启用
