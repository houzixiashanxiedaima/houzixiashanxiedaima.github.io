### [Claude Code 2.1.301 → 2.1.302](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 CLAUDE_CODE_AUTO_MODE_MODEL 环境变量，用于选择客户端自动模式分类器使用的模型
- 在 /config 中新增空闲压缩行，可关闭或重新开启空闲压缩功能
- 改进启动时间：启用大量插件时，加载插件命令和代理文件的系统调用大幅减少
- 改进自动模式服务端分类器：对话过长时会进行压缩，而非拒绝所有工具调用
- 优化提示词和代理钩子：同一事件最多同时运行 12 个，其余排队等待
- [云会话] 新增横幅显示例行任务未启动的原因（如组织并发限制）

**Breaking Changes**
- claude -p 和 Agent SDK 在无权限模式下默认以 default 模式启动第三方提供商会话
- fork 子代理在 claude -p、Agent SDK、桌面应用和 VS Code 中默认开启
- 桌面应用和 VS Code 现在始终在后台运行主对话的子代理
- Claude in Chrome 指令在系统提示中的位置已更改以利用共享提示缓存

**问题修复**
- 修复对话压缩期间停止回合导致的“Prompt is too long”错误
- 修复 Read 工具将任意大小图像文件或管道设备完全加载到内存的问题，现拒绝超过 128 MB 的源
- 修复切换至 Vertex 或 Bedrock 后请求失败的问题
- 修复 PowerShell 工具无法找到插件 bin/ 目录命令及管道搜索报错问题
- 修复 MCP 服务器协商特定协议版本但缺少字段时工具不可用的问题
- 修复 Windows 上 exFAT/FAT32 驱动器文件写入被拒绝的问题
- 修复 Git reftable 格式下插件市场重复克隆及版本显示未知的问题
- 修复自托管 Runner 中 Git fetch 因 reftable 格式导致失败的问题
- 修复 VSCode 中未闭合代码块流式传输时的显示异常
- 修复 Slack 中 HEIC、SVG 等图片附件无法发送给 Claude 的问题
- 修复远程控制会话离线后子代理面板无限旋转的问题
- 若干其他琐碎修复（包括 UI 显示、链接格式、状态栏同步等）



**说明**

本文追踪 GitHub Release 之外发布的 IDE / SDK（如 JetBrains、Android Studio、VSCode、Xcode 等），以及 Dart Code 等少数固定追踪项。其余在 GitHub 发布的工具更新请见每日 GitHub Releases 日报。
