### [VSCode 1.136.0 → 1.136.1](https://raw.githubusercontent.com/microsoft/vscode-docs/main/release-notes/v1_136.md) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Agent Merge（预览版），可自动处理评审反馈、失败检查和合并冲突直至 PR 就绪
- 多根工作区支持（实验性）：可在多根工作区中跨文件夹使用 Copilot 和 Claude agent 会话
- 重新设计新会话输入框，将提示词、模型选择和工作区选择等控件整合在同一布局中
- 改进工作区解析：agent 可通过项目名称解析工作区，并保留多根工作区的 URI 和工作目录
- Agents 窗口中可导航相关聊天和会话，以层级结构展示父子关系并显示状态与待审批项
- 会话文件面包屑改为可读的 provider 和 session 标签，不再暴露内部标识符
- Agents 窗口支持自定义背景图（实验性），可使用内置图案或自有图片
- 新增 agent 会话通知功能，在需要输入或完成工作时提醒用户，默认仅在窗口未聚焦时显示
- Agent host 允许从多个 VS Code 窗口连接同一 agent 会话，基于 AHP 协议运行独立进程
- 企业策略新增听写数据控制，可强制本地转录并禁用语言模型清理以防止数据上传云端
- Agents 窗口标题栏新增屏幕阅读器优化模式徽章，便于识别和切换无障碍模式
- 编辑器窗口布局密度（实验性）：新增紧凑布局选项以显示更多内容
- 拼写检查建议：在可编辑字段中右键点击拼写错误单词可选择修正或添加到词典

**问题修复**
- 修复注入文本导致换行超出编辑器视口的问题
- 修复换行未考虑颜色装饰器、内联提示间距、进度指示器和断点占位符视觉宽度的问题
- 修复 shell 集成就绪时扩展执行终端命令产生不必要延迟的问题，消除 JavaScript 调试器启动时的五秒延迟
