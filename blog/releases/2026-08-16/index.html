dmtrKovalenko/fff v0.10.4 gpt-oss-120b

新内容

  • 新增 Neovim 插件 Lua 模块（.so/.dylib/.dll）
  • 新增 C FFI 库，支持 Bun、Node、Python
  • 新增 MCP 服务器二进制 fff-mcp（.so/.dylib/.dll）
  • 发布 Python 包（wheel 与 sdist），可通过 pip 安装
  • 发布 npm 包、Rust crate，统一在 0.10.4 版本提供

问题修复

  • 修复多处问题，包括缓存 SDK 导入导致的 reload 卡顿、缺失的 clap 属性、构建步骤缺失、grep 结果分页、readOnlyHint 声明…
  • 若干依赖升级（zlob 1.6.3）及其他细微修复

hugohe3/ppt-master v4.8.0 gpt-oss-120b

新内容

  • AI 图像成为可组合系统，插图资产、装饰性文字、透明切片及三种组合模式可跨幻灯片复用
  • 图像来源改为任务驱动，支持每张图片单独决定来源、零配置网页获取和多提供商缩略图搜索
  • AI 能力在执行时解析，支持运行时恢复、自动重试和 12 个后端统一更新
  • 本地公式库升级至 Microsoft 365 完整配置，编译器拆分模块并支持上标下标原生导出
  • 预设形状可携带阴影或辉光，PPTX→SVG 重新构建转场效果并保留音频
  • 有限对象动画恢复，包括时长、延迟等属性，公式导入保留并在严格模式下报告不支持内容
  • 主题研究可保留网页为源包，事实 URL 作为溯源，字体默认使用目标 PowerPoint 本地字体

Breaking Changes

  • 图像来源决策改为强制每页单独决定，旧版默认行为将不再生效
  • 不兼容的模型覆盖将被拒绝，不再默默使用错误的 schema
  • 公式上标下标导出方式改变，基线偏移采用原生 DrawingML

问题修复

  • 修复在宽容模式下对不受支持载体的诊断行为
  • 修复在严格模式下对不支持公式内容的处理

AutoDarkMode/Windows-Auto-Night-Mode 11.1.1.1 gpt-oss-120b

问题修复

  • 修复意大利语与中文混用的问题
  • 修复在某些情况下关闭窗口后未保存窗口大小和语言选择的问题
  • 修复导航视图标题被截断的错误
  • 更新多项翻译

tashfeenahmed/freellmapi v0.8.0 gpt-oss-120b

新内容

  • 支持端到端图像输入，覆盖所有 OpenAI 兼容接口
  • 为卡顿的提供商实现请求对冲，超时后中止重试并继续故障转移
  • 自定义提供商模型列表支持定时自动同步
  • 新增 OrcaRouter 平台，提供免费限额模型别名
  • 在代理设置中暴露每个平台的 route‑via‑proxy 开关
  • 仪表盘工具提示改版，列表换行、点击或 Esc 可关闭
  • 完成仪表盘中文字符串翻译，优化 route‑via‑proxy 文案
  • 在响应面真实上报 reasoning_tokens
  • 将仅返回 “safe/unsafe” 分类的模型视为失败并绕过
  • 仅在模型实际下线时依据错误体的 “end of life” 短语退休模型
  • 未声明工具时跳过 tool‑call 方言救援，并在使用前验证
  • 启动时若 MODEL_ROUTING_OVERRIDES 条目永不生效会发出警告

问题修复

  • macOS DMG 未签名，首次启动需右键选择 Open
  • 若干路由和仪表盘修复（包括模型分类错误、启动警告等）

MetaCubeX/mihomo v1.19.30 gpt-oss-120b

新内容

  • 新增对 H2C 与 QUICv2 的嗅探支持
  • 为 hysteria2 添加 handshake-timeout 配置
  • 为多种出站协议（masque、ZeroTier、wireguard、openvpn）新增 ip-stack 选项
  • 支持 AmneziaWG v3.0 与 v3.1
  • 为 anytls 添加 client-metadata 配置，默认不发送
  • 为 mipstack 引入 bbr3 拥塞控制算法
  • 为 restls 监听器添加速率限制

安全修复

  • 修复 crypto/tls 中的安全漏洞 CVE-2026-56862

问题修复

  • 修复 Zerotier、Tailscale、QUIC、OpenVPN 等网络组件的多个错误，提升连接可靠性
  • 修复 HTTP/2、WebSocket、TLS 嗅探过程中的若干问题，包括不必要的等待和数据顺序错误
  • 修复若干编译、DNS、以及协议实现细节错误，如拼写错误、DNS 回复截断、NTP 前 DNS 初始化等
