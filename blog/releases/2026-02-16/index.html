anomalyco/opencode v1.2.5 GLM-4-Flash

新内容

  • 添加 Shift+Tab 键盘快捷键到应用

问题修复

  • 修复从文件树打开新文件时的问题
  • 仅在输入边界处导航提示历史记录
  • 在更新和重新启动后聚焦窗口
  • 确保 SQLite 迁移日志输出到 stderr 而不是 stdout

新内容

  • 优化德语本地化字符串

问题修复

  • 修复导出 / 导入设置中 telemetry_id 重命名为 remote_id 的错误

nguyenphutrong/quotio v0.13.0 GLM-4-Flash

新内容

  • 统一 Claude, Gemini, OpenAI, Qwen, Antigravity 订阅管理
  • 实时配额跟踪
  • 智能自动故障转移
  • 支持 Claude Code, OpenCode, Droid 等 AI 编码工具

SagerNet/sing-box v1.12.22 Qwen 2.5 7B

问题修复

  • 修复了一些错误

jdx/mise v2026.2.13 GLM-4-Flash

新内容

  • 部分缓解 GitHub 认证验证失败问题，导致工具安装失败
  • 更新 sigstore-verification 至 0.2 版本，解决 gzip 特征干扰 Snappy 压缩响应的问题
  • 添加新包 k1LoW/tcmux
  • 更新包 jdx/usage

问题修复

  • 修复 GitHub 认证验证失败导致的工具安装失败问题

code-yeongyu/oh-my-opencode v3.5.4 - v3.5.5 GLM-4-Flash

新内容

  • 增强背景代理稳定性，修复与 OpenCode 1.2.0 + 的兼容性问题
  • 写作代理默认使用 Kimi K2.5 模型，并加入抗 AI 模糊规则
  • 视觉工程任务使用 Gemini 3 Pro 高变体，优化设计输出质量

问题修复

  • 修复背景代理在 OpenCode ≥1.2.0 上运行时任务状态错误的问题
  • 修复背景代理在处理消息部分 delta 时的心跳问题
  • 修复背景代理在处理 OpenCode 会话状态时防止误报的问题
  • 修复了背景代理可能无声退出的问题
  • 修复了任务超时问题
  • 从 JSONC 配置文件加载 LSP 配置
  • 独立解析配置段，防止无效字段影响整个配置
  • 使用事件缓存减少 session.messages () 调用，防止内存泄漏
  • 执行所有 Stop hooks，而不仅仅是第一个非阻塞结果
  • 修复了 Google Auth 配置文档中的链接
  • 使用 fs.realpath 代替手动 path.resolve 进行符号链接解析
  • 检测代理提供商（litellm, ollama）后的 GPT 模型
  • 在项目技能发现中使用目录参数而不是 process.cwd ()
