### [yetone/alma-relay v1.3.1 - v1.4.0](https://github.com/yetone/alma-relay/releases) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增协议 3，为每个流提供独立的信用额度
- 中继在注册时通告窗口大小（1 MiB），并在响应体或 WebSocket 字节传输至手机时发送确认
- 桌面端保持每个流最多一个窗口的未确认数据
- Node 版从 res.write / ws send 回调中发送确认，若流在 STALL_TIMEOUT_S 内未写入任何应写数据则被切断
- Cloudflare 版在手机拉取响应字节及发送 WebSocket 消息时进行确认
- 当手机读取速度低于桌面发送速度时，中继现在会暂停读取该桌面的 socket，防止积压
- 在桌面 socket 暂停期间，中继每 5 秒发送一次主动 pong，保持连接不断开（兼容所有 Alma 版本）
- 新增 FLOW_HIGH_WATER_MB / FLOW_LOW_WATER_MB 配置项（默认值 8 / 1），用于控制流量高/低水位阈值
- 超过 2 秒的暂停、对端状态以及被切断的手机现在会记录在中继日志中

**Breaking Changes**
- 设置 RELAY_PROTOCOL=2 可关闭协议 3，旧版桌面端不受影响
- 需要支持协议 3 客户端的 Alma 桌面端（PR yetone/alma#492）

**问题修复**
- 修复手机停止读取导致 Node 版停止读取整个代理套接字，进而使该桌面上其他手机、herdr 查看器和 E2E 隧道全部停滞的问题
- 修复 Cloudflare 版将桌面端发送的数据保留在 Durable Object 内存中的问题
- 修复启动行错误显示版本号 1.2.0 的问题（应为 1.3.x）

- 文本编辑器升级为块编辑器，支持嵌入、引用和跨笔记编辑
- 表格功能增强：支持合并单元格、排序、批量增删行列及横向滚动
- AI 集成新增 ChatGPT Codex、OpenRouter 等提供商，并引入操作前确认机制
- 共享页面采用应用主题渲染，支持深浅色模式及块级公开链接
- 移动端移除侧边栏，iOS 采用 iOS 26 风格布局，Android 优化导航体验
- 桌面端支持本地会议转录（实验性），使用按需下载的语音模型
- 集合视图新增地理地图属性对话框，支持图形化设置图像地图
- 重写上下文菜单与笔记自动补全，提升键盘导航与无障碍访问体验
- 文本编辑器支持主题自适应颜色，智能粘贴去除多余样式
- 新增越南语、波斯语和丹麦语国际化支持
- Linux 用户可通过 Flathub 安装 Trilium
- ETAPI 和后端/前端 API 文档现作为帮助笔记提供，支持离线查阅

**安全修复**
- 同步新设备时若启用 TOTP 则强制要求验证，提高安全性
- 升级 Node.js 至 v24.22.1，修复 CVE-2026-111497
- 修复 ETAPI 相关的若干低中优先级安全报告
- 防止 ZIP 导入大文件时导致应用崩溃

**Breaking Changes**
- 同步协议版本从 39 升至 41，不同版本实例无法同步，需同时更新所有客户端
- 数据库版本从 240 升至 242，首次打开时自动迁移且旧版本将无法打开
- Docker 镜像重构为支持非 root 用户运行，需参考新文档配置
- 移除旧版布局，仅保留新版布局
- v0.106.0 引入的多级 #sorted 值必须使用 # 前缀，否则回退到标题排序
- 启用 TOTP 后，POST /etapi/auth/login 接口现在需要 code 参数

**问题修复**
- 修复同步实例中搜索受保护笔记失败的问题
- 修复非拉丁字符布局（如俄语、希腊语）下键盘快捷键失效问题
- 修复同步过程中可能丢失笔记修改的问题
- 修复 Windows 上打开设置导致应用冻结约六秒的问题
- 修复 Nginx Proxy Manager 和 Pocket ID 环境下 OIDC 登录失败问题
- 修复 Android 平板笔记菜单不可滚动及侧边栏切换无效问题
- 修复 Android 返回键直接退出应用而非关闭菜单的问题
- 修复 POST /login 缺少密码字段时请求永久挂起的问题
- 减小打包体积数 MB，移除 jQuery autocomplete 等废弃库
