tldraw/tldraw v5.5.4 - v5.6.0 Qwen/Qwen3.8-27B

新内容

  • 引入 ICU MessageFormat 和 react-intl 支持多语言翻译，支持复数、选择及值插值
  • 新增 defineMessages 和 useTldrawI18n API，允许在代码旁声明并渲染默认英文消息
  • 新增 ThrottledFunction 类型至 @tldraw/utils，用于标注 throttle 函数的返回值
  • 新增 startCommentAt (editor, point) API，支持从外部在特定画布位置发起评论线程
  • 新增 LaserTool.startScribble () 方法，支持向当前会话添加激光涂鸦
  • 改进菜单逻辑，自动隐藏或禁用不可执行的操作（如锁定形状分组、空页面导出等）
  • 恢复键盘导航对锁定形状的支持，允许通过 Tab 或方向键选中并解锁形状
  • 在配置了评论功能时，默认画布右键菜单中新增 “评论” 选项
  • 优化 store.query.index () 和 store.query.ids () 更新性能，减少内存分配
  • 调整提示轮廓线宽为 2px，提升拖拽形状进入框架时的视觉清晰度
  • TLSocketRoom 相关方法新增可选 socket 参数，忽略来自已取代连接的过期消息
  • TldrawUiMenuActionItem 现在根据 action.isEnabled 状态自动禁用或隐藏菜单项
  • 默认命中测试边距从 3 增加到 4.5，使形状边缘更容易悬停和选中

Breaking Changes

  • useTranslation 的 msg 现支持通过第二个可选参数插值值并接受声明的消息描述符
  • actions 新增 isAvailable、isEnabled 和 isChecked 方法，菜单项据此决定隐藏或禁用状态

问题修复

  • 修复边缘滚动速度非 1 时偏好设置显示错误及启动延迟后速度跳变问题
  • 修复旋转选区翻转导致子元素旋转错误、未对齐形状多次触发 resize 回调等问题
  • 修复复制页面时形状位置偏移及新页面相机视角未重置的问题
  • 修复文本形状标题下无法删除的空行及富文本工具栏 onUiEvent 报告错误操作类型
  • 修复双击框架边缘适配内容后撤销产生不一致历史步骤的问题
  • 修复多种场景下撤销操作回退到早期编辑状态的问题（如刷选、右键取消选中等）
  • 修复点击锁定组子元素时错误选中整个锁定组的问题
  • 修复包含书签等非缩放形状在组被缩放或翻转时位置错乱的问题
  • 修复略微旋转的框架或组内缩放 / 裁剪时边界吸附失效的问题
  • 修复箭头工具精确模式在切换目标形状时状态残留的问题
  • 修复 macOS 上使用 Cmd+Arrow 快捷键后方向键微调移动变为对角线的问题
  • 修复橡皮擦在靠近组拖动时偶尔丢失高亮形状的问题
  • 修复 editor.setCursor 处理 rotate/resize 光标类型抛出异常及十六进制颜色破坏 SVG 光标
  • 修复 editor.animateShapes 在插值空段 draw/highlight 形状时抛出 TypeError
  • 修复激光工具在涂鸦会话超时中途崩溃及无点涂鸦在一帧空闲后消失的问题
  • 修复字体加载完成后命中测试和视口剔除使用过时边界的问题
  • 修复编辑器重挂载且 persistenceKey 相同时，前一个实例保存期间编辑丢失的问题
  • 修复 iOS 上评论输入框需要二次点击才能聚焦并唤起软键盘的问题
  • 修复监听器移除前最后一帧的 store 变更未送达该监听器的问题
  • 修复写入 store 的反应函数在不相关的 store 变更时重复执行的问题
  • 修复单次 put 更新同一记录两次后撤销恢复中间状态的问题
  • 修复 store 监听器和 extractingChanges 接收到已回滚事务变更的问题
  • 修复 store.query 计算缓存在同 ID 记录重建时未重新运行 derive 函数的问题
  • 修复 migrateStoreSnapshot 遇到格式错误的持久化架构时抛出异常而非返回迁移错误
  • 修复持久化架构序列版本非数字时迁移在记录上重复运行的问题
  • 修复离线期间删除的记录在重新连接后偶尔重新出现的问题
  • 修复重连时使用相同会话 ID 导致大分块同步消息丢失及活动会话被取消的问题
  • 修复休眠主机上恢复的同步会话跳过版本检查，导致服务器重新部署后客户端收到无法处理的变更

新内容

  • 修复了工作流脚本调用 runs.run 时参数格式验证错误的问题
  • 优化了未信任项目中代理查找的性能，避免每次调用都扫描 .git、.pi 和 .agents 文件夹
  • 修复了 runs.lanes 结果中长错误信息截断导致字符损坏或超出 256 字节限制的问题
