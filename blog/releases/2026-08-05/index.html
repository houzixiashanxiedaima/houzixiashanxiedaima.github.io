srwi/EverythingToolbar 3.0.1 gpt-oss-120b

新内容

  • 新增任务栏搜索框，嵌入默认 Windows 11 任务栏
  • 支持 Everything 1.5 SDK，搜索结果列出性能大幅提升
  • 当 Everything 未启动时，Toolbar 会等待其可用再显示结果
  • “禁用动画” 设置现覆盖所有剩余动画
  • 工具提示已统一主题样式
  • 自定义操作规则改为首个匹配即生效，正则表达式不再被拒绝
  • 搜索查询不再阻塞 UI 线程
  • 多项性能优化，包括结果列表、图标加载和窗口动画
  • 通过 Crowdin 更新翻译

问题修复

  • 修复任务栏搜索框选项在部分 Windows 11 任务栏上呈灰色的问题
  • 修复使用 IME 输入的搜索仅在添加尾随空格后才显示结果的问题
  • 修复全局快捷键在应用空闲后被错过或延迟触发的问题
  • 修复 “以管理员身份运行” 始终在结果上下文菜单中可见的问题
  • 修复更新通知横幅在某些版本增量时未出现的问题
  • 修复任务栏固定图标在重新固定后未更新的问题
  • 修复设置在读取或写入自动启动注册表项失败时崩溃的问题
  • 修复 Everything 过滤器在过滤文件包含重复或缺失列时加载失败的问题

tldraw/tldraw v5.3.0 gpt-oss-120b

新内容

  • 新增评论层 @tldraw/commenting，支持锚点、回复、编辑、表情、解决、删除及深链
  • 为几何形状添加 flipX、flipY 翻转属性
  • 图像裁剪时支持对齐网格和形状，Alt 键可对称缩放
  • 嵌入尺寸自动匹配内容真实宽高比（如 Vimeo）
  • 新增 EditorPortal 及相关 Hook，用于将画布内容渲染到独立 DOM
  • 新增 renderHtmlFromRichTextWithExtensions，用于在形状外渲染富文本
  • 改进视口剔除性能，仅重新检查受影响的形状
  • 批量删除形状时提升性能
  • 长 toast 与对话框内容自动换行，避免溢出
  • “返回内容” 按钮出现延迟约 1 秒，防止抖动
  • 隐藏空的 “复制为”“导出为” 等子菜单，优化菜单展示
  • 移除键盘快捷键菜单项的省略号
  • 新增 ExportAsMenuGroup 子菜单组
  • 新增通用对象存储同步非文档记录及相关 API（objectTypes、getObjectsSnapshot 等）
  • 新增 getIsMounted () 与卸载事件

Breaking Changes

  • 移除 usePassThroughMouseOverEvents API，需改用其他方式处理鼠标悬停
  • 新增 objectAccess 字段，构造 RemoteTLStoreWithStatus 时需提供该字段

问题修复

  • 修复多项交互和崩溃错误，包括依赖解析、键盘快捷键、评论锚点聚簇、滚轮事件、覆盖层滚动、无效链接拖拽、标签换行、富文本标题行距、样式面板填充高亮、下拉弹出间距…

AlistGo/alist v3.63.0 gpt-oss-120b

新内容

  • 新增可选并行上传模式（personal_new）
  • 新增 CSTCloud Capsule（数据胶囊）驱动
  • quark_uc 支持范围下载并发度和分块大小可配置
  • s3 客户端可选覆盖 User-Agent
  • 123_open 接入离线下载临时目录
  • 123_open 在服务器合并上传时保持轮询
  • 上传剩余 URL 时包含第 101 部分
  • 声明 PC 客户端类型以解除 50 GB 上传上限
  • archive 限制总解压缩大小防止磁盘耗尽
  • baidu_netdisk 流式上传切片，降低内存占用
  • lanzou 处理登录时的 acw_sc__v2 反机器人挑战
  • net 对过载重试加回退并在不可恢复错误时快速失败
  • quark 定期刷新 __puus cookie 保持下载签名有效
  • thunder 持久化登录令牌并清除已消费的信用键
  • thunder 容忍未旋转刷新令牌的刷新响应

安全修复

  • 强制在所有请求路径上使用用户基路径，提升安全性

CherryHQ/cherry-studio v2.0.0 gpt-oss-120b

新内容

  • 新界面与全新体验，聊天、角色、项目、任务组织更清晰
  • 多窗口与分屏布局，支持多任务切换与进度查看
  • 支持 OpenAI 与 Anthropic 接口，复用 Claude 与 Codex 订阅
  • 内置 Agent 运行时，显著降低依赖安装和环境配置需求
  • 一键预览研究、文档、演示、数据分析和代码结果
  • Agent 可读取并维护知识库，实现持续 Wiki 式知识增长
  • 代码工具升级为 Code Mate，支持一键配置 Claude Code、Codex 等模型服务
  • 图像生成展示模型可调参数，便于控制生成结果
  • 数据底层全面升级，历史记录大量时仍保持响应
  • 超长对话滚动更流畅，大文件夹导入不再阻塞界面

jdx/mise v2026.8.2 gpt-oss-120b

新内容

  • 新增 bootstrap 声明式资源计划，支持文件、目录、秘密、用户组、systemd 服务、Docker Compose…
  • 新增 bootstrap plan 预览，支持表格或 JSON 输出及详细退出码
  • ruby.compile = false 改为严格预编译模式，未找到预编译二进制即报错
  • task.auto_infer 任务推断改为按提供者可选启用，默认关闭

Breaking Changes

  • ruby.compile = false 严格预编译模式，可能导致缺少预编译二进制时安装失败
  • task.auto_infer 默认关闭，原先自动推断任务的行为将改变

问题修复

  • 若干修复（brew、brew-cask、lock、pipx、pacman、sync、completion、registry）
