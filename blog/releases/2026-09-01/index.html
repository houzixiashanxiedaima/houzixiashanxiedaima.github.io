fastfetch-cli/fastfetch 2.66.1 - 2.68.1 Qwen/Qwen3.8-27B

新内容

  • DE/WM/LM 模块现在报告完整名称而非缩写
  • 改进登录管理器（LM）模块，支持 macOS、Windows 及无 systemd 的 POSIX 系统
  • 在 Linux 上报告美观名称
  • 新增 Top 模块，显示 CPU、内存或磁盘 I/O 使用率最高的进程
  • 新增模块键本地化支持
  • 新增 —key-language 选项以指定显示语言，默认为系统区域设置
  • Wi-Fi 模块改进：新增信道宽度检测、提高频率准确性并增强 Windows/macOS 检测
  • 新增 SunOS 和 Haiku 上的 Wi-Fi 检测支持
  • 新增 SunOS 上的电池检测支持
  • 新增 Termux 上的终端字体大小检测支持
  • 改进独立窗口管理器（如 Hyprland、sway、niri、i3）上的 GTK 主题 / 图标 / 字体检测
  • 改进 fish 补全脚本以打印枚举描述
  • 启用 Android 上的 Wayland 支持
  • 新增 ASUS Zenfone 的 DE 检测支持
  • 新增 ARM SoC 支持
  • 新增 macOS_old、Omarchy、Omarchy2 标志

安全修复

  • 修复 Shell 版本检测中潜在的越界读取问题
  • 为网络响应增加大小限制，防止过度内存分配
  • 在字符串缓冲区容量处理中增加整数溢出检查

问题修复

  • 修复 DiskIO 和 NetIO 中 I/O 速率计算精度问题并防止除以零错误
  • 修复 ash 版本检测的快速路径问题
  • 修复 x86-32 FreeBSD 上的内存使用检测支持
  • 内部清理与优化
  • 尝试修复大端系统中的潜在问题（未测试）
  • 修复磁盘 I/O 与网络 I/O 速率计算精度及除零错误
  • 修复 ash 和 fish 版本检测问题
  • 修复不同长度 sysctl 数据的整数处理问题
  • 修复 Camera、Codec、Display、Separator 和 Weather 模块中的多处内存泄漏
  • 修复大端主机上的 Base64 编码问题
  • 修复 VP9 编解码器检测及 macOS 10.15 Codec 兼容性问题
  • 放宽 HTTP 响应格式接受范围并修复 PublicIP URL 解析错误
  • 修复 Ubuntu Studio Core 检测问题
  • 修复 KDE Plasma 首选显示器模式检测问题
  • 修复浅色主题下亮色被错误启用的问题
  • 修复 macOS 编译器警告
