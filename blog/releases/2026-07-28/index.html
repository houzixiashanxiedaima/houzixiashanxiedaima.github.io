ben-manes/gradle-versions-plugin v0.56.0 gpt-oss-120b

新内容

  • 新增 io.github.ben-manes.versions.settings 插件，可在评估每个项目时报告 settings 脚本声明的插件版本
  • 改进 Groovy rejectVersionIf 闭包的解析，避免抛异常导致报告被清空
  • 累加解析策略，第二个 rejectVersionIf 不再覆盖第一个
  • 报告未解析依赖的完整原因链，而非仅顶层信息
  • 使用分离配置解析聚合结果，防止构建锁定所有配置时影响插件自身
  • 在查询副本中仅覆盖继承的目标 JVM 版本且不继承依赖约束
  • 为每个 README 示例提供 Kotlin 与 Groovy 示例

  • npm.package_manager=“aube_cli” 模式，使用独立 Aube 可执行文件安装 npm 工具
  • mise deps 显示提供者状态并在错误时给出原因
  • 新增 oh‑my‑pi 注册表入口并补全工具描述

问题修复

  • 修复任务时间戳比较、可执行位提示、循环依赖检测等导致的重复执行和错误
  • 修复任务头参数显示、—output 与 MISE_TASK_OUTPUT 覆盖行为不一致的问题
  • 修复 Homebrew 引导包链接失败及别名链接残留问题
  • 修复环境变量路径分隔符、PowerShell 激活、后端插件遮蔽等跨平台问题
  • 修复 generate task‑docs 注入错误提示、MCP 初始化身份以及若干文档描述错误

  • 修复 aria2 引擎因持久化设置超出范围而无法启动的错误
  • 修复拖动窗口时的多秒 UI 卡顿和 “未响应” 问题
  • 修复首次启动窗口位于左上角的问题，现居中显示
  • 修复文件大小为 9,728,000 字节整数倍的文件无法完成下载的问题
  • 修复带 AICH 校验的 ≤180 KB 小文件总是失败的问题
  • 修复上传槽泄漏问题
  • 修复下载速度显示为 0 且进度超出实际写入的问题
  • 修复磁盘写入失败未正确报告的问题
  • 修复停滞下载误报以及暂停 / 恢复触发的假警报
  • 修复使用 Visual Studio 生成器构建时导致应用无法启动的安装程序问题
