tashfeenahmed/freellmapi v0.6.1 - v0.6.5 gpt-oss-120b

新内容

  • 每个支持的编码代理现在显示其官方品牌标志及对应颜色
  • 根据主题使用适配的明暗版本标志，确保在浅色和深色模式下均清晰可见
  • 升级无需配置更改或数据库迁移，只需替换镜像或应用即可
  • 为每个自定义中继端点独立维护模型记录，启用状态、可靠性、速度分数、冷却时间和退役互不影响
  • 按模型纯 ID 请求时会同时发送至所有提供该模型的端点，实现默认自动故障转移
  • 当多个端点提供相同模型 ID 时，仪表盘显示每个端点的 URL 并支持为特定端点固定 ID
  • 精确模型 ID 优先匹配，只有在未找到精确匹配时才使用相似显示名作为回退
  • 单一自定义端点的部署无需额外配置或迁移
  • 首次启动时自动迁移现有数据库，无需手动操作
  • UI 界面优化，整体外观改进
  • 设置对话框重新设计为侧边栏，分组为通用、压缩、高级、预览
  • 设置页面标签和间距统一，新增信息提示解释压缩功能
  • 代理页面为每个支持的编码代理显示图标，设置片段标注为自动或手动
  • 新增 Playground 文件上传，支持图片（客户端压缩）和文本文件，非视觉模型会被标记
  • 新增自定义端点 “Fetch models”，可批量发现并注册模型，自动按合理排名
  • 在仪表盘中可编辑每个模型的智能 / 速度排名及 RPM、RPD、TPM、TPD 限额
  • 新增 /livez 与 /readyz 健康检查端点
  • 新增 GET /v1/providers 接口用于元网关互操作
  • 新增 GET /api/keys/providers 接口提供提供者配置清单

问题修复

  • SOCKS 代理（socks5h、socks4a）支持远程 DNS，已识别 ALL_PROXY、HTTPS_PROXY、HTTP_PROXY…
  • Cloudflare Workers AI 流在未指定 max_tokens 时不再截断，使用默认输出预算
  • 密钥健康检查改为跨提供商交错进行，加入间隔抖动，避免同步突发
  • 长时间超时现在降低模型速度分数并影响速度排序预设，用户自定义覆盖始终生效
  • 上游下线的模型（HTTP 410）自动隔离并标记为 “retired”，不再占用回退槽位
  • 对 400/401 错误视为访问被拒，终止无限冷却重试循环
  • 修复推理参数导致的硬性请求失败问题
  • 修复 X-Routed-Via 头部在包含括号或非 ASCII 名称时的错误报告
  • 修复向自定义端点添加第二个 API key 时会覆盖第一个的问题
  • 修复已禁用模型通过旧会话或自动排序被错误路由
  • 修复 Pollinations 键验证使用未认证端点导致的错误
  • 修复目录同步时删除已种子嵌入模型的问题
  • 修复 .env 导入时键带引号后跟内联注释被损坏的问题
  • 修复 Fusion 面板选择未考虑模型大小导致的占位错误
  • 修复 /v1/responses 对显式模型字段的优先级处理并返回正确错误

immich-app/immich v3.1.0 gpt-oss-120b

新内容

  • 网页上传时自动获取 wakelock 防止屏幕变暗（需 HTTPS）
  • 网页归档成功后提供撤销按钮
  • 工作流新增按服务器文件路径过滤选项 “Use path”
  • 工作流新增按 EXIF 元数据过滤资产的功能（当前仅支持字符串比较）
  • 命令面板加入维护页面快捷入口
  • 幻灯片按钮加入背景模糊容器，提升在亮色图片上的可见性
  • OAuth OIDC 角色声明同步改进：首次和后续登录均同步 isAdmin，支持单值和数组
  • 管理员 CLI 重置密码时可选择使现有会话失效
  • 移动端地图支持自定义日期范围过滤
  • CLI 上传子命令新增 —visibility 标志
  • 网页在重复项上保持 “显示更多” 状态
  • 新增相册资产事件处理
  • 工作流新增按上传路径过滤资产的选项
  • 为外部库 AssetCreate 添加触发器
  • 移除冗余的 Twitter 元数据标签

Breaking Changes

  • 移动端不再支持 iOS 14，需升级至 iOS 15 或更高版本

问题修复

  • 修复移动端视频组件释放导致的崩溃以及地图无响应等问题
  • 修复网页端幻灯片模式下隐藏缩略图、滑动控制可见性、URI 编码等问题
  • 修复服务器端默认 CSP 配置、工作流日期过滤、外部库触发等问题
  • 修复多项 UI 与权限相关的错误，如上下文菜单层级、搜索过滤、RTL 图标等
  • 修复文件上传、EXIF 方向、零字节图片、相册创建等功能的若干错误
