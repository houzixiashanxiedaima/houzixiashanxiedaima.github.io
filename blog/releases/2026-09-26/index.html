jdx/mise v2026.9.14 Qwen/Qwen3.8-27B

新内容

  • 新增 conf.d 文件夹片段支持，允许在配置目录中加载独立配置文件
  • dotfiles 新增相对符号链接和 dot- 前缀选项，提升部署灵活性
  • mise-versions 代理 GitHub 仓库版本查询，降低 API 速率限制影响
  • 注册表工具支持强制 GitHub 签名验证，增强供应链安全
  • 优化安装锁等待提示，明确显示持有锁的进程 ID
  • 下载速度低于阈值时发出警告并建议镜像源
  • 修复中断安装导致的版本列表污染问题
  • 修复 mise prune 误删其他项目固定版本的问题
  • 修复 pipx/pypi 解析开发版及 git+ssh URL 的问题
  • 修复 brew 源构建中 HTTPS 到 HTTP 重定向的校验逻辑
  • 修复 Windows 下 npm 后端 aube 更新导致的 EISDIR 错误

安全修复

  • 注册表工具支持强制 GitHub 签名验证，防止未经验证的资产安装

rxhanson/Rectangle v2.0 - v2.0.1 Qwen/Qwen3.8-27B

新内容

  • 新增键盘导航功能，支持在堆叠窗口切换器中操作
  • 新增可选的吸附动画和模糊吸附预览效果
  • 新增将显示器平铺为行或列的新窗口操作
  • 新增选项，允许半屏操作保留窗口另一轴的原始尺寸（可选）
  • 新增选项，允许重复最大化时恢复窗口之前的尺寸和位置（可选）
  • 新增选项，保持受约束窗口顶部对齐
  • 优化平铺功能，支持在平衡网格中循环切换行和列
  • 现代化重构 Rectangle 用户界面，保持简洁性的同时适应更多变更
  • 调整 macOS 27 的应用图标样式
  • 在窗口列表快捷键记录器旁显示描述信息
  • 在移动窗口到另一个显示器时保持其原有位置

问题修复

  • 修复 macOS 15 上的崩溃问题
  • 修复 macOS 15 上快捷键大纲视图左侧显示 20px 列的问题
  • 修复 Chromium 增强 UI 的性能回退问题
  • 修正窗口操作期间过时的 Dock 内边距
  • 修复无法容纳布局时窗口的说明提示
  • 修复当窗口几乎填满其区域时不必要的重新对齐问题
  • 修复关闭 unsnapRestoreFromSizeChange 时未保留恢复矩形的问题

TriliumNext/Trilium v0.106.0 Qwen/Qwen3.8-27B

新内容

  • 看板视图全面重构：支持列图标、颜色、卡片限制、折叠与归档，新增收件箱列、模板创建及属性控制
  • 看板视图增强：支持按标题 / 日期 / 属性自动排序、完整搜索语法过滤、多选批量操作及键盘 / 触控支持
  • 搜索功能重大改进：标点感知精确匹配、模糊容错随词长缩放、链接预览与引用目标可搜索、重音符号高亮归一化
  • 搜索结果排序优化：按匹配质量（精确短语 > 邻近度 > 单词 > 前缀 > 子串 > 模糊）排序，确保标题匹配优先于内容
  • 地理地图新增内置位置搜索、当前位置指示器及形状绘制（路径、区域、矩形、圆形），支持 Nominatim 全球搜索
  • 模板支持定义新笔记的默认父节点，未显式指定位置时自动放置在指定父节点下
  • LLM 集成新增对 Google Antigravity 的支持，兼容免费计划
  • 应用启动时显示专用加载屏幕，替代纯白背景
  • OCR 现在正确支持图像（扫描版）和基于矢量的 PDF 文件
  • 排序功能现支持多条件组合
  • 搜索框（完全搜索 / 快速搜索）新增语法高亮、自动补全、@- 笔记插入及内联错误提示，完全搜索支持多行
  • 文本笔记中现可插入图标
  • Markdown 导入 / 导出保持可折叠属性并尽可能保留格式转换时的样式
  • 桌面端额外窗口（如在新窗口打开笔记）打开速度显著提升
  • 电子表格打印、导出和分享时呈现编辑器中的外观，包括链接、旋转文本和边框
  • 插入日期 / 时间功能提供多种格式，可通过下拉箭头和斜杠命令访问
  • ETAPI 在创建笔记和补丁笔记时接受 utcDateModified 参数
  • 服务器和桌面应用迁移至 ESM，降低内存消耗并加快启动速度
  • 通过清理和优化依赖项，Trilium 磁盘占用减少约 8 MB
  • Docker 健康检查脚本优化，更快且 CPU 占用更低，能正确报告自签名证书状态
  • 演示集合新增几个主题
  • 前端脚本现可使用 SortableCard 和 dialog.pickSingleItem API
  • Linux 用户可在 Flathub 上获取 Trilium

安全修复

  • 加固了共享相关功能，包括包含笔记、共享别名和图标包
  • 加固了摘录渲染机制

Breaking Changes

  • cheerio 已从内置库中移除，因为它仅被第三方脚本使用，需参考文档进行迁移
  • 服务器已迁移至 ESM，入口点从 main.cjs 更改为 main.mjs，直接指向 main.cjs 的用户需更新配置
  • #label=value 现在是严格的全值相等匹配，#capital=Vienna 不再匹配 Vienna Austria，快速搜索仍保持 “包含” 语义

问题修复

  • 修复小尺寸下侧边栏按钮与标签按钮重叠的问题
  • 修复 macOS 上通过 npm 安装时 Claude Code/Copilot 集成有时无法找到二进制文件的问题
  • 修复中断 Claude Code 流时显示错误的问题
  • 修复 Markdown 导入时换行分割导致复选框未保留的问题
  • 修复 Home 目录中出现 startup-metrics.log 文件的问题
  • 修复 macOS 应用图标在小尺寸下渲染为彩色噪点的问题
  • 修复 Notion 导入时部分笔记尽管 HTML 导出中存在但未保留创建日期的问题
  • 修复首次初始化数据库时的一些非关键错误
  • GPX 轨迹拥有专用图标，导入时名称不再携带扩展名
  • 向量主题支持自动浅色 / 深色模式
  • Markdown 预览中移除标签
  • 分享时显示搜索结果的匹配内容
  • 检测 GitHub Copilot shims 并正确报告
  • Claude Code 和 GitHub Copilot 更高效，减少对话间的时间和内存消耗
  • 图标在整个应用中垂直对齐正确，包括图标包
  • CI 流程加固
  • 添加 Trillium 拼写变体以改善发现性
  • 对齐 Linux 窗口类与启动器
