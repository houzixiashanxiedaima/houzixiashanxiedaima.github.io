nexu-io/open-design open-design-v0.19.2 gpt-oss-120b

新内容

  • 一键安装 DeepSeek Harness，支持 macOS、Linux、Windows PowerShell 与 CMD。
  • 安装脚本采用 shell 安全路径，Windows 应用及 DSH_HOME 包含空格亦可正常连接。
  • 离线安全的 HTML 导出，打包本地图片、样式、字体、模块等为单文件。
  • 长时间代理运行保持响应，聊天流式输出同时后台批处理持久化与 React 更新。
  • 支持仅使用项目 ID 进行 od export，无需工作区或成员标志。
  • 结构化 Design System 3.0 运行时，提供意图映射、组件实现、令牌与规则。
  • 代理可在生成前解析组件，仅加载声明文件并验证复用、必需状态、令牌使用等。
  • 新增 13 个 DeepSeek Harness 设计插件，按视觉、生成 UI、工作流、预览等分类并提供本地化页面。
  • 包装应用搜索标准 nix-darwin、NixOS、系统及用户配置目录以发现本地安装的 CLI。
  • 首页创建行优先展示常用项目类型，提升创建体验。
  • 生产部署后清除活动主机并设置短 TTL，降低访问陈旧页面的时间。
  • 取消 Harness 运行后立即标记为已取消，保留提供者错误详情并记录正确的提供者与模型。
  • 预览与工作区 UI 改进：演示恢复、反向代理预览、评论桥等待提交的预览 URL、移动端预览无闪烁、全屏显示等。
  • Sidecar 支持内部主机白名单，确保在受限内部主机下的部署可用。
  • 统一 DeepSeek Pro 与 Flash 活动文案，保持产品与本地化登陆页一致。

问题修复

  • 解决缺失或过大依赖导致的导出错误，改为返回明确错误信息。
  • 取消运行状态不再显示为 Working、Done 或 Run failed，避免误导。
  • 缺少 DeepSeek 凭证时提供设置步骤，避免出现 [object Object]。
  • 长结构化事件流在输出后不再让聊天保持忙碌，提升交互流畅度。
  • 项目导出避免重复的工作区上下文失败，提高稳定性。
  • Chromium 中断 about:srcdoc 时演示可恢复，防止预览崩溃。
  • 通过反向代理的预览正常工作，评论桥在准备就绪前不提前报告。
  • 移动端评论预览关闭时不再闪烁，幻灯片预览填满视图且不出现信箱框。
  • 消息中心行重新显示已配置的 HTTP (S) 动作。
  • 不安全的动作 URL 被隐藏，提升安全性。

jdx/mise v2026.8.6 gpt-oss-120b

新内容

  • 可恢复的 HTTP 下载，支持通过 Range 请求在验证 ETag 或 Last-Modified 时续传
  • Homebrew cask 后端新增结构化 symlink 步骤、通用制品和复制 / 安装阶段，并支持事务回滚
  • 任务运行 mise run —all 可打开交互式任务选择器，遍历整个 monorepo
  • 新增 task.cache.audit_report，可将完整缓存审计报告写入 JSON Lines 文件
  • dotfiles 条目支持 inline content 声明，便于小型配置和用户可写路径
  • deps 提供者配置字段支持 Tera 模板渲染并进行环境变量展开
  • 新增 config-root 范围的 [tool_config] locked = true 策略，强制工具使用锁文件
  • 注册表新增 native-sdk、restate 二进制、mailpit 等工具

Breaking Changes

  • mise use —global 与路径同时使用将被拒绝，不再默默忽略
  • -b 现在是 —bump 的快捷方式，旧的 -l bump 缩写被隐藏并计划在 2027.8.5 移除

问题修复

  • 修复 monorepo 模式下任务名称解析及工作目录规范化等问题
  • 修复 HTTP 下载重试逻辑，包括 HTTP/2 REFUSED_STREAM 和系统安装路径
  • 修复 Windows 平台下的激活、补全、Shell 路径、shim 名称及工具路径处理错误
  • 修复 checksum 校验、pipx wheel 发现、conda 锁数据、npm 生命周期日志、OCI 标签处理等错误
  • 修复配置编辑过滤、生成绝对本地化目录、锁文件包含任务特定工具等问题
  • 修复 aqua 校验错误、ruby-build CLI 支持、rust nightly 解析、semver 标记等其他问题
