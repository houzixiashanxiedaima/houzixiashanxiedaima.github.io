### [jdx/mise v2026.10.0](https://github.com/jdx/mise/releases/tag/v2026.10.0) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 Homebrew cask 独立应用目录（appdir）配置，支持覆盖全局设置并展开 ~/

**安全修复**
- .tool-versions 中的内联工具选项现在需要信任，防止未受信任项目泄露 GITHUB_TOKEN

- mise bootstrap --from-git 已移除，请使用 --adopt 标志

- Alpine/musl 主机上如果注册表条目指定 gnu 资产但发布也包含 musl 构建，现在安装 gnu 构建…
- 脚本中检查 Ctrl-C 后的退出状态应从 1 改为 130

**问题修复**
- 修复锁定 SLSA 安装在无注册表签名者时的失败问题
- 修复 musl 主机上 aqua 工具安装失败的问题
- 修复 mise backends switch 处理过期锁条目的问题
- Ctrl-C 中断命令现在以状态码 130 退出，与 mise run 保持一致
- 拒绝信任提示时跳过当前运行的配置而非直接失败
- 移除过期的 latest 运行时目录一次性启动迁移逻辑
- 诊断过期的 dotfile 历史监视器，提示用户运行 mise bootstrap services apply
- Java 缺失元数据错误现在显示目标平台信息
