farion1231/cc-switch v4.0.9 glm-4.7-flash

  • 修复 Claude Code 上游格式选 OpenAI Chat 或 Responses 时，路由发出 x-api-key 导致认证失败的问题
  • 修复 Claude Code 聚合模式下兼容开关合并逻辑，避免因个别供应商不支持功能而报错
  • 修复启动时界面语言不对，打开设置页后才变回正确语言的问题
  • 修复 macOS 上连不上局域网 API 地址的问题，新增本地网络权限申请
  • 修复打开供应商编辑面板时页面闪一下的问题
  • 修正 Flatpak 构建文档中的 —bundles 参数写法及跳过更新包说明

code-yeongyu/oh-my-openagent v5.1.30 deepseek-ai/DeepSeek-V4-Flash

新内容

  • 首次真实提示词即开始引导，无需单独模型轮次

  • 新增 OmO 账户基础命令 omo login、omo whoami、omo logout

  • 默认链为 OpenAI 与 ChatGPT 订阅新增 GPT-6.1 Sol 中等推理
  • Windows 钩子命令与插件更新不再弹出额外控制台窗口
  • OpenCode 会话工具可跨项目查找会话
  • 计算机使用可检查并选择 macOS 菜单栏命令
  • 计算机使用可向 macOS 日期时间控件写入 ISO-8601 值
  • 计算机使用超时消息显示桌面引擎停止应答的位置
  • 线程绑定支持 WhatsApp 作为原生平台
  • 工作流节点 ID 在结果存储前检查
  • mass-ulw 通过单个审查节点连接相邻全对全波次
  • 下载统计改为每小时刷新
  • 任务分片在所属会话退出后不久停止
  • 长会话停止每轮重写提示缓存，上下文缩减保持稳定前缀
  • 修复 OpenAI 模型在兼容网关后每轮报错 Invalid value: allowed_tools
  • 页脚在有空间时显示推理模型的级别为 effort
  • 挂起的子任务不再滞留在任务列表中，自动恢复或结束

Breaking Changes

  • 前台计算机使用现在需要用户明确确认授权
  • 工作流节点 ID 含非法字符的现有运行升级后无法恢复结果，需重命名节点并重启运行

问题修复

  • 修复父级拆除期间子进程短暂误报失败的问题
  • 修复 Windows 下钩子与插件更新弹出额外控制台窗口的问题
  • 修复计算机使用设置 macOS 弹出菜单时忽略写入却报成功的问题
  • 修复计算机使用超时消息无法区分故障阶段的问题
  • 修复工作流节点 ID 含非法字符导致结果路径异常的问题
  • 修复任务分片宿主在会话退出后仍常驻的问题
  • 修复必需压缩在最新消息不安全时卡住的问题
  • 修复会话恢复时节点 ID 含非法字符无法恢复结果的问题
