nexu-io/open-design open-design-v0.21.0 Qwen/Qwen3.8-27B

新内容

  • 多文件 HTML 预览保持实时且正确加载脚本、样式、图片及模块，切换项目或文件不再出现白屏
  • 演示模式新增可靠的退出控件，点击预览区域可关闭视口菜单
  • 修复 Agent 检测逻辑，跳过失效的 PATH 垫片并支持 DeepSeek Harness 当前发布线
  • Kimi 0.37+ 版本会话移除不支持的 stdio MCP 传输，恢复流式回复功能
  • 应用重启时可安全回收崩溃遗留的 Web Sidecar 进程，防止后续启动失败
  • Coding Plan 模型访问权限改为读取实时认证权益列表，DeepSeek V4 Flash Vision Exp 加入无限使用套餐
  • AI Optimize 增加防重复机制，确保同一对话中仅运行一次设计系统优化
  • 新增 OD_MCP_STDIO_IDLE_EXIT_MS 配置项以控制 stdio MCP 空闲生命周期
  • 定价页面根据登录订阅状态动态显示，明确展示待处理、取消中等状态
  • Go 计划对新用户标记为售罄，客户端移除旧版活动徽章和欢迎弹窗
  • 所有社区入口统一指向 Discord，包括中文桌面端、网站及文档界面
  • 账户头像菜单首次点击后保持打开，需二次点击或按 Esc 键关闭
  • 空 Skills 源自动从过滤器中隐藏，有内容时自动恢复显示
  • 无头及容器部署环境不再提供无法渲染的 PPTX 导出路径，连接失败不再伪装为功能缺失
  • Antigravity Agent 接收真实用户提示词而非字面量 -
  • 原生恢复和转录回放共享跨 Agent 安全决策，仅在会话匹配时恢复，否则清除句柄并重播完整转录
  • ACP 使用量、会话信息及命令元数据不再作为原始状态文本泄漏到可见对话中
  • ACP 阶段超时保留真实静默时长并指明看门狗名称，便于诊断高成本停滞问题
  • 打包客户端在启动时回收无响应的 Web Sidecar，并在桌面端退出时清理守护进程和 Web 子进程
  • 前台失败不再触发冗余系统通知，后台通知和完成声音行为保持不变
  • DeepSeek 活动使用官方提供商标识，图片加载失败时提供无障碍可读的回退方案
  • 模型排序、计划文案及推荐颜色在定价页与主页间保持一致

问题修复

  • 修复 Antigravity Agent 接收错误提示词的问题
  • 修复 ACP 元数据泄漏至可见对话的问题
  • 修复 ACP 阶段超时诊断信息不准确的问题
  • 修复 Website Clone 起始文本未本地化及状态管理问题
  • 修复 Local CLI 选项在引导过程中对齐不一致的问题

  • 修复 FancyZones 在关机、重新配置及窗口关闭时的竞态条件与残留覆盖层
