jxxghp/MoviePilot v3.2.10 Qwen/Qwen3.8-27B

新内容

  • 媒体服务器：新增跨媒体服务器的统一浏览、筛选、三级详情、音轨 / 字幕选择与播放进度接口
  • 支持合集（BoxSet/Collection）媒体库及按父级逐级浏览子项
  • 重构绿联双模式前端配置界面，优化 NAS 账号 / 媒体库服务配置体验
  • 插件市场支持直达路由先打开目标插件，版本历史优先展示缓存并后台异步刷新
  • 隔离单仓库索引拉取与全量市场扫描，兼容第三方索引中的嵌套 history 格式
  • 插件 SDK 新增浏览器队列状态查询与取消契约
  • 重新设计设置页各配置卡片，优化信息层级、展开 / 收起交互与玻璃主题显示效果
  • Fanart 剧集查询在缺少 TVDB ID 时回退至 TMDB ID
  • 新增 AIGROW provider
  • 支持 ColaPT open API
  • 记录 logo_language 元数据并在用户全局设置中暴露 TMDB_LOCALE

Breaking Changes

  • 将 UberLLM 重命名为 MartLLM，需同步修改相关配置

问题修复

  • 修复绿联双模式下的媒体查询、条目获取与会话隔离问题
  • 修复季目录名带年份时误判为剧集根目录的问题
  • 修复集数偏移替换范围过大的问题
  • 修复规则组查询未保留调用方顺序的问题
  • 修复企业微信图文通知缺少标题时发送失败的问题
  • 添加或保存站点时保留多级子域名，自动清理 UA / 自定义请求头首尾空白并对非法请求头返回明确错误
  • 移除硬编码的 VAPID keys 并暴露运行时公钥 API
  • 补充缺失的 WebPush VAPID 公钥消息翻译
  • 音乐转移时剥离 HDDolby 规格尾部
  • PostgreSQL 序列迁移时跳过非整数 ID
  • 升级 moviepilot-rust 至 0.3.14
  • 若干琐碎修复（测试环境隔离、构建描述保留等）

  • 修复 Windows 上 gateway 测试释放数据库及 Linux 状态文件测试的平台兼容性
  • 若干琐碎修复：文档引用修正、bundle 重新生成、测试格式调整及 CI 配置优化

Stirling-Tools/Stirling-PDF v3.5.0 Qwen/Qwen3.8-27B

新内容

  • Docker 容器使用 Stirling Office Convert 替代 LibreOffice，转换速度更快、质量更高，且未来版本体积减半
  • 压缩功能现使用 Office Convert
  • HTML 转 PDF 重新支持缩放
  • 新增管理员设置以限制同时运行的 Office 转换数量并启用队列
  • 损坏的 Office、电子书和 HTML 文件现在显示清晰的 “无法读取” 消息而非错误提示
  • 桌面端 PDF 操作提速，PDF 引擎现已预装于应用中
  • 查看器、文件列表等整体性能优化
  • JPDFium 及其他依赖更新带来多项 Bug 修复与改进
  • 文本编辑器支持公式的可访问性标记
  • 未登录桌面用户在使用需要账户的工具时将被提示登录
  • PostHog 客户端延迟初始化以减少队列线程唤醒
  • 查看器工具栏通知订阅与状态变量解耦
  • 文件过滤逻辑整合并减少临时分配
  • 策略列表每会话状态仅获取一次
  • 设置导航的可访问性与样式改进
  • 繁体中文翻译更新与改进
  • 不再从磁盘重新加载已打开的文档，仅跟踪其原始文件是否丢失
  • 桌面端打包中预装 JPDFium 原生库

Breaking Changes

  • 移除 PDF 转 .doc（Word 97-2003）输出，请使用 docx 或 odt；API 调用、管道和自动化请求 doc 将返回错误
  • 不再接受 .wpd、.wps、.lwp、.abw、.hwp 和 .xps 文件进行转换
  • groupsToRemove 中针对已移除工具（LibreOffice、Calibre、Weasyprint、OpenCV 等）的条目不再禁用任何内容

问题修复

  • 修复桌面端文档在打开后几秒内自动重载并丢失进度的问题
  • 修复查看器中已填写表单字段值显示两次的问题
  • 修复深色模式下表单值不可见的问题
  • 修复应用更改后缩略图侧边栏卡在 “加载中…” 的问题
  • 静默开发代理 ECONNREFUSED 日志刷屏
  • 对齐添加密码高级下拉框与其他 UI 的一致性

  • 修复 SiliconFlow 中国余额恢复、Usage & Spend 未定价请求隐藏、Droid API 密钥说明缺失
