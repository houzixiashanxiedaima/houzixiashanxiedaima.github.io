lissy93/dashy 4.5.0 gpt-oss-120b

新内容

  • 拖拽编辑：可拖动章节、项目和小部件进行重新排序或移动
  • 新增实时网球小部件，显示 ATP/WTA 赛事实时比分
  • GitHub 统计小部件重构，使用 GitHub API 并支持 token 提升速率限制
  • 自定义 API 小部件新增字节、比特率、时长等格式及前后缀、缩放等功能
  • 长标题支持滚动并在悬停时显示完整 tooltip
  • 登出后可自定义跳转页面
  • 可通过 DISABLE_PROXY_ENDPOINTS 环境变量关闭内置 CORS 代理
  • 客户端仅 OIDC 选项，跳过服务器端 token 检查
  • 官方浏览器支持升级至 Chrome 111+、Firefox 114+、Safari 16
  • OIDC 用户 / 组的显示 / 隐藏配置键名更新，新增 showForGroups、hideForRoles 等数组选项
  • 强制章节名称唯一并使用 slug，更新 UI 编辑器和 schema
  • YAML 解析升级至严格 YAML 1，仍支持合并键、时间戳和二进制标签
  • 移除对旧版 ES256K、secp256k1、Ed448 等不安全算法的支持
  • Node 运行时升级至 24 LTS，要求 Node 24 或更高版本
  • Docker 镜像不再构建 arm/v7，构建时间显著缩短

安全修复

  • 修复 js-yaml 中的 GHSA-pm4m-ph32-ghv5 安全漏洞
  • 修复 jose 中的 key size mismatch 漏洞（#883）
  • 移除不安全的旧版认证算法（ES256K、secp256k1、Ed448），提升安全性

Breaking Changes

  • Docker 镜像不再支持 arm/v7，32 位 ARM 设备需自行构建或使用旧镜像
  • 浏览器支持仅限 2023 年及以后版本，旧版浏览器将失去兼容性
  • Node 版本要求提升至 24 LTS，低于此版本无法运行
  • 配置键名更改，旧的 show/hide 配置需迁移至新字段
  • 章节名称必须唯一且存在，重复或缺失名称的配置将报错
  • 不再支持 ES256K、secp256k1、Ed448 等旧算法，使用这些算法的 OIDC 提供者需升级
  • 以点开头的文件不再被服务，需重命名或移除相关引用

问题修复

  • 修复编辑后保存到错误位置的问题
  • 恢复左键点击上下文菜单功能
  • 配置编辑器打开更可靠，避免偶发失败
  • 会话过期后自动登出，避免假登录状态
  • 修复 Netlify 状态检查在新版 Node 上的失效
  • 修复短间隔检查的四舍五入错误并提升整体可靠性
  • 保存的配置立即生效，无需刷新页面
  • OIDC 提供者未返回 token 时给出警告而非崩溃
