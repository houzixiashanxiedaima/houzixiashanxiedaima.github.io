foru17/neko-master v1.4.4 - agent-v1.4.9 Qwen/Qwen3.5-27B

新内容

  • 本次发布未提供具体更新内容
  • 新增俄语界面支持，语言菜单中可选 “Русский”，未翻译字符串回退至英文
  • Agent 单实例锁改用内核 flock，进程退出自动释放，避免残留锁文件或 PID 复用导致启动失败
  • OpenWrt procd 配置改为无限重试（respawn 3600 5 0），不再因一小时内 5 次启动失败而放弃
  • Agent 报告请求复用连接，修复响应体未读完导致每 2 秒新建 TCP+TLS 连接的问题

Breaking Changes

  • Agent 检测到另一实例已运行时退出码由 0 改为 1
  • 手动启动的旧版 Agent 进程不持有新锁，升级前需先停止该进程

问题修复

  • 修复网关中断超过 5 分钟后长连接被重复计数的问题，陈旧性现基于最后接收快照计算
  • 修复 Cloudflare Tunnel 等代理下切换、测试或清除后端时出现 415 错误的问题，四个无 body 端点现接受空请求
  • 修复自定义范围不超过 6 小时且早于 7 天时显示全零的问题，现读取小时表数据
  • 修复非 UTC 时区下超过 6 小时的流量趋势时间偏移问题，存储时间键现按 UTC 解析
  • 修复 ClickHouse 模式下流量趋势当前点重复出现的问题，所有趋势时间统一使用 T 分隔符
  • 修复清除或删除后端后 Agent 缓冲流量仍被写回的问题，Agent 缓冲区现一并丢弃
  • 修复更改访问令牌或清除后端时错误提示显示原始消息键的问题
  • 修复窄屏下趋势卡片切换按钮溢出的问题
  • 修复 Agent 异常退出后可能永久无法重启的问题，单实例锁现由内核 flock 管理
  • 修复 Agent 停止时正在传输的批次可能丢失的问题，启动绑定冲突重试期间收到停止信号立即退出
  • 修复 pnpm check:api-routes 在目录重构后因 ENOENT 失败的问题

  • 凭据隔离：复用和缓存的插件结果限定在其连接凭据范围内，其他插件的传输钩子保持在提供商源上

  • 子进程环境：防止托管 Signal 守护进程和捆绑语言服务器继承无关的 Gateway 秘密
  • 认证错误：显示凭据读取失败而非将其视为缺失凭据，拒绝属于不兼容提供商的显式选择认证配置文件
  • 通道安全：将传入的 Twitch IRC 内容排除在解析器错误日志之外，多个 Tlon 审批待处理时要求显式请求 ID

  • 修复 Windows 等效路径别名下状态所有权错误报告离线维护的问题
  • 修复详细诊断中泄露被抑制回复文本和后台命令内容的问题
  • 修复 Doctor 填充回退发送者而非保留显式空组允许列表和禁用策略的问题
  • 修复已提交 SQLite 写入因工作结果不可序列化而触发不安全重放的问题

  • 修复分离后代清理不确定时未完成命令退出结果丢失及临时 MCP 配置目录残留的问题
