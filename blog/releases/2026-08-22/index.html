nicobailon/pi-subagents v0.54.0 Qwen/Qwen3.8-27B

新内容

  • 新增按代理模型限制及当前父级继承允许列表别名
  • 在子代理列表和详情输出中显示包名称、版本及外部任务提供者状态，便于发现和使用包代理（如 Surf 的 gpt-pro）
  • 简化 Council Mode 顾问选择，使基于模型的配置文件提供视角，问题提供决策框架
  • 将自然语言请求路由至 Council Mode 协议，支持顾问委员会、计划批评、交叉质询或多模型视角
  • 改进 doctor 和工作流指南中对脚本化工作流辅助支持和过期会话恢复的可见性
  • 移除公开工作流输出中的内部转换日志，使结构化单孩子执行回执更安静

问题修复

  • 修复自定义代理用户和项目覆盖层叠时丢失仅用户字段的问题，同时保留项目优先级
  • 通过仅在显式原生权限规则下加载外部权限系统桥接并关闭停滞询问决策，避免子工具调用挂起
  • 防止前台工作流孩子在工具结果回填后无单独执行结束事件时超时
  • 当持久化会话文件可用时，将已完成的前台工作流孩子标记为可恢复
  • 避免在子代理进程中加载父扩展图
  • 停止上下文溢出失败时的模型回退并暴露 contextOverflow
  • 停止空慢结果扫描刷屏会话记录
  • 暴露逻辑工具失败以便子代理工具结果正确回填

nexu-io/open-design open-design-v0.20.2 Qwen/Qwen3.8-27B

新内容

  • 导出性能优化：字体或图片加载失败时不再阻塞整个流程，卡住的导出从十分钟缩短至一分钟内完成
  • HTML 预览状态保持：切换项目、文件标签或预览 / 代码模式时保留滚动位置、实时文档和编辑内容，文本修改保存后立即显示
  • 首次运行设置增强：选择本地 CLI 后需检测到才允许继续；BYOK 模式下点击连接测试通过后才完成设置
  • 定价与套餐页面校准：当前套餐标记为 Current plan，低阶套餐不可点击，高阶套餐保留升级入口，节省金额、模型顺序等符合设计规范
  • 无限使用徽章修正：仅在实际包含的模型上显示 Unlimited，Team 工作区不再继承个人套餐徽章，BYOK 不再声称平台侧无限使用
  • 余额显示优化：余额恰好为零的订阅者不再显示无法操作的余额芯片，透支、免费套餐和 Team 仍显示需关注的余额
  • 更新按钮布局调整：新版本下载完成后，绿色更新按钮独立显示在头像 / 余额胶囊右侧，避免拥挤账户菜单
  • 消息中心简化：已读和未读消息合并为单一列表视图，移除筛选标签，未读项显示紧凑圆点，打开仅标记该条消息为已读
  • 社区链接移至导航栏底部：社交链接从账户菜单移至首页导航底部，中文界面显示飞书群，其他语言显示 Discord
  • 官网首页优化：品牌声明更清晰，能力芯片更轻量，CTA 更克制，视频演示改为点击加载，已点击下载的用户不再重复提示
  • 产品菜单新增 Codex Plugin 入口，DeepSeek Harness 指南改为按平台一行安装器，提供更直接的入门流程

问题修复

  • 修复生成文件的运行被错误报告为无产出的问题，浏览器未及时同步文件时信任守护进程确认的交付结果
  • 修复真正无产出的运行仍显示原始错误信息
  • 修复项目预览中内联脚本在 URL 重写后失效的问题，CSS 和其他资源保持工作区作用域
  • 修复定价页面语言闪烁问题，应用传递的语言环境在页面渲染前生效，直接访问无明确语言环境时遵循浏览器和保存偏好
  • 修复结账返回路径问题，来自测试、功能验证和本地环境的定价跳转返回各自入口而非生产环境，无效目标显示本地化错误并禁用结账
  • 修复低余额对话框操作按钮视觉一致性问题
