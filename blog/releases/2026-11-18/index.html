yetone/alma-releases v0.4.737 - v0.4.798 Qwen/Qwen3.8-27B

新内容

  • Go 轮次的中途压缩摘要现在运行在 Go 自身的提供商栈上
  • Node 在 Go 流式传输摘要（含重试）期间暂停压缩请求并返回摘要
  • 设置 ALMA_NODE_COMPACT_SUMMARY=1 可保留 Node 端的摘要处理
  • Android：离开家庭网络时，Tailscale 仅在提供比中继更好的连接时才使用
  • 长对话现在默认打开最新消息，并支持向上滚动查看历史消息
  • 优化移动端聊天性能：大型对话现在快速打开并显示最近消息，向上滚动时再加载更早的消息，而非一次性下载整个线程
  • 斜杠命令 /pwd、/ls 和 /cat 现在可直接在本地工作区中使用
  • 优化工具搜索功能，提升可用工具的查找效果

问题修复

  • 修复 iPhone 照片（HEIC、AVIF）无法附加或显示的问题，在 macOS 上现会自动转换为 JPEG
  • 修复默认终端名称未按应用语言（如中文或日文）显示的问题，自定义名称不受影响
  • 修复消息中极高图片变得过窄或被裁剪的问题，现在保持可见且可点击区域并完整显示
  • Desktop：对话搜索失败时，应用现在会提示搜索无法完成，而不是显示 “未找到结果”
  • iOS：修复手机上的聊天列表标题居中问题，设置位于左侧，控制计算机 / 代理位于右侧
  • iOS：改进代理输入框的模糊效果，内容平滑淡出且无生硬线条，滚动到底部箭头保持清晰
  • 修复了监控代际的静音检测，使其使用流空闲超时而非隐藏的 300 秒主体超时
  • 修复系统时区变更后消息时间戳未更新的问题，确保时间和 “今天” 标签在旅行后仍正确显示
  • 修复导致 0.4.741 版本无法构建的服务器问题
  • 修复点击引用时焦点未移动到被引用回复的问题
  • 修复重复标题的链接跳转问题，确保加载后能正确滚动到对应标题
  • 修复文本后跟虚线时可能错误转换为标题的格式问题，现在文本和分隔线显示正常
  • 修复发送消息时丢失前导空格的问题，缩进大纲、步骤和制表符详情现在能按输入原样显示，复制这些消息时也会保留空格

anomalyco/browse v0.1.4 - v0.1.5 Qwen/Qwen3.8-27B

新内容

  • 扩展名称更新为 OpenCode Browse，包括 Chrome 应用商店和工具栏按钮

  • 中继（relay）不再因无代理连接而自行关闭，从而能在后台持续检查更新

  • 任何与当前运行版本不同的版本均被视为更新，确保回滚也能触达所有用户
  • 从终端启动的中继在安装更新后仍会保持运行旧版本，需手动重启才能生效
