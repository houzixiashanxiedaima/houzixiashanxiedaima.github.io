callstack/agent-device v0.20.3 - v0.20.4 gemma-4-31b

新内容

  • 支持在回放后通过 —keep-session 或 SDK 保持会话以进行交互式操作
  • 增强回放执行的可靠性，包括脚本验证、启动重试、稳定性检查及离屏验证
  • 新增云端连接验证功能，可在不分配设备的情况下验证 BrowserStack、AWS Device Farm 和 Limrun 凭据
  • 增强 BrowserStack 会话配置，支持方向、位置、时区、语言、网络等设置
  • 优化设备自动化性能：支持并发设备发现、优先使用 usbmux 物理 iOS 传输，并优化快照遮挡缓存以降低延迟
  • 提升 Android 权限提示、文本读取和快照恢复的可靠性
  • 新增针对变异（mutation）的目标注解序列化与快照遮挡内核
  • 更安全的 replay 引用，仅发布实际暴露的元素引用，保持会话绑定且一次性
  • iOS 启动更可靠，保留 clear‑state 行为，使用 URL 作为原子冷启动触发
  • 扩展 Limrun 会话支持，新增应用管理、输入、日志、录制、安装、Android 端口转发和 iOS 模拟器操作等能力
  • 加速单元测试并简化检查流程（提升测试性能）

安全修复

  • 限制项目本地配置的信任范围，禁止其控制凭据、远程端点、提供商设置及请求头等敏感值

Breaking Changes

  • 敏感或操作员特定的配置值必须从项目本地 json 文件迁移至用户配置、环境变量、CLI 参数或远程配置文件中

问题修复

  • 修复 Android 权限提示被误认为点击逃逸的问题，现将其视为待处理警报
  • 修复 iOS 物理设备横屏点击的归一化问题
  • 修复 iOS 运行器安装失败时的诊断逻辑，不再误报为屏幕问题
  • 修复 Android 获取文本时未能从目标字段读取的问题
  • 修复 daemon CPU 占用过高问题，通过对快照遮挡覆盖检查进行缓存处理
  • 修复多个正则表达式导致的潜在 ReDoS 漏洞
  • 修复 iOS 滚动搜索的等待时长及离屏点击拒绝的验证逻辑
  • 修复 daemon 在请求入口处对不支持的 —save-script 标志的拦截逻辑
  • 修复若干测试用例（包括 Android 模拟器 E2E、iOS fixtures 及并行提供商场景）
  • 修复依赖项 qs 的安全警报
  • 修复 iOS 模拟器应用 URL 的原子重新启动问题
  • 修复在 iOS 启动 URL 前未保留 clear‑state 的问题
  • 修复在响应投影后未正确发布 replay 引用的问题
  • 若干测试相关修复（scroll‑edge‑state 套件、mutation gap、daemon 模块迁移合约等）
