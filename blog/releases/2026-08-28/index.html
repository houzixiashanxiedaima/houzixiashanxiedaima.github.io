farion1231/cc-switch v3.20.1 Qwen/Qwen3.8-27B

新内容

  • Codex 第三方切换改为 config-only，密钥写入供应商配置表以适配 Codex CLI 0.149
  • 同一 Team workspace 的多个 ChatGPT 账号支持安全共存，不再互相覆盖令牌
  • 用量统计新增「自动扫描会话记录」开关，大会话文件扫描耗时从秒级降至毫秒级
  • OpenCode Go 订阅用量查询支持显示 5 小时 / 周 / 月三个窗口的用量百分比与重置时间
  • macOS 终端选择器新增 Otty 支持，覆盖会话恢复、供应商终端与工具命令入口
  • TeamoRouter 预设端点迁移至 teamorouter.cn，并在多应用注册为可测速后备端点
  • Claude 会话日志采用字节游标增量扫描，大幅降低大文件解析延迟并提升导入效率
  • Pi 会话去重引入身份索引优化，避免随历史数据增长导致的性能退化

Breaking Changes

  • 数据库 schema 升级至 v18，降级需还原迁移前自动创建的备份
  • Codex OAuth 存量托管账号需在认证中心点击「重新登录」以建立独立用户身份
  • Codex 0.48 以前版本失去第三方鉴权能力，必须升级 Codex CLI
  • 保留官方登录开关关闭时，切换第三方供应商将删除 auth.json 而非覆盖
  • 部分依赖旧式路由或空配置的 Codex 供应商在切换时会被明确拒绝
  • 存量 Codex 配置将在下次写入时按 0.149 规范重写，手动设置的特定字段不保留
  • 被外部改写的 Claude 会话日志将被永久跳过且不重放，仅报告错误计数

问题修复

  • 修复 Codex 0.149 兼容性问题，自动修复存量配置中导致拒绝启动的历史形态
  • 修复崩溃残留备份行导致供应商编辑无法更新 live 配置文件的问题
  • 修复 Codex 编辑框显示或固化其他供应商卡遗留密钥导致的串染问题
  • 修复 WebDAV/S3 备份恢复时清空非受管 prompt 文件的问题
  • 修复 v3.20.0 中恢复界面退出按钮因权限缺失无响应的问题
  • 修复 Claude 会话记账中未完整行被跳过及外部截断文件重放导致的数据错误
  • 修复被拒绝的切换操作腐坏当前供应商已存设置的问题

nicobailon/pi-web-access v0.26.0 Qwen/Qwen3.8-27B

  • 防止 Defuddle 选择器处理失败导致原始页面内容被误判为成功提取

hugohe3/ppt-master v5.1.0 Qwen/Qwen3.8-27B

新内容

  • 合并原 “填充原生 PPTX” 与 “增强原生 PPTX” 路由为统一的 “编辑原生 PPTX” 路由，支持通过 pptx_to_svg 导入、逐页编辑及导出
  • 移除导致生成幻灯片过于单调的提示词退出条款，优化风格索引映射，确保文本源自动获取网络情绪 / 场景图像和图标
  • 新增 text_measure.py 宽度估算器，在创作时校准文本行宽，修复文本溢出边界问题并完善字体栈导出逻辑
  • 引入十二项客观检查以对齐原生图表 / 表格与其 SVG 预览，修复导出器缺陷（如均匀边框对角线、空标题等）
  • 新增紧凑语义创作工作区，支持跨页面复制对象（—adopt-object）及基于解析名册的编辑文本容量门控
  • 优化规划与快速模式：design_spec_depth 默认设为 brief 以节省 token，Quick 模式保留显式模板结构并验证元数据

Breaking Changes

  • 移除旧版 CLI 工具 template_fill_pptx.py 及 native-enhance 工作流…

问题修复

  • 修复 v5.0.0 暴露的问题：包括图表 / 表格漂移、现有幻灯片路径未往返 OOXML 而是修补、以及重叠直接根模块检测失败
  • 修复往返回归问题：原始表格负载通过标记验证，update_spec.py 重新标记原生回退基线，合并单元格空白按创作行判断
  • 对抗性审查与三轮真实幻灯片测试修复了资源变更、继承根属性、注释主发现、外部链接图片、无 ID 形状、重复关系 ID 等缺陷
  • 文档与仓库更新：记录 render-batch JSON 字段及表格对齐值，FAQ 和 README 同步路由变更，修复 24 个文件中的跨运行时漂移
