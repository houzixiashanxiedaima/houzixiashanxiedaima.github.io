openclaw/openclaw v2026.9.1 Qwen/Qwen3.8-27B

  • 新增 Mermaid 图表渲染支持，适用于 Control UI 及 macOS、iOS、Android 原生应用

安全修复

  • 限制 SMS Webhook 并发预认证读取，防止资源耗尽

  • Copilot Azure BYOK 代理要求每进程 nonce，提升安全性
  • 按客户端隔离 Webhook 速率限制，防止滥用
  • config.get 不再返回未脱敏的迁移前快照，防止敏感信息泄露
  • systemd 单元备份不再泄露 Gateway token，iOS 日志省略深链 URL
  • Chrome MCP —browserUrl 端点遵守 CDP 可达性策略，阻止未审查升级
  • 拒绝不支持的 fill 字段键，临时文件名拒绝点段，跳过符号链接文件
  • 委托权限关闭后停止 Agent 创建，系统 Agent 运行结束后停止写入
  • 角色需要验证身份时暂停客户端，修复私有沙箱中的访客编码问题

问题修复

  • 修复相同会话事件重放时的迁移问题，保持嵌套会话写入顺序
  • Schema-17 会话修复原子化，遗留 cron 行保留启用状态和投递意图
  • Doctor —fix 在空工作区证明上完成，解决陈旧工作区设置循环
  • 不完整的 exec-approvals 迁移大声失败，污染的设备配对记录不再崩溃
  • 修复 Windows Doctor 和保留工作区恢复问题，确保配置值在修复中存活
  • 中断的共享凭证迁移可恢复，搁置的凭证被还原，冗余重定位子集收敛
  • CLI 和 Gateway 状态目录脑裂在凭证写入前被检测，Model Setup 不再留下陈旧密钥
  • 修复 Codex 插件在监督消息分叉中保留原生历史，空闲聊天可在其他聊天运行时恢复
  • 会话命名和切换优化，大列表切换更快，侧边栏目录组限制为五个会话
