AAswordman/Operit v1.12.1 gpt-oss-120b

新内容

  • 用户资料升级为可编辑的 Markdown 档案，支持预览、自动更新、锁定和自定义记忆提取规则
  • 角色卡和角色组可分别保存主题，支持草稿编辑、目标切换确认和未保存修改保护
  • 新增聊天标题生成模型配置，可根据首条消息自动生成标题
  • ToolPkg 与 Skill 支持拖拽排序，长粘贴文本自动转为附件
  • 消息复制新增 “纯文本 / Markdown 源码” 模式，表格、代码块、链接、公式可转换为可读文本
  • 远程 MCP 支持 Streamable HTTP、SSE、Bearer Token、自定义 Header、分页工具发现和结构化结果
  • 外部 HTTP 服务新增 A2A 1.0，支持消息发送、流式输出、任务查询、取消和订阅
  • ToolPkg 新增 wasm_modules 与 wasm.call，支持多种数值参数、返回值及 AssemblyScript abort
  • ToolPkg 新增 message_persisted Hook，聊天输入、Prompt、Summary 前置 Hook 支持全链路超时（默认 10 秒…
  • 新增角色卡管理工具，支持截图、聊天消息范围读取、指定终端会话操作和带地址的定位接口
  • 市场发布支持直接上传文件或使用已有 GitHub Release，支持审核退回后的修订发布
  • Worldbook 示例新增分组管理、条目复制、角色卡多绑定和分组删除处理
  • 新增罗马尼亚语本地化，并扩展多语言市场、工作流和设置文本
  • 优化文件内容搜索，改为内置实现，不再依赖终端环境预装 rg
  • 优化 Android V3 签名轮换，Release 与 Nightly APK 支持，Debug 使用独立包名和签名

问题修复

  • 修复多个模型服务中思考内容丢失、工具调用 ID 不稳定、历史工具调用无法正确重放的问题
  • 修复五档思考深度在 Claude、DeepSeek、Gemini、NVIDIA、OpenRouter、Qwen 等服务中的映射问题
  • 修复切换角色卡后发送、重新生成或记忆处理仍使用错误角色的问题
  • 修复取消生成时部分回复、Token 和耗时信息丢失，以及旧任务干扰新一轮生成的问题
  • 修复切换聊天或页面重组后待发送消息丢失、错发到其他聊天的问题
  • 修复超大消息和消息分支无法正常读取、导出或参与记忆处理的问题
  • 修复流式工具调用被截断、末尾内容不刷新、Markdown 节点错误复用和表格滚动位置重置的问题
  • 修复自动续写误用输入框草稿、附件和回复目标的问题
  • 修复消息图片、LaTeX 公式、小屏弹窗和暗色主题市场文字的显示问题
  • 修复 API Key 轮换、模型首次配置、语言重启恢复和损坏头像配置导致的异常
  • 修复插件导入后列表不立即刷新、市场评论权限不准确和审核状态操作混乱的问题
  • 修复终端退出后旧会话被再次复用、网页访问超时处理不明确等问题
  • 修复聊天复制时纯文本 / Markdown 源码模式的兼容性问题
  • 修复 CI 中的 flaky 测试及文档链接失效

Breaking Changes

  • 移除 Gemini 2 模型列表中的温度参数，需更新配置
  • 微软翻译切换至 Edge 公开端点，可能需要调整认证方式

问题修复

  • 修复 Gemini 2 模型列表配置错误，移除不兼容的温度参数

steipete/CodexBar v0.49.0 gpt-oss-120b

新内容

  • 新增 Fireworks 功能，可使用 API key 与账户标识跟踪 30 天计费支出
  • 改进 Provider plugins：在 macOS 与 Linux 上使用捆绑的 TypeScript 实现取代 ClinePass
  • 改进 Codex：成本历史统一存储至单一 SQLite，内存占用受限，刷新无需大规模 JSON 解码
  • 改进 CLI：仪表盘快照身份默认完整，可使用 —identity redacted 隐藏邮箱
  • 改进 Provider plugins：在所有平台使用 QuickJS，提供字节相同输出并可硬中断挂起脚本
  • 改进 Provider plugins：在 Linux 通过沙箱 QuickJS 引擎运行相同的 JavaScript 提供者和本地插件 CLI…

问题修复

  • 修复 PTY 探针在负载下因子进程组杀死导致的长时间清理卡顿
  • 修复 PTY 运行器在命令退出后未正确排空导致的错误探针结果
  • 修复 Codex 成本存储在 macOS 26+ 环境下的执行上下文错误，防止 “Incorrect actor executor assumption”
  • 修复 Codex 计费行超出规范导致的成本估算错误
  • 修复 Claude 在仅钥匙串安装时刷新令牌轮转问题，确保凭证不被无效化
  • 修复插件在 Thread (block:) 闭包上导致的动态隔离崩溃，改为 Thread 子类运行
  • 修复插件 QuickJS HTTP/COOKIE 桥接的超时启动时机错误，防止短期限误触发
  • 修复 Codex 在跨日保存会话时未保留最近修改的缓存，避免重复发现和重新扫描
  • 修复 Codex SQLite 成本存储的事务一致性，防止崩溃或中断导致数据不一致
  • 修复 Codex SQLite 保存时的性能瓶颈，预计算计数和文件查找，将保存时间从分钟降至秒级
  • 修复 Codex SQLite 删除数据库的错误，确保在临时失败时保留历史
  • 修复菜单栏指标换行及计时对齐问题，支持非英文本地化完整显示
  • 修复 Kimi 使用官方使用线路名并隐藏重复的 7 天配额行
  • 修复 CLI 在缺失 provider‑plugin 资源包时的错误提示，避免卡死
  • 修复 z.ai/GLM 配额解析错误，正确显示信用额度和重置时间

OthmanAdi/planning-with-files v3.10.0 gpt-oss-120b

问题修复

  • 修复 UTF-8 相关崩溃，恢复会话恢复功能
  • 修复 README 在移动端显示不完整的问题，重新排版表格和统计面板
  • 更新 skill-review-and-optimize 的 SHA 引用至当前发布提交，解决标记伪造问题

hugohe3/ppt-master v4.5.0 gpt-oss-120b

新内容

  • 新增 26 个模板工作区，覆盖品牌、风格和布局
  • 新增 15 个品牌身份工作区（如 McKinsey、华为等）
  • 新增 11 个风格工作区（学术研究、创意推介等）
  • 新增 6 种布局系统，包括 4:3 与 16:9 多模板
  • 模板应用改为每个工作区独立规格，避免手动合并
  • 引入可视权重所有者机制，控制颜色等视觉属性的主导性
  • 结构语法化：将目录替换为运行时形状组合方法
  • 可视化按信息模型拆分，表格重构为六种网格语法
  • 引入方向性多图像组合，支持非网格布局的图像方向与几何
  • 音频字幕支持 Word‑timed 字幕（MiniMax、ElevenLabs、CosyVoice）
  • 字幕与音频同步输出，提供回滚安全的清单文件
  • Quick 运行时配置独立，Default 与 Quick 互斥，简化工作流
  • Beautify 自动选择运行时，仅在匹配时使用 Quick
  • 项目级别 workflow.log 审计日志
  • 刷新内置图标库（Tabler 3.46.0、Phosphor Core 2.1.1、Simple Icons 16.28.0）

Breaking Changes

  • 模板规格从合并的 design_spec 改为独立的 design_spec.md，需更新自定义模板
  • 结构目录被语法取代，旧的结构键可能不再被识别
  • Default 工作流不再加载到 Quick 提示，使用方式需调整

问题修复

  • UI‑free 图像方向审查，使用 EXIF 正规化的联系表
  • 终端显示 SVG 质量来源信息，统一 JSON 报告分类
  • 提示审计结果可操作，近似重复仅报告，精确重复进行裁定
  • 重新校准预算上限以匹配审计语料库

ben-manes/gradle-versions-plugin v0.61.0 gpt-oss-120b

新内容

  • 新增 filterDeclaredConfigurations 过滤器，可按配置名称排除报告条目
  • 报告构建导入的平台项目并标注平台来源
  • 在解析策略抛异常时报告被跳过的配置
  • 报告条目使用项目构建树路径命名，避免不同构建共享同一前缀
  • JSON 与 XML 报告统一使用相同的项目路径
  • buildSrc 构建的报告条目命名为 :buildSrc:dependencyUpdates
  • 条目可携带平台导入的归属行，显示导入自 :platforms 的平台项目
  • 支持在报告中显示 filterConfigurations 未能看到的配置名称
  • 在复合构建中报告不同版本的依赖为 “分歧” 并标注各自项目
  • checkConstraints 构建可为每个平台项目生成条目，显示可升级坐标
  • 对声明平台的配置进行二次解析，以触发 beforeResolve 钩子
  • 同步 isNonStable 正则以兼容 Guava -jre 与 -android 版本

Breaking Changes

  • 报告条目命名方式改为使用构建树路径，可能影响依赖解析工具
