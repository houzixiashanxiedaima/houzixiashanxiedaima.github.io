  • iOS 动态背景 ID 支持与 Widget 图标主题匹配开关

  • 修复无根部署中 matplotlib 依赖问题

  • 修复资产文件路径匹配、元数据提取及服务器设置可用性检查错误
  • 修复创建合作伙伴时拒绝无效 / 已删除用户及上传失败后残留记录问题
  • 修复人脸合并方向切换时的缩略图显示错误

  • 修复 Codex 账户在原生凭证需要更新时提供误导性自动 CLI 重试承诺的问题，改为提供特定账户的重新认证指导
  • 修复网站阿拉伯语和波斯语英雄文案与插图重叠、文本方向异常以及平板弹出层过大的问题
  • 文档更新：将 Spark 和 Daily Routines 可见性说明指向当前的逐项控制，并将 Overview 纳入其范围

openclaw/openclaw v2026.9.4 Qwen/Qwen3.8-27B

新内容

  • 新增兼容失败更新恢复机制，在验证安全后自动回滚至上一版本
  • 统一插件工作区，支持发现、安装及管理内置与 ClawHub 插件
  • 支持从本地项目或 GitHub 仓库启动预配置云会话并创建快照
  • 终端交互增强，支持键盘选择、自由文本输入及多问题提示
  • 新增 GPT Image 2.5 的 Flare 和 Sunburst 变体用于图像生成与编辑
  • 优化对话历史可靠性，修复中断流恢复、超时通知保留及重复回答问题
  • 语音功能改进，支持子代理结果返回 Talk 并在多次委托后交付最终答案
  • 新增 OPENCLAW_CONFIG_READONLY=1 环境变量以保护部署管理的只读配置
  • 插件管理优化，支持按类别浏览、短 URL 访问及统一搜索技能
  • 云就绪工作者支持复用预配置环境，减少重复设置步骤
  • 聊天导航与创作优化，新增紧凑侧边栏、文本添加至编辑器及视频预览
  • 技能学习功能允许在常规会话中检查并继续过往工作的学习过程
  • 命令审查功能支持基于上下文允许、拒绝或升级命令执行
  • Node.js 运行时恢复功能，在不兼容时提供更新建议及诊断工具
  • 只读部署模式全面生效，涵盖配置写入、设置、修复及插件变更等场景

安全修复

  • 修复 WhatsApp 群组白名单在安全修复期间被覆盖的问题
  • 持续阻止启用私有 IPv6 例外时的云元数据地址访问
  • 限制 Slack HTTP 请求体大小以防止潜在滥用
  • 限制 Tlon 引用检索范围仅限于被引用的帖子
  • 拒绝过期的签名 Feishu 令牌（证据截断，推测为相关安全校验）

Breaking Changes

  • SDK 弃用：agent-harness-credential-prompt-string-argument 于 2026 年 9 月 9 日进入弃用阶段…

问题修复

  • 工作区与备份安全：保留并发编辑、包含外部配置文件至完整备份、排除私有更新捕获
  • 迁移恢复：恢复无标记多代理配置、保留模糊 Skill Workshop 迁移供审查、解释硬链接拒绝
  • Doctor 与认证：保留 lint 源状态、对齐迁移中的认证配置、恢复无效范围的遗留节点令牌
  • 回复交付与历史：从终止流恢复最终回复、保留部分失败轮次文本、保持段落边界
  • 聊天连续性：历史交接期间保持已提交图片可见、防止冷会话切换闪烁、协调并发更新
  • Claude CLI 会话复用：在技能监视器就绪变化但内容未变时保持热会话存活
  • 语音对话：交付让渡及反复委托的结果、允许独立语音咨询、截断中断的实时音频
  • Telegram：HTTP 代理拒绝隧道时保留回复、识别文本和图片说明中的 bot-ID 提及、保留代码示例间距

jdx/mise v2026.9.5 Qwen/Qwen3.8-27B

新内容

  • 新增 macOS 引导支持，通过 defaults_entries 块显式设置偏好（含 current-host 与嵌套默认值）
  • 优化 macOS 偏好设置体验：Finder 文件夹排序、默认云保存位置、Dock 自动隐藏延迟及键盘自动大写 / 拼写检查等
  • [bootstrap.files] 和 [bootstrap.directories] 支持 phase = “pre-packages”…
  • 普通 [bootstrap.files] 模板现可引用已解析的 [vars] 值
  • dotfiles 单一来源可通过 variants 按操作系统、架构或 mise profile 部署到不同目标路径
  • 任务源和输出支持 {{usage.*}} 模板，根据每次调用的解析参数独立跟踪新鲜度
  • brew-cask 修复结构化 set_permissions 步骤的安装问题，避免不支持的步骤类型错误
  • 新增 lockfile_mode = “generate” 选项，支持完整锁文件生成（默认仍为增量合并）
  • 新增 disable_update_warning 设置，用于抑制版本检查和 doctor 命令中的新版本提示

问题修复

  • 修复交互式安装时进度显示问题，实时显示当前状态并在最终摘要中列出变更内容
  • 修复长非 TTY 安装时 CI 日志被频繁快照刷屏的问题，心跳间隔调整为约 10% 经过时间并限制在 3 秒至 1 分钟之间
  • 修复 32 位 ARM 自更新时选择错误架构归档导致签名验证失败的问题
  • npm 安装现在包含说明文件，将更新指引重定向至包管理器而非 mise self-update
  • 修复 brew-cask 升级正在运行的自我更新应用（如 Chrome）时可能导致辅助进程卡死的问题
  • 修复 cask 元数据获取错误信息中包含过时建议及损坏文档锚点的问题
  • 修复 dotfiles origin set 在未指定 —branch 时使用仓库默认分支的问题
  • 修复 dotfiles 历史监视器锁文件位置错误导致状态误报的问题
  • 修复 macOS Seatbelt 沙箱配置，允许读取可读路径祖先的文件元数据，解决 Ruby 可执行文件解析时的权限拒绝问题
  • 注册表新增 clipboard (github:Slackadays/Clipboard)
