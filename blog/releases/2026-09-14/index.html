jdx/mise v2026.9.7 Qwen/Qwen3.8-27B

新内容

  • 新增 lockfile 修订版 2，记录 npm 和 Python 工具的完整传递依赖图，支持严格冻结安装
  • 新增 mise bootstrap dotfiles conflicts 命令，用于在解决前检查 dotfile 同步冲突
  • dotfile 模板现在可以引用 [bootstrap.secrets] 值，支持 —prompt-secrets 参数
  • pypi: 成为 Python CLI 后端的首选名称，pipx: 保留为别名且无警告

安全修复

  • 修复 history.describe_command 安全漏洞，限制其仅从全局配置读取，防止项目级配置执行未加密的 diff 命令
  • 修复 mise oci build 安全漏洞，禁用 dotfile 模板中的 secret ()、get_env ()、exec () 等函数…

Breaking Changes

  • lockfile 修订版 2 不被旧版 mise 读取，需升级协作者和 CI 后再提交新版 lockfile
  • history.describe_command 在项目配置中被忽略，需移至全局配置或设置环境变量
  • mise oci build 的 dotfile 模板不再支持调用 secret ()、get_env ()、exec () 或 read_file ()

问题修复

  • 修复从已提交的 mise.lock 安装时因 minimum_release_age 导致的失败问题
  • 修复 .python-version 文件包含 system 时错误显示弃用警告的问题
  • 更新嵌入式 aube 至 2.2.16，修复 Bun 校验和安装回归及本地 npm tarball 包名问题
  • 恢复 mc 简写使用 aqua:minio/mc，保留 asdf:mise-plugins/mise-mc 作为回退
