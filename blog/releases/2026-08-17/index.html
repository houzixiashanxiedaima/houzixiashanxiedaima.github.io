steipete/CodexBar v0.50.1 - v0.52.0 gpt-oss-120b

新内容

  • 新增使用与花费统计：按项目聚合支出并排序，窗口范围行，项目 / 会话细分通过缓存的 Codex 预填保持一致，使仪表盘和菜单图表数据一致
  • 在设置面板新增 “项目” 面板，模型和项目列表可展开超过前八行
  • 新增 CLI 命令 codexbar cost --group-by session，在文本输出中按会话分组显示 Codex 会话成本
  • 添加显式重新认证操作，使用 kiro-cli login，刷新使用统计
  • 为每个提供商添加颜色覆盖（十六进制字段、颜色选择器、重置），同步跨 Mac
  • 使工作日刻度线可配置，提供隐藏、微妙、高对比度三种外观
  • 允许最小化设置窗口并保留 Dock 图标以便恢复
  • 可选显示 Claude 模型范围的每周配额（默认关闭）

问题修复

  • 移除 Mission Control 中不可见的生命周期 keepalive 窗口，重建的设置窗口不再需要它…
  • 成本历史图表本地化项目、对话、会话以及标准 / 快速模式标签，原先在所有 23 种语言中保持英文
  • Grok 中从 CLI 设置的 subscription_tier_display 显示 SuperGrok Heavy…
  • 修复 Keychain 在后台浏览器导入时保持非交互式、遵守全局访问门，并在读取失败时重试统一迁移而不清除密钥
  • 修复 OpenCode Go 在 Auto 未获取服务器确认的使用量时，将本地配额窗口标记为估计值
  • 修复 Claude OAuth 密钥链撤销后自动回退并保留配额历史
  • 若干 UI 与仪表板修复（菜单成本摘要、成本历史对齐、Cursor 重命名、Antigravity 配额行、Serve 隐私设置等）
  • 修复 Codex 保留已完成的空本地历史记录为零使用量
  • 修复 Codex 在刷新期间保持 auth.json 只读并委托 CLI 恢复
  • 修复使用与支出在请求层级不确定时保持已定价的 Codex 总计可见
  • 修复 Vertex AI 匹配无 limit_name 的配额使用，恢复配额百分比
  • 修复 OpenCode Go 在 CLI 输出中报告 5 小时和每周使用窗口的速率
  • 修复 Mistral 在图标和百分比布局中显示本月 API 支出
  • 修复 CLI 将通知和诊断保持在详细日志中
  • 修复 Ollama 去除复制的 Cookie: 和 cURL 语法
  • 修复 Codex 成本对路由模型使用匹配的 provider.dev 价格
  • 修复 CLI 发布记录仅包含资产基名以便 sha256sum -c 验证
