yetone/alma-releases v0.4.867 - v0.4.869 Qwen/Qwen3.8-27B

新内容

  • 内存状态检查现由 Go 处理，速度更快且更可靠
  • 优化 Go 服务器中工具模型自动检测：未配置工具模型时，带查询重写的记忆检索不再不必要地将整个检索推迟到 Node，减少 97% 的契约运行
  • Go 端新增流式支持，适用于不支持函数调用的模型，涵盖提示处理、流解析、裸 JSON 恢复、RJSON 及数据强制转换
  • Node 端保留 PatternProperties 模式及 ALMA_NODE_HERMES=1 选项

问题修复

  • 修复测试录制问题，通过屏蔽主机操作系统和临时文件路径细节，使错误详情和其他测试在任意机器上都能通过
  • 更新规划文档，重新盘点仍依赖 Node 的部分

  • 支持重新设计的 X 网页应用，修复了之前仅提取链接和计数列表而非帖子及回复的问题

问题修复

  • 修复图片处理：保留无 alt 文本的图片，即使同一 figure 中其他图片有 alt 文本
  • 修复图片链接：保留 figure 中图片的外层链接，恢复维基百科图表的文件页链接
  • 修复表格内容：保留单元格内的换行、段落和列表结构
  • 修复表格元数据：停止将单元格中的短列表误判为博客元数据并移除
