### [code-yeongyu/oh-my-openagent v5.1.32](https://github.com/code-yeongyu/oh-my-openagent/releases/tag/v5.1.32) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 优化长会话内存管理，bash 会话结束后仅保留最终可见屏幕内容，避免每次命令增加约 20MB 内存占用
- 改进上下文压缩逻辑，压缩后提示词、重试和恢复均使用压缩后的上下文，避免重复压缩或拒绝服务
- 增强配额耗尽处理，自动跳过不可用模型并在可用模型上执行压缩，错误信息明确显示提供商及重置时间
- ChatGPT 订阅的 GPT-6.1 Sol、Fast 和 Ultrafast 模型支持 500,000 token 上下文窗口
- Web 搜索优先使用当前模型的服务器端搜索功能，失败时回退至独立搜索服务
- 移除 Recommended 模型配置，未设置时默认使用 Daily · Normal（Claude Opus 5.5 等）
- Ultrawork 跟踪任务拥有的 worktree 和运行时缓存，清理指南要求路径特定待办事项并保留开放 PR 所需资源
- Linux 计算机使用功能支持列出和选择 X11/Wayland 菜单命令
- 计算机使用功能支持在一步中获取截图并读取窗口辅助功能树
- 计算机使用功能支持对截图区域进行全分辨率缩放，同时保持点击坐标不变
- Windows 计算机使用功能支持列出和选择经典菜单栏或 UI Automation 菜单命令
- OpenCode 请求遵循所选模型的实时能力而非过时的模型缓存
- background_task.taskCleanupDelayMs 现在也控制已完成后台任务的可检索时长，超过 30 分钟不再被截断
- MCP OAuth 回调服务器的错误响应改为纯文本格式，防止 HTML 渲染
- OpenCode 任务委派和团队创建尊重 claude_code.agents: false 配置，禁用的代理快速失败
- 委派的 OpenCode 会话标题显示任务类别前缀
- OpenCode 运行时回退可在提供商内容过滤错误后切换模型
- 记忆事实提取仅在用户输入提示词后进行，避免会话启动时触发模型调用
- 命名 ulw-* 技能不再自动开启 ultrawork，需显式使用 ulw 或 ultrawork 关键词
- 测试框架捕获导致环境泄漏的文件，报告变更的键名并确保下一个文件从干净环境开始

**Breaking Changes**
- 移除 Recommended 模型配置文件，未设置 model_profile 时默认使用 Daily · Normal
- model_profile: "recommended" 配置将被视为默认值并记录日志，但不会报错或重写 omo.json

**问题修复**
- 修复 macOS Intel 桌面引擎公证检查等待 Gatekeeper 确认的问题
- 修复 Linux musl 构建冒烟测试将已退出的宿主监督进程误报为泄漏的问题
- 修复会话工具无法读取 OpenCode 旧版 JSON 存储中的会话问题，现在可从旧存储读取
- 修复会话工具错误信息显示为 [object Object] 的问题，现在显示真实错误名称和信息
- 修复 session_search 或 session_list 无法读取会话时导致整个调用失败的问题，现在跳过并命名该会话
- 升级 senpi 至 2026.10.12 版本
