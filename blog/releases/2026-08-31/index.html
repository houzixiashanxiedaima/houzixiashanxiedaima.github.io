SagerNet/sing-box v1.14.0 Qwen/Qwen3.8-27B

新内容

  • iOS 和 tvOS 客户端重新上架 App Store，应用名称变更为 sing-box MT
  • 新增 OpenVPN 客户端和服务端支持，兼容标准 OpenVPN 协议及多种加密模式
  • 新增 OpenConnect 客户端支持 Cisco AnyConnect、GlobalProtect 等主流 VPN 服务器
  • 新增 Snell 入站和出站支持，保留其多路复用与流量特征优势
  • L3 入站（TUN/WireGuard/Tailscale）的 TCP/UDP 流量可直接转发至 L3 端点，无需 L3-L4 转换
  • 新增 bridge 出站，直接通过网卡转发 TUN 等 L3 端点的 TCP/UDP/ICMP 流量
  • 新增 network_namespaces 选项，支持无 root 权限创建 Linux 网络命名空间
  • 新增 gRPC API 服务，提供状态监控、日志查看、连接追踪及 Dashboard 下载等功能
  • 新增 sing-box api CLI 命令，作为 API 服务的命令行客户端
  • 新增 USB/IP 服务端和客户端，支持跨平台导出和导入 USB 设备
  • 新增 Hysteria Realm 服务，用于 Hysteria2 NAT 穿透的地址发现与 UDP 打洞
  • Hysteria2 客户端默认模拟 Chrome QUIC 握手，降低被指纹识别的风险
  • DNS 规则新增响应匹配字段，支持对已评估 DNS 响应的 rcode、answer 等进行匹配
  • DNS 规则中的 ip_version 和 query_type 现在在所有评估路径中生效，包括内部域名解析
  • 优化乐观 DNS 缓存，立即返回过期缓存并在后台刷新，降低重复查询延迟
  • 新增 mDNS DNS 服务器，支持本地网络组播查询
  • 新增基于 MAC 地址和主机名的局域网设备匹配规则项
  • TUN 入站新增 dns_mode 和 dns_address，默认劫持模式现设置系统原生接口 DNS
  • 新增 UDP NAT 配置字段，控制 TUN/TProxy/WireGuard 的 NAT 映射与过滤行为
  • UDP 连接首包在 pre-match 阶段可用，支持直接进行协议嗅探
  • 新增顶层 http_clients 选项，定义可复用的 HTTP 客户端配置
  • HTTP/2 和 QUIC 参数在 QUIC 出站和 HTTP 客户端间共享
  • 新增 outbound TLS spoof 字段及相关路由规则动作
  • Windows 构建新增 windows TLS 引擎值，通过 Schannel 处理 TLS 握手
  • Tailscale 端点新增 ssh_server 字段，支持在 tailnet 端口 22 运行 SSH 服务器
  • sing-box 配置现提供 JSON Schema，支持编辑器自动补全和验证
  • rule-set tag 字段现接受标签列表，支持一次性定义多个共享选项的规则集
  • 新增 sing-box for Desktop 桌面客户端，支持 Windows 10+ 和 Linux 多架构
  • iOS 越狱版客户端现以 .ipa 形式分发
  • Linux 软件包和 Docker 镜像现分为 stable、beta、testing、oldstable 四个发布轨道

Breaking Changes

  • iOS/tvOS 用户需从旧版 sing-box VT 迁移安装新版 sing-box MT
  • 编译 sing-box 1.14.0 现要求至少 Go 1.25

  • TLS 内联 ACME 选项已弃用，需改用 certificate_provider 证书提供者系统
