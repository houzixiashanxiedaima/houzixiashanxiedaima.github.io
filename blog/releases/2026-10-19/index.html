jdx/mise v2026.10.14 - v2026.10.15 Qwen/Qwen3.8-27B

新内容

  • 默认 24 小时最小发布年龄限制现适用于所有后端
  • 新增 Windows PowerShell 安装脚本，支持通过 iex 管道安装且无需管理员权限
  • 新增 dotnet@lts 和 dotnet@sts 别名，自动解析当前 LTS/STS 通道的最新 SDK
  • 新增 read_json、read_yaml 和 read_toml 模板函数，可从文件中读取值用于配置
  • 新增 mise bootstrap —prune-dotfiles 选项，在引导时清理未部署的 dotfiles
  • 新增 dotfiles.windows_symlinks 选项，允许在 Windows 上创建真实的文件符号链接
  • http: 工具可通过 version_date_expr 等选项报告发布日期
  • vfox 插件可通过 hook 返回 created_at 以报告版本发布日期
  • mise tasks -a 成为 mise tasks —all 的短别名
  • 更多后端（如 conda, aqua, dotnet, python, rust 等）现在能正确报告版本发布日期
  • npm:, pipx:, cargo: 等工具的版本列表现从 mise-versions 主机获取而非各自源
  • 文档新增 mise.toml 在线编辑器及可搜索的键值参考页
  • 新增全局配置文件支持，允许通过 override 文件覆盖项目配置
  • 新增 mise config explain 命令，用于解释配置文件中的键值并提供拼写建议
  • Paranoid 模式现支持按类别（如 config、env_files）独立启用
  • env_file 设置现支持指定多个文件名，并按目录层级和列表顺序确定优先级
  • find_up 条目现支持同时搜索多个文件名，提升环境变量查找灵活性
  • 文件任务中的 #MISE 头部注释现支持 timeout、vars 等更多配置项
  • 文档中新增交互式 mise.toml 参考指南，支持按键过滤和直接链接
  • 优化 mise dot status 和 sync 性能，处理大量文件时速度显著提升

Breaking Changes

  • 默认最小发布年龄限制扩展至所有后端，部分原本无限制的 asdf/vfox/conda 等工具现在也会受 24 小时冷却期影响
  • 工具安装现在会因后端不支持的选项而失败，需移除或修正无效选项
  • Paranoid 模式下 env 文件需要单独信任，升级后需在项目中重新运行 mise trust
  • macOS 和 Windows 上也会验证 [bootstrap.linux.firewall] 配置，无效值将导致加载失败

问题修复

  • 修复 mise fmt 破坏多行内联 TOML 表格的问题
  • 修复单个任务目录模板渲染失败导致其他任务命令也失败的问题
  • 修复 aqua 工具无法在 macOS 通用二进制包中找到可执行文件的问题
  • 修复 npm: 生命周期脚本在特定 .npmrc 配置下不运行的问题
  • 修复 npm: mise lock 在 aube 配置不同锁文件时失败的问题
  • 修复包含 .. 的数据目录路径下 .7z 工具压缩包解压失败的问题
  • 修复 Windows 发行版中 mise-shim.exe 版本标签丢失导致的过时警告
  • 修复 Windows 上 symlink-each dotfiles 消息错误显示为符号链接而非复制的问题
  • 修复配置 RUSTUP_DIST_SERVER 镜像且 GitHub 不可达时 Rust 通道列表失败的问题
  • 修复 Windows 上 http: 大文件归档安装因杀毒软件扫描导致的访问拒绝错误
  • 修复外部 rustup 代理目录优先级问题，防止系统 Node 被错误调用
  • 修复 cargo 后端忽略 rename_exe 选项的问题
  • 修复锁定 pypi: 安装时未正确传递 Python 路径给 uv 的问题
  • 修复 npm 后端在 TLS 根存储加载失败时崩溃的问题
  • 修复 fish shell 在 mise implode 后递归调用导致栈溢出的问题
  • 修复 mise bootstrap 无法找到同一运行中由 pre-packages 钩子安装的 Nix 的问题
  • 修复 MISE_WATCH_FILES_GIT_REWRITTEN 在 HEAD 未变时被错误设置的问题
  • 命令包装器模板现支持使用 config_root 和 config_source 变量
