jdx/mise v2026.10.12 Qwen/Qwen3.8-27B

新内容

  • pypi 和 pipx 工具现在可以独立选择 Python 运行时，支持指定次要版本或精确版本
  • 工作区图现可读取 Gradle 多模块构建，支持 Groovy 和 Kotlin 语法的项目发现
  • env.file 配置新增 find_up 选项，支持在父目录中搜索 .env 文件
  • watch_files 钩子可检测 git 重写文件，通过 MISE_WATCH_FILES_GIT_REWRITTEN 环境变量标识
  • dotfile 组模板自动推断 .tera 源文件路径，无需显式指定 source
  • mise lock 命令对不支持的平台发出警告，提示特定工具版本无法安装
  • 注册表新增 martin (github:maplibre/martin) 工具支持
  • GitHub 查询在 mise-versions 服务中断时自动重试 api.github.com

问题修复

  • 修复 GitHub 查询在 mise-versions 超时、连接断开或返回 429/5xx 时的失败问题
  • 修复 _.source 在 stdin 为 socket 且 SHLVL 未设置时错误加载～/.bashrc 的问题
  • 修复工具列出多个版本时，第一个条目的选项泄漏到后续条目（如 prerelease 标志）的问题
  • 修复工作区提供者失败时项目覆盖不生效的问题，现在可通过 [monorepo.projects] 声明项目
  • 文档更新：解释 mise activate 保留 shims 在 PATH 的原因，澄清 CI 平台特定的 mise cache 路径
