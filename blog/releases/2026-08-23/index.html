nicobailon/pi-subagents v0.55.0 Qwen/Qwen3.8-27B

新内容

  • 新增 subagents.maxThinking 配置，用于限制原生子代理启动时的思考上限
  • 新增 subagents.defaultProvider 及按代理覆盖的 defaultProvider，支持为裸模型 ID 设置首选提供商
  • 通过 subagent ({action: “resume” }) 支持对外部已完成任务进行后续请求，包含去重、持久化父任务血缘及更清晰的错误提示
  • 新增子作用域停止支持及异步 / 工作流运行的子停止观察者事件，拒绝格式错误的子停止请求以防止扩大至运行级停止
  • 为每个顶层子代理调用创建被动 Orca 观察者标签页，共享链式 / 并行进度并维护项目本地观察者清单
  • 在行内状态中统计 Herdr 项目窗格，并为活跃子代理工作报告紧凑的 Herdr 窗格标题后缀
  • 允许 agentOverrides 设置或清除默认输出路径和 defaultReads…
  • 从 {action: “models” } 展示可复制的提供商 / ID 模型选择器，并将无效模型警告指向该发现路径
  • 新增捆绑技能指导，用于在子代理扇出前处理轻量级任务配置文件
  • 新增委托审查指导，将证据要求与严重性标签分离，避免首轮审查仅默认为阻塞项

问题修复

  • 修复相对 workflowScript 输出路径未通过管理工件路由而在仓库根目录创建报告文件的问题
  • 修复父进程空闲时异步小部件旋转器和计时器停止移动的问题，通过实时小部件重建路径路由动画滴答
  • 将异步小部件动画重绘速度降低至 1 Hz，避免安静运行的任务以存活滴答率重绘整个 TUI
  • 当子进程报告的提供商 / 模型与解析的请求模型不同时，使 Pi 子进程启动失败
  • 将分离的工作流监督者交接渲染为暂停 / 等待状态，并在完成通知中包含工作流和子运行 ID
  • 将因缺少子工具而受阻的实现运行报告为受阻变更效果，而非无编辑完成守卫失败
  • 当运行时缺少请求的核心写入工具或实现工作者仅有只读启动工具时，使子进程启动尝试失败，包括继承只读能力上限的工作流子进程
  • 让只读审查者验收依赖父端暂存文件检查，而不是要求子进程报告的 noStagedFiles 证据
  • 直接运行公共单子进程启动，而不是将其包装在工作流中，避免异步外部作业代理在真实提供商作业完成前显示已完成的工作流
  • 以支持的后台模式启动省略异步的公共外部运行器单子进程启动，避免如 Surf gpt-pro 等包代理作为前台请求失败
  • 允许工作流脚本通过内部以后台方式启动并返回其终端结果来等待省略异步的外部运行器子进程
  • 当 runs.all (…) 结果被读取为键控对象而非有序数组时，报告有用的工作流错误
  • 澄清 Council Mode 可以包含已安装的外部运行器顾问（如 Surf gpt-pro）…
