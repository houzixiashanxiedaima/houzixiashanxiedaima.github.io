Devolutions/UniGetUI v2026.2.6 gpt-oss-120b

新内容

  • 界面刷新：采用 WinUI 风格沉浸式覆盖、改进上下文菜单、标题栏搜索框新增清除按钮、窗口边框随系统强调色、面板自动根据内容大小调整、托盘图标随系统主题自动刷新
  • 操作历史增强：提供更丰富的视觉效果和结构化信息，便于查看已完成的包操作
  • 新增导出功能：可将已安装的包和可用更新导出为 CSV 文件
  • 添加重置设置确认对话框：在恢复默认设置前弹出确认
  • 关闭应用时保留部分已输入的进程名称设置
  • 扩展环境变量支持：自定义安装参数和安装位置可使用环境变量
  • 关闭 UniGetUI 到系统托盘时自动清除搜索查询
  • 通知优化：仅在 UniGetUI 隐藏时显示通知，减少打扰

问题修复

  • 若干修复：内存泄漏、WinGet 更新循环、PowerShell 模块始终更新至 CurrentUser、WinGet 更新忽略自定义安装位置…

zed-industries/zed v1.13.1 gemma-4-31b

新内容

  • 改进分支选择器的过滤、分组、创建建议及远程提供商图标
  • 在可运行的边栏控件中新增运行状态指示器
  • AI 代理面板新增复制响应、跳转至用户消息及跳转至顶部按钮
  • 改进 LSP 日志，显示请求时长以方便诊断慢速语言服务器
  • Git 增强：支持远程 / 协作项目加载提交模板，支持 CLI 打开 diff 特定行
  • 新增缓冲区符号选择器的预览面板，支持在工具栏直接编辑图像缩放级别
  • 支持在 Rust、C、C++ 注释中为选中内容添加反引号
  • 改进文本查找器（Text Finder）并为其添加默认快捷键
  • 支持在代理响应和 Markdown 预览中打开相对文件链接（如 src/main.rs#L42）
  • 优化编辑器性能（锚点解析、行整形、工作树扫描等）
  • 更新 Mistral Medium 至 3.5 版本
  • 改进 Markdown 预览，悬停链接时显示目标地址

Breaking Changes

  • 移除 Mistral 提供商中已弃用的 magistral-medium-latest 等模型
  • macOS 上 cmd-alt-f 快捷键更改为打开文本查找器，替代原有的替换或过滤功能
  • Opus 4.6 和 4.7 的快速模式（Fast Mode）已被弃用

问题修复

  • 修复 KDE Wayland 上使用 Fcitx5 输入时内存占用过高的问题
  • 修复 Windows 上的重入窗口绘制导致 UI 内存损坏的崩溃问题
  • 修复关闭活动项时工作区更新导致的崩溃问题
  • 修复 Git 索引损坏、提交钩子被跳过及大文件 fetch 超时等 Git 相关 Bug
  • 修复 Dev Containers 的兼容性及 Docker Compose 服务启动问题
  • 修复编辑器在特定滚动位置右键菜单不显示及选择框渲染问题
  • 修复 Markdown 预览按钮在多窗格时打开错误文件的问题
  • 修复 Vim/Helix 模式下包含尾随换行符时的选择行为
  • 修复调试会话在获取昂贵变量作用域时冻结的问题
  • 修复多种 UI 裁剪、重叠及显示异常（如底部停靠栏、Git blame 边栏）

ben-manes/gradle-versions-plugin v0.57.0 gpt-oss-120b

新内容

  • 在 pom URL 中插值项目属性，生成真实链接并回退父 pom
  • 新增文档：maturityLevel rejectVersionIf 规则说明
  • 新增文档：惰性贡献依赖的报告条目说明
  • 新增示例：自定义 outputFormatter 如何触达配置缓存
  • 发布行为改为基于 release tag 而非默认分支
  • 初始化脚本配方现在在 beforeSettings 阶段应用 settings 插件

Breaking Changes

  • 不再允许在使用默认配置发布的项目中发布 dependencyUpdatesElements 变体，需调整发布方式

问题修复

  • 修复 v0.55.0 回归导致 dependencyUpdatesElements 变体发布后项目不可解析
  • 修复在 init 脚本中应用 settings 插件导致的构建崩溃
  • 解决 prior recipe 在 allprojects 上报告每个项目而非一次、遗漏插件以及在孤立项目下失败的问题

jdx/mise v2026.7.17 gpt-oss-120b

新内容

  • Node 工作区将 package.json 脚本导入为 mise 任务，无需每个包的 mise.toml
  • Node 工作区自动推断项目依赖关系并在任务图中展示，实现依赖感知的任务排序
  • 支持实验性的根任务默认配置（monorepo.task_defaults），按任务名共享
  • 支持 ^task 上游依赖语法，实现 “先构建上游项目” 任务顺序
  • 支持 optional = true 的可选任务依赖，匹配时运行，未匹配时静默跳过
  • 可为每个工具单独禁用惯用的版本文件（idiomatic_version_file_disable_files）
  • bootstrap dotfiles add 默认应用捕获的条目并移动真实路径，支持回滚

问题修复

  • 修复 hook-env 触发的重复加载、fish cd 钩子、zsh 启动、Homebrew cask 安装、Aqua 版本覆盖…

MHSanaei/3x-ui v3.6.0 deepseek-ai/DeepSeek-V4-Flash

新内容

  • 重新设计概览页面为趋势优先的命令面板，包含核心指标、吞吐量图表、连接图表等
  • 更新 xray-core 至 v26.7.28 并适配面板
  • 订阅功能增强：自动检测格式、身份令牌、在线状态端点、原始下载、XHTTP 会话字段兼容
  • 设置界面改进：标记默认设置、端口字段保护、日期选择器即时提交、REALITY 版本范围验证
  • 前端平台升级：迁移至 react-router 8、Node 24 LTS、Storybook 工作台、修复无障碍违规
  • 性能优化：客户端页面扩展性改进、email 快照优化
  • 新增自定义月度流量重置日功能
  • 新增按 Telegram ID 查找客户端 API
  • 新增连续失败阈值通知功能
  • 移动端卡片显示客户端备注
  • 删除 230 个死翻译键并添加防护测试
  • 升级依赖：google.golang.org/grpc、go-ldap、react-i18next 等

安全修复

  • 将 openapi.json 移至会话认证保护，防止未授权访问管理 API
  • 节点 API 令牌改为只写，创建后不再返回令牌值
  • 停止在生产二进制文件中嵌入源码映射（sourcemaps）
  • 默认自由规则阻止私有范围出口流量

Breaking Changes

  • GET /panel/api/openapi.json 现需认证会话，之前可未授权访问
  • 节点 API 令牌改为只写，创建后不再返回令牌值
  • XMC finalmask 配置变更：不完整的 mask 在保存时被拒绝，生成配置时仅丢弃有问题的 mask

问题修复

  • 完成两项大规模审计修复：54 项仓库自纠正审计修复和 16 项 bug 标签问题修复
  • 修复订阅输出正确性：链接信任、外部刷新合并、Clash 标量解析、VLESS 流控制、外部链接名称、WireGuard Allowed IPs 等
  • 修复数据库完整性：SQLite 在线备份快照、修复遗留字符串 tgId 值、修复 client_traffics 行删除问题
  • 修复设置界面问题：端口字段清零、日期选择器提交行为等
  • 修复文档依赖（sharp 升级至 0.35.3）

firebase/firebase-tools v15.25.0 gpt-oss-120b

新内容

  • Firestore emulator 更新至 v1.22.0，支持 DML
  • 新增 appcheck:debugtokens:create/list/delete CLI 命令用于管理 App Check 调试令牌
  • 在 OneMcpServer 请求中添加 MCP-Protocol-Version、Mcp-Method、Mcp-Name HTTP 头
  • 添加 extdeprecationwarnings 实验，显示 ext:* CLI 命令的弃用通知和指导

  • 移除 Dart 函数不可见的警告，已在控制台显示
  • 添加 V1 环境变量 FUNCTION_REGION 到 v2 functions

问题修复

  • 修复多项 emulator 问题，包括 JSON 上传超限、GraphQL 请求取消崩溃、并发请求挂起

earendil-works/pi v0.83.0 gpt-oss-120b

新内容

  • 新增凭证导出命令 pi auth print-api-key 与 print-bearer-token，支持自动 OAuth 刷新和最小有效期校验
  • 新增 Headless OpenRouter 登录方式，可在 SSH 环境手动粘贴重定向 URL 或授权码完成登录

  • 向扩展暴露会话解析后的模型范围为 ctx.scopedModels

  • 为多家提供者（Google、Anthropic、Amazon Bedrock、Mistral、OpenAI）添加继承的原始停止原因…
  • 为 OpenRouter 登录加入手动重定向 URL 与授权码输入，支持远程和无头环境
  • 将 OAuth 凭证刷新策略改为在剩余有效期不足 5 分钟时即刷新

Breaking Changes

  • 升级 TypeBox 至 1.3.7，移除 Type.Base、Type.Awaited、Type.Promise、Type.AsyncIterator…

问题修复
