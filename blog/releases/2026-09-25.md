### [jdx/mise v2026.9.13](https://github.com/jdx/mise/releases/tag/v2026.9.13) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增实验性 OpenTelemetry 支持，mise run 可导出 OTLP 追踪与日志
- 新增实验性守护进程提供者，支持多项目共享 PostgreSQL、CockroachDB 或 NATS 服务并隔离数据
- 新增 mise backends switch 命令，用于手动切换工具的后端
- 新增 mise bootstrap unapply 命令，用于移除模块配置的文件与服务
- 新增 mode = "absent" 及 remove_empty 模板，支持声明式清理文件与空目录
- 新增 mise search 支持查询 npm、crates.io 等包注册表
- 新增 mise ls -b/--backend 参数，支持按后端过滤列表
- 新增 mise config get/set 的键名自动补全功能
- 新增 .miserc.local.toml 支持，允许在本地覆盖部分配置而不修改共享文件
- 新增 mise dot track --dry-run 预览功能，显示文件统计与排除项
- 新增 mise cache prune 安全加固，不再跟随符号链接删除安装目录中的文件
- 新增 mise lock --bump 远程版本检查，获取失败时明确报错而非静默退出
- 新增 mise install 支持从 file:// URL 安装本地归档文件
- 新增 mise --help 彩色输出与 Logo 显示，并适配终端宽度
- 新增 MISE_INSTALLED_TOOLS 环境变量包含 backend 和 install_path 信息

**安全修复**
- 修复以 root 运行 bootstrap 时可能跟随恶意符号链接的安全漏洞 (CWE-59)

**Breaking Changes**
- 移除实验性 pkgx: 后端，需迁移至注册表简写或 aqua:/github: 格式
- 锁定工具将保持其锁定的后端，不再自动跟随注册表变更，需使用 mise backends switch 迁移
- TOML 命令现在会替代同名文件任务，原被忽略的 [tasks."hello.sh"] run 字段现在生效

**问题修复**
- 修复 Windows 下 vfox 插件 Lua 错误导致的 panic 崩溃问题
- 修复 Windows 下 cargo install mise 无法正常工作的问题
- 修复 bash mise 函数在未复制 $__MISE_EXE 的 shell 中失效的问题
- 修复 Windows 下用户服务因控制台窗口关闭而意外终止的问题
- 修复嵌套 Git 仓库被错误保存为提交指针的问题
- 修复 mise lock 记录未确认版本的问题
- 修复 pnpm 配置优先级低于 Node 内置 pnpm 的问题
- 修复任务元数据块意外隐藏同名脚本文件的问题
- 升级依赖并更新注册表条目（mole, reviewdog, nim, aube）

- Codex：订阅变更后，优先使用新的 CLI 使用响应中的计划，而不是缓存的账户计划
- Codex：根据余额缩放个人信用条，而不是在 1,000 积分时填满条形图，同时保留报告的月度上限和工作区余额

- Claude 小部件：在 claude-swap 账户更新后刷新，并跟随活动账户，无需账户小部件即可保留配额所有权和测量年龄

- Command Code：根据与积分一起报告的授权大小调整月度用量，保持行在可选订阅查找失败时可用
- Kimi：为所选区域从 Chromium 本地存储导入 Web 访问令牌，保留手动和保存账户凭据隔离
- MiniMax：跨共享 Chromium 目录发现浏览器会话存储，包括 Comet 和 Yandex
- Ollama：解释空的 Manual cookie 配置并提供单一操作以使用自动 cookies

- CLI：将 shell 发现输出限制为 1 MiB 并拒绝不完整的捕获，以防止嘈杂的启动脚本导致失控缓冲或截断的 PATH 结果
- 网站：使用最新的集成刷新社交预览图像，并在卡片更改时使缓存的预览失效
