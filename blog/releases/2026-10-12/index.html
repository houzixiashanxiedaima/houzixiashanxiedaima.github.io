MHSanaei/3x-ui v3.10.0 Qwen/Qwen3.8-27B

新内容

  • 新增 MASQUE 协议支持入站与出站，WARP 模态框可注册基于 MASQUE 的 WARP
  • 新增 XDRIVE 传输层，支持通过 Google Drive、本地文件夹或 HTTP 存储 API 隧道流量
  • 升级 Xray-core 至 v26.10.10，新增 Lua DNS 和路由脚本及 TUN/finalmask 选项
  • 优化节点同步机制，主节点推送可达所有节点，重置节点不再清除中心客户端
  • 恢复端口跳跃功能，Hysteria 和 XHTTP 客户端可通过 udphop mask 实现端口跳跃
  • 沙箱化 systemd 服务，面板运行于受限权限集且系统目录只读
  • 安全更新流程，数据库迁移在服务启动前完成，更新不再触及 TLS 配置
  • 新安装默认使用 PostgreSQL 18（来自官方 PGDG 仓库）
  • finalmask 编辑器支持更多格式特性，包括 header-custom 变量、TCP 错误组等
  • 出站 TLS 新增 “使用系统 CA” 开关，支持私有 CA 签名的服务器
  • 公共订阅页面支持面板主题（浅色、深色、极暗模式）
  • 优化流量格式化性能，减少状态和报告输出构建时的内存分配
  • CI 测试覆盖端到端节点同步场景，支持 admin-token 和 node-sync-token 注册方式

安全修复

  • systemd 单元沙箱化：限制可写目录、降低权限、限制命名空间和地址族、设置 UMask=0077…
  • 自动化 PR 审查和问题分析工作流不再持有写入或 OIDC token，防止从拉取请求检出的代码生成写入 token

Breaking Changes

  • 多个节点修复需在节点本身运行：原地客户端更新、应用主节点推送、托管 MASQUE 入站；旧版本节点保持旧行为，放置 MASQUE 入站将被拒绝 —— 需升级所有节点
  • Xray-core v26.10.10 检查出站 TLS 时使用内置 Mozilla 根证书而非操作系统证书库 —— 对私有 CA 签名的服务器出站…
  • JSON 订阅现在以 udphop mask 发送端口跳跃（需 Xray-core 26.9.9+）…
  • systemd 安装中服务现已沙箱化：/usr、/boot、/etc、/home 和 /root 除面板自身的 DB…
  • impact

问题修复

  • 修复主节点上附加、禁用或编辑的客户端无法到达使用 admin token 注册的节点的问题
  • 修复节点报告空客户端列表时导致中心删除这些客户端的问题，现在中心会将其推回节点
  • 修复在节点入站上续期、重置或自动禁用客户端时重建入站导致连接中断的问题，现在原地更新用户
  • 修复使用 node-sync token 或 mTLS 注册的主节点无法设置订阅排序、批量重置流量和读取活跃入站的问题
  • 修复从节点入站分离的客户端被节点过期统计禁用的问题，旧配额不再写回
  • 修复节点入站在新标签下替换时客户端流量历史和配额使用丢失的问题
  • Shadowsocks-2022 入站不再提供 Xray 无法多用户运行的 2022-blake3-chacha20-poly1305…
  • 拒绝保存大小不匹配的 Shadowsocks-2022 服务器密钥，避免停止 Xray
  • 拒绝保存短于 4 字节的 salamander 或 gecko finalmask 密码，避免监听器打开时停止 Xray
  • 修复服务测试套件中的数据竞争，由测试结束后仍在运行的公共 IP 查找引起

  • 位于 Cloudflare 后面的源在需要解决挑战时失败得更快

  • 设置搜索现在可以通过部分名称查找设置
  • 更新和即将更新中的筛选图标现在会在启用筛选时显示

  • 将备份恢复到现有图书馆时，现在保留最远的阅读进度和最早的添加日期
  • 更新了应用图标，下载章节现在显示波浪形进度环
  • 应用更新现在直接从更新屏幕下载
  • 在详情屏幕上从图书馆移除条目时现在要求确认
  • 扩展详情现在显示扩展来自哪个仓库，并提供其网站链接

  • 修复编辑不在图书馆中的条目封面
