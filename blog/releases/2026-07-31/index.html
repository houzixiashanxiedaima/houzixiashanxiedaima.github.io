UsefulSoftwareCo/executor v1.5.37 gpt-oss-120b

新内容

  • 默认开启 MCP 连接的 artifacts，需通过？artifacts=false 或 —no-artifacts 关闭
  • 为本地守护进程（CLI、桌面）及自托管添加匿名产品分析，统计执行次数、工具使用等
  • 新增 Artifacts 选项卡，保存并实时渲染代理生成的交互组件，支持深链接和重命名
  • Artifact 工具结果旁显示网页深链接，提升访问便利性
  • Workers 主机通过 static‑assets 绑定获取构建的 shell，缺失时提供可操作错误
  • 升级依赖（@executor-js/sdk 1.5.37、@executor-js/api 1.4.57、@executor-js/local 1.4.4…

Breaking Changes

  • 构建若未生成 shell 资产将导致构建失败，需确保构建输出包含 shell 文件

问题修复

  • 修复 artifact migration 不再将 definition.name 限制为 varchar (255) 导致的迁移失败
  • 修复 GraphQL 连接在 schema introspection 失败时仍接受凭证并提供同步诊断
  • 修复添加连接向导在健康检查保存时会清除粘贴的凭证的问题
  • 修复 MCP 响应超过 128 KiB 限制导致客户端挂起的错误
  • 改进传输层：超大消息跳过事件存储并记录警告，避免无限等待
  • 修复云主机 MCP 客户端出现 “Shell not built” 占位符导致的 artifact 小部件加载不完成

JanDeDobbeleer/oh-my-posh v30.0.0 gpt-oss-120b

新内容

  • 新增 CLI 参数 —background-color 用于导出图像
  • 新增终端 UI，供提示引擎使用
  • 新增记录段落方法返回值的功能
  • 配置构建时将段实现排除在浏览器版之外
  • 支持在不运行机器的情况下渲染配置
  • 工作室添加下载 PNG 按钮
  • SVG 中将 macOS 流量灯替换为 WT 风格的 Chrome
  • 终端记录提示为带样式的运行序列
  • 网站在本地开发时实时重载主题和 wasm
  • 网站文档围绕目录和工作室重构
  • 网站渲染制品时无需启动 CLI
  • 网站首页英雄 SVG 随站点主题切换
  • 性能提升：终端计数单元格时不再使用 go-runewidth

Breaking Changes

  • 字体安装现在必须指定字体名称，需使用 oh-my-posh font list 查看
  • 交互式选择器已移除，—headless 标志不再可用
  • 导出图像命令仅生成 SVG，原有 —author、—background-color、—cursor-padding、—rprompt-offset…

问题修复

  • 修复 battery 在 illumos/solaris 上的交叉编译失败
  • 修复缓存持久化时未更新 session 文件修改时间
  • 修复 CLI 帮助信息中残留的迁移提示
  • 修复配置渲染数据段时与 writer 的不一致行为
  • 修复在无 writer 时段渲染保持一致
  • 修复 PowerShell 使用空字符串处理 CONDA_PROMPT_MODIFIER
  • 修复 SVG 渲染模式切换、去除水印前的空行以及颜色显示错误
  • 修复主题模板未显式列出导致的隐式 11 主题问题
  • 重构 CLI：提供字体列表及安装命令
  • 修复导出配置时默认使用 PNG 而非 SVG 的问题
