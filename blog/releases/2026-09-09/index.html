FreshRSS/FreshRSS 1.30.0 Qwen/Qwen3.8-27B

新内容

  • 新增按状态和搜索过滤全局视图订阅列表

  • 对话错误提示优化，显示安全可操作的提供商详情而非通用错误码
  • 修复消息调试面板中长输出被截断和 UI 卡死的问题
  • OpenCode Go/Zen 的健康检查、话题命名和上下文压缩请求现在携带必需的会话头部
  • 删除用于上下文的回复时，保留其他回复并将上下文转移至相邻回复

  • 修复纯文本续写轮次错误处理残留图片附件并在响应开始前失败的问题

nexu-io/open-design open-design-v0.22.1 Qwen/Qwen3.8-27B

新内容

  • 支持的设计任务（原型、幻灯片、营销设计、Hyperframes 视频）默认使用 OD Next，可在设置中关闭

  • API 密钥无效时提供专属解释及跳转模型设置的快捷方式
  • 针对不可用模型、不支持的功能、超时、缺失预览文件及区域限制提供更具体的错误指引

  • OD Next 不再为问候语或非设计请求虚构网站，避免重复的失败卡片
  • 符合条件的 HTML 交付物进行最终语法检查和安全自动修复，无需额外代理轮次；检查不完整时保留原始产物并继续交付
  • 官方 Codex 插件接受简报收集返回的工作流标识符以确认简报，同时拒绝不匹配的标识符
  • 重新打开模型选择器时立即显示当前模型及其所属公司
  • “What’s New” 支持本地化按钮标签以匹配公告目标页面
  • 项目引用列表显示当前活动工作区的项目，并在切换工作区时刷新
  • 连接测试显示滚动别名背后解析出的实际模型，便于验证
  • 更新法语设置、恢复消息及核心文档措辞以提升一致性
  • 导航工具提示实现本地化并支持从右到左布局
  • Docker 安装中恢复捆绑插件的海报和悬停预览片段

问题修复

  • 选择下载位置时不再将名称类似系统杂项的目录或符号链接误判为可忽略的系统文件

  • Maestro 新增递归树选择器和位置选择器支持
