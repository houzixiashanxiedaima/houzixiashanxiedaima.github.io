tashfeenahmed/freellmapi v0.6.0 gpt-oss-120b

新内容

  • 新增设置对话框，支持系统 / 浅色 / 深色主题并实时跟随 OS 偏好
  • 仪表盘支持 60 种语言（含 RTL），语言字典懒加载，README 列出贡献方式
  • 路由可靠性提升：请求租约、每分钟门控、按键评分、冷却探测、客户端断开中止等机制
  • 新增 /v1/audio/transcriptions 端点，实现 OpenAI 兼容的语音转文字
  • 新增 reasoning_effort 参数并映射 Gemini 思考预算，提供 reasoning_content
  • 新增每次尝试路由追踪及模型漂移检测，记录回退链和提供者返回非请求模型
  • 仪表盘功能增强：回退梯子细化、音频标签拆分、诚实分数展示、通知自动消失，资源包体积缩减 70%

安全修复

  • 将 Gemini 密钥移至 x-goog-api-key header，避免在查询字符串和日志中泄露
  • 控制台凭证脱敏，防止敏感信息泄露
  • Provider 日配额改为 UTC 午夜计数，Retry-After 限制至 24 小时
  • 冷却信息可通过 API 查看并清除
  • SQLite 使用 busy_timeout 并设置文件权限 0600，WAL 副本同样受限

问题修复

  • 若干修复：TTS 语音映射、模型 ID 正确上报、Android/Termux 支持、健康检查错误捕获并脱敏
  • 文档更新、NVIDIA NIM 400 错误视为容量限制、Docker 镜像包含依赖、Catalog 同步防护、macOS DMG 未签名回退

code-yeongyu/oh-my-openagent v4.19.2 gpt-oss-120b

新内容

  • 通过权威通知实现完成和团队消息的即时推送，取代阻塞轮询
  • 背景任务输出改为即时状态或转录预览，完成通知自动携带最终结果
  • CodeGraph 默认以受管共享守护进程运行，OpenCode 与 LazyCodex 自动使用
  • 引入运行时校验、进程树清理和更严格的生命周期所有权，可选隔离模式
  • Sisyphus 添加针对 Claude Opus 5 的专用提示并更新模型路由文档
  • start-work —make-pr 与 —ship 通过连续体携带交付意图，实现更清晰的交付工作流
  • cmux 环境下子代理面板直接附加，避免重复重启并正确清理会话
  • 隐藏的 ultrawork 指令注入支持 Senpi、oh‑my‑pi 与 gajae‑code 会话发现
  • 任务输出改为非阻塞，完成通知成为权威来源，提升运行时效率
  • 依赖升级：TypeScript 升至 7.0.2，加入跨进程测试隔离与调用响应日志

Breaking Changes

  • CodeGraph 默认启用受管守护进程，需在配置中关闭以保持原有行为
  • 任务输出改为非阻塞，可能影响依赖同步结果的代码
  • team_wait 被替换为注入式 lead inbox 投递，需更新团队消息处理逻辑
  • 引入运行时校验和进程树清理，可能导致自定义二进制不兼容

问题修复

  • 修复 CodeGraph 在 Windows 环境的排除逻辑
  • 对已排除项目跳过 CodeGraph 扫描，防止不必要的处理
  • 强制受管的 CodeGraph 进程生命周期，防止残留进程
  • 调整 shared‑skills 调试描述以匹配 TypeScript 源码
  • 稳定 CI 测试超时问题，减少 flaky 测试
  • 修复 goal‑command 在空终端下的错误
  • 保持原生命令的来源信息，避免丢失 provenance
  • 修复 cmux 子代理面板直接附加、激活标记及优雅关闭等问题
  • 修复团队注入相关的空闲注入交付和成员收件箱行为
  • 纠正 ultrawork 中对 live todos 的强制要求

jdx/mise v2026.7.14 gemma-4-31b

新内容

  • GitHub/GitLab/Forgejo 后端支持 additional_asset_patterns，允许将多个发布存档叠加安装到同一目录
  • npm 新增 allow_low_downloads 选项，允许特定包绕过每周下载量流行度限制
  • 结构化环境文件（JSON/YAML/TOML）支持 expand = true 选项以实现 shell 风格的变量扩展
  • CLI 性能优化：不再在每次调用时重建两次 clap 命令树
  • 注册表新增 checkstyle、grok 和 tak
  • 更新命令参考，明确标注每个命令对系统的影响（只读、修改状态或破坏性）
  • 新增 llms.txt 索引以支持 AI 代理
  • 更新文档（Socket 集成、模板变量、clap 链接）

安全修复

  • 修复配置信任漏洞：默认 shell 参数设置现在仅限全局配置，防止不受信任的本地仓库影响命令执行

Breaking Changes

  • 升级至 usage 4.0，导致 shell 补全和文档渲染依赖于新版本

问题修复

  • 修复 Windows 上 pip 的可用性，包括合成包装器和 PATH 配置
  • 修复 Windows 上 GitHub 发布资源优先选择 .exe 文件的逻辑
  • 修复 GitHub Token 401 错误，现在提供更详细的来源信息和修复建议
  • 修复单二进制文件存档在 PATH 中的重命名行为
  • 修复 brew-cask 安装支持，包括生命周期块和 sudo 权限提升
  • 修复 lockfile 行为：prefix 工具请求现在遵循锁定版本而非自动解析最新版
  • 修复 aqua 跨平台 lockfile 的 URL 404 问题
  • 修复 Swift lockfile 记录目标 Linux 发行版，避免校验和不匹配
  • 修复任务（task）在 git worktree 嵌套时的命名空间加载问题
  • 修复任务缓存失效逻辑，确保修改命令、来源或输出后重新运行
  • 修复任务来源哈希的持久化时机，避免失败运行被标记为最新
  • 修复 shell 补全在任务名称后出现全局标志的问题
  • 修复 npm 包含大数字版本号的排序问题，确保正确选择稳定版
  • 修复 JSON/YAML/TOML 环境文件默认值为字面量，修复之前的 shell 扩展回归问题
  • 优化更新检查缓存，为无网络环境提供负缓存以提升启动速度
  • 修复 npm aube 的信任降级错误提示及输出显示问题
  • 修复 std::env::vars () 调用点为 vars_safe ()

callstack/agent-device v0.20.1 gemma-4-31b

新内容

  • 新增 Amazon Vega OS TV 支持，包含应用控制、生命周期命令及遥控界面
  • 扩展物理 iOS 设备支持，xctrace 设备现可通过 usbmux 使用 XCTest 自动化
  • 新增录制安全机制，敏感输入将以 ${VAR} 占位符存储以保护隐私
  • 增强回放验证，等待地标现保留元素标识以防止误报
  • 优化回放启动，通过有限重试处理应用启动时的瞬时捕获失败
  • 优化设备选择，回放可自动选择包含请求应用的模拟器
  • 增强恢复引导，针对屏幕外交互错误提供方向建议和选择器重试
  • 新增 iOS 系统 UI 指南，涵盖 SpringBoard 及模拟器组件管理工作流
  • 提升诊断能力，提供更丰富且经过脱敏的会话事件详情
  • 新增 WebView 辅助功能实验室
  • 增强代理帮助基准测试及脚本依赖图报告
  • 升级依赖项以解决 Dependabot 警报

Breaking Changes

  • 旧版录制手势形式（包含已移除的持续时间或速度位置参数）在 .ad 解析时将失败，需转换为手势平移或使用当前标准语法

问题修复

  • 修复 Android 状态栏 Chrome 戳记问题
  • 修复 Apple 物理设备 xctrace 格式解析问题
  • 修复 iOS 模拟器选择逻辑，支持通过安装的应用进行选择
  • 修复 Android 快照过滤后固定兄弟节点的保留问题
  • 修复 Bundle 大小报告的精度问题（保留两位小数）
  • 修复守护进程在未提交修复关闭时的中止消息显示
  • 修复回放会话在 CLI 路径下的守护进程存活问题
  • 修复回放时打开会话的当前工作目录（cwd）作用域保留问题
  • 修复屏幕外恢复提示的命名与顺序问题

Homebrew/brew 6.0.13 gemma-4-31b

新内容

  • 引入 Linux Landlock 沙箱支持，并允许 PTY、设备、IPC 及 POSIX 消息队列访问
  • 新增服务 DSL 的 stop_timeout 属性，支持优雅停止超时
  • 新增多种安装步骤增强：包括权限步骤、约束命令、进程终止步骤及 gzipped 可执行文件操作
  • 优化 brew prof，新增阶段耗时统计
  • 改进 brew search —desc，现在会显示没有描述的 Cask
  • 优化 bundle add，支持来自未 tapped 仓库的全限定名
  • 优化 Git 配置读取，直接从 .git/config 读取 remote.origin.url 而无需启动 Git 进程
  • 在 untap 前提供卸载相关软件包的选项
  • 支持在 formula 中通过 ldflags: :goreleaser 使用常见的 goreleaser 标志
  • 优化终端重绘，使用同步更新包装原地重绘
  • 更新文档，包括 formula 作者指南、维护者操作指南及软件添加流程

Breaking Changes

  • 移除 Cask 的 verified 参数
  • 移除不再使用的 HOMEBREW_ARCHFLAGS 环境变量

问题修复

  • 修复 cask/audit 在 min_os 检查时的空指针崩溃
  • 修复 DownloadQueue 中不稳定的中断测试
  • 修复 Caskroom 损坏的符号链接，并在卸载或列出时提供警告
  • 修复 cask/migrator 在重命名别名时将 cask 复制到自身的漏洞
  • 处理 Cask 挂载失败和中断的情况
  • 修复 OSV.dev 导出漏洞时的重复引用问题
  • 修复 Cask-Cookbook 中指向已重命名 Cask 的链接
