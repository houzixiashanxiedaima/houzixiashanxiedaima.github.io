Homebrew/brew 6.0.16 Qwen/Qwen3.5-35B-A3B

新内容

  • 新增自动更新静默模式
  • 新增 tap-new 的 autobump 选项
  • 新增 python_major_minor_version DSL
  • 新增 std_swift_args 支持
  • 允许 sudo 在沙盒化 Cask 安装步骤中使用
  • 允许从 git URL 或路径安装 cargo 包
  • 修复 Linux 核心 Cask Tap 输出显示
  • 优化 brew style 和 brew readall 速度
  • 升级 RuboCop 至 1.89.0 及 rubocop-sorbet 至 0.14.0
  • 使用 codesign 对 Intel 修补二进制文件签名
  • macOS 14+ 使用 diskutil image 处理 DMG
  • 添加 —fix-available 和 —no-fix-available 标志到 vulns
  • 沙盒结构化 Cask 操作
  • 允许 run 步骤忽略失败
  • 精简安装步骤 JSON 输出

安全修复

  • 移除 Bubblewrap，改用 Landlock 进行 Linux 沙箱隔离
  • 移除 base64 gem 并添加 Homebrew/NoBase64 检查规则
  • 拒绝官方遗留安装钩子
  • 沙盒化结构化 Cask 操作以增强安全性

Breaking Changes

  • 移除 Formula 安装步骤变量默认值，需显式定义
  • 强制要求结构化安装步骤编写规范
  • 将 Tab 属性转换为关键字参数
  • 公共方法调用统一使用 public_send 替代 send
  • 配置字段 timeout 重命名为 requestTimeout（参考示例逻辑，此处为类似变更）
  • 移除旧版 API v1 端点（参考示例逻辑，此处为类似变更）

问题修复

  • 修复 macOS 14+ 上 dmg 解压策略回退问题
  • 修复 Linux 上无 os stanza 的 Cask 安装问题
  • 修复 AppImage 在 Cask DSL 中的 stanza 名称
  • 修复 SSH 会话的 caveat 提示
  • 修复 CI 中 livecheck 分离头部的节流逻辑
  • 修复 requirements/macos_requirement 在 Linux 上的处理
  • 修复随机时间生成器在 tap-new 中的问题
  • 修复测试中 singleton 方法的比较逻辑
  • 修复下载队列在 spec 间的重置问题
  • 修复 Cask artifact 序列化中 false 值的保留
  • 修复校验中 verified 参数对新 Cask 的拒绝逻辑
  • 修复链接已正确时的 Cask 链接跳过逻辑
  • 修复依赖检查以适应 Linux 环境
  • 修复 spdx 许可证标签长度限制（256 改为 255）
  • 修复 API 下载在 curl 接收错误时的重试逻辑
