karakeep-app/karakeep v0.33.0 - v0.33.1 gpt-oss-120b

新内容

  • 新增语义搜索，支持全文、语义（实验）和混合（实验）三种模式，可在搜索栏下拉切换，API、MCP、CLI 均可使用
  • 基于向量嵌入的智能自动标签，提升标签一致性并减少标签冗余
  • 移动端离线阅读，支持保存文章后在无网络环境下阅读
  • 移动端布局、排序和剪贴板保存功能，默认使用紧凑列表布局并可按新旧排序
  • 管理书签界面新增收藏、归档、分享和高亮操作
  • MCP 服务器工具从 8 增至 29，新增完整的 CRUD、标签 CRUD、高亮、删除书签、获取资源等接口
  • 新增可读内容 API，返回文章内容的 markdown 或纯文本，支持段落分页
  • 预检请求加速书签元数据提取，新增 CRAWLER_PREFLIGHT_USER_AGENT 配置项
  • 重新保存书签会取消归档并置顶，预览更智能，根据页面类型显示阅读视图或截图 / 概览面板
  • 批量编辑悬停即出现选择圈，侧边栏加宽且滚动条仅在悬停时显示
  • 支持作为 PWA 安装，在 Chrome 桌面使用；新增 Instagram 渲染器，帖子和短视频在预览中嵌入显示
  • 默认推理模型更换为 gpt-5.6-luna，默认开启自动嵌入，使用 OpenAI text-embedding-3-small 模型或自定义提供者
  • Docker 健康检查支持自定义端口
  • OAuth 提供商可配置 ID Token 签名算法
  • 移动端 UI 优化：加载状态、暗模式阅读对比度、登录页面错误提示、标签管理页面服务器端搜索加速
  • 新增语义搜索，支持全文、实验性语义和混合三种模式，可在搜索栏下拉切换
  • 通过嵌入向量生成书签语义表示，提升搜索意义匹配和自动标签一致性
  • 使用嵌入的更智能自动标签，依据相似书签标签建议，减少标签冗余
  • 移动端离线阅读，支持保存文章离线阅读并提供新布局，默认列表布局
  • 移动端新增排序功能，可按最新或最旧排序
  • 移动端剪贴板一键保存，快捷将剪贴板内容保存为书签
  • MCP 服务器工具从 8 增至 29，新增完整的 CRUD、标签、高亮、删除书签等接口
  • 新增可读内容 API，返回书签文章内容的 markdown 或纯文本，支持分页
  • 通过预检请求加速书签元数据获取，新增 CRAWLER_PREFLIGHT_USER_AGENT 配置
  • UX 改进：重新保存已存在的书签会取消归档并置顶
  • UX 改进：更智能的书签预览，根据页面类型显示阅读视图或截图
  • UX 改进：悬停即进入批量编辑模式，提升编辑效率
  • 新增 Instagram 渲染器，帖子和短视频在书签预览中直接嵌入显示
  • 支持将 Karakeep 安装为 Chrome PWA，桌面可像原生应用使用

安全修复

  • 修复爬虫 SSRF 保护中的 DNS 重绑定 / TOCTOU 漏洞（GHSA-vc53-r298-c6h6）
  • API 密钥和签名资产令牌验证改为计时安全比较（GHSA-hjm9-gc55-5hgv）
  • 创建和更新书签时限制 URL 仅为 http/https（GHSA-6mfw-xrw2-h5x3）
  • 过滤 RSS 和 Netscape HTML 导出中的不安全方案书签，并对导出 URL 进行 HTML 转义（GHSA-4vx2-9j8p-jg8v）
  • Netscape 书签导出中标签名称进行 HTML 转义，防止标签属性被注入
  • 发送邮件时对用户提供的名称进行 HTML 转义，修复列表邀请邮件的 HTML 注入
  • 密码登录实现速率限制（每 15 分钟每 IP + 邮箱最多 10 次），需启用 RATE_LIMITING_ENABLED
  • 导出 Netscape 书签时对标签名进行 HTML 转义，防止标签属性被注入
  • 对外发送的邀请邮件中对用户提供的名称进行 HTML 转义，修复 HTML 注入
  • 密码登录实现速率限制，每 15 分钟每 IP 最多 10 次尝试（需启用 RATE_LIMITING_ENABLED）

问题修复

  • 放宽标签生成提示中的验证码拒绝逻辑
  • 工作线程在页面加载时并行等待自动同意
  • 修复更改默认模型后导致的测试失败
  • 升级 Docusaurus 依赖
  • 页面加载时并行等待自动同意，提高加载速度
  • 将默认推理模型更改为 gpt-5.6-luna
  • 默认启用自动嵌入功能以配合默认推理配置
  • 升级 Docusaurus 依赖以获取最新文档功能

jdx/mise v2026.8.0 gpt-oss-120b

新内容

  • Linux x64 二进制性能提升，shims 延迟降低约 15%，配置感知命令加速 8‑11%
  • 实验性 monorepo 任务工作流扩展，支持 Cargo、uv、Go、Node 依赖推断
  • 默认使用预编译 Ruby 二进制，减少安装时间
  • 新增任务：自动推断 Cargo 工作区并构建项目依赖图
  • 新增任务：从 pyproject.toml 推断 uv (Python) 工作区
  • 新增任务：从 go.work 与 go.mod 推断 Go 工作区
  • 新增任务：Node 提供者读取 turbo.json 生成任务定义
  • 任务图 —explain 显示来源信息，—json 支持同样的属性序列化
  • 任务 watch 支持 per-task watch.no_vcs_ignore 选项
  • 新增受影响项目任务选择，基于 Git 基准 / HEAD 解析变更文件映射
  • Shim 重用已解析的工具集和配置根，降低调用开销
  • 任务工作区发现缓存文件系统访问，加速
  • Release 二进制使用 BOLT 优化，整体体积下降 5‑11%

问题修复

  • 修复 —path 参数在已有配置目录时被忽略的问题
  • 修复任务执行时 Ctrl‑C 被视为失败，改为中断并返回状态 130
  • 修复任务源 / 输出支持 brace glob，保留单元素大括号
  • 修复 python@3.12 运行时使用正确的解释器创建虚拟环境
  • 修复 unuse node@20 仅移除匹配版本，保留其余配置
  • 修复 env 变量 redact=false 时不再被错误遮蔽
  • 修复 hook‑env 检测并恢复被覆盖的 mise 管理变量
  • 修复 dotfiles symlink‑each 不递归遍历共享目标
  • 修复 asdf 依赖在安装期间正确加入 PATH，防止首次安装失败
  • 修复 vfox 插件 pre_install 校验 sha1/md5 检查和错误
  • 修复 aqua 检查文件带 BOM 的读取问题
  • 修复 brew‑cask 直接安装的安全硬化（事务激活、指纹收据等）
  • 修复 forgejo 新的 macOS key 路径支持
  • 修复 GitHub、GitLab 配置在 Windows 上的定位
  • 修复 HTTP 客户端初始化失败的异常处理

OthmanAdi/planning-with-files v3.9.0 gpt-oss-120b

新内容

  • 改进提示缓存，跨调用注入保持字节一致并加入断言

问题修复

  • 修复 PowerShell 脚本在 Windows PowerShell 5.1 上解析错误
  • 修复 provider 错误导致的自动重试耗尽重试预算
  • 修复未规范化的墙钟时间导致的时间显示错误
  • 修复 Stop hook 在六台主机上找不到脚本的问题
