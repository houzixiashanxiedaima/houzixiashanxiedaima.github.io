code-yeongyu/oh-my-openagent v5.1.17 - v5.1.19 Qwen/Qwen3.8-27B

新内容

  • 代码模式支持按会话安装 JavaScript 包，无需重启内核即可在后续单元格中导入
  • Python 单元格的 @tool 函数现在可以像 JavaScript tool (fn) 一样授予给任务子进程
  • 空闲网关存储会在 60 秒无调用后释放工作线程，每个终端控制端点可释放约 2.9 MB 内存
  • omo 升级至 senpi 2026.10.10，请求不可用的思考级别时发出警告而非直接丢弃
  • Windows 上项目规则发现限制在项目内部，常驻 Claude 订阅会话在压缩时仅接收新消息
  • 代码模式新增可选的隔离单元格（isolate: true 配合 sandbox）
  • 新增 Code 模式支持在 omo 自身的任务子进程和 workpool 上调用 wait () 与 handle ()
  • 权限提示现在会显示具体批准的工具调用及其输入，纯问答回复不再被包裹在引号中
  • Code 模式新增 Python agent (prompt, tools=[…])、workpool 的 cell 定义工具…
  • /memfs 维护命令改为首次使用时加载，插件包体积减少约 8 KB
  • 空闲引擎主机在会话完成后，会在空闲窗口结束后自动退出
  • 工作池创建时，若复用名称但请求的工具与现有授权不匹配，将拒绝并提示名称冲突，不再继承旧工具
  • 支持将聊天网关作用域的操作规则注入绑定会话的系统提示词（待网关连接器发布后生效）
  • 升级至 senpi 2026.10.8 及 Claude Agent SDK 0.3.289，优化长桌面续接超时问题

Breaking Changes

  • omo 升级至 senpi 2026.10.9，需同步更新依赖

问题修复

  • 修复 Web 端宣言顶部四分之三区域未完全点亮的问题
  • 修复 Web 端跨字体度量保持阅读顺序并持久化字形证据
  • 修复网关销毁时等待正在退出的存储工作线程，并仅报告一次不可读的旧版邮箱
  • 若干琐碎修复与测试调整（openclaw 回复监听器测试预算、Web 字形截图抗锯齿归一化等）
  • 修复一次性引擎命令（如 omo models discover、omo schedule）被错误传入 TUI 的问题，现原样传递给引擎
  • 强制所有 Bun 运行时满足引擎所需的 1.4 最低版本；低于 1.4 时启动即报错并提示升级，未显式选择的旧版 Bun 自动回退至 Node
  • 修复 x /computer 因缺少 node:sqlite 模块而失败的问题
  • 修复共享任务宿主上带有自身 fallback 模型的任务子进程无法按配置链降级的问题；不支持链的宿主会给出一次警告而非静默丢失
  • 空 /tasks 回答现在会说明其他会话是否有任务，并提示使用 /tasks —all 列出全部
  • ulw-plan 技能仅引用实际存在的委派类别，移除了已废弃的 git 和 deep 类别
  • 若干琐碎修复（发布流程等待 registry 就绪时间调整为 60 分钟、CI 验证超时限制为 120 分钟等）
  • 修复重试、压缩后续接或跟进操作导致主机永久忙碌无法退出的问题
  • 修复回复内容被错误渲染为 Markdown 引用块的问题
  • 修复繁忙机器上 Python 冷启动因固定静默窗口判定而失败的问题
  • 修复 Windows 上内存反思功能因误判为提供商拒绝而停止保存事实的问题
  • 若干琐碎修复（Web 对比度与动效、测试用例稳定性、文档更新等）
