callstack/agent-device v0.20.7 gpt-oss-120b

新内容

  • 新增 HarmonyOS 设备自动化支持，包括发现、快照、应用生命周期、HAP 部署等
  • open —foreground 可直接附加到未歧义的 iOS 模拟器并立即返回交互式快照
  • 常用命令启动速度提升约 54%，CLI 启动时间从约 146ms 降至 68ms
  • snapshot —actions 支持在合并的可访问元素上暴露自定义操作
  • 隐藏键盘文本输入在提交完整文本后才报告成功
  • Android 快照恢复机制改进，自动退役不健康的辅助会话
  • 掩码填充返回目标绑定的验证证据，免费文本 shell 参数安全引用
  • 强化云端和远程设备支持，BrowserStack、AWS Device Farm iOS 会话可靠捕获快照，云填充等待焦点证据
  • MCP 服务器兼容无状态 2026-07-28 修订版，支持发现和可缓存工具元数据
  • 选择器在出现真正不同的歧义匹配时拒绝，而非静默选择
  • CLI 帮助卡和版本头部紧凑展示
  • 在 iOS 上暴露合并可访问元素的自定义 AX 操作
  • 添加模拟器验证技能
  • 将设备库存、日志、网络捕获迁移至基于请求的平台运行时，提升取消、恢复和进程重启处理
  • 通过懒加载专用客户端命令处理器提升性能

Breaking Changes

  • 选择器在出现真正不同的歧义匹配时拒绝，可能导致之前默认接受的用例需调整

问题修复

  • 若干关键错误修复（daemon 提示、隐藏键盘提交、Android 快照可靠性、并发远程连接隔离、XCTestDevices 重定向、云端快照与填充…

AChep/keyguard-app r20260811 gpt-oss-120b

新内容

  • 新增 GPG 密钥管理功能，可在 Keyguard 中导入、管理并设置密钥及子密钥的过期时间
  • 在 Windows 上提供 SSH/GPG 代理，支持调用方范围的批准及 Wear OS GPG 项目类型
  • 重构 KeePass (KDBX) 同步引擎，支持最高 500 MB 附件、流式编码并实现本地分段上传以提升可靠性
  • 新增 Android 集成：OpenKeychain Provider、Credential Exchange (CXF) 以及在自动填充前验证目标应用的包名…
  • UI/UX 改进：可自定义导航栏、链接 vault 项目、简化嵌套文件夹创建、智能移除已删除项的选择，并在桌面阻止 IME 输入
  • 支持 WebDAV 远程 vault，改进与不支持原子写入的服务器的兼容性
  • 性能优化：加速 vault 列表加载、搜索以及 Watchtower 扫描
  • 更新内部数据库，包含最新的 passkey、双因素认证服务和公共域后缀列表

安全修复

  • 在 macOS 与 Windows 上实现剪贴板保护，防止复制的密码被写入系统剪贴板历史
  • 强化 KDBX 文件解析安全，限制 KDF 参数并校验内部结构以防止恶意数据库
  • 对 Windows 临时文件设置安全权限，确保同步过程中的临时文件不被未授权访问
  • 硬化 SSH/GPG 代理的密钥策略，在签名和解密时执行更严格的密钥和公钥验证

问题修复

  • 修复 Flatpak 发行版缺失托盘图标的问题
  • 改进 Bitwarden 同步，单个条目 JSON 解析错误不再导致整体同步失败
  • Watchtower 现在能够标记仅出现一次的泄漏密码
  • 修复加密存储失败的恢复机制，确保在特定错误下能够恢复数据
  • 若干其他小错误修复，包括错误信息拼写、CI 稳定性等

steipete/CodexBar v0.49.2 gpt-oss-120b

问题修复

  • 合并同一提供商账户的重复使用行，保留当前 Mac 的配置结果优先。
  • 菜单卡：在每周 / 每月计划的最终重置前显示配额已用尽，同时保留会话细节和独立购买的积分。
  • 菜单卡：当主要使用值和本地化重置时间戳无法同时显示时，堆叠行以保持可读性。
  • 插件：在用户安装的提供商卡片中遵循 “使用条填充” 剩余 / 已用设置，保持百分比标签和条方向一致。
  • Sub2API：将配额标签、本次请求、令牌和费用总计本地化并分组为紧凑的使用摘要。
  • Codex：避免在成本缓存刷新期间重复转换历史令牌快照，防止大历史会话的持续 CPU 占用。
  • Codex：将自动成本历史追赶设为近空闲，并将本地历史扫描限制为提供商刷新，每 15 分钟一次。
  • Agent Sessions：在监控被禁用时停止不活跃的本地和远程刷新调度器唤醒。
  • 成本使用：在 “打开菜单时刷新所有提供商” 启用时刷新令牌费用数据，并设定一分钟扫描底线以避免重复工作。

jdx/mise v2026.8.4 gpt-oss-120b

新内容

  • 后端工具可声明显式 version_order，实现语义化版本排序（Aqua、GitHub、GitLab、Forgejo、HTTP）
  • mise ls 现在能够匹配跨后端安装的同一工具
  • mise install —force 可在不指定工具时重新安装所有已配置、支持的工具
  • 新增 upgrade.auto_prune 设置（默认 true）并提供 —prune 标志，控制升级后是否自动删除旧版本
  • bootstrap packages prune —manager brew-cask 可保守地移除不再声明的 Homebrew cask
  • bootstrap.packages 支持表格形式，可指定版本和操作系统选择器，实现跨平台包管理
  • brew-cask 管理器支持从 Git URL 安装字体 cask，可指定分支和子目录
  • aqua 相对 registries 条目现在相对于配置根解析，便于项目内部 registry.yaml 使用
  • spm 安装可通过 rev（或 ref）固定到特定提交，支持源码构建
  • generate 生成的 git hook 可携带额外的 mise 标志，支持在子目录或全局标志下运行
  • watch 在未指定任务名时默认运行默认任务，避免错误
  • activate 的 —silent 与 —log-level 现在传递至生成的激活 hook，支持静默输出
  • sops 解密在未提供 age key 时不再被跳过，支持 KMS、Vault、PGP 等非严格模式
  • Windows 平台上 conda、ruby、rust 等工具安装行为改进，解决 DLL 丢失、版本选择和并发冲突等问题
  • 任务系统改进：Azure DevOps 远程 git 包含处理、单仓库任务匹配、任务输出检测、参数验证及 hook 配置解析

问题修复

  • Windows 平台上 conda DLL 放置、RubyInstaller2 构建选择、Rust 工具链并发安装序列化等问题已修复
  • 任务相关修复：Azure DevOps 远程 git 包含、单仓库任务匹配、任务输出检测与参数验证、hook 配置解析等
  • 其他修复：watch 默认任务、activate 静默日志转发、sops 解密、bootstrap 依赖顺序、registry URL、cli 版本前缀解析…

localsend/localsend v1.18.0 gpt-oss-120b

新内容

  • 首次发布 CLI
  • 支持通过链接接收文件
  • 自定义配色主题（颜色选择器）
  • 支持 IPv6
  • 默认启用校验和
  • 默认自动接受收藏设备的文件
  • 使用十进制单位显示文件大小（1 GB = 1000 MB）
  • 支持使用 —text 或 -t 参数启动文本分享
  • 改进长时间传输的剩余时间显示
  • 更改重复文件命名格式为 “file (1).txt”
  • Android 后台传输并添加快速设置磁贴
  • macOS 多项改进：快捷键、按钮、ComputerName、Dock 图标文字拖放
  • Linux 使用原生窗口装饰取代 GTK3 大标题栏
  • 性能提升：对慢速接收设备更快传输
  • Windows 将 LocalSend 添加到共享面板

问题修复

  • 修复大量文件收发导致的卡顿 / 延迟
  • 传输完成后释放唤醒锁，允许设备进入睡眠
  • 修复历史对话框中文本消息显示三次及大小计算错误
  • 修复 DNG 文件保存到相册的问题
  • 修复 iOS/Android 将不支持的媒体格式保存到文件夹的错误
  • 修复 Android 分享到 LocalSend 有时失效并保留位置元数据
  • 修复 macOS 启动隐藏时 Dock 图标短暂出现以及拖拽 / 共享扩展恢复
  • 修复 Linux 添加 CJK 字体支持
