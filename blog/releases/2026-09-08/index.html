herdrdev/herdr v0.9.0 Qwen/Qwen3.8-27B

新内容

  • 新增从单一 Herdr 窗口管理本地和已保存的 SSH 机器，支持合并代理列表、机器范围导航、通知及自动重连
  • 支持多客户端独立查看不同工作区和标签页，共享标签页时最后交互者控制其大小
  • 新增 Muse 代理检测，支持空闲、工作中、审批和问题状态识别
  • 侧边栏文本和元数据令牌现可根据值改变颜色、粗细和变暗效果
  • 自定义主题在启用自动切换时可分别定义浅色和深色颜色覆盖
  • ui.pane_borders = “always” 现在可以在启用外部边框时为单个窗格添加边框
  • 客户端更新现在可以保留兼容服务器及其运行中的代理不受影响，缺失的服务器功能仅禁用受影响的操作
  • 终端 UI 现在在每个客户端中运行，减少繁忙多客户端会话中的重绘工作，并使主题、菜单等设置本地化
  • 空闲终端滚动缓冲区现在使用更少的内存，同时不减少保留的历史记录或更改读取和调整大小行为
  • 窗格图像和图形 API 现在在兼容终端中默认启用，可通过 terminal.kitty_graphics = false 禁用
  • 关闭包含打开的工作树工作区的主工作区现在需要显式组意图：workspace close —group 或 workspace.close 配合 close_…
  • 新的生命周期事件订阅现在以实时事件开始，而不是重放保留的历史记录

Breaking Changes

  • 移除了单进程 —no-session 模式。所有终端 UI 启动现在都附加到后台服务器；分离使窗格继续运行，而服务器停止结束会话
  • API 客户端应在获取初始快照前订阅，以避免错过变更，因为新的生命周期事件订阅现在以实时事件开始而不是重放保留的历史记录
  • 关闭包含打开的工作树工作区的主工作区现在需要显式组意图：workspace close —group 或 workspace.close 配合 close_…

问题修复

  • 鼠标选择现在在终端输出继续时保持可见和可复制，包括禁用自动复制时；Ctrl+C 和 Cmd+C 即使在延迟鼠标释放前也能复制选择
  • Wayland 剪贴板复制不再冻结 Herdr，当 wl-copy 提供选择时
  • 实时交接现在为运行的窗格应用程序保留鼠标转发
  • 主机关机期间中断的窗格退出不再用空会话或新默认工作区替换保存的会话
  • SSH 客户端的终端消失时现在分离，而不是将运行的窗格调整到回退大小并触发昂贵的历史记录重新流
  • 聚焦工作区现在滚动侧边栏以保持其可见
  • 移除后台工作树工作区不再将焦点更改为其父级；Windows 工作树也可以在代理窗格运行时移除
  • 工作树命令现在可以使用 —trust-repository 信任一次请求中验证的仓库，包括由另一个 SID 拥有的可访问 Windows 仓库
  • 超大 Kitty 图像不再阻止较小图像显示，图像替换不再逐行重绘或消失；直接图形保持在拥有它们的客户端上绑定
  • 像素鼠标坐标在窗格应用程序重新断言 SGR 鼠标报告时保持正确
  • 直接终端附加现在尊重 ui.mouse_capture 并将多行粘贴保留为一个粘贴，而不是逐行提交
  • agent prompt 现在可靠地在报告成功提交前发送提示和 Enter；使用 —wait 时，发送到非工作代理的提示需要观察到的工作或阻塞活动
  • 长 Codex 提示在 Windows 上现在有足够的时间等待文本到达再提交 Enter；过期的排队提交在输入开始前被拒绝
  • 最近的窗格读取现在包括尚未滚出视口的输出，而不是返回空文本
  • pane report-agent 和 pane report-agent-session 现在接受选项在窗格 ID 之前以及 —option=value …
  • herdr agent explain —file 现在将不可读文件报告为结构化 JSON，而不是原始 Rust 错误
  • 正在运行的命名服务器现在可以获取由另一个服务器下载的检测清单，无需重启
  • 在启动时设置终端标题或进度一次的代理不再在首次识别时失去该检测信号
  • Claude Code 现在在终端标题不可用时识别可见的回合和后台代理活动，并在后台 MCP 任务继续时保持工作状态
  • Claude Code MCP 问题和 Bash 审批提示现在在等待回答时保持阻塞，包括不同的选项布局和光标位置
  • Claude Code hooks 现在忽略 Cursor 的 Claude 兼容事件，防止 Cursor 会话被保存为 Claude 会话
  • Codex 不再因为早期输出引用确认提示而显示为阻塞，其启动更新对话框现在正确报告阻塞；显式恢复的会话在第一个提示前保存，因此在服务器重启后存活
  • GitHub Copilot CLI 现在在等待后台代理时保持工作状态
  • Oh My Pi 现在通过已调度的继续保持工作状态，而不是短暂报告空闲并提前结束代理等待
  • OpenCode 子代理权限和问题提示不再在工作继续后将父窗格卡住为阻塞
  • 前台工作目录读取现在跟随前台进程组领导者而不是后代，使新窗格保持在预期目录中
  • 超大或不可读的 Git ref 文件不再导致重复的重型状态读取或使工作区使用过时的 ref 数据
  • 标签栏状态命令不再显示杂散的 ANSI 转义片段，主机调色板回复一起应用以避免冗余更新
  • Unix 插件窗格现在除非明确覆盖，否则保持 PWD 与其请求的工作目录一致；Windows 插件窗格现在从插件根解析相对命令并正确处理启动路径
  • 插件链接处理器现在接收匹配的 OSC 8 file:// 点击；不匹配的文件链接仍然不会启动系统 URL 打开器

  • Windows OpenSSH 会话现在可靠地接收鼠标输入，没有丢失的报告或泄漏到窗格的转义片段；远程和仅 LF 多行粘贴保留其换行符和顺序
  • Windows 窗格现在保持 Cursor 和捆绑的 Pi 启动被检测到，PowerShell 代理垫片接受原生参数…
  • Antigravity hooks 现在在 Windows 上正确运行，Devin 集成设置使用正确的 Windows 配置目录
  • Windows 安装不再需要单独安装的 Visual C++ 运行时；安装程序路径在 OpenSSH 会话中仍可发现，畸形继承的环境值被安全拒绝
  • 端点安全阻止无文件 PowerShell 安装的 Windows 用户可以使用带有校验和验证下载的本地 install.cmd 引导
  • 前缀绑定如 prefix+ - 现在识别由 macOS Option 和自定义键盘布局产生的字符，同时精确和弦保持优先级…
