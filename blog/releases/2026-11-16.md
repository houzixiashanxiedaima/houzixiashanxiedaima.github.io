### [yetone/alma-releases v0.4.687 - v0.4.709](https://github.com/yetone/alma-releases/releases) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增在对话中引用选中文字的功能，选中文字后提供 Quote 选项，将其以 Markdown 引用格式插入编辑器并自动定位光标
- iOS 聊天列表新增回复（Replies）部分

- 消息输入框在文本换行时自动转换为卡片样式

- 失败的分支和侧边聊天现在会以文字清晰显示其状态
- 暂存和排队的预览现在会按名称显示引用
- 在 Herdr 聊天中，当 agent 正在工作时按 Enter 可立即停止当前轮次并发送消息
- 为发送按钮新增提示框，说明该中断并发送的行为
- 聊天消息现在显示时间戳和复制选项：完成的回复在悬停时显示“耗时”时间和复制按钮；发送的消息显示其时间和复制按钮

- 原生工具输入验证现在直接在 Go 中运行，消除了对有效输入的 Node 往返；无效输入仍会收到来自 Node 的详细错误信息
- 新增 Go 原生 Glob 模式匹配，支持 *、?、**、字符类和花括号展开，并与 fast-glob 结果保持一致
- 复杂模式（如 extglobs、否定、范围、转义）仍由 Node 处理，通过契约测试确保跨工具一致性
- Read、Write、Edit 和 Grep 操作现直接在 Go 中执行，减少通过 Node 的往返次数以提升性能
- 针对图像、密钥、hashline、远程主机、Windows 及缺失 ripgrep 等特殊场景仍使用 Node 处理

**问题修复**
- 修复在聊天消息区域点击并输入或粘贴文本时，内容未发送到编辑器的 bug
- 修复在斜杠和 @ 选择器中滚动时，静止鼠标光标下自动选中项目的问题；现在仅实际移动鼠标才会选中项目
- 桌面应用：工作区预览文件在文件标签页后重新打开时，现在会恢复到之前的位置
- 行内换行的源码视图中，“全选”现在会复制整个文件，且滚动时选区端点保持不变
- 标题：引号仅在包围整个标题时才被移除
- 修复生成的线程标题保留引用词末尾引号的问题，现在仅移除整个标题周围的引号
- 修复已停止的运行被标记为“已完成”而非“已读”，导致下一次运行再次显示为新消息的问题
- 修复复制的代码缺少末尾换行符，导致粘贴的命令立即执行而非等待回车的问题
