### [herdrdev/herdr v0.9.1](https://github.com/herdrdev/herdr/releases/tag/v0.9.1) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 新增 herdr --machine 命令，支持在已保存的 SSH 机器上控制代理、窗格和工作区
- 支持从 Linux、macOS 或 Windows 连接 Windows SSH 主机，并支持交互式安装更新
- 输入框支持光标处编辑及多种快捷键（如 Ctrl+A/E/K/U/W/Y），兼容 Unicode 文本
- 新增 Letta Code 检测与原生会话恢复功能，可通过 CLI 安装集成
- 按住 Ctrl 可高亮链接后再打开，支持视口外 URL 和 OSC 8 链接点击
- 侧边栏令牌规则支持隐藏匹配的令牌及其分隔符，无令牌时行自动消失
- 工作区键盘导航现跨连接的机器按侧边栏顺序进行，切换前有可见高亮提示
- 实验性实时交接现支持传输超过 64 个窗格（需发送端服务器包含此更新）
- Linux 和 macOS 上停止接收输出的终端观察者在 30 秒无写入后断开连接
- Windows 终端清理现显式重置鼠标报告模式

**问题修复**
- 修复远程输入、切换和弹窗交互不再重发整个窗格屏幕，降低带宽占用
- 修复停滞的 SSH 机器不再将客户端困在本地之外，支持取消未完成的远程切换
- 空闲 SSH 连接减少 CPU 使用且不丢失最终输出，重复失败会退避而非快速重连
- 大粘贴不再因输出队列错误断开客户端连接
- SSH 设置现显示认证说明和有用错误（如 Tailscale 登录 URL），不再挂起
- 机器和工作树组正确折叠而不改变选中的工作区，侧边栏在调整大小时保持稳定
- 代理列表在切换机器时保持滚动位置，区分不同机器上的相同 ID
- 后台机器激活不再调整其他客户端聚焦窗格的大小，窗口标题跟随各自视图
- agent focus 和 pane move --focus 现在将附加客户端移动到请求的窗格
- 创建工作树后重新聚焦其新工作区，部分失败的移除可重试，子模块提供强制移除选项
- 临时工作树操作错误横幅会自动过期，不再无限期保留在屏幕上
- 标签溢出时最后一个标签完全可见，会话导航器再次绘制连接的树分支
- 静音的侧边栏和标签在深色主题下（包括 Windows Terminal）保持可读
- 鼠标拖拽和复制模式选择在活动输出期间保持有效，即使部分选择在视口外
- 双击选择在禁用自动复制时保持可见，支持整词扩展和 CJK 标点停止
- 滚动不再组合不匹配的终端快照或在 Neovim 等全屏应用中留下陈旧换行行
- 本地 Kitty 图形在首次图像后保持直接传输，弹窗仅隐藏重叠的图像放置
- 像素鼠标坐标独立于图像渲染工作，防止点击在屏幕上漂移
- Kitty 键盘报告中识别 F1–F12 功能键，foot 等终端的参数化报告也支持 F1–F4
- WezTerm 控制键报告保留 Enter、Backspace、Tab 和 Escape，修饰键输入完整到达应用
- 鼠标报告跨延迟读取拆分时不再泄漏尾部字节到窗格输入，重连后重新断言鼠标报告
- 无法加载的保存会话在替换前被保留，恢复副本保存在 session-backups/ 目录
- 删除会话现在需要精确名称（包括大小写），以连字符开头的名称可在 -- 后传递
- 新启动的 macOS 服务器在注销后保留用户查找和 DNS 访问权限
- Linux 进程发现在卡住的 WSL 代理周围保持响应，避免反复扫描不断增长的进程树
- Linux 桌面通知正确标识 Herdr 为来源
- pane split 无目标时在 Herdr 内调用时分割调用窗格，而非其他客户端的聚焦窗格
- 实时代理名称在临时进程检测不确定时存活，活动代理可按名称访问
- Windows Codex 提示在粘贴文本后可靠提交，不再丢失 Enter 键
- OpenCode V2 从显示对话的窗格报告生命周期状态，共享服务器不再混淆窗格
- Codex 在静态标题、动画禁用和排队后续情况下保持正常工作
- Claude Code 的 Unicode 活动旋转器和 Pi 的工作边框被正确识别
- Pi 在 Windows 上记录原生会话路径，嵌套 OMP 进程不再替换父窗格的会话
