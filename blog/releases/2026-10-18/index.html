  • 移动端新增平板布局、标签管理、公共列表协作及附件查看等功能
  • 爬虫引擎升级至 patchright 驱动真实 Chrome，大幅降低被反爬拦截概率
  • 新增按需视频保存功能，支持通过 yt-dlp 下载指定书签的视频
  • 优化内存与性能：修复查询缓存泄漏，按需加载依赖降低约 40MB 内存占用
  • 搜索索引默认工作线程数提升至 50，加快大型导入的索引速度
  • SQLite 启动时及每日执行 PRAGMA optimize 以优化数据库性能
  • Web 应用界面视觉刷新，新增跟随系统的 “系统” 主题选项
  • MCP 服务器升级至 MCP v2 SDK，CLI 集成官方 Karakeep skill
  • 新增 /.well-known/api-catalog 等标准端点，文档新增 llms.txt 供 AI 代理使用

安全修复

  • 强制校验上传请求体大小，防止解析 multipart 前的资源滥用
  • 资产下载改为尊重客户端背压机制，避免内存缓冲溢出风险
  • 所有 tRPC 端点增加分页限制验证，防止恶意大查询
  • AI 提示词分词前限制内容长度，防止处理超大文本导致的资源消耗
  • 升级 Next.js 至 16.4.1 以获取 10 月安全更新

Breaking Changes

  • 认证库从 next-auth 迁移至 better-auth，所有 Web 用户需重新登录一次
  • 数据库中的邮箱地址将自动转为小写，存在冲突的账户需在升级前手动处理
  • 建议迁移至 karakeep-chrome 镜像以享受反爬改进，Browserless 方案不再推荐

问题修复

  • 修复 Android 应用在后台被杀后分享丢失或重复的问题
  • 忽略 Android 不可靠的网络可达性检查，避免应用错误标记为离线
  • 修复移动端键盘遮挡服务器保存按钮的问题
  • 修复 Markdown 列表中项目符号和数字未使用前景色的问题
  • 修复 Prometheus 未配置时仍收集默认指标导致的 CPU 基线升高问题
