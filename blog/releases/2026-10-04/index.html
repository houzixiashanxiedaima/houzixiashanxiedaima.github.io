2026-10-04 GitHub Releases 日报：mattpocock/skills、jdx/mise、exelban/stats 等13个项目更新 | implement-spec 技能升级至 Engineering 分类，支持在 Claude Code 插件中发布并生成文档页

mattpocock/skills v1.3.0 - v1.3.1 Qwen/Qwen3.8-27B

新内容

  • implement-spec 技能升级至 Engineering 分类，支持在 Claude Code 插件中发布并生成文档页
  • pr 技能升级至 Engineering 分类，作为 PR 正文收尾流程，包含摘要、证据及合并风险评估
  • retro 技能升级至 Engineering 分类，用于回顾编码会话并建议环境改进而非代码修改
  • domain-modeling 触发条件扩展至术语讨论及 GLOSSARY.md/ADR 的编写与编辑
  • grilling 模板更新，连续问题间使用水平线分隔以提升可读性
  • 标准化跨技能调用指令，明确要求调用 Skill 工具以提高加载成功率
  • wait-what 技能支持通过 GLOSSARY-MAP.md 索引多上下文仓库中的 GLOSSARY.md
  • implement-spec 技能升级至 Engineering 类别，支持在单次运行中实现完整规格说明
  • pr 技能升级至 Engineering 类别，规范 Pull Request 正文结构，包含摘要、前后证据及合并风险评估
  • retro 技能升级至 Engineering 类别，回顾编码会话并建议改进代理环境配置而非代码本身
  • domain-modeling 触发条件扩展，涵盖讨论代码库术语及直接编写或编辑 GLOSSARY.md 或 ADR 的场景
  • grilling 模板更新，连续问题之间使用水平线分隔以提升可读性
  • 跨技能调用标准化为显式 “调用 Skill 工具” 指令，提高模型调用其他技能的可靠性
  • wait-what 技能支持通过 GLOSSARY-MAP.md 索引定位正确的 GLOSSARY.md

Breaking Changes

  • CONTEXT.md 和 CONTEXT-MAP.md 重命名为 GLOSSARY.md 和 GLOSSARY-MAP.md，需手动迁移文件
  • 移除 resolving-merge-conflicts 技能，不再提供专用冲突解决流程
  • 移除 resolving-merge-conflicts 技能，代理将直接在无专用技能的情况下处理合并或变基冲突
  • 将 CONTEXT.md/CONTEXT-MAP.md 领域文档约定重命名为 GLOSSARY.md/GLOSSARY-MAP.md，现有文件需手动重命名

问题修复

  • 修复 to-spec 等六个技能的 YAML front matter 引号缺失导致的解析错误
  • 移除 resolving-merge-conflicts 技能，由 Agent 直接处理合并或变基冲突
  • 修正跨技能引用违规，防止用户调用型技能被其他技能通过 Skill 工具调用
  • 移除 diagnosing-bugs 向 improve-codebase-architecture 的自动交接逻辑
  • 全库移除 em-dash 符号，替换为逗号、冒号等标点以优化纯文本阅读体验
  • ask-matt 路由更新，指向 /retro 和 /improve-codebase-architecture 替代旧有交接说明
  • 修复 to-spec、code-review 等六个技能描述元数据中的 YAML 格式错误，确保 skills.sh 能正确解析
  • 移除所有文档和脚本中的破折号，改用逗号、冒号等标点符号以符合纯文本阅读习惯
  • 修复多个技能中违反 “用户调用技能不可被其他技能调用” 不变量的交叉引用问题
  • 修正 grilling 技能 SKILL.md 中的标点符号使用，提升指令清晰度

jdx/mise v2026.10.2 Qwen/Qwen3.8-27B

新内容

  • 新增实验性 spinel 后端，支持将 Ruby CLI 编译为原生二进制文件
  • JSON schema 现在支持各后端的类型化工具选项，提供自动补全和验证
  • Windows 上支持 daemon 预设（除 redis 外均可运行）
  • 安装指南新增通过 packslip 安装 mise 的方法，无需执行安装脚本
  • helmfile (1.8.1+) 和 dagu (2.18.0+) 现从签名的 packslip manifest 安装
  • 新增 aqua 包：goccy/tobari、ymmt2005/pbschema-lens

问题修复

  • 修复不受信任的项目配置导致 shell 激活失败的问题
  • 设置重载失败时不再崩溃，改为报告错误
  • —no-config 和 MISE_NO_CONFIG=1 现在跳过 .miserc.toml 发现
  • 超时任务即使正常退出也会正确报告失败
  • Windows 上超时的任务可以清理资源（发送 Ctrl+C）
  • mise exec — cmd /c 保留双引号，修复引号处理问题
  • 带 init 步骤的任务守护进程在 Windows 下使用 cmd.exe 启动
  • packslip 跟随仓库转移到新所有者的情况
  • mise dot save 和 history sync 在跟踪目录被符号链接替换后正常工作

exelban/stats v3.0.20 Qwen/Qwen3.8-27B

新内容

  • 新增传感器映射以支持 MacPro5,1 机型
  • 新增选项，允许在菜单栏仅显示 Stats 图标并打开组合弹窗
  • 改进 SMC 缓存和风扇控制的可靠性
  • 新增 HID 传感器发现的缓存机制

安全修复

  • 停止在未获得位置权限的情况下查询 Wi-Fi SSID 和 BSSID

问题修复

  • 修复组合模块中传感器对齐的问题

code-yeongyu/oh-my-openagent v5.1.14 - v5.1.16 Qwen/Qwen3.8-27B

新内容

  • 升级至 senpi 2026.10.7，优化主机交接机制，避免旧引擎占用导致的首轮失败
  • 代码模式新增 in-cell wait () 屏障及 handle () 视图，支持四种内核
  • JavaScript 内核新增 tool.define ()、tool.undefine (name) 及命名工具支持
  • 增强 eval 恢复能力，在会话切换取消或运行时启动失败后不再保持损坏状态
  • Ruby 内核的内存通知功能重新兼容 Ruby 2.6
  • 内置 visual-qa 技能新增 Apple HIG 检查清单，支持多分辨率捕获矩阵及逐项判定
  • 新增自动权限预设，仅批准可证明在项目内的操作
  • 升级至 senpi 2026.10.6，启动横幅合并为单行摘要，429/5xx 错误显示为重试横幅而非原始 JSON
  • 工具卡片差异对比度提升至 7:1，每个编辑卡片显示变更内容
  • 子代理完成后的卡片显示为摘要（如运行时间、工具数、成本），替代调试令牌行
  • 内存 /doctor 检查改为首次使用时加载，减少启动负载
  • 权限系统启动失败时不再静默跳过检查，而是拒绝工具调用并提示修复配置
  • 浏览器技能跟随桌面应用选择的浏览器引擎，缺失时提示连接，不可逆操作前询问确认
  • 会话网关数据库支持命名空间扩展，允许集成在同一事务中更新状态、绑定对话或确认消息
  • 新增持久化所有权注册表保护核心对象，拒绝名称冲突的触发器和视图
  • 迁移跨进程协调，禁止的架构变更自动回滚，联合入队创建唤醒标记并在回滚时移除
  • 任务工具不再建议将少量读取或小前台检查委托给子任务，避免 GPT-6 Astra 等待子任务
  • 升级 senpi 至 2026.10.5，评估内核解释器死亡时仅替换一次而非失败所有后续单元格
  • 空闲共享主机返还成本，Claude Agent SDK 升级至 0.3.288

Breaking Changes

  • senpi 2026.10.5 要求权限预设名称有效且无 null 规则，否则拒绝工具调用直至修复
  • 会话网关存储或扩展架构版本高于运行 omo 时拒绝访问，旧二进制不迁移也不降低 user_version

问题修复

  • 修复孤立临时内存运行在每次扫描时重复报告的问题，现仅报告一次
  • 修复临时内存身份提升冲突时的警告日志重复记录问题，现仅首次记录
  • 修正主机状态显示，确保正确标识由交接启动的代际对应的引擎构建版本
  • 修复会话中继到聊天线程的问题在终端回答后未关闭的 bug
  • 修复中继问题在网关存储中保持待处理状态导致聊天连接器阻塞的问题
  • Outbox 行现在包含 answer_state，连接器等待已交付的回答而非将声明视为已解决
  • 修复配置热重载因弃用键通知被拒绝的问题
  • 修复 thread_read 使用 next_cursor 时无法向前翻页的问题
  • 修复截断读取返回游标但重试时返回相同首个窗口的问题
  • 修复内存使用写入在关闭后失败时作为未处理拒绝暴露的问题
  • 若干琐碎修复（测试清理、文档更新等）
  • 修复首轮强制工具调用被严格模式网关拒绝时导致回合结束的问题，改为重试一次不强制
  • apply_patch 保留文件行尾格式，不再将 CRLF 或混合行尾重写为 LF，缩进文件头正确应用
  • NVIDIA 专用设置默认模型更新为 nvidia/nemotron-3-ultra-550b-a55b，解决上游退役问题
  • Codex 版（LazyCodex）语言服务器未安装时不再阻塞编辑，遵循用户安装决定
  • 计算机使用权限拒绝在代码模式下正确返回错误标志，防止模型忽略拒绝继续操作
  • Windows 下终止委派任务报告为已终止而非崩溃，内存原子状态重命名重试短暂文件持有
  • macOS 计算机使用诊断检查超时探针报告为超时而非 EPERM 错误，清理已退出进程组
  • 若干琐碎修复（扩展调用目标解析、唤醒标记事务提交、延迟扩展错误吸收等）

  • 修复笔记本平台定制睡眠 SSDT 补丁时，可能导致 OpenCore 引导 Windows 系统出现蓝屏的问题

earendil-works/pi v1.0.1 - v1.0.2 Qwen/Qwen3.8-27B

新内容

  • 新增按思考级别采样功能，支持在 models.json 中为 OpenAI 兼容 API 的不同思考级别配置 temperature、top_p 等采样参数
  • 新增 Nix flake，支持通过 nix run 或 nix profile add 安装和运行最新版本
  • 新增 MCP 服务器项目级覆盖功能，允许在单个项目中启用、禁用或更改用户级服务器的暴露设置
  • 新增 MCP Client ID Metadata Documents (CIMD) 支持，授权服务器可通过文档 URL 识别 pi 而非动态注册
  • 新增任意工具的渲染器支持，pi.registerToolRenderer () 可绘制未注册工具（如恢复会话中的 MCP 工具）的调用
  • 新增 Cloudflare Clef 分类器模型，可在 codemode 脚本和扩展中使用
  • OAuth 登录界面新增复制快捷键（默认 ctrl+x），当浏览器无法打开时复制登录 URL
  • Anthropic 工具在对话中途添加或重新定义时现在内联定义，保持提示缓存而不重发完整工具列表

安全修复

  • 修复 brace-expansion 5.0.9 漏洞，将其固定为直接依赖 5.0.12（GHSA-q2hr-2g5m-vwhr…

Breaking Changes

  • 全局 npm 安装的 pi update 现在建议迁移到 pi.dev 安装器的托管安装，后者固定所有依赖
  • 从发布的包中移除 npm-shrinkwrap.json，npm 安装不再固定传递依赖，库消费者可以覆盖它们；如需固定安装请使用 pi.dev 安装器

问题修复

  • 修复 —models 参数末尾逗号导致模型循环中多出一个模型的问题
  • 修复 codemode 脚本循环打印导致内存耗尽崩溃的问题，输出超过 16 Mi 字符或 100000 项时失败
  • 修复扩展通过 Image 渲染的 JPEG、GIF 和 WebP 图像在 Kitty、Ghostty、WezTerm 和 Warp 中不显示的问题
  • 修复恢复会话和 HTML 导出中 MCP 工具调用在服务器连接前完全展开渲染的问题
  • 修复 WezTerm 中全屏 Kitty 图像滚动后折叠为一行条带的问题
  • 修复 “Selected model is at capacity” 提供商错误结束回合而非重试的问题
  • 修复 Cloudflare AI Gateway Claude 模型因使用连字符模型 ID 而返回 404 的问题
  • 修复 ChatGPT 登录回调端口被占用时继续执行导致 OAuth 状态不匹配的问题
  • 修复 Amazon Bedrock OpenAI 模型输入超过 272k token 时按短上下文计费的问题
  • 修复 Amazon Bedrock Claude 请求在系统提示或工具变更后出现 “Invalid signature in thinking block” 错误…
  • 修复 Together DeepSeek V4 Pro 在重命名后丢失思考级别控制的问题
  • 修复默认 NVIDIA 模型指向已停用的 nemotron-3-super-120b-a12b，现改为 nemotron-3-ultra-550b-a55b
