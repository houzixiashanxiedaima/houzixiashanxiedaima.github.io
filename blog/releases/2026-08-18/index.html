  • 扩展 Windows 支持：覆盖生成的启动器、dotfiles、shell 和文件任务

farion1231/cc-switch v3.20.0 Qwen/Qwen3.5-35B-A3B

新内容

  • Pi 成为第九个受管应用，支持供应商、提示词、Skills、会话浏览与用量统计全链路接入
  • Codex 支持多个 ChatGPT 账号，官方卡可逐卡绑定账号且退出自动故障转移
  • Claude Code 内置 WebSearch 在 GPT 路由下可用，结果引用保留并计入用量
  • 模型选择器全面支持模糊搜索，按模型 ID 和厂商名匹配
  • Codex 表单回归 1M 上下文开关及配套的自动压缩阈值输入
  • OpenCode Go 改为直连模式，不再需要路由接管
  • DeepSeek V4 按新峰值档牌价重定价，Gemini 3.7 Flash 加入预设
  • Kimi 上游改为干净透传，停止注入非标准思考块字段
  • 字节跳动千帆 Token Plan 预设上线，支持六模型目录及真实思考开关
  • 各厂预设按官方文档预填真实思考档位（如火山、混元、智谱等）
  • Codex OAuth 配额显示支持逐卡配置，刷新间隔可自定义
  • 供应商表单一致性打磨，统一组件样式与无障碍标签
  • Claude Desktop 连接模式改为下拉选择，直连与映射模式互不覆盖
  • Grok Build 表单重建在 Codex 布局上，统一端点与高级区字段
  • 接管开启确认动画优化，初始代理状态加载完成前置灰接管开关

Breaking Changes

  • 数据库从 v16 迁移至 v17（Pi 用量去重账本），降级需还原备份
  • 存量 Grok Build 供应商保存后 api_backend 钉为 responses，需手动调整上游格式
  • 部分存量供应商因输入法缺陷损坏的文本需重新编辑才能生效
  • 早期版本改写过 model_catalog_json 指针的供应商需手动指回一次
  • MSI 存量垃圾注册表键不会被清理，需手动处理旧安装残留
  • WSL 或 exFAT 上停止 Codex 接管改为拒绝恢复并报错，而非冒险写入半份文件
  • 预设改动仅作用于新建供应商，存量供应商保留创建时的配置不变

问题修复

  • 修复 v3.19.2 在 WSL 路径上无法更新或切换配置的问题
  • 修复启动时白 / 黑闪屏问题，窗口着色顺序已调整
  • 修复 Windows MSI 安装包写入垃圾注册表键的缺陷
  • 修复代理接管恢复抹掉官方 ChatGPT 登录的问题
  • 修复环境检查在全部升级或冲突诊断时挂死的问题
  • 修复 macOS 输入法导致供应商表单文本重复与乱序的缺陷
  • 修复 SQL 备份逐值保真问题，拒绝截断导入并重建依赖数据库
  • 修复用量趋势图跨年时高亮与提示框年份不一致的问题
  • 修复 DeepSeek 缓存命中在 Chat 路径被计为零导致的成本高估
  • 修复文件丢失的 Skill 显示为可更新的逻辑错误
  • 修复模型拉取报错时回显 API 密钥的安全隐患
  • 修复火山方舟 Agent Plan 预设指向 Coding Plan 的错误
  • 修复 ModelScope / Novita / Nvidia 平台思考开关方言不兼容问题
  • 修复部分 ChatGPT 账号需重新登录以同步 id_token 持久化的问题
  • 修复故障转移队列中内置官方卡未被过滤导致 Auto 模式异常的问题
