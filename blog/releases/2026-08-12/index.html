AChep/keyguard-app r20260811.1 - r20260812.1 Qwen/Qwen3.5-35B-A3B

新内容

  • 新增 GPG 密钥管理功能，支持导入、管理及设置过期时间
  • Windows 平台新增 SSH/GPG 代理支持，集成开发工具与 Git
  • 代理请求支持按调用者范围审批，无需每次操作确认
  • Wear OS 平台新增 GPG 密钥项类型支持
  • KeePass (KDBX) 同步引擎全面重构，提升可靠性与性能
  • KeePass 同步支持大文件附件（最大 500MB），采用流式编码降低内存占用
  • 附件同步改为本地暂存机制，防止数据丢失并确保可靠同步
  • Android 新增 OpenKeychain 兼容提供者，支持 Termux 等应用使用密钥
  • Android 新增凭证交换 (CXF) 支持，实现安全凭证共享
  • 增强自动填充安全性，验证目标应用的包名和签名身份
  • 新增 WebDAV 支持，可连接并浏览远程服务器以存取保险库
  • 主导航栏支持自定义，可添加过滤器及调整标签顺序
  • 新增保险库项目链接功能，相关项目区域升级为独立字段
  • 简化嵌套文件夹创建流程，垃圾桶 / 归档项目自动移除选中状态
  • 桌面端密码输入框屏蔽输入法编辑器 (IME)，防止第三方键盘窃取
  • 提升 KDBX 金库处理的稳定性和兼容性
  • 改进 KDBX 修订处理精度，确保数据同步更可靠

安全修复

  • 剪贴板保护：macOS 和 Windows 复制敏感字段时不保存至系统历史记录
  • 强化 KDBX 解析：限制密钥派生函数并验证内部结构以防恶意数据库
  • 临时文件安全加固：Windows 上同步或操作生成的临时文件权限更严格
  • GPG/SSH 代理加固：实施更严格的密钥策略、公钥验证及连接处理

问题修复

  • 修复 Windows 启动时应用程序崩溃的关键稳定性问题
  • 修复 Windows 上代理相关项目显示异常的问题
  • 修复 Bitwarden 同步中的 JSON 解析失败及连接处理问题
  • 修复 Flatpak Linux 版本托盘图标缺失的问题
  • 修复 Watchtower 未正确标记仅出现一次的数据泄露密码问题
  • 优化保险库列表加载、搜索及 Watchtower 扫描性能
  • 更新 Passkeys、双因素认证服务及公共域名后缀的内部库
  • 修复加密存储故障恢复机制及排除敏感数据备份的问题
  • 改进错误处理：清晰提示附件超限，保留解码错误详情并减少重试
  • 修复 KDBX 文件解析问题，支持含额外数据的金库
