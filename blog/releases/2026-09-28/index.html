jdx/mise v2026.9.16 Qwen/Qwen3.8-27B

新内容

  • Aqua 工具支持按单个工具选择 glibc 或 musl 构建，避免全局 libc 偏好导致静态构建失效
  • Monorepo 深层嵌套配置根目录支持短路径别名（如 //123:build），可用于任务依赖、模式匹配及子路径
  • Packslip 工具在 GitHub/GitLab 仓库重命名后仍可正常安装，通过锁文件 v3 记录仓库 ID 进行固定
  • SLSA 来源验证现在要求预期的签名者身份，防止无关工作流的签名通过验证
  • 修复 mise run —no-timings 回归问题，正确隐藏每个任务的耗时行并覆盖环境变量设置
  • 修复 cargo +nightly 与 rust = “nightly” 的兼容性问题，正确配置 rustup 的 nightly- 工具链
  • 修复 mise outdated/upgrade 版本比较错误，不再将带 v/V 前缀的旧版本误报为更新，且忽略仅构建元数据不同的版本
  • 修复 mise run/tasks run —no-cache 无法重新克隆远程 git:: 任务包含和获取远程依赖任务的问题
  • 修复 mise dot track 对已跟踪路径重复操作时的提示与配置重写问题，以及凭据类文件名静默跳过保存的问题
  • Blob-pack 从远程缓存下载时增加临时流错误重试机制
  • 性能优化：Shims 在配置了 rust 及其他工具时不再运行 rustup 检查，显著降低 go shim 等启动延迟
  • 性能优化：配置加载与模糊版本解析减少不必要的工作量，包括插件简写构建、符号链接解析及正则编译开销
  • 文档修正：任务文档更正默认作业数为 8，并准确描述并行与顺序执行时的默认输出模式

安全修复

  • SLSA 来源验证强制检查证书 URI 身份与 OIDC 颁发者是否匹配预期签名者，未配置则跳过 SLSA 检查
  • 公共密钥 DSSE 捆绑包验证现在要求 SHA-256 主题摘要与下载的工件匹配，防止有效捆绑包被复用验证不同下载

Breaking Changes

  • 锁文件升级至修订版 3，新 / 空 mise.lock 写入 lockfile_version = 3，旧版 mise 拒绝读取…
  • 锁定工具若要求 SLSA 但未配置预期签名者，安装时将失败并提示，需配置签名者或刷新锁条目
  • Dotfiles 历史跨机器共享引入 allow_plaintext 元数据，旧版 mise 无法读取…

Huanshere/VideoLingo v3.1.1 Qwen/Qwen3.8-27B

新内容

  • 新增 Fish Audio 官方配音，支持从原视频克隆音色或选择固定 / 自定义音色
  • OpenAI 兼容 TTS 后端现支持 OpenLux 语音端点，可自定义 Base URL 和模型
  • 支持直接导入 SRT 字幕进行翻译，也可仅运行转录阶段生成原文字幕
  • 新增流程检查点，允许在翻译前修改术语表或在生成字幕前审查翻译表格
  • 增强字幕输出控制，支持设置翻译风格、调整字体字号颜色及独立选择字幕类型
  • 新增 MAI-Transcribe-2 作为可选 ASR 后端，支持 Azure Speech 和 OpenRouter
  • 优化长视频处理稳定性，Demucs 分块处理音频，日语 NLP 支持分批，字幕切分增加降级方案
  • 改进配音失败处理机制，TTS 重试失败后明确中止并记录截断句子，避免生成静音

Breaking Changes

  • 移除旧的 fish_tts (302.ai) 和 azure_tts Provider，默认改为 Edge TTS
  • Fish Audio 需要配置 fish_audio.api_key 且账户需有可用额度
  • Qwen3-ASR 模型大小调整为 config.yaml 中的高级选项 whisper.qwen_model

问题修复

  • 修复翻译和标点边界情况导致流程中断的问题

openai/codex rust-v0.158.0 Qwen/Qwen3.8-27B

新内容

  • 新增全屏 TUI 中复制选择与右键粘贴的配置选项，复制的转录内容保留 Markdown 格式
  • 支持连接需要预注册 OAuth 客户端密钥的 MCP 服务器，可通过 codex mcp add —oauth-client-secret 配置
  • 使用 Bearer Token 保护 exec-server WebSocket 直连，包括通过 app-server 配置的连接
  • 图像生成和编辑可显式请求透明背景，且编辑操作现支持基于文件的会话图像
  • 终端输入审批默认对以高权限运行的命令启用，仅运行时授权不再触发不必要的审查

问题修复

  • 修复 Windows 沙箱在普通 Windows 10 路径、被拒绝的存储凭据及大型权限策略下的失败问题
  • 修复 Linux 沙箱在嵌套可写根目录下的启动问题，并在 Linux 和 macOS 上跨可写根目录保留 Git 元数据保护
  • macOS 补丁操作现在识别现有权限覆盖的系统路径别名，避免不必要的审批提示
  • 审批审查在新用户输入到达时重试，状态询问不再自动中止待处理的操作
  • Mermaid 流程图现在正确渲染带引号的标签和 & 符号；不支持的图表会说明回退到源码的原因
  • 命令完成事件现在包含早期输出并向客户端报告进程启动失败
