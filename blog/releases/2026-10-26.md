### [MHSanaei/3x-ui v3.11.0](https://github.com/MHSanaei/3x-ui/releases/tag/v3.11.0) <sup>Qwen/Qwen3.8-27B</sup>

**新内容**
- 升级 Xray-core 至 v26.10.21，支持新核心的 XDRIVE、Lua 脚本规则及 finalmask 源 IP 过滤
- 新增 AmneziaWG Linux 内核数据路径选项，提升上传速度并支持 NAT-only 模式
- 重构 Telegram 机器人，支持单聊天实时屏幕编辑、内联搜索及管理通知路由至论坛主题
- 优化主机规则，支持绑定特定客户端、SNI 池随机选择、CIDR 范围展开及拖拽排序
- 分享链接支持携带 TLS 密码套件（cs 参数）并固定指纹，编辑器提供预设与警告
- 提升大规模安装性能，包括缓存订阅内容、索引令牌查询、gRPC 连接池化及减少冗余数据库写入
- Docker 镜像现支持 linux/386、arm/v6 和 arm/v7 架构，包含正确的 Xray 和 MTProto 二进制文件
- 新增斯洛伐克语（sk-SK）面板和机器人本地化支持
- Shadowsocks TCP HTTP 头入站现通过 obfs 插件出现在 Clash/Mihomo 订阅中
- 新增节点管理员 API 令牌作用域，允许主节点更新子节点面板而无需完整管理员令牌

**安全修复**
- 安全加固：新数据库首个用户生成随机用户名和密码，不再使用固定默认值
- 安全加固：WireGuard/AmneziaWG 配置文件逐行检查，拒绝包含控制字符的值及恶意 wg-quick 钩子指令
- 安全加固：修复代理后客户端 IP 伪造漏洞，仅信任 X-Forwarded-For 的代理端地址，忽略 X-Real-IP

**问题修复**
- 修复 VLESS/Trojan TLS 入站后启用 PROXY 协议导致 fallback 目标失效的问题
- 修复私有 DoH 服务器不可达问题，DNS 允许规则现在打开 Xray 实际拨号的端口
- 修复 TUIC 流量路由匹配问题，添加或删除 TUIC 客户端不再重启 Xray
- 修复 PostgreSQL 上删除入站或清理耗尽客户端时导致的流量轮询死锁问题
- 修复周期性重置和“重置所有客户端流量”未重新启用配额禁用客户端的问题
- 修复 fail2ban 禁用时客户端 IP 无法记录和显示的问题
- 修复订阅路由缺少 Cache-Control: no-store 头导致缓存返回过期数据的问题
- 修复概览页服务器公网 IPv4/IPv6 仅在首次查找或重启时更新的问题
