steipete/CodexBar v0.61.0 Qwen/Qwen3.8-27B

新内容

  • 新增五个提供商支持：Nous Portal、Muse Code、CodeRabbit…
  • 完善额度显示：支持 Mistral API/Vibe Code、Venice 订阅积分及 Grok 使用限制重置优惠券
  • 丰富消费详情：支持 DeepSeek 分模型消费、OpenRouter 按量付费及账户活动，并在 CLI 输出中展示历史
  • 优化账户切换体验：Codex 卡片在菜单打开时实时更新，Claude 区分切换与刷新阶段
  • 稳定菜单栏布局：保留图标位置并对齐拥挤切换器中的提供商名称
  • Azure OpenAI：设置中可选 OpenAI 兼容 v1 接口，保留现有环境变量默认值
  • CodeRabbit：通过单一有界 CLI 报告展示审查计数和计费状态，避免混合账户数据
  • DeepSeek：以原始计费货币和周期展示分模型消费，尊重可选用量可见性
  • Grok：独立于每周用量，展示可用使用限制重置优惠券及到期日期
  • Hugging Face：通过捆绑插件展示 Inference Providers 费用及 ZeroGPU 配额，隔离令牌账户身份缓存
  • Mistral：并列展示包含的 API/Vibe Code 额度、消费及积分，支持可选数据不可用时的独立回退
  • Muse Code：通过捆绑插件展示五小时及每周订阅配额，复用现有 CLI 登录无需交互认证
  • Nous Portal：通过捆绑插件展示月度订阅积分及购买余额，复用 Hermes 登录不刷新凭据
  • OpenRouter：新增无上限按量付费消费摘要，保留有上限密钥配额，识别管理密钥并展示过去 30 天活动
  • Replicate：通过捆绑计费插件展示月度推理消费及预付费积分，支持原生 Chrome 会话恢复
  • Venice：新增显式 Web 源用于订阅积分、月度消费、银行上限及补充日期，支持账户隔离

问题修复

  • 修复 Codex 在菜单保持打开时刷新选中账户卡片的问题，保留子菜单及账户所有权
  • 修复 Claude 账户激活澄清问题，展示切换 / 刷新阶段直至对账完成，保留活跃账户检查
  • 修复 Claude Remote Control 启动覆盖未应用于直接 CLI 用法回退的问题
  • 修复菜单栏在隐藏 / 移除状态项、退出或显示变更恢复时丢失保存图标位置的问题
  • 修复切换器中多词提供商名称与图标 / 标签对齐问题，保留完整辅助功能标签
  • 修复 OpenRouter 在推理令牌超过完成令牌时保留消费历史的问题，保持计数器分离
  • 修复 OpenRouter 忽略已弃用密钥速率限制元数据的问题，防止隐藏有效配额或产生负数限制
  • 修复 OpenRouter 在诊断中区分无效响应与网络故障的问题，保留其他来源可用数据
  • 修复 Antigravity OAuth 回退措辞误导问题，在 CLI / 日志 / 诊断中报告各来源结果
  • 修复 Devin 尊重选定组织并仅导入浏览器会话的问题，优先当前解码凭据
  • 修复共享功能保留网关模型家族的问题，排除原始命名空间及私有模型名
  • 修复 CLI 在用法文本及终端卡片中展示提供商历史 / 总计的问题，包括正确周期 / 货币 / 零值
  • 开发：插件新增 ctx.http.post 支持 JSON 请求，以便提供商分类非 JSON 错误页
