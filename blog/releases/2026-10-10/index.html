nicobailon/pi-web-access v0.38.0 Qwen/Qwen3.8-27B

新内容

  • 新增 Ceramic 关键词搜索提供商，需配置 ceramicApiKey 或 CERAMIC_API_KEY
  • OpenAI web_search 默认切换至更经济的 Luna 模型（如 gpt-6-luna），成本降低约 20 倍
  • 支持无 API Key 的提供商（如 pi-multiprovider）使用回答模式和查询重写功能
  • 优化代理请求处理，保留原始方法、头部、请求体及 Content-Length，HEAD 请求保持为 HEAD
  • 修复多会话进程隔离问题，确保同一进程中不同 Pi 会话不再丢失搜索结果
  • 更新 @modelcontextprotocol/sdk 依赖版本以解决安全审计警告

Breaking Changes

  • OpenAI web_search 默认模型变更为 gpt-6-luna，如需使用旧模型需手动设置 openaiSearchModel
  • 搜索摘要和回答模式不再自行构建 OpenCode 请求头，改为传递会话 ID 由提供商处理

问题修复

  • 修复代理环境下 fetch 请求丢失自定义属性及 HEAD 请求被转为 GET 的问题
  • 修复无 API Key 模式下回答模式因缺少密钥而报错的问题
  • 修复 Parallel MCP 免费层级因 User-Agent 共享导致的速率限制错误
  • 调整 OpenCode 相关请求头发送逻辑，由 Pi 内置提供商负责添加会话头
