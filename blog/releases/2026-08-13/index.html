hugohe3/ppt-master v4.6.0 - v4.7.0 gpt-oss-120b

新内容

  • 新增可编辑的 PowerPoint 本地公式，LaTeX 直接编译为 OMML
  • 公式默认使用本地路径，去除图片渲染选项
  • 支持行内公式在段落内呈现，块级公式保持独立
  • 新增真实的 PowerPoint 超链接，支持同稿件内部跳转
  • 超链接在导入导出时保持，验证失败时安全关闭
  • 本地图表保留绘制时的布局，支持水平条形轴和环形孔径
  • 路线图改为覆盖四层结构的可视化映射，明确范围决策
  • 新增 Quick-only Generate 配置，可将页面图像重建为可编辑 PPTX 并恢复文本
  • 支持低分辨率图形在身份锁定下高分辨率重建，数据图形保持精确
  • Stage 2 设计方案升级为三个完整方案，包含项目特定的自定义模式、视觉风格和图像渲染，可内联编辑
  • 引入方向备注作为风格摘要，首选方向在比较后自动选择
  • 非破坏性位图处理，支持亮度、对比度、色调、模糊等本地派生，保留尺寸和透明度
  • 在 SVG 创作前解析派生图像，支持 A1/A2/A3 模式映射及原生组合
  • 注册主题层对，确保层级 Z 顺序确定
  • 可编辑文本的本机图片填充，支持 stretch 与 tile 模式并保持填充透明度
  • 原生动画声音混入导出带旁白的视频，音频轨道校准并保留
  • 实时幻灯片捕获用于保留旁白和动画提示，提供单源系统音频捕获
  • 按需转场声音，提供 186 条 CC0 WAV，选定 ID 同步至项目
  • 旁白等待转场完成，页面时序可配置，动画同步启动模式支持旁白同步
  • 工作流优化：Bounded inventory 视图用于 Beautify，Default Generate 采用轻量级 spec_lock 重读
  • 视觉连续性在幻灯片创作前规划，重新对齐语义视觉层次、画布装饰和图表设计，动态画布尺寸得到尊重
  • 添加繁体中文（zh‑TW）本地化 UI，提升本地用户体验

Breaking Changes

  • 移除公式策略和图片渲染选项，默认使用本地公式路径，可能需要迁移
  • SVG 预览仅限作者使用，公式不再生成图片回退

问题修复

  • 解决预览和确认服务器共享端口导致的服务被意外关闭问题
  • 改进视觉连续性规划，避免幻灯片创作后恢复的缺陷

nicobailon/pi-subagents v0.48.0 gpt-oss-120b

新内容

  • 添加持久的每运行子任务分配预算，默认上限 64，适用于静态、动态、工作流和嵌套子任务。
  • 添加可选的每会话并发上限，用于顶层异步运行，支持原子 admission、恢复转移、状态可见性等。
  • 添加实时 Prompt Audit 抽屉到 Fleet，显示当前会话前台子任务的提示文本，且在序列化状态外并在多处被遮蔽。
  • 添加全局 timeoutMs 配置项，设置单个、并行、链式启动的默认运行截止时间。
  • 将启动重试升级为在零活动 SIGKILL 子进程退出后对文件任务投递进行重试，使 EDR 拒绝的启动自我恢复。
  • 添加 PI_SUBAGENT_TASK_DELIVERY 环境变量设置，控制任务文本如何传递给子 Pi 进程（默认 auto，file 方式写入临时文件）。

问题修复

  • 修复打开 Fleet Prompt Audit 时默认显示任务并在详情面板展示摘要。
  • 修复使用完整任务文本哈希进行 LLM 意图仲裁，防止前缀相同任务共享缓存判决。
  • 修复在停止和超时时正确终止异步 Pi 写入器进程组。
  • 修复当任务被限定到其他工作树时提供项目根目录和任务目录说明。
  • 修复在显式接受拒绝已完成前台子任务时保留输出引用。
  • 修复拒绝工作树基目录位于代理扩展目录内的情况，包括符号链接别名。
  • 修复未命名 intercom 回退编排目标对齐问题，使子代理可达编排器。
  • 修复可选 LLM 意图仲裁逻辑，仅在只读判决时拯救运行。
  • 修复接受报告字符串数组中空字符串条目导致的整体拒绝。
  • 修复外部 CLI 工作流子任务忽略继承的 Pi 模型问题。
  • 修复停止读取连字符形容词导致的错误硬失败。
