新内容

  • 新增任务标签功能，支持通过 mise run —tag 运行带有特定标签的任务

  • 支持 gitlab.com CI/CD 的 npm 来源验证（含子组项目），与 GitHub Actions 验证方式一致
  • 新增命名环境集（[env_sets]），可在 miserc.toml 中定义并通过 env、MISE_ENV 或 -E 按名称选择
  • vfox 插件下载时显示已下载量、总大小和速度，而非仅显示耗时

Breaking Changes

  • temporal 注册表源变更为从 aqua:temporalio/cli 安装 CLI…
  • npm.provenance 默认为 true：来源验证失败的 npm 包或来自不同仓库的包将安装失败…
