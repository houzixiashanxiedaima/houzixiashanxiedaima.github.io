openclaw/openclaw v2026.6.33 - v2026.6.34 gpt-oss-120b

新内容

  • 更加稳健的代理和提供者运行：会话写入保留、提供者回退、流进度处理、stdio 失败恢复
  • 更强的通道恢复：恢复后继续挂起工作，确认幂等，Discord 网关突发保持受限
  • 更健壮的本地运行时状态：SQLite 检查点、工作区读取、网关进程信号、插件 HTTP 响应、依赖处理不再因瞬态主机条件失败
  • 更可靠的长时间运行代理，区分真实卡顿与活跃模型调用
  • Discord 重连不再丢失队列消息，Telegram 线程保持并授权结果正确
  • 支持扩展稳定更新渠道，可选择、更新并接收可用性通知

安全修复

  • 加强浏览器和网络边界安全，沙箱路由、受信 DNS、定制浏览器来源和回环提供者端点拒绝不安全访问路径
  • 加强运营者诊断安全，命令和状态仅限所有者操作，防止凭证泄露在账户 URL 或摘要中
  • 依赖安全更新：修复 brace-expansion、PostCSS、fast-uri、ip-address、Undici 等库的安全漏洞
  • 执行和传输安全修复：浏览器、沙箱、exec、MCP、密钥解析路径拒绝不安全输入并防止主进程崩溃
  • 网络和密钥边界更安全，限制恶意响应大小，日志不泄露 Telegram 凭证
  • 服务重启保留 SecretRef Telegram 凭证，OAuth 修复不覆盖有效配置
  • Codex 命令需人工或插件批准，执行自动审查绑定具体命令，工具白名单受工厂所有
  • 外部 MCP 循环客户端使用短期会话绑定的 attach 授权，网关消息保留可信请求者来源并拒绝不可信调用
  • Gateway HTTP 在未认证前拒绝不允许的浏览器来源，动作桥接拒绝不可信请求者
  • 在高流量下拒绝 Twilio 重放请求，Telegram 令牌在日志块中被遮蔽

Breaking Changes

  • 插件 SDK 迁移：在 2026 年 7 月 24 日后将移除 before_agent_start、根 openclaw/plugin-sdk 导入…

问题修复

  • OpenCode Go 使用文档化的 hy3 模型标识符，避免 hy3-preview 别名失败
  • Codex 本地子代理保留父 app-server 订阅并识别多代理 V2 子活动直至完成
  • 交付与通道稳定性修复：出站回执、交付证据、通道生命周期、健康监控、网关队列在重试、重启、过载时恢复
  • 网关和存储可靠性修复：插件响应、进程探针、工作区引导读取、SQLite 写入容忍瞬态失败并保持正确状态
  • 若干稳定性修复（缓存受限、文件描述符泄漏、UTF-8 关闭原因、心跳读取等）
  • 若干可靠性修复（Anthropic 部分流挂起、OpenAI Realtime 认证、远程 CDP 凭证泄露等）
