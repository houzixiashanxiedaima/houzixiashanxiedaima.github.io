**新内容**

- 按模型纯 ID 请求时会同时发送至所有提供该模型的端点，实现默认自动故障转移

- 精确模型 ID 优先匹配，只有在未找到精确匹配时才使用相似显示名作为回退
- 单一自定义端点的部署无需额外配置或迁移

- UI 界面优化，整体外观改进
- 设置对话框重新设计为侧边栏，分组为通用、压缩、高级、预览

- 代理页面为每个支持的编码代理显示图标，设置片段标注为自动或手动

- 新增自定义端点 “Fetch models”，可批量发现并注册模型，自动按合理排名
- 在仪表盘中可编辑每个模型的智能/速度排名及 RPM、RPD、TPM、TPD 限额
- 新增 /livez 与 /readyz 健康检查端点
- 新增 GET /v1/providers 接口用于元网关互操作
- 新增 GET /api/keys/providers 接口提供提供者配置清单
