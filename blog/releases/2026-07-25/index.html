jdx/mise v2026.7.13 gpt-oss-120b

新内容

  • 新增 archive backend 支持通过表映射一次发布多个可执行文件的 rename_exe
  • Homebrew cask 现在安装并追踪 bash、zsh、fish、pwsh 等 shell 补全
  • go.mod 现在可用作版本文件，支持精确 pin 或最低版本解析
  • PowerShell 任务 shell 默认使用 -NoProfile，避免路径冲突
  • 新增 mod version-file 支持

问题修复

  • env 指令 .path/.file/_.source 按书写顺序解析，解决变量引用问题
  • 安装失败不再误报 “installed but not activated”，并序列化状态避免竞争
  • 升级已锁定的 github 工具不再触发供应链回归错误
  • npm 安装失败显示完整错误链并提供 trust_policy_excludes 或 npm.shell_out 指导
  • 任务 inline 定义遵循首胜优先级，源文件刷新正确追踪子项目编辑
  • cask 升级处理结构化 preflight/postflight 步骤，清理 zap pkgutil ID 不再误判为安装记录
  • cask 升级删除受保护应用备份时恢复权限后重试，避免 Permission denied 失败
  • Windows 提供 python3 可执行文件
  • Ruby 预编译 URL 直接从 GitHub 获取，避免 403 警告；Gemfile 多位版本号解析正确
  • bootstrap 路径显示去除前导 ./，http 无效 URL 返回错误不再 panic，settings 内联表导致的 panic 已修复
  • self-update TLS 后端匹配构建特性，解决 native-tls 编译后的更新失败

TriliumNext/Trilium v0.104.1 gpt-oss-120b

新内容

  • OneNote 导入大幅升级，支持持续 Graph 限流、504 错误处理、跳过不可下载页面、设备码流、令牌刷新及多项 UI 改进…
  • 自动格式化扩展待办列表状态

  • 文本笔记中可缩进表格
  • 搜索功能增强：链接预览可搜索，元数据出现在快速搜索摘要，摘要解码 HTML 实体
  • 可折叠块改进：记住展开 / 折叠状态，搜索结果高亮时自动展开，提升对齐与外观
  • 桌面端新增禁用 GPU 加速的选项
  • 技术更新：修复 Nix flake 相关问题

问题修复

  • 修复隐藏笔记受保护时迁移失败
  • 修复桌面同步在多 Cookie 反向代理或代理自带 Cookie 时失败
  • 修复首次同步错误未显示以及同步状态工具提示常驻
  • 修复 Windows 上通过 npm 安装的 Claude Code 集成失效
  • 修复 Spellcheck 重启后自动重新激活及自定义词不可编辑
  • 修复平滑滚动关闭无效、图像查看器快捷键冲突、媒体播放器控制无法滚动等 UI 问题
  • 修复 Docker 升级至 v0.104.0 在 CentOS 7 上因 SQLITE_IOERR_SHMSIZE 失败
  • 修复新实例启动时编辑器工具栏选项被重置、单段落链接删除不完整、较大笔记内容刷新异常
  • 合并可折叠块多项修复：拖拽选择、撤销、打印 / 导出时强制展开、默认展开、状态写回错误、搜索匹配临时展开、折叠箭头指示错误
  • 媒体播放器及附件查看器修复：使用完整 UI、前后导航、快捷键冲突及提示泄漏、替换后仍显示旧内容、快捷键与浮动按钮冲突

earendil-works/pi v0.82.1 gpt-oss-120b

新内容

  • 修复不可用的作用域模型在 /models 中被隐藏的问题，支持手动删除
  • 修复启动上下文文件发现时跳过与上下文文件同名目录的 EISDIR 警告
  • 修复 llama.cpp 扩展模型目录持久化问题，确保模型在首次刷新前已列出

hugohe3/ppt-master v4.2.0 gpt-oss-120b

新内容

  • 新增原生 PowerPoint 视频导出，支持直接生成 MP4。
  • 添加与动画同步的字幕，并重新校准至导出视频。
  • 保留运动语义，导出视频时保持对象边界、顺序、效果等信息。
  • 通过并发 TTS 加速旁白生成，默认三路并发。
  • 旁白稿基于完成的 SVG 页面生成，提供更完整的演讲内容。
  • 当缺失 narration_timing.json 时，自动生成时间映射并在 stderr 标记风险幻灯片。
  • 动画编排恢复内容判断，支持自定义编排并保留完整效果词汇。
  • 动画组依据幻灯片语义重新划分，支持编辑与刷新预览。
  • 支持嵌套编辑组，仅在顶层保持语义与自动动画锚点。
  • 排版角色锚点取代 body‑ratio 包络，允许 ±2px 调整。
  • 稀疏显示尺寸受限，每页最多出现两次相同未命名尺寸。
  • 字体发现范围扩大，恢复拉丁字体族并提供对比轴种子。
  • 规划修复不再强制完整重新加载，局部修复即可生效。
  • 阶段特定推荐文件取代单一 recommendations.json，支持阶段验证。
  • UI 字体根据语言切换，提升本地化体验。

问题修复

  • 通过整体规划、排版和确认流程的改进，修复近期生成暴露的边界问题。
  • 解决缺失 timing plan 时的静默问题，现会在 stderr 标记风险幻灯片。
  • 修复页面结构到效果映射的错误，恢复正确的动画编排。
